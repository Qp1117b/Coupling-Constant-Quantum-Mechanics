## 1. 相变弧线：从旧尺度失效到新尺度形成

### 1.1 临界点与尺度结构

连续相变在临界点 $T=T_c$ 处关联长度发散：$\xi\to\infty$。系统失去全部内禀长度尺度，物理表现为幂律关联：

$$\langle\phi(r)\phi(0)\rangle \sim r^{-2\Delta}.$$

在重整化群（RG）语言中，临界点对应一个**不动点**：粗粒化变换不改变理论，尺度变换 $x\to\lambda x$ 不改变物理。这一「无标度」状态是旧尺度失效的极限表现——微观截断（晶格间距、相互作用程）被 RG 流洗掉，系统进入由不动点主导的普适区域【文献确立：Wilson–Kogut 1974】。

对局域、平移不变、旋转不变的物理系统，标度不变性通常提升为共形不变性，理论由共形场论精确描述【文献确立】。这一提升恰与 CQM 的共形固定点判据相合：**「与能量无关」＝势能中无带量纲参数（$m=0$）且耦合锁死为纯数字，等价于 $\beta(g)=0$**（`01 核心理论/CQM_核心_共形场论与OPE.md` §1.1）：

$$\beta(g) = \frac{dg}{d\ln\mu} = 0 \;\;\Longleftrightarrow\;\; \text{无质量尺子} + \text{耦合锁死为纯数字} \;\;\Longleftrightarrow\;\; \text{共形固定点}.$$

### 1.2 相变弧线的五个阶段

相变不应被理解为一个「点」，而是一条完整的弧线【CQM 构造假设（阶段划分）】：

| 阶段 | 物理内容 | 尺度关系 | CFT 地位 |
|:---:|:---|:---|:---|
| **一·旧尺度主导** | 远离临界点，关联长度有限且与微观尺度可比 | $\xi \sim a$ | CFT 无关 |
| **二·旧尺度开始失效** | $T\to T_c$，$\xi$ 增大，微观细节被 RG 洗掉 | $a \ll \xi \ll L$（临界区域） | 临界区域 |
| **三·旧尺度完全失效** | 严格临界点，无标度 | $\xi=\infty$ | **纯 CFT 精确成立** |
| **四·新尺度形成** | 稍偏离临界点，旧尺度已洗掉，新尺度 $\xi$ 接管 | $a \ll \xi \ll L$ | 有效理论 = CFT + 相关扰动 |
| **五·新尺度主导** | $\xi$ 完全建立，进入有序相或无序相 | $\xi \sim a$（新基准） | CFT 退出描述 |

第四阶段的有效理论写作：

$$S_{\text{eff}} = S_{\text{CFT}} + \lambda \int d^dx\, O(x).$$

**核心阶段是第三阶段**：旧尺度完全失效打开了共形不变性的窗口，在此窗口内共形对称性精确成立，重整化群不动点即共形固定点。相变弧线的两端（阶段一与阶段五）分别由旧尺度与新尺度主导，CFT 只描述弧线的中段。

### 1.3 局部与全局的同步实现

传统表述把相变读作时序序列：先有局部共形对称性，再「传播」到全局，最后「显现」为自守形式。这一读法在二维 CFT 中不成立。

在二维 CFT 中，Virasoro 代数的局部共形变换在环面上「积分」后，自动产生模群 $SL(2,\mathbb{Z})$ 的作用；局部共形变换的无穷小生成元经指数化，直接产生全局模变换：

$$\text{局部无穷小共形变换} \;\xrightarrow{\ \text{环面}\ }\; \text{全局模变换}.$$

这不是两个阶段，而是同一对称性在不同拓扑上的表现。自守因子 $j(\gamma,\tau)=c\tau+d$ 的**无穷小版本正是局部共形变换的生成元**，其**有限形式则是全局模变换的因子**——局部与全局经同一套自守因子同步关联，而非先后推导【CQM 构造假设（同步诠释）】。

在临界点，旧尺度失效打开了共形不变性的窗口；在此窗口内，局部共形对称性与全局模不变性同步涌现。自守形式是这一同步结构的数学结晶。

## 2. 四层同步框架：从局部种子到自守形式

同步框架的**结构分解**为：

$$\text{局部种子} \;\to\; \text{传播同步} \;\to\; \text{全局} \;\to\; \text{自守形式}.$$

四个层级不是时间上的先后序列，而是同一同步结构在不同数学层面上的同时显现。与其配套的**过程分解**（预备 → 发生 → 过程 → 完成）见 `01 核心理论/CQM_核心_共形场论与OPE.md` §8；二者的对接见 §6。

### 2.1 第一层：局部种子——自守因子的起源

**物理对象。** 在临界点，原初场 $\phi(z)$ 在局部共形变换 $z\to f(z)$ 下变换为：

$$\phi(z) \;\to\; \left(\frac{\partial f}{\partial z}\right)^{h}\phi(f(z)),$$

其中 $h$ 是原初场的共形权重，$(\partial f/\partial z)^{h}$ 是**局部自守因子**【标准数学】。

**数学结构。** 局部自守因子是无穷小共形变换的指数化结果。无穷小层面由 Virasoro 代数生成：

$$[L_m, L_n] = (m-n)L_{m+n} + \frac{c}{12}m(m^2-1)\delta_{m+n,0},$$

中心荷 $c$ 编码共形反常，权重 $h$ 决定场的标度行为【标准数学】。

**同步要点。** 局部自守因子是同步结构在无穷小层面的表现，不是「先于」全局存在的独立阶段。当 $f$ 退化为莫比乌斯变换时，局部自守因子退化为全局自守因子 $(c\tau+d)^{-2h}$——局部与全局共享同一代数结构，区别仅在变换的有限性。

### 2.2 第二层：传播同步——共形块与 KZ 方程

**物理对象。** 共形块 $\mathcal{F}(\tau)$ 是模空间上的全纯函数，描述算符在黎曼面上的传播与融合。在 WZW 模型中，共形块满足 Knizhnik–Zamolodchikov（KZ）方程【标准数学：Knizhnik–Zamolodchikov 1984】：

$$\left(\frac{\partial}{\partial z_i} - \frac{1}{k+h^\vee}\sum_{j\neq i}\frac{\Omega_{ij}}{z_i-z_j}\right)\mathcal{F} = 0,$$

其中 $k$ 是水平，$h^\vee$ 是对偶 Coxeter 数，$\Omega_{ij}$ 是 Casimir 算符。中心荷由 Sugawara 构造给出 $c=k\dim\mathfrak{g}/(k+h^\vee)$（`01 核心理论/CQM_核心_共形场论与OPE.md` §5.2）。

**数学结构。** KZ 方程的解空间构成模空间上的一个向量丛，带平坦联络。共形块作为该丛的截面，在模变换下按自守因子变换：

$$\mathcal{F}(\gamma\tau) = j(\gamma,\tau)^{k}\,\rho(\gamma)\,\mathcal{F}(\tau),$$

自守因子 $j(\gamma,\tau)^{k}=(c\tau+d)^{k}$ 显式出现。

**同步要点。** 传播同步是局部与全局之间的**桥**：共形块的定义是局部的（算符插入点的局部 OPE），但它在模空间上的变换是全局的（按自守因子变换）。局部 OPE 系数决定共形块的解析结构，环面的全局拓扑决定共形块的模变换性质——两者不是先后推导，而是同步约束。KZ 方程的解在模空间上具有平坦联络，其单值化表示正是自守因子在共形块空间上的作用：**局部 KZ 方程与全局模变换不是两个独立条件，而是同一平坦联络的两个面向**。

**与 CQM 的对接。** 共形块的 L 函数化给出 $D\psi=0 \leftrightarrow$ OPE 结合律的对应（`09 精细引力（FG）/FG_纤维丛理论.md` §9.6）；「同一平坦联络的两个面向」正是该节「Dirac 方程 = 共形自举方程」的几何表述。

### 2.3 第三层：全局——特征标与模不变性

**物理对象。** 环面上 CFT 的配分函数可分解为不可约模的特征标：

$$Z(\tau,\bar{\tau}) = \sum_{i,j} M_{ij}\,\chi_i(\tau)\,\overline{\chi_j(\tau)},\qquad \chi_i(\tau) = \mathrm{tr}_{V_i}\!\left(q^{L_0-c/24}\right),\quad q=e^{2\pi i\tau}.$$

**数学结构。** 在模群 $SL(2,\mathbb{Z})$ 作用下，特征标按有限维表示线性组合：

$$\chi_i(\gamma\tau) = \sum_j \rho_{ij}(\gamma)\,\chi_j(\tau).$$

因此特征标向量 $(\chi_1,\ldots,\chi_n)$ 构成一个**权为 0 的向量值模形式**——这是自守形式在 CFT 中最标准、最直接的出现。模不变性要求组合矩阵满足

$$\rho(\gamma)\,M\,\rho(\gamma)^{\dagger} = M.$$

【标准数学（有理 CFT / 模张量范畴）】

**例（$SU(2)_k$ WZW 模型）。** 其模矩阵 $S$ 由 Kac–Peterson 公式给出【标准数学】：

$$S_{\Lambda\Lambda'} = \text{const}\cdot\prod_{\alpha>0}\sin\!\left(\frac{\pi(\Lambda+\rho,\alpha)}{k+h^\vee}\right)\sum_{w\in W}\sigma(w)\exp\!\left[-\frac{2\pi i}{k+h^\vee}(\Lambda+\rho,\,w(\Lambda'+\rho))\right].$$

**同步要点。** 全局层面不是「最终产物」，而是局部-全局同步结构在环面上的自然显现。特征标的模性不是外加约束，而是局部共形对称性在全局拓扑上的结果。以 CQM 口径：特征标是环面上无插入点的（真空）共形块，是共形块的特例。

### 2.4 第四层：自守形式——同步结构的数学结晶

**四类体现**（取自同步结构的四个数学面貌）：

- **特征标**：权为 0 的向量值模形式；
- **配分函数**：自守形式的模不变组合；
- **共形块**：权为 $k$ 的向量值自守形式；
- **VOA 特征标**：Zhu 定理保证的模函数【文献确立：Zhu 1996】。

**上闭链条件。** 自守形式的核心是自守因子满足**上闭链条件**：

$$j(\gamma\gamma',\tau) = j(\gamma,\gamma'\tau)\cdot j(\gamma',\tau),$$

它保证局部变换的相容性（结合性）与全局变换的表示论性质（群同态）同步成立。该条件与 `01 核心理论/CQM_核心_唯物主义群论.md` §8.2 的上循环条件 $j(\gamma_1\gamma_2,x)=j(\gamma_1,\gamma_2 x)\,j(\gamma_2,x)$ 是同一条件——**同一自守因子，在两处分析给出相容性，在 CFT 处给出同步性**。

**四层同步框架的逻辑链**：

$$\underbrace{\text{局部种子}}_{\text{自守因子的无穷小生成元}}\;\to\;\underbrace{\text{传播同步}}_{\text{共形块与 KZ 方程}}\;\to\;\underbrace{\text{全局}}_{\text{特征标与模不变性}}\;\to\;\underbrace{\text{自守形式}}_{\text{数学结晶}}.$$

四个层级不是时间上的先后序列，而是同一同步结构在不同数学层面上的同时显现。**自守形式是这一同步结构的最终数学表达，但它同时反向约束局部种子**——局部 OPE 必须与全局模不变性自洽，否则理论不存在。这一「反向约束」不是自守形式的先在性，而是**同步自洽性**：自守形式是物质自组织的同步进入自洽态后的数学影像，其自洽条件（模不变性、上闭链）反过来筛除不自洽的局部行为（唯物主义读法，见 §6.3）。

| 角色 | 变换 | 含义 |

## 4. 自守形式的主动结构性效果

自守形式在 CFT 中不是被动的「结果」，而是发挥主动的、结构性的组织作用。以下五种效果，前四种【标准数学／文献确立】，其 CQM 落点【CQM 框架基础】。

### 4.1 一致性约束：筛掉不合法理论

模不变性是 CFT 的强自洽条件。特征标必须构成模形式，且组合矩阵满足 $\rho(\gamma)M\rho(\gamma)^{\dagger}=M$（§2.3）。这一条件极为严格，直接筛掉绝大多数看似合理的 CFT。有理 CFT 的分类（如 Virasoro 极小模型、WZW 模型）本质上就是模不变性的分类。幺正极小模型由中心荷

$$c = 1 - \frac{6}{m(m+1)},\qquad m = 3,4,5,\ldots$$

分类，对应一系列临界统计模型：Ising 模型（$c=1/2$）、三临界 Ising 模型（$c=7/10$）、$q$ 态 Potts 模型等【文献确立：BPZ 1984；Cardy 1986】。

**CQM 落点**：壳层选择定则由共形块 + $A_4$ 代数锁定，$A_4$ 结合律恰好锁定 $s,p,d,f$ 四模式并禁戒 $g$（`01 核心理论/CQM_核心_共形场论与OPE.md` §3.5.5）；一致性约束在 CQM 中是「共形自举 = 共形自洽」的具体化。

### 4.2 谱生成：Verlinde 公式

自守形式的模变换矩阵 $S_{ij}$ 通过 Verlinde 公式决定理论的融合规则【标准数学：Verlinde 1988】：

$$N_{ij}^{k} = \sum_m \frac{S_{im}\,S_{jm}\,S_{km}^{*}}{S_{0m}},$$

给出

$$\text{自守形式（}S\text{ 矩阵）}\;\to\;\text{融合代数}\;\to\;\text{算符谱}.$$

模变换的代数结构主动生成理论的算符内容与 OPE 系数——自守形式不是「描述」谱，而是「生成」谱。

**CQM 落点**：OPE 通道选择定则由 Verlinde 公式 + SU(2) Clebsch–Gordan + 径向 descendant 加法规则给出，大 $k$ 极限退化为经典 CG 规则（`01 核心理论/CQM_核心_共形场论与OPE.md` §10.1）。

### 4.3 对偶性编码：T 对偶与镜像对称

模不变性要求理论在 $\tau\to-1/\tau$ 下不变，物理上对应 T 对偶：大半径与小半径给出同一物理。这一对偶性在数学上正是模形式自守性质的体现。更一般地，模空间上的自守形式编码了镜像对称与几何朗兰兹对偶的物理内容【文献确立】。

**CQM 落点**：$GL(5)$ 固定层级的谱对偶——紧化投影 $\hat{\mathcal{S}}_0:\mathcal{H}_{\text{auto}}(\mathrm{GL}(5))\to\mathcal{H}_{\text{phys}}(SU(5))$ 把非紧约化群的自守形式投影到紧物理群的表示（`01 核心理论/CQM_核心_朗兰兹分层共振与相变量子.md` §3；`09 精细引力（FG）/FG_纤维丛理论.md` §9.7）。

### 4.4 临界指数的来源

特征标的 $q$-展开系数直接给出态的数密度：

$$\chi_i(\tau) = q^{-c/24+h_i}\sum_{n=0}^{\infty}d_n q^{n},$$

其中 $h_i$ 是共形维数，直接决定临界指数【标准数学】。**例**：Ising 模型序参量 $\sigma$ 的共形权重 $(1/16,1/16)$，能量算符 $\epsilon$ 的权重 $(1/2,1/2)$，由此给出临界指数 $\beta=1/8$，$\nu=1$，$\eta=1/4$。自守形式的解析结构主动决定了临界相变的普适类。

**CQM 落点**：共形维度 $h=n+l$ 决定壳层填充顺序（Madelung 规则），$A_4$ 给出 $Z_{\max}=118$（`01 核心理论/CQM_核心_共形场论与OPE.md` §9.2）——临界指数来源在 CQM 中的对应物是壳层谱。

### 4.5 单值化：物理态的选择

共形块在模变换下按自守因子变换，但物理配分函数必须是单值的。共形块的多值性由自守因子编码，物理态的选择（模不变组合 $M_{ij}$）正是**单值化条件**。自守形式在这里充当单值化函数，决定哪些共形块组合能成为物理配分函数【标准数学】。

**CQM 落点**：和乐平庸化条件 $W(\gamma)=1\Leftrightarrow\delta_v=0$ 给出该层级的稳定构型（稀有气体闭壳层）（`09 精细引力（FG）/FG_纤维丛理论.md` §9.4）；单值化在 CQM 中即和乐平庸化。

## 5. 前沿：共形 Bootstrap 与自守形式谱理论

### 5.1 一般维度下的类比

一般维度 $d$ 的共形场论与双曲 $(d+1)$ 维流形上自守形式的谱理论之间存在深刻对应【文献确立：Kravchuk–Mazáč–Pal 2021；Mazáč】：CFT 的算符谱与自守形式谱理论的拉普拉斯特征值对应：

$$\Delta_i \;\longleftrightarrow\; \lambda_i = \Delta_i(d-\Delta_i),$$

OPE 系数与自守形式的三重积积分对应：

$$c_{ijk} \;\longleftrightarrow\; \int f_i f_j f_k,$$

结构常数与 L 函数的关系为：

$$|c_{ijk}|^2 \;\sim\; L\!\left(\tfrac{1}{2},\,\pi_i\otimes\pi_j\otimes\pi_k\right).$$

这一对应使得 CFT 的共形 Bootstrap 方法可直接应用于数论问题（三重积 L 函数的新上界由此得到）。

### 5.2 模 Bootstrap 与 RCFT 分类

模 Bootstrap 方法将 RCFT 的特征标视为模线性微分方程（MLDE）的独立解。通过分析这些微分方程的模性质，可系统地分类允许的 CFT【文献确立】。该方法把自守形式的模性从「约束条件」提升为「分类工具」，进一步印证自守形式作为 CFT 组织原则的地位。

### 5.3 同步结构的跨维度推广

局部-全局同步结构能否推广到更高维度是开放问题【CQM 构造假设（研究纲领）】。在二维 CFT 中，Virasoro 代数的无穷维性使局部共形变换的指数化直接产生全局模变换（§1.3）。在高维 CFT 中，共形代数有限维，模空间几何更复杂，但共形 Bootstrap 的谱理论框架（§5.1）提示类似同步结构可能以更隐蔽的方式存在。
