# 归档 CNT — CNT 阶段历史文档

本目录保存 **闭合核理论（CNT, Closed Nuclear Theory）** 阶段（2025-2026）的全部历史研究文档。CNT 已完成其历史使命——其核心洞见（因果集序的再生产约束、引力退相干导致禁闭、Adele 统一框架）已被扬弃并纳入 **耦合常数量子力学（CQM）** 框架。

**CQM 是 CNT 的直接继承者，不是替代者。** 两者在物理本体论上一致，差异在于理论的组织形式：
- CNT 以"闭合核"为组织中心，强调质子的自维持循环
- CQM 以"耦合常数空间"为组织中心，将量子化的基本舞台从位置空间转移到耦合空间

归档文档中的术语（如"CNT"、"闭合核"、"闭合核理论"）和部分公式形式可能与 CQM 版本有差异，请以 CQM 文档为准。
