## 一、两份候选的核心内容

### 候选 A：Adele 哈密顿量路线图

**核心主张**：以三条公理（[û, p̂_u] = i、τ_p = ln(p)/C、Adele 自对偶性）为起点，沿七条分支路线走向零唯象参数。

**七条分支**（教学价值保留）：
```
核心：[u, p_u] = i + p进分解 + Adele自对偶性
    ├─→ ① p进-费曼图（Bruhat-Tits树）
    ├─→ ② 路径积分（树上所有路径求和）
    ├─→ ③ 元RG方程（一阶幺正流 + 二阶投影）
    ├─→ ④ 二阶化（实/ p进薛定谔方程）
    ├─→ ⑤ 哈密顿量（H_Adele = H_∞ ⊕ ⊕_p H_p）
    ├─→ ⑥ 相互作用力学（g_p = f_p(E_n)，三力=投影）
    └─→ ⑦ 核心恒等式（$E_1 \cdot A_{12} = W_2^2/3$，$W_2=10$）
```

**可吸收的物理图像**（与权威一致/互补）：
- 一阶=运动学，二阶=动力学 → 与元RG一致
- 三种力=引力本征值在三个 p进底上的投影 → 与记忆约定一致
- 禁闭=壳层退相干 → 与§10.2 互补

### 候选 B：δθ_W^(1) 和 (1+C_θ) 的结构推导

**核心主张**：将 δθ_W^(1) 和 (1+C_θ) 从唯象参数提升为结构推导。

**δθ_W^(1) = -W₁·α_GUT 推导**（真空极化图像）：
- W₁ = dim(5) = 5（SU(5) 基本表示维度）
- α_GUT = C·λ_c（候选自定义，与权威定义量级差 ~6 倍）
- 结果 ≈ -0.152（权威用 -0.156，偏差 2.6%）

**(1+C_θ) = 1+D/C 推导**（随机扩散图像）：
- 扩散系数 D = C²/E₁
- C_θ = D/C = C/E₁
- 符号依赖 E₁ 约定（C1 冲突）

**α⁻¹ 候选公式**（冲突 C3）：
```
α⁻¹ = (C·λ_c·sin²θ_W)/(1+C_θ) − W₁ − ρ₂ − ρ₃ = 134.6
```

## 二、两份候选的共同方法论缺陷

1. **E_n 状态误标**（D1）：两份候选均将 E_n 视为待消除的"唯象参数"，但定理 4.1 中 E_n 已从黎曼零点函数严格给出。

2. **缺失 exp(-2/C)**（D3/D8）：两份候选的 G_N 公式均丢弃了因果回路的指数压制项，导致量级偏差 ~10⁹。

3. **零唯象参数叙事的结构性问题**：两份候选均称"仅剩 1 个唯象参数（E_n）待消除"，但E_n 非唯象参数，真正的开放项是 α⁻¹ 的严格导出（定理 7.5 已给出公式，当前代码值 137.021，−107 ppm；旧值 137.036 +0.6 ppm 已更新）。

## 三、结论

**零唯象参数里程碑目前不成立。**

诚实状态：0 唯象拟合值、1 公理假设（E_n 公式）、1 实验输入（m_p）。α⁻¹ 已严格导出（当前值 137.021，−107 ppm；旧值 137.036 +0.6 ppm 已更新），与候选的 134.6 冲突需先解决。

**可保留价值**：
- 七条分支作为"研究路线可视化"（教学用途）
- 一阶=运动学 / 二阶=动力学的辩证图像（与权威一致）
- 三力=p进投影 + 禁闭=壳层退相干（与权威互补）
