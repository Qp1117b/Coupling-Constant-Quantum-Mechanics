### 三层联系

```
局部（辛空间） ←→ 全局（adele自守）
     ↕               ↕
    p进（Hecke / Vladimirov）
```

- **局部 ↔ 全局**：$\sqrt{E_n + 1/16} - 1/4 = \gamma_n$（形式需与定理4.1核对，权威为E_n = -(γ_n/2+γ_n²))
- **局部 ↔ p进**：Hecke算子与H近似对易，共同本征向量
- **p进 ↔ 全局**：Z_p零点同步要求ξ(s)=0
- **限制场 ↔ 全部**：使边界条件、自守约束、p进分辨率得以可能

## §3 限制场作为元条件：四个"不行"论证

> 来源：候选_限制场作为元条件与p进爱因斯坦常数.md（§一）

| 问题 | 答案 | 理由 |
|:---|:---|:---|
| 哈密顿本征矩阵不考虑限制场能行吗？ | **不行** | 没有限制场 → 没有Berry-Keating截断 → 没有硬壁边界 → 没有离散谱 |
| 波动方程不考虑局部限制场能行吗？ | **不行** | 没有限制场 → 没有因果分辨率 τ_res → 没有边界条件 → 准连续谱 |
| 自守共振不考虑全局限制场能行吗？ | **不行** | 没有限制场 → 没有因果闭合性 → 没有adele范数乘积公式 → 没有ξ(s)=0 |
| p进-能动张量不考虑限制场能行吗？ | **不行** | 没有限制场 → 没有p进分辨率差异 → 没有三种力 → 没有p进-爱因斯坦方程 |

### 因果图

```
限制场（引力因果限制场）
    │
    ├─→ 局部：Berry-Keating截断 L = π/2
    │       → 硬壁边界 ψ(±π/2) = 0
    │       → 离散谱
    │
    ├─→ 全局：Adele自守 Ψ(qx) = Ψ(x)
    │       → 因果闭合性 |q|_A = 1
    │       → 黎曼零点 ξ(s) = 0
    │
    └─→ p进：因果分辨率差异
            → 不同再生产频率
            → 三种力（p=2,3,5）
            → p进-爱因斯坦方程 ★候选，无对应
```

## §4 壳层三重结构与三力投影

### 4.1 壳层三重结构

> 来源：候选_CNT完整元RG框架数值验证与结构梳理.md（§一）

| 维度 | 变量 | 结构 | 谱 |
|:---|:---|:---|:---|

| p | 规范群 | 力 | 耦合 | 退相干特征 |
