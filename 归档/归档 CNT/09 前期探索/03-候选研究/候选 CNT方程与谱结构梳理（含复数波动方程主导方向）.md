## §1 核心方程体系

### 1.1 五个核心方程

#### 方程1：一阶传输方程（实数）

$$\partial_\tau \Psi + C e^u \partial_u \Psi = 0$$

- 来源：公理I（辛结构 $[\hat{u}, \hat{p}_u]=i$）
- 类型：双曲型一阶PDE
- 谱：连续（无离散谱）
- 物理角色：经典再生产动力学
- 特征线解：$u(\tau)=-\ln(-C\tau+\text{const})$

#### 方程2：一阶复数传输方程

$$(\partial_{\tau_{\text{real}}} + i\partial_{\tau_{\text{imag}}})\Psi + C e^u \partial_u \Psi = 0$$

- 来源：公理I + 复数扩展
- 类型：复数双曲型一阶PDE
- 谱：连续
- 物理角色：量子化再生产动力学（概率解释、幺正演化）
- 衍生：Madelung实部→连续性方程，虚部→Hamilton-Jacobi方程

#### 方程3：二阶静态方程

$$\left[-\frac{d^2}{du^2} + V(u)\right]\psi = E\psi$$

其中 $V(u)=\sum_{n=1}^\infty\frac{4e^{2u}/\gamma_n^2}{(1-e^{2u}/\gamma_n^2)^2}$ 来自公理III（Hadamard乘积）。

- 来源：公理II（拓扑量子化）+ 公理III（Hadamard乘积）
- 类型：椭圆型二阶ODE
- 谱：离散 $E_n \approx n^2$（硬壁盒子）
- **注意**：此V(u)形式与定理4.1的ξ自守导出机制不同，谱类型评估需审慎对待

#### 方程4：二阶复数波动方程 ★（用户指定主导研究方向）

$$(\partial_{\tau_{\text{real}}} + i\partial_{\tau_{\text{imag}}})^2\Psi + C^2 e^{2u}\partial_u^2\Psi = 0$$

- 来源：复数框架扩展
- 类型：复数双曲型二阶PDE
- 谱：离散 $E_n \propto n$（贝塞尔谱）

> **用户研究意图**（引自原始文档）："记录复数波动方程，之后用复数波动方程主导研究计算。"
>
> 后续进展（复数波动方程的修正、与定理4.1的对接尝试）应作为候选笔记持续记录。注意：导出E_n的实际机制是ξ函数自守（定理4.1），复数波动方程若要对齐，需解释其离散谱如何过渡/对应到黎曼零点谱。

#### 方程5：不确定性关系

$$\frac{\Delta r}{\langle r\rangle} \cdot \Delta v_\tau \geq \frac{C}{2}$$

- 来源：公理I（对易关系）
- 类型：不等式（运动学约束）
- 物理角色：耦合常数-流速互补性

---

### 1.2 三个衍生方程

#### 方程6：特征线方程

$$\frac{du}{d\tau} = -C e^u \quad\Rightarrow\quad u(\tau) = -\ln(-C\tau + \text{const})$$

- 来源：方程1的特征线
- 物理意义：经典RG流 $dr/d\tau = C r^2$

#### 方程7：连续性方程（Madelung实部）

$$\partial_\tau |\Psi|^2 + \partial_u(C e^u |\Psi|^2) = 0$$

- 来源：方程2的实部（设 $\Psi = \sqrt{\rho}e^{iS}$）
- 物理角色：概率守恒

#### 方程8：Hamilton-Jacobi方程（虚部）

$$\partial_{\tau_{\text{real}}} S + C e^u \partial_u S = 0$$

- 来源：方程2的虚部
- 物理角色：相位演化

---

### 1.3 两个已证明失败的候选方程

#### 方程9：修正贝塞尔方程

$$I_{i\epsilon}(w_{\max}) = 0$$

- 来源：早期WKB近似推导
- 状态：**失败**（WKB对反平方势失效，全局势假设错误）
- 注：使用Mathieu方程而非贝塞尔方程

#### 方程10：全局转移矩阵量子化

$$\det\left[T(E)\begin{pmatrix}1\\0\end{pmatrix}\right]_{(1)} = 0$$

- 来源：早期近似推导
- 状态：**失败**（近似链条无法控制，常数项"抵消"无依据）

## §2 谱诚实评估

| 方程 | 变量类型 | 谱类型 | 备注 |
|:---|:---|:---|:---|
| 传输方程（实数） | 实数 | 连续 | 无离散谱 |
| 传输方程（复数） | 复数 | 连续 | 无离散谱 |
| 二阶静态方程 | 实数 | $E_n \approx n^2$（硬壁） | V(u)形式待与权威纲领对齐 |
| 二阶波动方程 | 复数 | $E_n \propto n$（贝塞尔） | 用户指定主导方向 |
| 不确定性关系 | 不等式 | — | 运动学约束 |

> **与本框架的关系**：定理4.1实际通过ξ函数自守结构导出 $E_n = -(\gamma_n/2 + \gamma_n^2)$，而非上述PDE。上述评估反映的是"若将PDE视为独立导出机制"的谱类型分析。复数波动方程作为后续主攻方向的价值与上述PDE谱评估是两回事。

## §3 方程关系图

```
公理I: [u, p_u] = i
    ├──→ 传输方程（实数）∂_τΨ + Ce^u∂_uΨ = 0
    │       └──→ 特征线 du/dτ = -Ce^u → 连续谱
    ├──→ 复数扩展 (∂_τ_real + i∂_τ_imag)Ψ + Ce^u∂_uΨ = 0
    │       ├──→ 连续性方程（概率守恒）
    │       ├──→ Hamilton-Jacobi方程（相位演化）
    │       └──→ 连续谱
    └──→ 不确定性关系 Δr/⟨r⟩·Δv_τ ≥ C/2

公理II+III: 拓扑量子化 + Hadamard乘积
    ├──→ 二阶静态方程 [-ψ''+V(u)]ψ = Eψ → 离散谱
    └──→ 二阶波动方程 (∂_τ)²Ψ + C²e^{2u}∂_u²Ψ = 0 → 离散谱 ★主导方向

失败候选:
    ├──→ 修正贝塞尔方程 I_{iε}(w_max)=0 → 失败（WKB不适用）
    └──→ 全局转移矩阵 det[T(E)(1,0)^T]_(1)=0 → 失败（近似链断裂）
```

## §4 一阶=运动学，二阶=动力学

> 整合自：候选_Adele哈密顿量与零唯象参数路线图.md（§4.1）

| | 一阶（运动学） | 二阶（动力学） |
|:---|:---|:---|
| **方程** | 传输方程 $\partial_\tau\Psi + Ce^u\partial_u\Psi = 0$ | 薛定谔方程 $[-\partial_u^2 + V(u)]\psi = E\psi$ |
| **类型** | 双曲型（传播） | 椭圆型（振荡/束缚） |
| **物理** | 再生产结构的连续演化 | 相互作用的离散量子化 |
| **谱** | 连续 | 离散 |

**元RG = 运动学（一阶幺正流）与动力学（二阶投影）的辩证统一**——此图像与元RG章节一致。
