## 一、引言 Introduction

### 1.1 传统退相干理论的困境：宏观性特权

量子力学的测量问题自诞生以来便困扰物理学界。Zurek 等人提出的**环境诱导退相干理论**（Environment-Induced Decoherence, EID）试图通过系统与环境的纠缠来解释经典世界的涌现。然而，该理论隐含一个更隐蔽的**"宏观性特权"**（Macroscopic Privilege）问题。

**形式数学层面**，EID 没有"特权观察系"——它只是对联合幺正系统做偏迹（partial trace），哪个子系统被"追踪掉"是人为选择，不涉及客观特权。若换一个观察者不与环境耦合，他只看到系统与环境的纯纠缠态，而非约化密度矩阵——这两者在 Everett 相对态诠释下不矛盾。

**但诠释与本体论层面**，EID 在解释"经典世界为何涌现"时，偷偷塞进了三个未经辩护的预设：

**预设一：环境是"天然的指针基"（Preferred Pointer Basis）的给定者。** EID 能选出指针基（如位置而非动量），靠的是系统-环境哈密顿量 $H_{\text{int}}$ 的具体形式。但问题来了：这个环境凭什么被赋予"选择现实"的功能？它自身不应该也是一个量子系统吗？谁截断了环境？Zurek 的回答是"环境的巨大自由度"，但这只是把问题推回给宏观性本身——即"宏观=客观现实"这个未经证明的等价关系。

**预设二：环境的量子态被默认为"未观察但可经典描述"。** EID 中的环境（空气分子、光子）在计算中通常被处理为热浴、高斯态、随机噪声，从未问过：这些环境分子的"经典性"从何而来？它要么悄悄假设环境已经经典（偶极近似、经典噪声谱），要么假设环境内部已退相干（循环论证）。这就是**"把环境视为给定的经典背景"**——虽然 EID 标榜自己是"量子系统与环境纠缠"，但实际计算中环境的输入参数总是半经典的。

**预设三：观察者视角的等级差异未被解释。** 如果一个实验者直接耦合到系统（强测量），另一个实验者不耦合，只看到"系统+探测器"的纠缠态，EID 认为前者的结果是"真实的"，后者是"不完整的"。这种不对称性是 EID 给出的操作规则，而非推导结果。它默认"与环境耦合=现实化"，但没有解释为什么环境有这个特权——除了它"大"。

**因此，传统退相干理论的根本困境不在于"存在一个特权观察者"，而在于"将宏观环境的因果地位预设为不言自明的现实基础"——环境被赋予"冻结相位、选出指针基"的功能，却从不解释这些环境分子自身的量子性何以被冻结。这一困境的根源在于：传统退相干将环境的"宏观性"作为外部输入，而非需要被解释的动力学结果。**

CQM 将此"宏观性特权"替换为"质子集体因果截断的普遍自举网络"，使所有层级的确定性都是内部涌现的，而非外部输入的。

## 二、引力因果限制场与理论假设

### 2.0 引力因果限制场的本体论定义

在 CQM 中，**引力因果限制场 = 引力固有时场**。它不是四种相互作用之一，而是使物理事件得以在时空中确立的**元条件**——它划定物理事件在时空中**何时、何地、以何种节奏、何种精度**确立的边界，但不规定边界内各层级因果结构的具体组织方式。

其关键特征：

- **微观量子性** = 限制场在单个再生产循环（中子/质子）上的分辨率不足。固有时流速 $v\tau$ 无法被精确锚定，导致 $\Delta v\tau$ 内禀放大。
- **宏观确定性** = 大量再生产循环通过玻色子中介实现频率锁定与耦合常数重整化，互耦退相干使不确定性边界收缩。
- **层级时空正交**：物理时空、生物时空、社会时空各有独立限制场，彼此正交（非包含关系），仅通过奠基关系耦合。
- **黑洞** = 因果时冻结（$v\tau \to 0$）；**奇点** = 有限本体（中子/质子）再生产结构瓦解的边界。

退相干理论所讨论的"因果截断"，正是这一限制场在具体质子集体（原子、分子、探测器）上的**关系性实现**：一个质子集体的引力因果限制结构，通过其固有时流速差异，对非本体粒子的可能性空间施加筛选。因此，**因果截断不等式 $\Delta\tau \geq \tau_{\text{res}} = \hbar/(Mc^2)$ 是引力因果限制场的固有时分辨率在退相干现象中的直接表达**。

## 三、核心机制：退相干的四层结构 Core Mechanism: Four-Layer Structure of Decoherence

退相干不是单一事件，而是**连续谱**（continuous spectrum）：

```
截断（Truncation）
 ↓ 筛选
相容性（Compatibility）
 ↓ 匹配
可能性空间（Possibility Space）
 ↓ 压缩
唯一性（Uniqueness）
```

### 3.1 第一层：截断 Truncation

**定义**：观测器的必要引力因果限制结构（质量分布、固有时、能量分辨率）对量子态可能性空间进行**筛选动作**。

**关键**：截断**不等于**收敛。截断可以发生而收敛未完成。

**物理表现**：
- 有质量即筛选（$M_{\text{eff}} > 0$）
- 但筛选可能只是"粗截断"——可能性空间从 $N$ 维降到 $N'$ 维（$N' > 1$）
- 多分支仍对设备因果可达

**例**：弱测量。设备"动了手"（截断发生），但手不够细，没筛到唯一。

**核心不等式**：
$$\Delta\tau_{\text{eff}} \geq \tau_{\text{res}} = \frac{\hbar}{M_{\text{det}}c^2}$$

其中 $\tau_{\text{res}}$ 为设备能分辨的最小固有时间隔，$\Delta\tau_{\text{eff}}$ 为系统不同配置在设备因果限制结构中积累的固有时差异。

### 3.2 第二层：相容性 Compatibility

**定义**：被截断后留在可能性空间中的分支，必须与观测器的因果限制结构**可建立稳定耦合**。

**关键**：相容性**不是截断的外部前提**，而是**截断机制本身**。

**相容性层级**：
- **强相容**（Strong Compatibility）：分支的再生产时标与设备因果分辨率完全对接 → 可建立稳定耦合闭环 → 唯一性涌现
- **弱相容**（Weak Compatibility）：分支与设备可建立耦合，但耦合深度不足 → 多分支同时可达 → 弱相干/弱测量
- **不相容**（Incompatibility）：分支的再生产模式与设备固有时结构无法对接 → 因果不可达

**物理表现**：不是"先相容，后截断"，而是"截断即相容性筛选"。不满足相容性的分支在截断中已被排除。

### 3.3 第三层：可能性空间 Possibility Space

**定义**：截断+相容性筛选后，对特定观测器**因果可达**的分支集合。

**关键**：可能性空间是**关系性的**（relational），不是本体性的。

**层级**：
- **全局可能性空间**（Global）：始终幺正，所有分支继续演化，维度不变
- **观测器可达子空间**（Accessible）：被该观测器的因果限制结构"够到"的分支集合
- **经典子空间**（Classical）：退相干后，对宏观观测者表现为"经典"的子集

**物理表现**：
- 不同观测器有不同的可能性空间（因果限制结构的相对性）
- 被截断的分支**未被消灭**，只是对该观测器不可达
- 改变观测器（改变因果限制结构），可能性空间随之改变

### 3.4 第四层：唯一性 Uniqueness

**定义**：耦合深度临界时，可能性空间被压缩到**唯一分支**（或有限不可区分分支），观测器与系统建立稳定耦合闭环。

**关键**：唯一性是**耦合深度的函数**，不是截断的必然结果。

**条件**：
$$U = f(M_{\text{eff}}, \Delta L, \delta E, \delta t) \geq U_{\text{critical}}$$

- $U < U_{\text{critical}}$：截断发生，但收敛未完成 → 多分支因果可达 → 弱相干
- $U \geq U_{\text{critical}}$：截断+深度临界 → 可能性空间压缩到 1 → 唯一性涌现

**物理表现**：
- 强测量：$U \gg U_{\text{critical}}$ → 确定值
- 弱测量：$U < U_{\text{critical}}$ → 弱值（多分支干涉残留）
- 部分退相干：某些自由度被截断，其他自由度仍相干

### 3.5 退相干的完整定义 Complete Definition

> **退相干 = 截断 + 相容性筛选 + 可能性空间压缩 + （可能的）唯一性涌现。**

**连续谱表**：

| 阶段 | 截断 | 相容性 | 可能性空间 | 唯一性 |
|------|------|--------|-----------|--------|
| **零耦合（完全不确定）** | 无 | — | 全局幺正（无限维） | 无 |
| **弱耦合** | 浅截断 | 弱相容 | 多分支可达 | 无 |
| **部分耦合** | 部分截断 | 部分相容 | 混合态 | 部分 |
| **退相干深耦合** | 深截断 | 强相容 | 经典子空间 | 表观 |
| **临界耦合** | 完全截断 | 强相容 | 唯一分支 | 是 |

> **注释**：上表中的"经典子空间""混合态"等标签均为相对于特定观测器（其 $M_{\text{eff}}$、$\tau_{\text{res}}$、$U$ 已知）的操作性描述。不存在"自身就经典"或"自身就量子"的对象。如果将同一个系统的密度矩阵投影到不同观测器的因果可达子空间，可能同时得到经典子空间（对探测器 A）和相干叠加态（对探测器 B）。两种描述都"真实"，但都是关系性的真实。

> **关于"零耦合（完全不确定）"**："完全不确定"不是指粒子"本质不确定"，而是指不存在任何与其耦合的质子因果限制结构。一旦引入任意非零耦合（哪怕极弱），截断即发生，谱系立即离开此端点进入"弱确定"区间。自由光子在真空中传播是此端点的唯一严格物理实例（$m=0$ 使其与任何质子的固有时差异 $\Delta\tau$ 恒为零）。

## 四、互耦退相干 Bootstrap Decoherence

**互耦退相干**是质子集体之间互相截断形成的**内部循环确定性网络**（internal cyclic determinacy network），无外部经典基础。确定性不是从外部"注入"的，而是内部循环耦合的涌现（emergence）。

```
分子 A 截断分子 B → 分子 B 截断分子 C → 分子 C 截断分子 A
 ↓
 循环闭合，确定性涌现
```

每个分子既是"原因"（截断者），又是"结果"（被截断者）。**没有外部设计者**。

### 4.2 宏观环境互耦退相干 Macro-Environmental Bootstrap Decoherence

**主体**：大量环境分子集体（$N \sim 10^{23}$，空气、尘埃、背景辐射中的原子）。

**机制**：单个环境分子质量小（$\sim 10^{-26}$ kg），因果分辨率 $\tau_{\text{res}}^{(k)} = \hbar/(m_k c^2) \sim 10^{-11}$ s，对系统的经典波函数截断**很弱**。大量分子的集体效应使系统对宏观探测器的经典波函数可能性空间压缩到经典子空间。

**推导链条**：

1. **质量密度差异**（本体不变量）：
 $$\delta\rho(\mathbf{r}) = \rho_1(\mathbf{r}) - \rho_2(\mathbf{r})$$

2. **引力势差异**（泊松方程）：
 $$\nabla^2\delta\Phi(\mathbf{r}) = 4\pi G\delta\rho(\mathbf{r})$$
 $$\delta\Phi(\mathbf{r}) = -G\int_{V_{\text{sys}}}\frac{\delta\rho(\mathbf{r}')}{|\mathbf{r}-\mathbf{r}'|}\,d^3r'$$

3. **环境探针积累**（经典探针，无再生产机制）：
 环境分子在两种引力场配置中积累不同固有时：
 $$\Delta\tau(\mathbf{r},t) = \frac{|\delta\Phi(\mathbf{r})|}{c^2}\,t$$

4. **测量设备截断**（质子集体，因果分辨率 $\tau_{\text{res}}$）：
 当环境探针的固有时差异达到 $\tau_{\text{res}}$，该探针对两配置的因果可达性被截断：
 $$\frac{|\delta\Phi|}{c^2}\,t \geq \frac{\hbar}{M_{\text{det}}c^2}$$

5. **单探针退相干时间**：
 $$t_D(\mathbf{r}) = \frac{\hbar}{M_{\text{det}}|\delta\Phi(\mathbf{r})|}$$

6. **集体退相干率**（连续环境密度 $\rho_{\text{env}}$）：
 $$\Gamma = \frac{M_{\text{det}}}{\hbar M_{\text{env}}}\int_{V_{\text{env}}}\rho_{\text{env}}(\mathbf{r})\,|\delta\Phi(\mathbf{r})|\,d^3r$$
 紧凑形式：
 $$\Gamma = \frac{M_{\text{det}}}{\hbar}\,\langle|\delta\Phi|\rangle_{\text{env}}$$

7. **自引力极限**（$M_{\text{env}} \sim \delta M \sim M_{\text{det}}$）：
 $$\Gamma \approx \frac{\Delta E_G}{\hbar}, \quad \Delta E_G \sim \frac{G(\delta M)^2}{R}$$

**结果**：强确定（Strong Determinacy），唯一性涌现。

**与 Penrose-Diósi 的对应**：
- **形式一致**：$\Gamma \approx \Delta E_G/\hbar$
- **本体论根本不同**：
 - Penrose：引力导致**客观态缩减**（本体性坍缩，全局幺正破坏）
 - CQM：引力差异导致**关系性因果截断**（全局幺正保住，被截断分支继续演化）

**与电子-电子散射的区分**：电子-电子散射无质子参与，无截断，全局幺正。环境退相干有质子环境分子参与，有截断。

**由此可得出一个重要推论：CQM 不依赖"宏观-微观界限"来定义退相干。** 退相干率 $\Gamma$ 唯一取决于质量密度差异 $\delta\rho(\mathbf{r})$ 和探测器的有效质量 $M_{\text{eff}}$。一个 $M_{\text{eff}}$ 足够小的探测器（比如一个轻原子）面对一个 $10^6$ 原子的大分子，后者可能仍处于弱确定端——尽管它的尺度"宏观"。反之，一个重探测器面对一个单原子，后者可能已经处于强确定端。决定退相干的是耦合双方的质量-因果限制结构关系，而不是任何一方的绝对尺度。

### 4.3 微观环境互耦退相干 Micro-Environmental Bootstrap Decoherence

**前置声明**：本节讨论的"微观环境"（单个分子）对应的状态是**弱确定**（浅截断），不是**完全不确定**。须严格区分二者：
- **完全不确定（零截断）**：$U = 0$，仅存在于无任何质子耦合的理想情形（如自由光子）。
- **弱确定（浅截断）**：$0 < U \ll U_{\text{crit}}$，截断已发生但收敛未完成（如单个环境分子对系统波函数的弱作用）。

传统量子力学常将"弱确定"误称为"不确定"，这是概念混淆。CQM 明确将二者置于谱系的不同位置。

**本节标题中的"微观"仅指环境分子质量相对于宏观探测器较小这一操作事实，而非指涉任何本体论意义上的"量子性"。**"微观"不是不确定性的来源。一个原子相对于另一个原子处于弱确定端（$U \ll U_{\text{crit}}$），但相对于一个 CCD 靶面处于强确定端（$U \gg U_{\text{crit}}$）。同样的对象，不同的探测者，不同的谱系位置。因此，本节所谓的"弱确定"不是微观对象的固有属性，而是该环境分子与系统之间耦合深度的关系性描述。

**主体**：单个环境分子（$N_2, O_2$，质量 $\sim 10^{-26}$ kg）。

**机制**：单个分子质量小，$\tau_{\text{res}} \sim 10^{-11}$ s（因果分辨率粗），耦合深度 $U < U_{\text{critical}}$。

**结果**：截断发生，但收敛未完成。可能性空间从 $N$ 降到 $N'$（$N' > 1$），多分支仍对设备因果可达。**弱确定**（Weak Determinacy）——部分确定，部分相干残留。

**物理表现**：弱测量、部分退相干、量子芝诺效应。

**与宏观的对比**：
- 微观：弱确定（弱测量、部分退相干、量子芝诺效应）
- 宏观：强确定（完全退相干、经典确定性）

**"弱确定"比"不唯一"更准确**，因为它强调：(1) 截断确实发生了（有确定性成分）；(2) 但收敛未完成（确定性是弱的）；(3) 多分支同时可达（弱相干残留）。

---

> **专栏：空气分子的确定度**
>
> · **空气分子之间**（内部自举）：$m \sim 5\times10^{-26}\,\text{kg}$，$\tau_{\text{res}} \sim 10^{-11}\,\text{s}$，碰撞间隔 $\tau_{\text{coll}} \sim 10^{-10}\,\text{s}$。$\tau_{\text{coll}} \approx 10 \times \tau_{\text{res}}$，每次碰撞仅积累约 $1/10$ 截断阈值，$U \sim 0.1\,U_{\text{crit}}$，**确定度 $D \sim 10\%$** —— 弱确定（浅截断）。
>
> · **空气集体**（$10^{23}$ 个分子）对外界系统：有效质量 $M_{\text{env}} \sim 10^{-3}\,\text{kg}$，$\tau_{\text{res}} \sim 10^{-48}\,\text{s}$，截断瞬间完成，$U \gg U_{\text{crit}}$，**确定度 $D \to 100\%$** —— 强确定（深截断）。
>
> · **空气分子相对于宏观探测器/人**：探测器质量 $M \sim 1\,\text{kg}$，$\tau_{\text{res}} \sim 10^{-53}\,\text{s}$，任何空气分子的位置/动量被瞬间截断至经典轨迹，**确定度 $D \to 100\%$**。
>
> **结论**：同一个空气分子，确定度是一个三元关系 $D = f(\text{对象},\text{探测者},\text{环境背景})$。空气分子之间仅 $10\%$ 确定，但对探测器和你则是 $100\%$ 确定。这不矛盾——**确定性从来不是固有属性**。

### 4.4 第三类互耦退相干 Type-III Bootstrap Decoherence

**主体**：特殊物理条件下的质子集体（如超导、玻色-爱因斯坦凝聚、拓扑绝缘体等）。

**机制**：质子在特殊能态或拓扑约束下形成非平庸的自举网络，截断特性偏离常规。

**特点**：可能呈现**保护性相干**（coherence protection）或**反常截断**（anomalous truncation），需具体物理条件分析。

**例**：超导中的库珀对——质子集体在低温下形成特殊耦合模式，可能抑制或改变常规截断行为。

## 五、自耦退相干 Self-Coupled Decoherence

### 5.1 定义与总论 Definition and Overview

**自耦退相干**是闭合核系统因自身因果循环闭合失败而自我截断到可维持子空间的机制，属于**引力因果场退相干理论**在单一系统自指涉因果闭合上的实现。其截断同样来自引力因果限制场——区别仅在于因果域的来源为 $\mathcal{C}_{\text{self}}$（系统自身）而非 $\mathcal{C}_{\text{collective}}$（多体网络，自举）或 $\mathcal{C}_{\text{joint}}$（系统+设备，观测）。$\hat{\mu}$（再生产算符）是上游算符，下游退相干通道中表现为 $\hat{\mu}_{\downarrow\text{dc}} = \hat{\mathcal{P}}_{\mathcal{C}_{\text{self}}}^{(\mu)}$（被再生产筛选后的自耦退相干投影）。

**三类退相干的核心区分**：

| | 互耦退相干 | 自耦退相干 | 观测退相干 |
|---|---|---|---|
| **因果域** | $\mathcal{C}_{\text{collective}}$（多体质子网络） | $\mathcal{C}_{\text{self}}$（系统自身） | $\mathcal{C}_{\text{joint}}$（系统+设备） |
| **截断来源** | 其他质子的引力因果结构 | 自身引力因果结构的有限分辨率 | 设备引力因果结构的介入 |
| **典型现象** | 环境退相干、宏观确定性 | 夸克禁闭、质子稳定性、W/Z衰变 | 量子测量、延迟选择 |
| **算符表达** | 集体因果网络投影 | $\hat{\mu}_{\downarrow\text{dc}} = \hat{\mathcal{P}}_{\mathcal{C}_{\text{self}}}^{(\mu)}$ | 联合因果域投影 |

三者共享同一因果截断不等式 $\Delta\tau_{\text{eff}} \geq \tau_{\text{res}} = \hbar/(M c^2)$，仅在 $M$ 和 $\Delta\tau_{\text{eff}}$ 的具体赋值上不同。

### 5.2 核心命题：再生产幂等性筛选下的因果投影

$$\boxed{\hat{\mu}_{\downarrow\text{dc}} = \hat{\mathcal{P}}_{\mathcal{C}_{\text{self}}}^{(\mu)}, \quad \hat{\mu}_{\downarrow\text{dc}}^2 = \hat{\mu}_{\downarrow\text{dc}}}$$

> **上游注**：$\hat{\mu}$ 是上游算符（upstream operator），下游退相干通道中表现为 $\hat{\mu}_{\downarrow\text{dc}} = \hat{\mathcal{P}}_{\mathcal{C}_{\text{self}}}^{(\mu)}$（被再生产筛选后的自耦退相干投影）。中性的 $\hat{\mathcal{P}}_{\mathcal{C}_{\text{self}}}$ 本身不是 $\hat{\mu}$ 的表现——它是因果自洽子空间的正交投影，不承诺存在论方向（黑洞蒸发亦属此类）。$\mu^2=\mu$ 的幂等性将其筛选为 $\hat{\mu}_{\downarrow\text{dc}}$，本征值 1 = 存在维持。

其中：
- $\hat{\mu}_{\downarrow\text{dc}}$：下游退相干算符，$\hat{\mu}_{\downarrow\text{dc}}^2 = \hat{\mu}_{\downarrow\text{dc}}$，本征值 1 = 存在维持，0 = 存在终止
- $\hat{\mathcal{P}}_{\mathcal{C}_{\text{self}}}^{(\mu)}$：被再生产幂等性筛选后的因果自洽子空间投影——系统自身因果结构 $\mathcal{C}_{\text{self}}$ 所张成的子空间的正交投影，经 $\mu^2=\mu$ 赋值后转为存在维持

**"自耦"的语义**：退相干不是系统与外部环境的耦合，而是**系统内部因果循环网络与自身的耦合**——因果分辨率不足以分辨所有自由度时，系统自我截断到可维持闭环的子空间。

### 5.3 投影算符的数学性质

下游退相干算符 $\hat{\mu}_{\downarrow\text{dc}} = \hat{\mathcal{P}}_{\mathcal{C}_{\text{self}}}^{(\mu)}$ 作为因果自洽子空间上被再生产筛选后的正交投影算符，满足：

1. **幂等性**：$\hat{\mu}_{\downarrow\text{dc}}^2 = \hat{\mu}_{\downarrow\text{dc}}$ —— 再生产不生长，只维持
2. **自伴性**：$\hat{\mu}_{\downarrow\text{dc}}^\dagger = \hat{\mu}_{\downarrow\text{dc}}$ —— 因果结构是实的（Hermite投影）
3. **与哈密顿量对易**：$[\hat{H}, \hat{\mu}_{\downarrow\text{dc}}] = 0$ —— 只有因果自洽的态才有确定的能量

**推论**：
- $\hat{\mu}_{\downarrow\text{dc}}|\psi\rangle = |\psi\rangle$：因果闭环成功 → 存在维持 → 退相干不发生
- $\hat{\mu}_{\downarrow\text{dc}}|\psi\rangle = 0$：因果闭环失败 → 存在终止 → 退相干自耦发生

**关键物理意义**：能量本征态必须满足再生产条件。这不是外加约束，而是因果结构自我闭合的数学推论——$[\hat{H}_\infty, \hat{\mu}_{\downarrow\text{dc}}] = 0$ 意味着 $\hat{H}_\infty$ 的能谱只出现在 $\mathcal{C}_{\text{self}}$ 内。因此 $\hat{H}_\infty = \hat{D}^2 + 1/4$（双曲Laplacian）的物理语义——为什么只有因果自洽的态有能量——从投影公设自动涌出。

### 5.4 p进分解与规范力禁闭

因果自洽子空间可按 p 进扇区分解：
$$\hat{\mu} = \bigoplus_{p \in \{2,3,5\}} \hat{\mu}_p \otimes \hat{\mu}_{\text{real}}$$

各 p 进扇区的截断特性：

| p | 规范力 | $\hat{\mu}_p$ 行为 | 物理现象 |
|---|--------|-------------------|----------|
| 2 | SU(3) 强力 | $\hat{\mu}_2 = 1$ 在禁闭尺度 $\lambda_{\text{QCD}} \approx 1$ fm 强制完全截断 | 夸克禁闭 = 壳层退相干 |
| 3 | SU(2) 弱力 | $\hat{\mu}_3$ 部分截断，有限寿命 | W/Z 衰变 |
| 5 | U(1) 电磁力 | $\hat{\mu}_5 \approx 1$ 在长程尺度（最弱截断） | 光子长程传播 |

**禁闭=壳层退相干**：$\hat{\mu}_2 = 1$ 意味着在 SU(3) 色因果域中，因果分辨率不足以分辨色自由度 → 色荷被投影到一维子空间 → 夸克禁闭。这不是力，而是**引力因果限制场在 p=2 扇区的因果结构边界条件**。投影算符本身给出禁闭条件——无需先构造 p 进能动张量。

### 5.5 闭合的理论缺口（B2 + E2）

自耦退相干命题**一次性闭合** CQM 框架中的两个核心缺口：

| 缺口 | 原问题 | 自耦命题的解决 |
|:---|:---|:---|
| **B2（再生产算符化）** | $\mu \circ \mu = \mu$ 如何转化为希尔伯特空间算符？ | 因果截断的数学形式就是被再生产筛选后的投影——$\hat{\mu}_{\downarrow\text{dc}} = \hat{\mathcal{P}}_{\mathcal{C}_{\text{self}}}^{(\mu)}$ 天然满足 $\hat{\mu}_{\downarrow\text{dc}}^2 = \hat{\mu}_{\downarrow\text{dc}}$ |
| **E2（禁闭=壳层退相干）** | 禁闭退相干但 p进能动张量未构造 | $\hat{\mu}_2 = 1$ 在禁闭尺度上强制因果完全截断——投影算符直接给出禁闭条件 |

### 5.6 与自举、观测的关系

自耦退相干与互耦退相干、观测退相干的精确动力学关系**暂时悬置**。当前可确定的是：

- 三者共享同一引力因果限制场的数学结构（因果截断不等式、投影算符框架、四层截断谱系）
- 自耦是最基础的层次——它决定单个闭合核能否维持存在（$\hat{\mu}_{\downarrow\text{dc}}|\psi\rangle \neq 0$）
- 自举建立在多个自耦系统的基础上（多体因果网络——多个 $\mathcal{C}_{\text{self}}$ 的交互）
- 观测在自举网络的背景上介入（外部因果域 $\mathcal{C}_{\text{det}}$ 的扩展）

$\mathcal{C}_{\text{self}} \subset \mathcal{C}_{\text{collective}} \subset \mathcal{C}_{\text{joint}}$ 的因果域包含关系、以及三类退相干的动力学耦合机制，属于远期研究方向。

## 六、观测退相干 Observational Decoherence

### 6.1 定义与总论 Definition and Overview

**观测退相干**是测量设备（由质子组成的事物）对非本体粒子经典波函数的**直接二元截断**（direct binary truncation）。与前两类退相干的根本区别在于：**观测退相干涉及外部实验者的介入**，是可控的、定向的。

**关键区分**：
- 互耦退相干：无外部设计者，内部循环耦合
- 自耦退相干：系统自身因果闭环失败，自我截断
- 观测退相干：有外部实验者介入，可控、定向

### 6.2 延迟选择/擦除实验的完整推导 Complete Derivation of Delayed-Choice/Erasure Experiments

**实验设置**：马赫-曾德尔干涉仪（Mach-Zehnder Interferometer），两臂几何长度严格相等，分束器 BS1、BS2 对称，反射镜对称，介质相同（空气或真空）。**唯一不对称来源**：偏振器（标记器）仅在臂 1 中。

**推导链条**：

1. **偏振器的作用**（纯电磁调制器）：
 偏振器通过折射率 $n > 1$ 引入等效光程差：
 $$\Delta L_{\text{eff}} = (n-1)d$$
 其中 $d$ 为偏振器厚度。

2. **坐标时差异**：
 光通过臂 1（有偏振器）所需坐标时：
 $$t_1 = \frac{L - d}{c} + \frac{nd}{c} = \frac{L}{c} + \frac{(n-1)d}{c}$$
 光通过臂 2（无偏振器）所需坐标时：
 $$t_2 = \frac{L}{c}$$
 **坐标时差异**：
 $$\Delta t = t_1 - t_2 = \frac{(n-1)d}{c} = \frac{\Delta L_{\text{eff}}}{c}$$

3. **测量设备引力场转化**（核心物理）：
 测量设备（探测器 D，质量 $M$）的引力场在偏振片位置 $\mathbf{r}_{\text{pol}}$ 决定局部固有时流速：
 $$\frac{d\tau}{dt}\bigg|_{\mathbf{r}_{\text{pol}}} = \sqrt{-g_{00}(\mathbf{r}_{\text{pol}})} \approx 1 + \frac{\Phi_{\text{det}}(\mathbf{r}_{\text{pol}})}{c^2}$$
 其中 $\Phi_{\text{det}}(\mathbf{r}_{\text{pol}}) = -G\int_{V_{\text{det}}}\frac{\rho_{\text{det}}(\mathbf{r}')}{|\mathbf{r}_{\text{pol}}-\mathbf{r}'|}d^3r'$ 为设备在偏振片位置的引力势。

 固有时差异：
 $$\Delta\tau = \frac{d\tau}{dt}\bigg|_{\mathbf{r}_{\text{pol}}} \cdot \frac{\Delta L_{\text{eff}}}{c}$$

4. **弱场极限**（实验室中设备引力修正可忽略）：
 测量设备质量 $M \sim 10^{-3}$ kg 到 1 kg，偏振器距离设备 $r \sim 0.1$ m 到 1 m，设备引力势在偏振片位置：
 $$\Phi_{\text{det}}(\mathbf{r}_{\text{pol}}) \sim -\frac{GM}{r} \sim 10^{-10} \text{ 到 } 10^{-7} \text{ m}^2/\text{s}^2$$
 修正项：
 $$\frac{\Phi_{\text{det}}}{c^2} \sim 10^{-27} \text{ 到 } 10^{-24} \ll 1$$

 因此固有时流速**退化为 1**：
 $$\frac{d\tau}{dt}\bigg|_{\mathbf{r}_{\text{pol}}} \approx 1$$
 固有时差异简化为：
 $$\Delta\tau \approx \frac{\Delta L_{\text{eff}}}{c}$$

 **注意**：退化为 1 的是**测量设备在偏振片位置的引力修正**，不是偏振器本身。偏振器质量小，其引力场可忽略。

5. **设备截断**：
 $$\frac{\Delta L_{\text{eff}}}{c} \geq \frac{\hbar}{Mc^2}$$

6. **二元判据**（宏观设备极限）：
 对实际光学实验：偏振器厚度 $d \sim 10^{-3}$ m，折射率差异 $n-1 \sim 0.5$，等效光程差 $\Delta L_{\text{eff}} \sim 5 \times 10^{-4}$ m，固有时差异 $\Delta\tau \sim 1.7 \times 10^{-12}$ s。

 对实际探测器（光屏/CCD 质量 $M \sim 10^{-3}$ kg）：因果分辨率 $\tau_{\text{res}} = \hbar/(Mc^2) \sim 1.2 \times 10^{-48}$ s。

 **比较**：$\Delta\tau \sim 10^{-12}$ s $\gg \tau_{\text{res}} \sim 10^{-48}$ s，截断条件**必然满足**。

 - **无偏振器**（$\Delta L_{\text{eff}} = 0$）：$\Delta\tau = 0 < \tau_{\text{res}}$ → 不截断 → **波动性**
 - **有偏振器**（$\Delta L_{\text{eff}} \neq 0$）：$\Delta\tau \gg \tau_{\text{res}}$ → 截断 → **粒子性**

7. **擦除机制**（Erasure Mechanism）：
 擦除器（如与标记器正交的偏振片）在臂 1 中引入**反向**等效光程差：
 $$\Delta L_{\text{eraser}} = -\Delta L_{\text{marker}}$$
 总等效光程差：
 $$\Delta L_{\text{total}} = \Delta L_{\text{marker}} + \Delta L_{\text{eraser}} = 0$$
 坐标时差异归零：
 $$\Delta t = 0$$
 固有时差异归零：
 $$\Delta\tau = \frac{d\tau}{dt}\bigg|_{\mathbf{r}_{\text{pol}}} \cdot 0 = 0$$
 截断条件不再满足：
 $$0 < \tau_{\text{res}}$$
 设备重新同时与两臂建立稳定耦合 → **波动性恢复**。

 **不是"信息被销毁"**，而是**"因果时差被补偿，设备无法区分两臂"**。

8. **因果倒置的澄清**（Resolution of Causal Paradox）：
 **坐标时描述**（Coordinate Time Description）：
 - 光通过分束器 BS1（$t=0$）
