# 01 系统架构设计

> Godot 4.6 三维分子构建交互系统架构

---

## 场景树

```
Main (Node3D)
├── CameraRig (Node3D)          ← 轨道相机
├── MoleculeWorkspace (Node3D)  ← 分子构建空间
│   ├── Atoms (Node3D)          ← 原子容器
│   ├── Bonds (Node3D)          ← 化学键容器
│   └── LatticePreview (Node3D) ← 晶格预览
├── UI (CanvasLayer)
│   ├── ElementPalette          ← 元素周期表
│   ├── IsotopeSelector         ← 同位素选择器
│   ├── CalculationPanel        ← 计算控制
│   ├── ResultPanel             ← 结果展示
│   └── Toolbar
└── System (Node)
    ├── CQMCalculator           ← CQM 计算引擎
    ├── ElementDatabase         ← 元素数据库
    ├── UndoRedoManager         ← 撤销/重做
    └── ProjectManager          ← 项目保存/加载
```

## 分层架构

| 层 | 组件 |
|:---|:---|
| UI 层 | 元素周期表、模式引擎面板、画笔材料面板 |
| 交互层 | 3D 拾取、拖拽放置、右键结合连接、框选、相机 |
| 3D 场景层 | 上屏: 原子/键/分子组；下屏: 画笔/TubeMesh/密度场 |
| 计算引擎层 | 嘉当矩阵、主丛曲率判定、Tc估算、模式匹配、Regge |
| 数据层 | 元素DB、同位素、CQM常数、预设分子、模式库、超导DB |

## 交互流程

元素周期表取原子 → 3D空间放置 → 右键结合连接 → 自动推导化学式 → 自动匹配超导家族模式 → 选择同位素 → 点击计算 → CQM超导判定
