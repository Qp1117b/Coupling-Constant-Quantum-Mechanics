## 1. 总体架构

### 1.1 五层双轨架构

超导材料设计从原子到宏观实体分为五层，支持模式设计（经验规则）与自由设计（物理约束）双轨工作流：

```
┌─────────────────────────────────────────────────────────┐
│ L0 化学式 (全局锚点) │
│ 由工作区原子自动推导，驱动模式筛选 │
├─────────────────────────────────────────────────────────┤
│ 上屏 (分子/原子设计) │ 下屏 (画笔=L4晶胞分布) │
│ L1 结合方式 (骨架拓扑) │ L3 晶胞 (周期性堆积) │
│ L2 相对位置 (几何参数) │ L4 晶胞分布(晶粒) │
│ 模式库: 保守子结构/可变模块 │ 单晶/多晶/薄膜/粉末 │
│ 键长/键角/构象 │ 画笔绘制→Regge单元 │
│ 右键结合连接→自动匹配模式 │ →嘉当矩阵→FG退相干场 │
├─────────────────────────────────────────────────────────┤
│ 模式引擎 (PatternEngine) │
│ 双轨: 模式设计(经验规则挂载) / 自由设计(物理硬约束) │
│ 4家族: 铜氧化物/铁基/氢化物/BCS │
└─────────────────────────────────────────────────────────┘
```

## 3. 交互系统设计

### 3.1 积木拼接交互流程

```
用户操作 系统响应
──────── ────────
1. 从元素周期表选择元素 → 高亮该元素，进入"放置模式"
2. 在 3D 空间点击 → 在该位置创建原子节点
3. 拖拽原子 → 实时更新位置，更新键几何
4. 选择"键连接"模式 → 进入键连接模式
5. 点击原子 A → 标记为键起始
6. 点击原子 B → 创建 A-B 键
7. 选择同位素 → 更新中子数，重建嘉当矩阵
8. 点击"计算" → 触发 CQM 超导判定
```

 float value = 0.0;
 // ... 矩阵元素获取逻辑

 // 热力图颜色映射
 float normalized = value / max_abs_value;
 vec3 color;
 if (normalized > 0.0) {
 color = mix(vec3(1.0), vec3(1.0, 0.0, 0.0), normalized);
