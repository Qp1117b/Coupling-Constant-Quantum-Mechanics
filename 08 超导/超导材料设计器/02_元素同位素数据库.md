# 02 元素及同位素数据库集成与管理机制

> 118 化学元素 + 同位素数据库的格式定义、加载机制、管理策略与 UI 呈现

## 1. 数据范围与覆盖

### 1.1 元素覆盖

| 范围 | 原子序数 | 元素数 | 说明 |
|:---|:---:|:---:|:---|
| 周期 1-7 主族 + 过渡族 | 1-118 | 118 | 全部已知元素，含超重元素 |
| 稳定元素 | — | ~251 种稳定核素 | 同位素标记为稳定 |
| 不稳定元素 | — | ~3300 种已知核素 | 标记半衰期与衰变模式 |

### 1.2 同位素覆盖策略

```
元素 (Z=1, H)
├── ¹H  (N=0, 稳定, 丰度 99.985%)
├── ²H  (N=1, 稳定, 丰度 0.015%, 氘)
└── ³H  (N=2, β⁻, t½=12.33yr, 氚)

元素 (Z=8, O)
├── ¹⁶O (N=8, 稳定, 丰度 99.76%)
├── ¹⁷O (N=9, 稳定, 丰度 0.04%)
├── ¹⁸O (N=10, 稳定, 丰度 0.20%)
└── ¹⁹O (N=11, β⁻, t½=26.46s)
```

**设计原则**：
- 每个元素至少包含所有已知同位素
- 稳定同位素优先展示，放射性同位素折叠
- 超重元素（Z>92）的同位素数据可能不全，标注"数据不足"

### 1.3 CQM 理论所需数据

对每个同位素，CQM 理论需要以下参数：

| 参数 | 符号 | 来源 | 用途 |
|:---|:---:|:---|:---|
| 原子序数 | Z | 实验测量 | 质子扇区大小（Z 个 A₄ 块） |
| 中子数 | N | A − Z | 中子扇区大小（N 个缺陷 A₄ 块） |
| 中子缺陷参数 | ε(N) | CQM 公式计算 | 中子扇区缺陷强度 |
| 原子质量 | m | 实验测量 | 约化质量计算 |
| 价电子数 | v | 化学常识 | 电子扇区建模 |
| 电负性 | χ | 实验测量 | 键极性估算 |
| 原子半径 | r | 实验测量 | 3D 渲染 + 键长估算 |

### 2.3 CQM 中子缺陷参数计算

$$\delta(N) = \delta_0 \cdot \left(1 - \beta \cdot \frac{N - N_{\text{ref}}}{N_{\text{ref}}}\right)$$

```gdscript
# element_database.gd
static func compute_neutron_defect(Z: int, N: int, element_data: Dictionary) -> float:
    var delta_0 = element_data.cqm_parameters.defect_base_delta
    var beta = element_data.cqm_parameters.defect_beta_coefficient
    var N_ref = element_data.cqm_parameters.reference_neutron_count
    if N_ref == 0:
        return 0.0
    return delta_0 * (1.0 - beta * float(N - N_ref) / float(N_ref))
```

## 3. 数据加载机制

### 3.1 分级加载策略

```
启动时
├── 加载 _index.json（轻量索引，~30 KB）         ← 立即
├── 加载前 36 元素 JSON（常用元素，~200 KB）      ← 启动时
└── 其余元素                                      ← 按需延迟加载

运行时
└── 用户选择元素 E
    └── 若 E 未加载 → 从磁盘加载 E.json → 缓存
```

### 3.2 元素数据库管理器

```gdscript
# element_database.gd
class_name ElementDatabase
extends Node

const INDEX_PATH = "res://data/elements/_index.json"
const ELEMENT_PATH = "res://data/elements/%s.json"

var _index: Dictionary = {}
var _cache: Dictionary = {}  # symbol -> element data
var _preload_count: int = 36  # 启动时预加载元素数

signal element_loaded(symbol: String)
signal database_ready()

func _ready():
    _load_index()
    _preload_elements()

func _load_index():
    var file = FileAccess.open(INDEX_PATH, FileAccess.READ)
    if not file:
        push_error("元素索引文件不存在: " + INDEX_PATH)
        return
    _index = JSON.parse_string(file.get_as_text())

func _preload_elements():
    var loaded = 0
    for symbol in _index.elements.keys():
        _load_element(symbol)
        loaded += 1
        if loaded >= _preload_count:
            break
    database_ready.emit()

func _load_element(symbol: String) -> Dictionary:
    if _cache.has(symbol):
        return _cache[symbol]

    var path = ELEMENT_PATH % symbol
    var file = FileAccess.open(path, FileAccess.READ)
    if not file:
        push_warning("元素数据不存在: " + path)
        return {}

    var data = JSON.parse_string(file.get_as_text())
    _cache[symbol] = data
    element_loaded.emit(symbol)
    return data

# --- 公共 API ---

func get_element(symbol: String) -> Dictionary:
    return _load_element(symbol)

func get_element_by_number(Z: int) -> Dictionary:
    var symbol = _index.by_number.get(str(Z), "")
    if symbol.is_empty():
        return {}
    return get_element(symbol)

func get_element_by_position(period: int, group: int) -> Dictionary:
    for symbol in _index.elements.keys():
        var info = _index.elements[symbol]
        # 需要从完整数据中读取 period/group
        var data = get_element(symbol)
        if data.get("period") == period and data.get("group") == group:
            return data
    return {}

func get_isotopes(symbol: String) -> Array:
    var data = get_element(symbol)
    return data.get("isotopes", [])

func get_stable_isotopes(symbol: String) -> Array:
    var isotopes = get_isotopes(symbol)
    return isotopes.filter(func(iso): return iso.is_stable)

func get_isotope(symbol: String, mass_number: int) -> Dictionary:
    for iso in get_isotopes(symbol):
        if iso.mass_number == mass_number:
            return iso
    return {}

func get_all_symbols() -> Array:
    return _index.elements.keys()

func get_elements_by_category(category: String) -> Array:
    return _index.categories.get(category, [])

func compute_neutron_defect(Z: int, N: int, symbol: String) -> float:
    var data = get_element(symbol)
    var params = data.get("cqm_parameters", {})
    var delta_0 = params.get("defect_base_delta", 0.0)
    var beta = params.get("defect_beta_coefficient", 0.0)
    var N_ref = params.get("reference_neutron_count", 0)
    if N_ref == 0:
        return 0.0
    return delta_0 * (1.0 - beta * float(N - N_ref) / float(N_ref))
```

```python
# generate_element_data.py（示意）
import json
from nist_api import fetch_element
from nubase_table import fetch_isotopes
from cqm_theory import compute_defect

def generate_element(Z: int) -> dict:
    base = fetch_element(Z)
    isotopes = fetch_isotopes(Z)

    for iso in isotopes:
        N = iso["mass_number"] - Z
        iso["cqm_neutron_defect"] = compute_defect(Z, N, base)

    base["isotopes"] = isotopes
    base["cqm_parameters"] = build_cqm_params(Z, base)
```

### 4.3 CQM 参数默认值

对未单独标定的元素，使用默认 CQM 参数：

```gdscript
# cqm_defaults.gd
class_name CQMDefaults

const DEFAULT_DELTA_0 = null        # 基础缺陷（δ ≠ 1，未确认的开放问题）
const DEFAULT_BETA = 0.1           # 缺陷斜率
const DEFAULT_PROTON_SECTOR = "A4"
const DEFAULT_NEUTRON_SECTOR = "A4_defect"

static func build_defaults(Z: int) -> Dictionary:
    return {
        "proton_sector": DEFAULT_PROTON_SECTOR,
        "neutron_sector": DEFAULT_NEUTRON_SECTOR,
        "reference_neutron_count": _estimate_N_ref(Z),
        "defect_base_delta": DEFAULT_DELTA_0,
        "defect_beta_coefficient": DEFAULT_BETA,
        "electron_sector_model": "free_electron_gas",
        "preferred_bond_geometry": _estimate_geometry(Z)
    }

static func _estimate_N_ref(Z: int) -> int:
    # 参考中子数 ≈ 最稳定同位素的中子数
    # 粗略估计：N_ref ≈ round(1.6 * Z^0.7)（经验公式）
    return round(1.6 * pow(Z, 0.7))

static func _estimate_geometry(Z: int) -> String:
    if Z <= 2:
        return "linear"
    elif Z <= 10:
        return "tetrahedral"
    else:
        return "octahedral"
```

```gdscript
# isotope_selector.gd
extends Control

var _current_symbol: String = ""
var _isotope_buttons: Array[Button] = []
var _detail_labels: Dictionary = {}

func _ready():
    Events.element_selected.connect(_on_element_changed)
    _build_ui()

func _build_ui():
    # 标题
    var title = Label.new()
    title.name = "Title"
    add_child(title)

    # 同位素按钮容器
    var btn_container = HBoxContainer.new()
    btn_container.name = "IsotopeButtons"
    add_child(btn_container)

    # 详情面板
    var detail = VBoxContainer.new()

        _detail_labels[key] = lbl

func _on_element_changed(symbol: String):
    _current_symbol = symbol
    _refresh_isotopes()

func _refresh_isotopes():
    _clear_buttons()
    var element = ElementDatabase.get_element(_current_symbol)
    if element.is_empty():
        return

    _detail_labels.selected.text = "元素: %s (%s)" % [element.name, element.symbol]

    var isotopes = element.isotopes
    isotopes.sort_custom(func(a, b): return a.mass_number < b.mass_number)

    var btn_container = get_node("IsotopeButtons")
    for iso in isotopes:
        var btn = Button.new()
        btn.text = str(iso.mass_number) + element.symbol

        btn.tooltip_text = _isotope_tooltip(iso)
        btn.pressed.connect(_select_isotope.bind(iso))
        btn_container.add_child(btn)
        _isotope_buttons.append(btn)

    # 默认选最丰富稳定同位素
    var default = _find_most_abundant_stable(isotopes)
    if default:
        _select_isotope(default)

func _isotope_tooltip(iso: Dictionary) -> String:

        iso.mass_number, iso.neutrons, stability, iso.abundance * 100
    ]

func _select_isotope(iso: Dictionary):
    var defect = ElementDatabase.compute_neutron_defect(
        iso.mass_number - iso.neutrons, iso.neutrons, _current_symbol
    )
    _detail_labels.selected.text = "选中: %d%s" % [iso.mass_number, _current_symbol]
    _detail_labels.neutrons.text = "中子数: %d" % iso.neutrons
    _detail_labels.defect.text = "CQM 中子缺陷 ε: %.6f" % defect
    _detail_labels.spin.text = "核自旋: %s" % str(iso.get("spin", "—"))
    _detail_labels.abundance.text = "自然丰度: %.4f%%" % (iso.abundance * 100)

    Events.isotope_selected.emit(_current_symbol, iso.mass_number)

func _format_half_life(seconds: float) -> String:
    if seconds == 0 or seconds == null:
        return "—"
    if seconds < 1e-6: return "%.1f ns" % (seconds * 1e9)
    if seconds < 1e-3: return "%.1f μs" % (seconds * 1e6)
    if seconds < 1:    return "%.1f ms" % (seconds * 1e3)
    if seconds < 60:   return "%.1f s" % seconds
    if seconds < 3600: return "%.1f min" % (seconds / 60)
    if seconds < 86400: return "%.1f h" % (seconds / 3600)
    if seconds < 3.156e7: return "%.1f d" % (seconds / 86400)
    if seconds < 3.156e10: return "%.2f yr" % (seconds / 3.156e7)
    return "%.2e yr" % (seconds / 3.156e7)
```

## 6. 数据验证

### 6.1 启动时校验

```gdscript
# data_validator.gd
extends Node

func validate_database() -> Array:
    var errors = []

    # 1. 检查 118 元素齐全
    for Z in range(1, 119):
        var data = ElementDatabase.get_element_by_number(Z)
        if data.is_empty():
            errors.append("缺失元素 Z=%d" % Z)

    # 2. 检查每个元素的必要字段
    for symbol in ElementDatabase.get_all_symbols():
        var data = ElementDatabase.get_element(symbol)
        errors += _validate_element(symbol, data)

    return errors

func _validate_element(symbol: String, data: Dictionary) -> Array:
    var errs = []
    var required = ["symbol", "name", "atomic_number", "atomic_mass",
                    "category", "group", "period", "isotopes", "cqm_parameters"]
    for field in required:
        if not data.has(field):
            errs.append("%s 缺少字段: %s" % [symbol, field])

    # 检查同位素
    if data.has("isotopes"):
        for iso in data.isotopes:
            if iso.mass_number != data.atomic_number + iso.neutrons:
                errs.append("%s 同位素 A≠Z+N: A=%d Z=%d N=%d" %
                    [symbol, iso.mass_number, data.atomic_number, iso.neutrons])

    return errs
```

### 6.2 一致性检查

| 检查项 | 规则 |
|:---|:---|
| A = Z + N | 每个同位素质量数 = 原子序数 + 中子数 |
| 丰度和 | 稳定同位素丰度之和 ≈ 1.0（±0.01） |
| Z 连续 | 1-118 无缺失 |
| CQM 参数 | δ ≠ 1（δ₀ 未确认，开放问题），β 有界 |
| 颜色格式 | 合法的 Hex 颜色字符串 |
