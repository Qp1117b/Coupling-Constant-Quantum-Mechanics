# 02 元素及同位素数据库集成与管理机制

> 118 化学元素 + 同位素数据库的格式定义、加载机制、管理策略与 UI 呈现

---

## 1. 数据范围与覆盖

### 1.1 元素覆盖

| 范围 | 原子序数 | 元素数 | 说明 |
|:---|:---:|:---:|:---|
| 周期 1-7 主族 + 过渡族 | 1-118 | 118 | 全部已知元素，含超重元素 |
| 稳定元素 | — | ~251 种稳定核素 | 同位素标记为稳定 |
| 不稳定元素 | — | ~3300 种已知核素 | 标记半衰期与衰变模式 |

### 1.2 同位素覆盖策略

```
元素 (Z=1, H)
├── ¹H (N=0, 稳定, 丰度 99.985%)
├── ²H (N=1, 稳定, 丰度 0.015%, 氘)
└── ³H (N=2, β⁻, t½=12.33yr, 氚)

元素 (Z=8, O)
├── ¹⁶O (N=8, 稳定, 丰度 99.76%)
├── ¹⁷O (N=9, 稳定, 丰度 0.04%)
├── ¹⁸O (N=10, 稳定, 丰度 0.20%)
└── ¹⁹O (N=11, β⁻, t½=26.46s)
```

**设计原则**：
- 每个元素至少包含所有已知同位素
- 稳定同位素优先展示，放射性同位素折叠
- 超重元素（Z>92）的同位素数据可能不全，标注"数据不足"

### 1.3 CQM 理论所需数据

对每个同位素，CQM 理论需要以下参数：

| 参数 | 符号 | 来源 | 用途 |
|:---|:---:|:---|:---|
| 原子序数 | Z | 实验测量 | 质子扇区大小（Z 个 A₄ 块） |
| 中子数 | N | A − Z | 中子扇区大小（N 个缺陷 A₄ 块） |
| 中子缺陷参数 | ε(N) | CQM 公式计算 | 中子扇区缺陷强度 |
| 原子质量 | m | 实验测量 | 约化质量计算 |
| 价电子数 | v | 化学常识 | 电子扇区建模 |
| 电负性 | χ | 实验测量 | 键极性估算 |
| 原子半径 | r | 实验测量 | 3D 渲染 + 键长估算 |

### 2.2 字段说明

#### 基础化学字段

| 字段 | 类型 | 必填 | 说明 |
|:---|:---|:---:|:---|
| `symbol` | String | ✓ | 元素符号（IUPAC） |
| `name` | String | ✓ | 中文名 |
| `name_en` | String | ✓ | 英文名 |
| `atomic_number` | Int | ✓ | 原子序数 Z |
| `atomic_mass` | Float | ✓ | 标准原子量（按丰度加权） |
| `category` | String | ✓ | 分类：nonmetal / metal / metalloid / transition_metal / post_transition_metal / halogen / noble_gas / lanthanide / actinide |
| `group` | Int | ✓ | 族号（1-18，镧锕系为 3） |
| `period` | Int | ✓ | 周期号（1-7） |
| `block` | String | ✓ | 区块：s / p / d / f |
| `electron_configuration` | String | ✓ | 电子排布 |
| `valence_electrons` | Int | ✓ | 价电子数 |
| `electronegativity` | Float | — | 鲍林电负性 |
| `atomic_radius_pm` | Int | — | 原子半径（pm） |
| `covalent_radius_pm` | Int | — | 共价半径（pm） |
| `van_der_waals_radius_pm` | Int | — | 范德华半径（pm） |
| `melting_point_k` | Float | — | 熔点（K） |
| `boiling_point_k` | Float | — | 沸点（K） |
| `density_g_cm3` | Float | — | 密度（g/cm³） |
| `color` | String | ✓ | 显示颜色（Hex） |
| `cpk_color` | String | — | CPK 配色（Hex） |

#### 同位素字段

| 字段 | 类型 | 必填 | 说明 |
|:---|:---|:---:|:---|
| `mass_number` | Int | ✓ | 质量数 A = Z + N |
| `neutrons` | Int | ✓ | 中子数 N |
| `mass_da` | Float | ✓ | 精确质量（Da = u） |
| `abundance` | Float | ✓ | 自然丰度（0-1） |
| `is_stable` | Bool | ✓ | 是否稳定 |
| `half_life_s` | Float/Null | ✓ | 半衰期（秒），稳定则 null |
| `decay_mode` | String/Null | ✓ | 衰变模式：alpha / beta_minus / beta_plus / ec / sf / … |
| `spin` | Float | — | 核自旋 |
| `nuclear_magnetic_moment` | Float | — | 核磁矩（μ_N） |
| `cqm_neutron_defect` | Float | ✓ | CQM 中子缺陷参数 ε(N) |

#### CQM 参数字段

| 字段 | 类型 | 必填 | 说明 |
|:---|:---|:---:|:---|
| `proton_sector` | String | ✓ | 质子扇区类型（恒为 "A4"） |
| `neutron_sector` | String | ✓ | 中子扇区类型（"A4" 或 "A4_defect"） |
| `reference_neutron_count` | Int | ✓ | 参考中子数 N_ref（用于 δ(N) 公式） |
| `defect_base_delta` | Float | ✓ | 基础缺陷 δ₀（δ ≠ 1） |
| `defect_beta_coefficient` | Float | ✓ | 缺陷斜率 β |
| `electron_sector_model` | String | ✓ | 电子扇区模型 |
| `preferred_bond_geometry` | String | — | 优先键几何 |

### 2.3 CQM 中子缺陷参数计算

$$\delta(N) = \delta_0 \cdot \left(1 - \beta \cdot \frac{N - N_{\text{ref}}}{N_{\text{ref}}}\right)$$

## 3. 数据加载机制

### 3.1 分级加载策略

```
启动时
├── 加载 _index.json（轻量索引，~30 KB） ← 立即
├── 加载前 36 元素 JSON（常用元素，~200 KB） ← 启动时
└── 其余元素 ← 按需延迟加载

运行时
└── 用户选择元素 E
 └── 若 E 未加载 → 从磁盘加载 E.json → 缓存
```

### 3.3 内存管理

| 策略 | 说明 |
|:---|:---|
| LRU 缓存 | 最近使用的 50 个元素保留在内存 |

### 4.2 批量生成脚本

`tools/generate_element_data.py`（待实现）从 NIST/NUBASE 数据生成 JSON 文件：

```python
# generate_element_data.py（示意）
import json
from nist_api import fetch_element
from nubase_table import fetch_isotopes
from cqm_theory import compute_defect

def generate_element(Z: int) -> dict:
 base = fetch_element(Z)
 isotopes = fetch_isotopes(Z)

 for iso in isotopes:
 N = iso["mass_number"] - Z
 iso["cqm_neutron_defect"] = compute_defect(Z, N, base)

 base["isotopes"] = isotopes
 base["cqm_parameters"] = build_cqm_params(Z, base)
 return base

for Z in range(1, 119):
 data = generate_element(Z)
 with open(f"data/elements/{data['symbol']}.json", "w") as f:
 json.dump(data, f, indent=2, ensure_ascii=False)
```
