# 05 元素嘉当矩阵参数化设计与理论可跟进性分析

> 分析元素嘉当矩阵的构造原理，设计参数化架构使理论变动可方便跟进

---

## 1. 核心问题澄清

### 1.1 嘉当矩阵"相同"与"不同"的精确回答

**A₄ 矩阵本身是固定的**（所有元素共享）：

$$A_4 = \begin{pmatrix} 2 & -1 & 0 & 0 \\ -1 & 2 & -1 & 0 \\ 0 & -1 & 2 & -1 \\ 0 & 0 & -1 & 2 \end{pmatrix}$$

这是 SU(5) 群论的 Cartan 矩阵，**不会随元素改变**。

**元素嘉当矩阵因元素而异**，差异来自三个参数：

| 参数 | 符号 | 来源 | 对矩阵的影响 |
|:---|:---:|:---|:---|
| 原子序数 | Z | 实验测量 | 质子扇区大小：Z 个 A₄ 块 |
| 中子数 | N | A − Z | 中子扇区大小：N 个缺陷 A₄ 块 |
| 中子缺陷参数 | δ(N) | CQM 公式 | 中子扇区每个块的缺陷程度 |

**元素嘉当矩阵公式**：

$$\mathcal{C}_{\text{element}}(Z, N, \delta) = \underbrace{\bigoplus_{i=1}^{Z} A_4}_{\text{质子扇区（固定）}} \oplus \underbrace{\bigoplus_{j=1}^{N} C_n(\delta_j)}_{\text{中子扇区（可变）}}$$

其中 $C_n(\delta)$ 为 $A_4$ 的 $\alpha_4$ 末端非对角元缺陷：$(2,3)/(3,2)$ 元从 $-1$ 变为 $-\delta$（$\delta \neq 1$），$\det C_n = 8 - 3\delta^2$。

### 1.2 具体示例对比

```
氢 (Z=1, N=0): C_H = A₄ ← 4×4，纯 A₄，无缺陷
氦 (Z=2, N=2): C_He = A₄ ⊕ A₄ ⊕ C_n(δ) ⊕ C_n(δ) ← 16×16
镧 (Z=57,N=82): C_La = ⊕⁵⁷A₄ ⊕ ⊕⁸²C_n(δ) ← 556×556
```

**结论**：每个元素的嘉当矩阵**维度和内容都不同**，但都由同一个 A₄ 和非对角元缺陷参数 δ 参数化生成。

## 2. 理论参数分层：固定 vs 可变

### 2.1 理论固定部分（不会变动）

这些是 CQM 理论的数学基础，已由 Lean 形式化验证，**不需要参数化**：

| 固定量 | 值 | 来源 | Lean 验证 |
|:---|:---:|:---|:---|
| A₄ 矩阵 | 4×4 具体值 | SU(5) 群论 | `CartanAlgebra.Basic` |
| A₄ 本征值 | λ_k = 2−2cos(kπ/5) | 解析解 | `A4_eigenvalues` |
| A₄ 谱间隙 | (3−√5)/2 ≈ 0.382 | 最小本征值 | `spectralGap` |
| BCS 前因子 | 2e^γ/π ≈ 1.1339 | 弱耦合极限 | `Reduction.lean` |
| 普适能隙比 | 2πe^{−γ} ≈ 3.5278 | BCS 极限 | `Reduction.lean` |
| 谱量子 C | 0.02309570897 | ξ'(1)/ξ(1) | `Spectral.lean` |

### 2.2 理论可变部分（可能随理论发展调整）

这些是当前理论的**建模选择**，未来可能被修正：

| 可变量 | 当前模型 | 可能变动方向 | 影响范围 |
|:---|:---|:---|:---|
| **缺陷位置** | α₄ 末端非对角元 (2,3)/(3,2) | 已确定（§4 唯一性证明） | 所有中子扇区 |
| **δ(N) 函数形式** | 线性：δ₀(1−βΔN/N_ref) | 可能改为二次/指数/分段 | 同位素效应 |
| **δ₀ 基础缺陷** | 未确认（全局默认，δ≠1，开放问题） | 可能元素相关 | 所有元素 |
| **β 缺陷斜率** | 0.1（全局默认） | 可能元素相关 | 所有元素 |
| **N_ref 参考中子数** | 元素特异 | 可能调整公式 | 同位素效应 |
| **质子扇区修正** | 无（纯 A₄） | 未来可能加修正项 | 所有质子扇区 |
| **跨元素耦合 T_ij** | t_ij·I₄（标量耦合） | 可能改为矩阵耦合 | 分子层级 |

### 2.3 元素特异参数（实验输入）

这些参数**因元素而异**，来自实验测量，非理论推导：

| 参数 | 示例 | 来源 |
|:---|:---|:---|
| 原子序数 Z | H=1, He=2, ... | 实验测量 |
| 同位素列表 | H: {¹H,²H,³H} | 核物理实验 |
| 电负性 χ | H=2.20, O=3.44 | 实验测量 |
| 原子半径 | H=53pm, O=48pm | 实验测量 |
| 价电子数 | H=1, O=6 | 化学常识 |

## 3. 参数化架构设计

### 3.1 三层分离原则

```
┌─────────────────────────────────────────────────┐
│ 第 1 层：理论核心（固定，版本控制） │
│ A₄ 矩阵、本征值、谱间隙、BCS 常数 │
│ → 理论变动时整体更新，所有元素共享 │
├─────────────────────────────────────────────────┤
│ 第 2 层：建模选择（可变，配置文件） │
│ 缺陷位置（α₄末端非对角）、δ(N) 函数、耦合模型 │
│ → 理论变动时修改配置，不影响元素数据 │
├─────────────────────────────────────────────────┤
│ 第 3 层：元素数据（实验，逐元素） │
│ Z、同位素、电负性、半径等 │
│ → 实验更新时修改，不受理论变动影响 │
└─────────────────────────────────────────────────┘
```

### 3.4 嘉当矩阵生成器（运行时组装）

```gdscript
# cqm_cartan_builder.gd — 嘉当矩阵生成器
class_name CQMCartanBuilder
extends RefCounted

static var _config: Dictionary = {}

static func load_theory_config(path: String = "res://data/cqm_theory_config.json"):
 var file = FileAccess.open(path, FileAccess.READ)
 _config = JSON.parse_string(file.get_as_text())

# --- 第 1 层：理论固定 ---

static func A4() -> PackedFloat32Array:
 # 从配置读取（理论变动时配置更新）
 var m = _config.fixed_constants.A4_matrix
 var mat = PackedFloat32Array()
 for row in m:
 for val in row:
 mat.append(float(val))
 return mat

static func spectral_gap() -> float:
 return _config.fixed_constants.spectral_gap

# --- 第 2 层：建模选择 ---

static func defect_matrix(delta: float) -> PackedFloat32Array:
 # α₄ 末端非对角元缺陷：(2,3)/(3,2) 从 -1 变为 -δ
 var mat = A4()
 mat[2 * 4 + 3] = -delta # (2,3) 位置
 mat[3 * 4 + 2] = -delta # (3,2) 位置
 return mat

static func neutron_defect(N: int, element_symbol: String) -> float:
 # 检查元素特异覆盖
 var overrides = _config.get("element_overrides", {})
 if overrides.has(element_symbol):
 var ov = overrides[element_symbol]
 if ov.has("force_neutron_defect"):
 return ov.force_neutron_defect

 # 通用公式
 var model = _config.model_choices.neutron_defect_function
 var delta_0 = model.default_delta_0
 var beta = model.default_beta
 var N_ref = _estimate_N_ref(element_symbol)

 match model.type:
 "linear":
 return delta_0 * (1.0 - beta * float(N - N_ref) / float(N_ref))
 "quadratic":
 var dN = float(N - N_ref) / float(N_ref)
 return delta_0 * (1.0 + beta * dN * dN)
 "exponential":
 return delta_0 * exp(beta * float(N - N_ref) / float(N_ref))
 return delta_0

# --- 第 3 层：元素嘉当矩阵组装 ---

static func element_cartan(Z: int, N: int, symbol: String) -> PackedFloat32Array:
 var eps = neutron_defect(N, symbol)
 var size = 4 * (Z + N)
 var mat = PackedFloat32Array()
 mat.resize(size * size)
 mat.fill(0.0)

 # 质子扇区：Z 个纯 A₄
 var a4 = A4()
 for i in range(Z):
 _place_block(mat, size, a4, 4 * i)

 # 中子扇区：N 个缺陷 A₄
 var a4_defect = defect_matrix(eps)
 for j in range(N):
 _place_block(mat, size, a4_defect, 4 * (Z + j))

 return mat

static func _estimate_N_ref(symbol: String) -> int:
 var data = ElementDatabase.get_element(symbol)
 var isotopes = data.get("isotopes", [])
 # 取最丰富稳定同位素的中子数
 var best = isotopes[0] if isotopes else {"neutrons": 0}
 for iso in isotopes:
 if iso.get("abundance", 0) > best.get("abundance", 0):
 best = iso
 return best.get("neutrons", 0)
```

## 4. 理论变动的跟进场景

### 4.1 场景 A：缺陷模式已确定

**当前状态**：CQM 理论已确定缺陷在 α₄ 末端非对角元 (2,3)/(3,2) 位置（由 `CQM_核心_三种引力存在论前提.md` §4 唯一性证明给出）。此为当前最优模型。

**如需变更**：仅修改 `cqm_theory_config.json`：

```json
"defect_mode": {
 "positions": [[2, 3], [3, 2]] // 当前模型
}
```

**影响**：所有元素的嘉当矩阵自动更新，无需修改 118 个元素文件。

### 4.2 场景 B：δ(N) 函数形式改变

**理论变动**：线性模型改为二次模型。

**跟进方式**：仅修改配置：

```json
"neutron_defect_function": {
 "type": "quadratic",
 "formula": "delta_0 * (1 - beta * ((N - N_ref) / N_ref)^2)"
}
```

### 4.3 场景 C：质子扇区加修正

**理论变动**：质子扇区不再是纯 A₄，需加微扰修正。

**跟进方式**：修改配置 + 生成器代码：

```json
"proton_sector_model": {
 "type": "A4_with_correction",
 "correction": "alpha * diag(0, 1, 0, 0)",
 "alpha": 0.0001
}
```

```gdscript
static func proton_matrix(alpha: float) -> PackedFloat32Array:
 var mat = A4()
 if alpha != 0:
 mat[1 * 4 + 1] += alpha # 修正项
 return mat
```

### 4.4 场景 D：A₄ 本身被修正

**理论变动**：发现应用 A₅ 而非 A₄。

**跟进方式**：修改配置中的 A₄ 矩阵定义（重命名为 Cartan 矩阵）：

```json
"fixed_constants": {
 "cartan_matrix": [[2,-1,0,0,0],[-1,2,-1,0,0],[0,-1,2,-1,0],[0,0,-1,2,-1],[0,0,0,-1,2]],
 "matrix_rank": 5
}
```

### 4.5 场景 E：元素特异参数

**理论变动**：发现氢的 ε 应恒为 0（退化极限）。

**跟进方式**：配置中添加覆盖：

```json
"element_overrides": {
 "H": {"force_neutron_defect": 0.0}
}
```

## 5. 是否需要为 118 元素都创建文件？

### 5.1 结论：需要，但分两种策略

| 策略 | 适用 | 优点 | 缺点 |
|:---|:---|:---|:---|
| **全量创建 118 个 JSON** | 正式版 | 数据完整，离线可用 | 需维护 118 文件 |
| **模板生成 + 按需加载** | MVP/开发版 | 快速启动，维护少 | 需在线生成 |

### 5.2 推荐策略：模板 + 生成器

**核心思想**：118 元素的**实验数据**从公开数据库批量导入，**理论参数**由配置统一管理，**不逐个手写**。

```
数据来源 生成流程 产出
─────── ──────── ────
NIST/NUBASE 数据库 → generate_elements.py（待实现） → 118 个 JSON
 ↑
 cqm_theory_config.json
 （理论变动只改这里）
```

 print(f"已生成 {118} 个元素文件 + 索引")

if __name__ == "__main__":
 generate_all()

## 8. 总结

### 8.1 回答用户的三个问题

**Q1: 是不是所有元素都要创建一下？**
→ 是的，但通过生成器批量创建，不手写。每个元素 JSON 只含实验数据。

**Q2: 对应的嘉当矩阵应该不同吧？**
→ 是的。A₄ 矩阵固定，但元素嘉当矩阵因 Z、N、δ(N) 而异：维度不同（4(Z+N)），缺陷程度不同。

**Q3: 如何设计使理论变动可跟进？**
→ 三层分离：理论核心（固定）+ 建模选择（配置文件）+ 元素数据（实验）。理论变动只改配置文件，不动 118 个元素文件。
