## 核心设计

**一句话定位**：用户用元素拼接三维分子结构，系统基于CQM超导理论实时计算并判定超导性质，可视化A₄嘉当矩阵、凝聚温度等物理量。

### 五层双轨架构

| 层 | 名称 | 物理意义 | 归属 |
|:---:|:---|:---|:---:|
| L0 | 化学式 | 全局锚点 | 上屏 |
| L1 | 结合方式 | 骨架拓扑 | 上屏 |
| L2 | 相对位置 | 几何参数 | 上屏 |
| L3 | 晶胞 | 周期性堆积→Regge→嘉当→FG退相干场→CQM | 下屏 |
| L4 | 晶胞分布 | 晶粒排列（单晶/多晶/薄膜/粉末） | 下屏 |

双轨：模式设计（4超导家族经验规则）/ 自由设计（物理硬条件）

### 理论对接

1. 嘉当矩阵计算链：质子A₄ → 元素 → 分子 → 晶胞 → Regge
2. 晶胞=Regge单元 → 离散角亏 → FG退相干场 → CQM超导
3. 超导本质：晶粒中质子-中子关系网络 → FG退相干场 → 库珀对
