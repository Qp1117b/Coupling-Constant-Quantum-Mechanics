# CQM 3D专业引力超导实验软件

> 基于 Godot 引擎的3D专业引力超导实验软件，从质子A4嘉当矩阵出发，经五环节展开至晶胞分布结构，实现CQM超导理论的交互式计算

**项目代号**：CQM-SuperCon-Designer
**引擎**：Godot 4.6（GDScript）
**理论基底**：CQM 超导核心理论（耦合常量量子力学超导涌现框架）
**状态**：已实现并持续专业化（godot_project/，回归 105 项 + 冒烟 52 项全通过）

## 核心设计理念

### 1. 积木拼接 = 元素嘉当矩阵组装

CQM 理论的核心命题：**元素——而非质子或中子——才是 CQM 超导理论的理想因果积木**（§2.1）。本设计器将这一理论命题具象化为交互体验：

- 每个元素 = 一个积木块，内含 A₄ 嘉当矩阵结构
- 积木拼接 = 元素嘉当矩阵组装为分子有效超级嘉当矩阵
- 同位素选择 = 调整中子缺陷参数 ε(N)

### 2. 实时判定 = CQM 主丛曲率判定快速估算

CQM 主丛曲率判定公式：
$$\psi(\mathbf{r}, T) = \int_{\text{BZ}} d^3k \; \mathcal{D}_{\text{lattice}} \cdot \mathcal{P}_{\text{electron}} \cdot \mathcal{C}_{\text{triple}} \cdot \mathcal{K}_{\text{causal}} \cdot e^{-\Gamma_\phi|\tau|}$$

设计器对用户构建的分子结构进行快速估算（非第一性原理计算），给出：
- 临界温度 T_c 估算值
- A₄ 谱分解序参量张量可视化
- 超导判定（是/否/边界）
- BCS 退化路径展示

### 3. 可视化 = 物理量到视觉映射

| 物理量 | 可视化方式 |
|:---|:---|
| A₄ 嘉当矩阵 | 4×4 矩阵热力图 |
| 本征值谱 | 条形图（4 通道） |
| 凝聚温度 | 温度计 + 序参量张量正性状态 |
| 固有时流速 | 实时数值 + 节律曲线 |
| 主丛曲率判定值 | 实时数值 + 颜色映射 |
| 超导判定 | 绿/黄/红三色指示灯 |

## 五层双轨架构 (L0-L4)

超导材料设计从原子到宏观实体分为五层，每层有明确的物理意义和可控性：

### 层次模型

| 层 | 名称 | 物理意义 | 可控性 | 归属 |
|:---:|:---|:---|:---|:---:|
| **L0** | 化学式 | 全局锚点，元素组成 | 由原子自动推导 | 上屏 |
| **L1** | 结合方式 | 骨架拓扑（保守子结构/可变模块） | 模式库 | 上屏 |
| **L2** | 相对位置 | 几何参数（键长/键角/构象） | 模式库 | 上屏 |
| **L3** | 晶胞 | 周期性堆积（空间群/Bravais/Wyckoff） | 模式库 → Regge → 嘉当 → FG退相干场 → CQM | 下屏 |
| **L4** | 晶胞分布(晶粒) | 晶胞在空间中的分布排列（单晶/多晶/薄膜/线材/粉末） | 用户自由定义 | 下屏 |

### 双轨工作流

- **模式设计**：L1-L3挂载已知超导家族经验规则（铜氧化物/铁基/氢化物/BCS），自动适用性检查+跨层联动
- **自由设计**：仅受物理硬约束（键长/键角/空间群/Z值），直接输入参数

### 上下分屏与理论对应

```
┌─────────────────────────────────────────┐
│  上屏: 分子/原子设计 (L0-L2)            │
│  放置原子 → 右键结合连接 → 自动推导化学式 │
│  → 自动匹配超导家族模式 → 挂载L1-L3规则  │
├─────────────────────────────────────────┤
│  下屏: 画笔材料 = L4晶胞分布设计          │
│  画笔绘制晶胞分布(晶粒) → Regge单元       │
│  → 嘉当矩阵 → FG退相干场（角亏场）        │
│  → CQM超导计算                            │
│  TubeMesh粗细实体几何 + 离散密度场        │
└─────────────────────────────────────────┘
```

### 关键理论对接

1. **五环节发生学**：化学式→结合方式→相对位置→晶胞→晶胞分布结构（晶粒），五环节依次展开发生超导
2. **L4晶胞分布 = 介观精细引力结构作用场所** — 自由度主要锚定在此环节，画笔材料设计
3. **嘉当矩阵计算链**：质子A4嘉当矩阵 → 元素嘉当矩阵 → 分子嘉当矩阵 → 晶胞嘉当矩阵 → Regge嘉当矩阵
4. **三条独立链**：链A(几何分布,生成) / 链B(嘉当矩阵,约束) / 链C(拓扑抽象,筛选) — 在主丛处汇合
5. **晶胞=Regge单元** → 离散Regge角亏 → FG退相干场（角亏场直接给出因果约束强度） → CQM超导
6. **超导本质**：晶粒中质子-中子关系网络 → FG退相干场 → 因果约束 → 库珀对涌现
7. **还原论不可达**：L4晶胞分布自由度需人工参与(画笔设计)，不排除AI可达
8. **五维设计模式**：从已有超导材料提取五环节经验展开模式，选择模式自动展开

## CQM 理论基础速查

### 核心数值（来自 CQM 形式化验证）

| 参数 | 符号 | 数值 | 来源 |
|:---|:---:|:---:|:---|
| 谱量子 | C | 0.02309570897 | ξ'(1)/ξ(1) |
| 第一耦级 | 𝔠₁ | 200.04045483 | 1/4 + γ₁² |
| Mathieu 临界 | λ_c | 1.316022911 | b₁(q) = 2q |
| Dynkin 指数 | I | 5/3 | SU(5) 群论 |
| A₄ 谱间隙 | λ₁ | (3−√5)/2 ≈ 0.382 | A₄ 最小本征值 |
| BCS 精确常数 | 2e^γ/π | ≈ 1.1339 | 弱耦合前因子 |
| 普适能隙比 | 2πe^{−γ} | ≈ 3.5278 | 弱耦合极限 |

### A₄ 嘉当矩阵

$$A_4 = \begin{pmatrix} 2 & -1 & 0 & 0 \\ -1 & 2 & -1 & 0 \\ 0 & -1 & 2 & -1 \\ 0 & 0 & -1 & 2 \end{pmatrix}$$

本征值：λ_k = 2 − 2cos(kπ/5)，k = 1,2,3,4

### 元素嘉当矩阵

$$\mathcal{C}_{\text{element}} = \left(\bigoplus_{i=1}^{Z} C_p\right) \oplus \left(\bigoplus_{j=1}^{N} C_n(\delta_j)\right)$$

- C_p = A₄（质子扇区，纯 A₄）
- C_n(δ) = A₄ 的 α₄ 末端非对角元缺陷：(2,3)/(3,2) 元从 -1 变为 -δ（δ ≠ 1），det C_n = 8 - 3δ²
- δ(N) = δ₀·(1 − β·(N−N_ref)/N_ref)（中子缺陷参数）

### 临界温度公式

$$k_B T_c = \frac{2e^\gamma}{\pi} \cdot \hbar\Omega_0 \cdot \exp\left(-\frac{1}{N(0)\cdot V_0}\right)$$

## 诚实声明

本设计器的超导判定基于 CQM 超导理论框架，该理论**尚未经实验完全验证**。设计器输出的判定结果为**理论估算**，非实验确认。设计器的主要价值在于：

1. **理论可视化**：将 CQM 抽象数学结构具象化为可交互的 3D 体验
2. **教育工具**：帮助理解超导理论与分子结构的关系
3. **探索辅助**：为理论研究者提供快速结构-性质映射的工具
4. **非预测工具**：不用于预测新材料，仅用于理论框架的可视化探索
