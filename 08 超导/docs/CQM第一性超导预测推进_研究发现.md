# CQM 第一性超导预测推进：研究发现

## 目标

消除类别校准依赖，实现纯第一性Tc预测，目标LOOCV中位≤45%（匹配类别校准精度）。

## 当前状态

| 方法 | 中位误差 | 2倍内 | 5倍内 | 类别依赖 |
|:---|:---:|:---:|:---:|:---|
| one-hot类别模型（基线） | 43.1% | 80.5% | 92.1% | ✅ 依赖 |
| 纯几何线性特征（7维） | 75.1% | 71.3% | 79.3% | ❌ 纯第一性 |
| 扩展几何线性特征（11维） | 69.4% | 73.2% | 83.5% | ❌ 纯第一性 |
| 黎曼零点+几何γ_n推导 | 72.3% | 70.7% | 82.9% | ❌ 纯第一性 |
| GBR纯第一性（13维含交互） | 56.8% | 77.4% | 89.0% | ❌ 纯第一性 |
| GBR端到端（已有最佳） | 51.0% | 79.0% | 90.0% | ❌ 纯第一性 |

## 关键发现

### 1. 类别校准为何有效

K_0^cat的变异主要来自**类别间跳变**（铜氧 vs A15 vs 氢化物），而非类别内材料参数连续变化。one-hot类别特征为每类别提供独立偏置项，等价于将K_0的类别间变异从残差中提取。

### 2. 纯几何特征的局限

分子FG同步算符特征（δ_intrinsic、spectral_gap、size_disorder）与ln(K_eff)相关系数极低：

| 特征 | 相关系数 | 说明 |
|:---|:---:|:---|
| ln(δ_intrinsic) | -0.061 | 内禀角亏估计太粗糙 |
| ln(spectral_gap) | +0.000 | 谱间隙无区分力 |
| ln(size_disorder) | -0.063 | 尺寸失配贡献微弱 |
| ln(Z) | -0.300 | 原子序最强相关 |
| ln(θ_D) | -0.300 | 德拜温度最强相关 |

**根源**：当前δ_intrinsic从化学式粗估（配位偏离×0.3 + 尺寸失配×0.1），未用精确分子几何（键角、键长、点群对称性）。

### 3. GBR特征重要性排序

| 排名 | 特征 | 重要性 | 物理含义 |
|:---:|:---|:---:|:---|
| 1 | ln(N) | 0.230 | 原子数（分子复杂度） |
| 2 | ln(B) | 0.179 | 体模量（晶格刚度） |
| 3 | ln(M) | 0.103 | 总质量（同位素效应） |
| 4 | ln(θ_D/Δδ₀) | 0.095 | **非线性交互项**（GBR发现） |
| 5 | ln(V) | 0.080 | 晶胞体积 |
| 6 | ln(Δδ₀) | 0.063 | 角亏涨落 |
| 7 | ln(sd) | 0.056 | 尺寸失配（分子FG特征） |

### 4. 非线性交互项的物理意义

GBR发现的第4重要特征ln(θ_D/Δδ₀)是**非线性交互项**，线性模型无法捕获。其物理意义：

- θ_D/Δδ₀ = 德拜温度/角亏涨落
- 高比值 → 声子频率高且角亏涨落小 → BCS-like常规超导
- 低比值 → 声子频率低或角亏涨落大 → 非常规超导

这为构建可解释的非线性公式提供了线索。

## 推进路线

### 路线A：改进分子FG同步算符数值计算

当前δ_intrinsic从化学式粗估。需用精确分子几何：
- 从DFT/实验获取键角、键长
- 精确计算球面剖分角亏 δ = 2π - Σ α_面片
- 用点群投影构造L_mol = Σ λ_Γ · Π_Γ
- 预期：δ_intrinsic与K_eff相关性提升

### 路线B：可解释非线性公式

基于GBR发现的关键交互项，构建显式公式：
```
ln(K_eff) = a·ln(N) + b·ln(B) + c·ln(M) + d·ln(θ_D/Δδ₀) + p·ln(G) + q·ln(θ_D) + const
```
预期：中位误差介于线性69.4%和GBR 56.8%之间。

### 路线C：连续化γ_n推导

当前γ_n = RIEMANN_ZEROS[n]，n由几何信号离散选择。需连续化：
```
γ_n = f(δ_intrinsic, spectral_gap, size_disorder)  // 连续函数
```
预期：消除离散化损失，提升预测精度。

### 路线D：晶格结构特征

加入晶格结构类型作为连续特征（非one-hot类别）：
- 配位数（cn=4,6,8,12）
- 对称数（sym）
- 维度（1D/2D/3D）
- 层间距/层内距比（c/a）

预期：捕获类别间K_0跳变的物理根源。

## 结论

纯第一性预测当前最佳GBR中位56.8%，距类别校准43.1%仍有差距。核心瓶颈是分子FG同步算符的数值计算精度不足——δ_intrinsic从化学式粗估无法捕获电子结构差异。推进方向是精确分子几何计算（路线A）和可解释非线性公式（路线B）。
