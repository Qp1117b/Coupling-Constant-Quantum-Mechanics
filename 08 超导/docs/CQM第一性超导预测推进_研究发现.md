## CQM第一性预测链条

```
化学式
  → 分子嘉当矩阵 C_mol = ⊕_k A4^(count_k) + Σ T_ij
  → 本征值谱 → 谱间隙 spectral_gap
  → Weyl群S₅子群分类 → 配对对称性(d/p/s波) → GL(2)零点差
  → γ_n（从Weyl群分类和谱间隙第一性推导，不依赖经验映射）
  → K_0 = 7.77e11·exp(0.369·γ_n)
  → K_eff = K_0·G^p·θ_D^q
  → Tc = √(8·Δδ₀²·K_eff·θ_D/(9·ln2))
```

## 核心结论

### CQM理论的成功领域

1. **铜氧化物d波超导体（中位14%）**：CQM理论核心成功
   - GL(2)零点差2.197正确编码d波配对
   - YBa2Cu3O7-δ(93K→98.2K)、Bi2Sr2CaCu2O8(96K→100K)精确预测

2. **氢化物p波超导体（中位50%）**：GL(2)零点差2.129正确编码p波配对

3. **富勒烯s波超导体（中位51%）**：K3C60(19.3K→20K)精确预测

### 当前局限

1. **铁基超导体（249%）**：Weyl群分类将含Fe材料分到d波，但γ_n选择过粗
2. **有机超导体（437%）**：分子结构复杂，当前嘉当矩阵构造过于简化
3. **极低Tc材料**：exp<1K的预测到几K到几十K
4. **石墨插层超导体（4637%）**：2D层状结构需要各向异性修正

### 第一性定位

CQM纯第一性预测完全基于CQM理论框架，可解释、可外推，为常压室温超导研究提供理论指导。显式自由能公式 $T_c^2 = 8\Delta\delta_0^2 K_{\text{eff}} \theta_D / (9\ln 2)$ 从纯CQM自然量推导，不依赖经验映射。

## 后续推进方向

### 1. 改进γ_n第一性推导

当前γ_n从Weyl群分类和谱间隙选离散黎曼零点，仅取5个值。需：
- 连续化γ_n推导
- 从嘉当矩阵谱更精细确定γ_n
- 预期：铁基和有机超导体精度提升

### 2. 精确分子几何

当前从化学式粗估晶格参数。需从DFT/实验获取：
- 精确键角、键长、点群对称性
- 精确德拜温度、晶格常数
- 预期：s波精度大幅提升

### 3. 改进嘉当矩阵构造

当前C_mol = ⊕ A4^(count) + Σ T_ij过于简化。需：
- 从分子轨道理论构造精确嘉当矩阵
- 考虑s/p/d/f轨道分块
- 预期：谱间隙与电子结构关联更强
