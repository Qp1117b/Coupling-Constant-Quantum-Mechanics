## 1. 体系结构（按文档主张的依赖关系）

```
                        物质先在（本体论前提）
                              │
                    自组织 = 退相干（同一过程）
                              │
        ┌─────────────────────┼─────────────────────┐
        │                     │                     │
   QG（前几何/存在论前提）  GR（平庸网络/广度）   FG（非平庸网络/深度）
   因果集 + 黎曼零点谱      伪黎曼流形 + T_μν     Regge 底空间 + 主丛 P(M,G)
        │                     │                     │
   谱参数 ☯, 𝔠₁           G_N 公式            同步算符 Ŝ = L_u/(2π☯)·√(1−βδ̂_v) + Ĉ₂
        │                                           │
        └──────────────► 超导涌现链 ◄───────────────┘
                    （元素/分子/晶胞 FG → 角亏 → 声子 → 同步 → T_c）
```

**层级主权**（文档各处的实际主张，无冲突）：

| 层级 | 本体 | 几何映射 | 谱算符 |
|:---|:---|:---|:---|
| QG | 物质关系网络 | 因果集 $(X,\prec)$ | 紧化投影 $\hat{\mathcal S}_0$ |
| GR | 物质分布的平滑化 | 伪黎曼流形 | —（无谱算符） |
| FG | 物质晶胞 | Regge 剖分 | $\hat{\mathcal S}_\ell$（层级截面空间实现） |

**未闭合的接口**（本报告认为这是体系的主要结构性弱点，按重要性排序）：

1. **FG 纤维丛层 → CFT 层的映射是"表格式类比"**：`FG_纤维丛理论.md` §9.8 的对应表把"联络 ↔ Virasoro 生成元""和乐 ↔ monodromy"等列为"严格对应"，但 §9.2–§9.5 给出的是**结构类比 + 少数定量式**，未构造从主丛 $P(M_\ell,G_\ell)$ 到共形场 $\mathcal H_{\text{CFT}}$ 的函子或态射。§9.4 的 $h = \delta_v\hat T/(2\pi)$ 中 $\hat T$ 是算符、$\delta_v$ 是数，该式在数学上未赋义（标量与算符不可直接相乘得数）。
2. **"L 函数非平凡零点 ↔ 相变临界点"无定量实现**：`FG_纤维丛理论.md` §5.1 只列 GRH 为"数学前提"，`04 前沿研究/CQM_前沿研究_规范重组超导与SU5五重态内禀时间.md` 把该命题**降级为诠释层**。链条在此处断裂：没有"零点 $\gamma_n$ → 相变温度/临界耦合"的公式。
3. **"质量 = 自守关联的涌现"依赖 $G_N$**：`04 前沿研究/CQM_前沿研究_质量研究思路汇总.md:234` 定义 $M_p = L_p^3/(G_N T_p^2)$，而 $G_N$ 由 §5 的公式给出；同时 §0/§3 又说 $L,T$ 属性经自守关联生成质量。**若 $G_N$ 的公式已用质子数据构造，再用 $G_N$ 定义质子质量的 $L/T$ 关联，则构成核对循环**（该文档 §13 已把"$\lambda_c,\mathfrak c_1,\kappa$ 的来源"列为开放问题，但未指出循环本身）。

### 【严重】4.3 "$b_1(q)=2q$ 的参数化一致性"需要作者复核（本报告不裁定，给出判定配方）

`README.md:116`、`01 核心理论/CQM_核心_集成理论.md:360-364`、`03 引力与退相干/CQM_引力_GN可能公式.md:299-307` 主张：

$$\lambda_c=2\,b_1(\lambda_c/4),\qquad q_c=\lambda_c/4=0.32900572782691445,\quad b_1(q_c)=0.6580114556538295=2q_c$$

**（一）约定无关的结论**

在标准约定（Mathieu 方程 $y''+(b-2q\cos2x)y=0$，DLMF 28.2.26）下：

$$b_1(q)=1+q-\frac{q^2}{8}-\frac{q^3}{64}+\frac{q^4}{1536}+\cdots,\qquad
b_1(0.32900572782691445)=1.3149275574$$

两种互相独立的算法给出同一结论：

| 方法 | $b_1(0.3290057)$ |
|:---|:---|
| DLMF 28.2.26 幂级数（前 10 项） | **1.3149275574** |
| 三对角 Jacobi 矩阵（$\sin(2k+1)x$ 基，矩阵元 $2q\cos2x$）最小本征值 $\lambda_{\min}$，再按 $\lambda=b+q$ 换算 | **1.3154903490**（$\lambda_{\min}=0.9864846211$） |

两法相差 $5.6\times10^{-4}$（幂级数截断误差量级）。矩阵法本身经一阶微扰校验：$\lambda_{\min}=1-q^2/8+\cdots=0.9996875$（$q=0.05$）与直接对角化结果逐位吻合。

**⇒ 在标准约定下 $b_1(q_c)\approx1.315\approx 4q_c$，而文档称 $b_1(q_c)=2q_c=0.6580114557$；相对差约 50%。**

**（二）约定相关：文档数值可能对应另一种 $b_1$ 定义**

若反过来要求 $b_1(q_c)=2q_c$ 成立，则需 $\lambda_{\min}=b_1-q$ 的约定，此时 $\lambda_{\min}(q_c)=0.9864846211$，$b_1=\lambda_{\min}-q=0.6574789$。该值与 $2q_c$ 的相对差为 $8.1\times10^{-4}$——**不是**文档自称的 $4.22\times10^{-16}$，但数量级与形状完全对上。

进一步，在**同一种**（$\lambda=b-q$）约定下精确求解 $b_1(q)=2q$ 得 $q^\ast=0.3288329327$、$\lambda_c=4q^\ast=1.3153317309$；而文档的 $q_c=0.3290057278$ 与该根相差 $5.3\times10^{-4}$（相对 $1.6\times10^{-3}$）。**即：文档的 $q_c$ 在其自身约定下也只是一个近似根，而非精确解。**

**（三）结论与建议**

- 两种约定下"机器精度自验"都不成立：误差或为约 50%（标准约定），或为 $8.1\times10^{-4}$（作者可能采用的约定）。
- 这不是文字问题：$G_N$ 对 $\lambda_c$ **线性敏感**。以 $\lambda_c=1.3160229113$ 代入得偏差 $-2.73$ ppm；以 $\lambda_c=1.322275$（反解使 $G_N$ 精确等于 CODATA 值所需）代入则偏差为 0。$\lambda_c$ 的 0.47% 变化即对应 $G_N$ 的约 4700 ppm 变化（§4.4）。
- `06 Lean形式化/SpectralGeometry/MathieuContinuedFraction.lean` 编码的临界方程是
  $f(q)=1-3q-T_1(2q,q)=0$，其根 $q^\ast=0.32900572782691$、$\lambda=4q^\ast=1.3160229113077$ 与文档**逐位一致**——说明 Lean 忠实地形式化了文档采用的方程，**问题在于该方程与标准 Mathieu 特征值的对应关系**，而不在形式化实现。
- **建议作者执行的判定**：(i) 写出 Mathieu 方程的确切形式；(ii) 写出 $b_1$ 的定义（哪一分支、与 $\lambda_{\min}$ 的换算关系）；(iii) 给出三对角矩阵的元素约定。三者对齐后重算 $b_1(\lambda_c/4)$，并把 §6.4 的"机器精度 4.22e-16"改为实际残差。

### 【严重】4.4 $G_N$ 的 −3 ppm 不能作为验证证据（敏感度分析）

本次实算：以文档 $\lambda_c=1.3160229113077$ 代入，$G_N=6.708811657\times10^{-39}$ GeV⁻²，偏差 −2.73 ppm（与文档/CODATA 一致）。

但反解：要把 $G_N$ 精确打到 CODATA 值，需 $\lambda_c^{\text{fit}}\approx1.322275$，与文档的 $1.3160229$ 相差 **+0.47%**。即：

- $G_N\propto\lambda_c$，**0.47% 的 $\lambda_c$ 修正 = 4700 ppm 的 $G_N$ 修正**；
