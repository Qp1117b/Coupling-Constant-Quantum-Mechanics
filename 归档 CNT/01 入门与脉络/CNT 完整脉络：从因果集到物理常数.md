## 一、是什么

### 1.1 问题

标准模型有 19 个自由参数，广义相对论与量子场论不相容，暗物质、暗能量、真空灾难、夸克禁闭、测量难题——物理学的"为什么"越积越多。主流物理精确描述了现象，但从不追问底层：为什么时空是 4 维的？为什么有三种力？为什么精细结构常数约等于 1/137？为什么引力比电磁力弱 40 个数量级？

CNT 的核心追问是：

> **一个有限存在者（如质子）为什么持续是它自己，而不是消散？**

这不是一个哲学问题——它是一个物理问题，且必须从物理上回答。质子已经稳定存在了 138 亿年。它没有外部指令，没有外部维护者。它内部必然有一个机制，主动维持着自己的结构形式。

### 1.2 一条公理

CNT 只有一条不可还原的公理预设：

**物质先在（L0）**：物质是先在的，不依赖任何外部预设。存在就是存在，不可追问"为什么存在"。

这不是"假设物质存在"——那是同义反复。这是划定推导的**边界**：你不能引入任何未经论证的预设。具体而言：

- 不能预设连续时空——时空必须是推导的结果，不是前提
- 不能预设量子场或拉格朗日量——场的动力学必须从更底层涌出
- 不能预设规范对称性——对称性必须是结构推论，不是外加假设
- 不能预设维度、耦合常数或粒子谱——它们必须从数学必然性中产生

整个物理学的一切内容，都必须从"存在本身"开始，经纯逻辑和数学必然性推导出来。

### 1.3 核心概念链

从这一公理出发，推导按自然顺序展开：

- **再生产（L1）**：有限存在者通过主动的自我维持机制保持自己的结构形式。数学表达为幂等态射 $\mu\circ\mu = \mu$——每次再生产后结构形式回到同一性。再生产不产生存在（L0 已预设存在），而是**维持已有存在的特定形式**。

- **因果集 $C = (X,\prec)$**：再生产事件的离散集合 $X$ 与事件间的因果序关系 $\prec$ 构成因果集——时空的底层结构。再生产是动力学（如何维持），因果集是结构（维持事件的因果骨架）。两者是同一实在的两面，共同构成不可还原本体论。

- **Sprinkling**：离散因果集通过泊松嵌入连续几何，自然涌出测度 $d\mu = e^{-u}du$——这是下游所有内积和变分的 Hilbert 测度。

- **$\mathbb{H}^2$ 双曲几何**：Sprinkling 的连续极限涌出 Poincaré 半平面度规 $ds^2 = du^2 + e^{-2u}d\theta^2$。几何来源是 $A_4$（SU(5) 嘉当矩阵）嵌入 overextended Kac-Moody 代数 $A_4^{++}$ 后的 Weyl 群作用。

- **谱几何**：$\mathbb{H}^2$ 的 Laplace-Beltrami 算符经再生产投影 $\hat{\mu}$ 筛选后给出谱哈密顿量 $\hat{H}_\infty = \hat{D}^2 + 1/4$，其本征谱 $E_n = 1/4 + \gamma_n^2$ 连接黎曼 $\zeta$ 函数与物理常数。第一谱不变量 $C = \xi'(1)/\xi(1)$ 出现在所有耦合常数中。

- **Adele 统一**：三个质数扇区 $p=2,3,5$ 对应三种规范力——结构来自再生产离散性的数学必然，非经验拟合。Adele 约束 $\prod_p \mathbb{Z}_p = 1/30$ 统一所有扇区。

- **物理常数涌出**：从谱几何和群论的数学结构中，$\alpha^{-1}$、$G_N$、$\Delta m$ 等物理常数以零自由参数的方式严格确定。

## 二、为什么

### 2.1 为什么需要比标准模型更深的底层？

标准模型预设了太多：连续时空、量子场、拉格朗日量、规范对称性、19 个自由参数。它告诉你怎么算，但不告诉为什么。CNT 追问的是：

- **时空为什么是 4 维的？** ——从再生产计数（离散固有时）加 p 进结构（三个质数扇区）涌出：3 维耦合空间 + 1 维因果时 = 4 维相空间。

- **为什么有三种力？** ——从质的不可还原性涌出：再生产分裂必须在质数次发生，$p=2,3,5$ 是 1 到 6 之间仅有的质数。物理上只能有三个非 Abel/Able 规范相互作用。

- **为什么力的强度如此不同？** ——从 $p$ 进大小 $\gamma_p = 1/p$ 涌出：$p=2$（强力）折损 50% 最强，$p=5$（电磁力）折损 20% 最弱。

- **精细结构常数为什么是 1/137？** ——从 Adele 周期 $2^{14}3^{-1}5^{-3}\pi = 137.258$ 涌出。

- **引力为什么这么弱？** ——从谱几何的 $\exp(-2/C)$ 指数因子涌出，$C = 0.0230957$ 极小，指数压低极强。

- **测量难题如何解决？** ——退相干不是客观坍缩，而是因果结构限制（因果集局部有限性的直接推论）：某些分支因果不可达，但本体上未被消灭。

### 2.2 为什么因果集必须为底层？

推导过程中出现两条独立的路径，它们给出全同的方程形式，但本体论地位根本不同：

**因果集路径（唯一可行）**：以因果集 $C=(X,\prec)$ 为底层本体论。Sprinkling 严格涌出 $\mathbb{H}^2$ 几何，$\mathbb{H}^2$ 的 Laplacian 谱给出谱哈密顿量 $\hat{H}_\infty$ 和传输方程 $\partial_\tau\phi + c e^u\partial_u\phi = 0$。每一步——"为什么是双曲几何"、"为什么是此测度"、"为什么是此谱"——都有从因果集结构出发的严格回答。该路径是唯一的本体论自洽路径。

**经典路径（已走不通，保留为计算入口）**：以作用量原理为假设起点，写出 $S[\Phi] = \int d\tau\int d\mu\,[|\partial_\tau\Phi|^2 - \Phi^\dagger\hat{H}_\infty\Phi]$，经变分得到同样的谱方程。数学推导严格，在各层提供了精确的计算入口（变分原理、Sturm-Liouville 理论、边界匹配等），但**无法回答"为什么取此作用量形式"**。作用量是特设假设，没有第一性原理可以"推导出"其形式或维度提升。

根本原因——**传输方程违背光速因果限制，与四维时空对抗**：

$$\partial_\tau\phi + c e^u\partial_u\phi = 0$$

该方程是一阶双曲型，其 $u$ 方向不是时空维度，而是**耦合常数/能标维度**（$u = \ln r$，$r$ 为耦合空间中的径向标度）。传输方程描述的 RG 流动力学（$du/d\tau = c e^u$）不遵守 4D Lorentz 因果结构，无法与四维时空自洽共存。作用量路径自身无法发现这一点——它需要因果集路径的视角才能看到其根本局限。

**结论**：两路径的方程形式全同，交汇于完整的方程系统。但唯因果集路径能从第一性原理到达该交汇点。经典路径贡献数学骨架与精确计算入口，但作为本体论路径已根本失败。

## 三、来时路——七阶段研究展开链

### 第零阶段：出发点——物质先在（研究问题：物理学的最底层预设是什么？）

起始处不是假设连续时空或量子场——那已经是需要解释的东西了。起点必须是**存在本身**：物质是先在的，不可还原为理念或数学结构。这不是"假设物质存在"（那是同义反复），而是划定边界——此后不能再引入任何未经论证的预设。

从这一公理直接推出**五命题递进**：
- 物质先在（公理）→ 有限本体（存在必须以具体形式显现）
- → 张力（有限即不完备，不完备驱动变化）
- → 再生产闭环 μ∘μ=μ（变化必须被约束为回归，否则消散）
- → 离散固有时（回归次数构成时间）

走完这五步，就有了时间——再生产计数。没有度规、没有场、没有力，只有"存在维持自身，数它的回归次数"。

**关键决策**：早期曾尝试"合成 p 进数"概念，因加法未定义、无环结构、物理产出不足而暂弃。保留标准 Adelic 框架。

### 第一阶段：本体论发动机 —— 从"存在"到"壳层发现"（研究问题：有限存在者如何持续维持自己？）

给定有限存在者，它必须主动维持自身，否则消散。再生产的范畴论表述 μ∘μ=μ 是幂等态射——每次再生产后结构形式回到同一性。但再生产是离散事件序列，不是连续流动。离散性导致两个结构需求：

1. **不可还原的分裂**：分裂必须在第 p 次再生产处发生，p 必须是质数——唯一不可分解的乘法单元。
2. **历史的内禀编码**：第 n 次事件必须内在地记住前 n-1 次——数学上唯一指向 p 进数的投射极限构造：

$$\mathbb{Z}_p = \varprojlim \mathbb{Z}/p^n\mathbb{Z}$$

由此发现三个质数 p=2,3,5 对应三种规范力。但此时还不知道因果集——只知道再生产事件是离散序列。

**★ 壳层发现（本阶段核心输出）**：再生产结构自然产生层级——耦合壳层是终极本体的内部结构。粒子不是场的能量量子，而是壳层的元激发（跃迁）。这个发现后来被称为"本体论发动机"，是整个 CNT 大厦的第一块基石。

**这一时期尚未看到的**：离散再生产事件之间的因果次序关系是什么结构？即将在下一阶段揭示。

### 第二阶段：相容性发动机 —— 从"壳层"到"因果集"(研究问题：离散再生产如何与连续时空相容？)

这是 CNT 研究史上最关键的转折点。Phase 1 给出了离散再生产事件序列，但没追问这些事件之间的结构形式。本阶段识别出：这些事件不是孤立发生的，它们构成**因果集**（causal set）——一个局部有限的离散偏序集。

## 四、如何做——八层递进

### 第 0 层：出发点——物质先在

**唯一公理**：物质不可还原为理念或数学结构。不存在比"存在"更基本的预设。

从这一公理出发，第一步推理是"有限本体"：存在必须以具体有限形式显现。一个"无限存在者"在物理上没有意义——没有有限的结构能承载无限的信息。因此存在者必须是有限的：质子、中子等具体粒子。

**张力**是下一个逻辑环节：有限即不完备。一个有限存在者若不主动维持自身，就会消散。这种"必须维持否则消散"的状态就是张力——存在者内在的分裂动力。

### 第 1 层：再生产与因果集

#### 再生产（L1）

再生产是有限存在者回应张力的方式：通过主动的自我维持操作保持结构形式。数学表述：

$$\boxed{\mu \circ \mu = \mu}$$

这是一个幂等态射 $\mu: S \to S$。幂等性意味着：
- $\mu^2 = \mu$：再生产两次与再生产一次效果相同——结构形式不变
- 本征值 1 = 存在维持，0 = 存在终止
- 质子已经稳定存在 138 亿年，其再生产是完美维持（$\mu^n = \mu$ 对所有 $n$）

**重要区分**：再生产不产生存在（L0 已预设存在）。它是**维持已有存在的结构形式**。

**五命题递进**（纯逻辑推导链）：

```
物质先在 (L0，公理)
  → 有限本体 A = A (结构性推论：存在必须以具体有限形式显现)
  → 张力 (推理：有限即不完备，不完备驱动变化)
  → 再生产闭环 μ∘μ=μ (推理：变化必须被约束为回归，否则结构形式消散)
  → 离散固有时 τ_k = k·T_rep (推理：回归的次数构成时间)
```

走完这五步，你已经得到了时间的定义——固有时 = 再生产计数。你还不知道度规、不知道引力、不知道规范力——只有"存在维持自身，数它的回归次数"。后面的一切都从这长出。

#### 因果集（Ca）

再生产不是在虚无中发生的。再生产事件之间必须有因果联系：一次分裂的结果必须能影响下一次分裂。这给出存在者的结构形式——**因果集**：

$$\boxed{C = (X, \prec)}$$

其中 $X$ 是再生产事件的集合，$\prec$ 是因果序关系。因果集满足严格的公理系统：

| 公理 | 内容 | 物理含义 |
|:---|:---|:---|
| CS0 | 物理实在由因果集 $C=(X,\prec)$ 构成 | 底层本体论 |
| CS1 | $\prec \subseteq X \times X$ | 序关系的定义域 |
| CS2 | $\neg(x \prec x)$ | 无自环——事件不能因果地影响自身 |
| CS3 | $x \prec y \prec z \wedge x \neq z \implies x \prec z$ | 传递性——因果链可复合 |
| CS4 | $x \prec y \wedge y \prec x \implies x = y$ | 反对称——没有闭因果环 |

**三个关键性质**：
1. **局部有限性**：$\|\text{Past}(x)\| < \infty$——每个事件只有有限多的因果前驱。这直接来自再生产的离散性。
2. **因果序先于度规**：$\prec$ 关系先于 $g_{\mu\nu}$ 涌现，无需预设连续时空。
3. **层级分层**：再生产闭环在不同 p 进扇区产生不同尺度的因果分层。

**L1 与 Ca 的关系**：L1（再生产动力学）与 Ca（因果集结构）是**同一底层实在的两面**——L1 描述"存在者如何维持自身"（态射 $\mu$），Ca 描述"维持事件之间的因果骨架"（偏序集 $(X,\prec)$）。两者共同构成不可还原本体论。没有再生产，因果集没有动力学内容；没有因果集，再生产没有结构载体。

### 第 2 层：离散结构——p 进数与 Adele

再生产是离散事件序列——不是连续流动。这一简单事实有深远的结构后果。

**第一个需求：不可还原的分裂。** 再生产过程中，某个质数次的分裂不能被还原为更基本分裂的组合。$p$ 必须是质数——唯一不可分解的乘法单元。这是"什么是基本的？"这一问题的数学回答：质数就是整数世界中最基本的"原子"。

**第二个需求：历史的内禀编码。** 第 $n$ 次再生产事件的产物必须内在地"记住"经历了前 $n-1$ 次事件，且可通过投影操作恢复任何一层的历史状态。数学上，这唯一地指向 p 进整数的投射极限构造：

$$\boxed{\mathbb{Z}_p = \varprojlim_{n} \mathbb{Z}/p^n\mathbb{Z}}$$

p 进数在这里扮演双重角色：
- **层析论角色**（空间分析）：$\mathbb{Z}_p = \varprojlim \mathbb{Z}/p^n\mathbb{Z}$——规范群的层级结构
- **循环论角色**（时间分析）：$\nu_p: \mathbb{Q}^\times \to \mathbb{Z}$——再生产事件计数

**为什么是 2、3、5？** 三种规范力对应三个质数扇区。从数学上看，1 到 6 之间的质数只有 2、3、5（$7$ 及以上导致物理上不可行的额外扇区）。从物理上看：

| 质数 $p$ | 规范群 | 物理内容 | 退相干程度 |
|:---:|:---:|:---|---:|
| 2 | SU(3) 色 | 夸克、胶子 | 完全 |
| 3 | SU(2) 弱 | $W^\pm, Z$、中微子 | 部分 |
| 5 | U(1) 电磁 | 电子、光子 | 最小 |

Adele 约束 $\prod_{p\in\{2,3,5\}} \mathbb{Z}_p = 1/30$ 统一所有扇区的测度归一化。

**★ 壳层发现**：再生产结构自然产生层级——耦合壳层是终极本体的内部结构。粒子不是场的能量量子，而是壳层的元激发（跃迁）。这一发现是 CNT 的"本体论发动机"的核心输出。

### 第 3 层：时空涌现——从因果集到双曲几何

#### 固有时

CNT 中，固有时不是坐标时——它是再生产的计数：

$$\boxed{\tau_k = k \cdot T_{\text{rep}}}$$

其中 $T_{\text{rep}}$ 是单次再生产的周期（由闭合核几何结构决定，约 $10^{-23}$ 秒量级）。

**三重时间结构**：

|:---|:---|:---|

| 虚时间 | 自指闭合 | 圈图展开——因果回路的方向折叠 |

#### Sprinkling → 测度

因果集通过泊松 Sprinkling 嵌入连续几何。Sprinkling 在坐标 $v = e^{-u}$ 中均匀（密度 $\rho$），则测度：

$$d\mu_{\text{spr}} = \rho\,dv = \rho\,(-e^{-u}du) \;\longrightarrow\; \boxed{d\mu = e^{-u}du}$$

吸收常数 $\rho$ 入定义后，$d\mu$ 即为下游所有内积与变分的 Hilbert 测度。Hilbert 空间：

$$\mathcal{H} = L^2(\mathbb{R}, e^{-u}du), \quad \langle f,g\rangle = \int f^*(u)g(u)e^{-u}du$$

这个测度是关键——它不同于几何体积元 $d\text{vol}_g = e^{-2u}du$，而是 Sprinkling 过程从底层因果结构直接涌出的概率测度。

#### $\mathbb{H}^2$ 双曲几何

$\mathbb{H}^2$ 几何的涌现走过一条严格的代数路径。SU(5) 嘉当矩阵 $A_4$ 嵌入 overextended Kac-Moody 代数 $A_4^{++}$。$A_4^{++}$ 的偶 Weyl 群 $W^+(A_4^{++})$ 同构于 $\text{PSL}_2^{(0)}(\mathcal{I})$（模群的同余子群）。这个群作用在 Poincaré 半平面上，基本域为镶嵌 $\{5,4\}$：

$$ds^2 = du^2 + e^{-2u}d\theta^2$$

**物理意义**：再生产动力学的离散结构，在其连续极限下，必然指向双曲几何。这不是假设——是 $A_4$ 嘉当矩阵的代数结构的严格推论。

#### 两阶层动力学

在因果集上，存在两个独立但互补的动力学层次：

**一阶层——传输方程（单向因果，费米子型）**：

在 1 维因果集链 $u_1 \prec u_2 \prec \cdots \prec u_N$ 上，标量场的离散演化为：

$$\psi(u_j, \tau_{n+1}) = \psi(u_{j-1}, \tau_n)$$

物理含义：$u_{j-1}$ 处的存在者在因果时 $\tau_n$ 产生 $u_j$ 处的新存在者。因果序 $u_{j-1} \prec u_j$ 保证单向性。

连续极限下（$\delta u \to 0, \Delta\tau = \delta u/c \to 0$）：

$$\boxed{\partial_\tau \psi(u,\tau) + c\,\partial_u \psi(u,\tau) = 0}$$

经测度补偿 $\Psi = e^{u/2}\phi$（从 Hilbert 测度 $d\mu = e^{-u}du$ 到 $L^2(du)$ 的转换），得到传输方程：

$$\boxed{\partial_\tau \phi + c\,e^u \partial_u \phi = 0}$$

特征线：$du/d\tau = c\,e^u$——经典 RG 流。

**二阶层——谱方程（双向干涉，玻色子型）**：

定义二阶离散算符：

$$(B\Phi)_j = -\frac{1}{\delta u^2}[\Phi_{j+1} - 2\Phi_j + \Phi_{j-1}]$$

与一阶传播不同，$B$ 同时考虑"过去"和"未来"邻居，描述虚拟过程的双向干涉。

连续极限下，在 $L^2(e^{-u}du)$ 中：

$$\boxed{(i\partial_\tau)^2\Phi = c^2(-\partial_u^2 + \partial_u)\Phi = \hat{H}_\infty\Phi}$$

两种层次的关系：

| | 一阶层 | 二阶层 |
|:---|:---|:---|
| **离散形式** | $\psi_j^{n+1} = \psi_{j-1}^n$ | $(B\Phi)_j$ 三点差分 |
| **连续形式** | $\partial_\tau\psi + c\partial_u\psi = 0$ | $(i\partial_\tau)^2\Phi = c^2(-\partial_u^2+\partial_u)\Phi$ |
| **算符** | $\hat{\mathcal{G}} = -iCe^u\partial_u$ | $\hat{H}_\infty = c^2(-\partial_u^2+\partial_u)$ |
| **主象征** | $\sigma = c e^u k$（变系数，单向） | $\sigma = c^2 k^2$（常系数，双向） |
| **物理** | 真实再生产传播（费米子型） | 虚拟量子涨落（玻色子型） |

**关键**：两者不是推导关系，而是**互补关系**。一阶平方 $\hat{\mathcal{D}}^2 = c^2 e^{2u}(-\partial_u^2 + 1/4) \neq \hat{H}_\infty$，两者独立构造。通过共享边界条件 $\partial_u\phi(0)=0$（Neumann）锁定。
