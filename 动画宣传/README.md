# CQM 理论动画（动画宣传）

> **定位**：CQM 理论动画的**方案层与制作层**文档与产物。不含理论内容——所有主张、数值、缺口状态一律以 `01`–`07` 原文与 `08` 组织层为准。
> **当前状态**：180 s 独立宣传片已按 **Remotion 引擎工程（v3）** 根本重构。现行成片 `输出/CQM_宣传动画_引擎重构_1080p60.mp4`，唯一工程入口 `promo-engine/`。v1／v2 的「手写 SVG ＋ headless Chrome 逐帧截图」管线已整体移入 `_归档_v1v2_手写SVG管线/`，**不保留兼容入口、不再作为交付**。22.5 s 视觉语法样片与 S0 90 s 分段成片仍在。v5 的 8:00 正片仍按 S1–S3 分期推进，尚未合片。
> **重构要点**：把「确定性文档渲染器」换成真正的动画引擎——声明式 Track 时间轴、Remotion Studio 实时预览、`<Audio>` 统一音画、并发分片渲染、出片前七道静态门禁与成片级自动验收。内容层（46 条字幕／24 格演算刻度／13 条推导链／全部限定语）由 `tools/extract_kernel.py` 逐字迁入，门禁 G1／G2 校验与 v2 基线零差异。
> **v3.0 的关键结论**：全库公式审计实测**演算容量仅 1820 s** ⟹ 体裁由「5 部 × ≥10 分钟」改为「**2 部 × ≥10 分钟，12 章 / 30:20**」；时长由**演算步数**决定，不由章节数决定。
> **v5 的现行体裁**：8:00 六段「五次替换」＋演算驱动＋仪器声场；宣传片是其压缩版，共用同一份白名单与状态徽章。

## 三、三条纪律（贯穿全部文档）

1. **状态双编码**：金环＝框架公理／青三角＝框架内推导／琥珀断环＝待推缺口／白方框＝外部标准／紫虚线＝哲学诠释。
2. **琥珀措辞 lint**：禁「证明／已证／确定／彻底解决」；只允许「框架内构造／待推／缺口／构造后验数字校验，待独立复现」。
3. **上屏公式白名单 ＝ 文档审计后「有推导链路」的公式集**（见 v3.0 §六）——动画与文档共用一份白名单。
