# CQM 理论动画：Claude 生成技法参考与落地规格（v1.0）

> **定位**：生产方法论文档。只借**视觉语法与工程手法**，不借任何物理结论；CQM 的主张、数值、缺口状态一律以 `01`–`07` 原文与 `08` 组织层为准。
> **服务对象**：[全研究覆盖与系列规划](CQM_理论动画_全研究覆盖与系列规划.md)、[视觉圣经](CQM_理论动画_视觉圣经.md)、[分镜脚本](CQM_理论动画_分镜脚本.md)、[组件库规划](CQM_理论动画_组件库规划.md)。
> **本文解决什么**：现有方案的技术栈偏重（React／Remotion／Blender），周期长、门槛高；而 2026 年下半年最强的动画生产力来自**「大模型直接写代码，浏览器即播」**这条轻轨。本文把那条路上的成熟手法拆成可执行规格，补成 Track 0。

### 1.2 共性：为什么这些片子看起来「是视频」而不是「会动的 PPT」

| 维度 | 常见 AI 动画（网页 PPT 感） | 上述作品的做法 |
|:---|:---|:---|
| 叙事单位 | 一页 → 下一页 | 一个镜头 → 交棒给下一个镜头 |
| 空间 | 平面排版，元素淡入淡出 | 有纵深、有推轨、有焦点转移 |
| 时间 | 均匀翻页节奏 | 跟着旁白呼吸：说到哪，画面推到哪（「旁白」指屏上文字节奏，全片不配音） |
| 文字 | 满屏小字与说明 | 少而大，只在必要处出现 |
| 转场 | 淡入淡出／硬切 | 用同一对象的形变完成过渡（溶解、展开、拉伸） |
| 可改性 | 重新生成＝抽卡 | 改一个数／一句文案，其余帧不动 |
| 清晰度 | 位图放大发虚、文字变形 | 矢量渲染，文字永远是文字 |

轩辕的总结最直接：差异不在「会不会动」，而在**「有没有镜头意识」**——知不知道该往哪推、什么时候交棒下一个画面（[出处同上](http://mp.weixin.qq.com/s?__biz=MzIyNjMxOTY0NA==&mid=2247506685&idx=1&sn=90fe3929cd9c54f048750b28fa287113)）。

## 二、技法解码：十二条可执行规则

> 每条都给出「规则 → 操作定义 → CQM 中的落点」。操作定义是可以写进提示词、写进代码的判据，不是形容词。

### T01 镜头意识优先于排版
- **操作定义**：每个镜头必须先写「景别（远／中／近／微）＋机位运动（推／拉／摇／移／不变）＋焦点（谁在动）＋时长」，再写画面内容。没有机位描述的镜头视为未完成。
- **判据**：抽掉字幕，只看画面，观众仍能说出「镜头在往哪走」。
- **CQM 落点**：主片 33 个镜头全部补机位列（见[分镜脚本](CQM_理论动画_分镜脚本.md) v0.3 修订）。

### T02 一个镜头只跨一个抽象层级
- **操作定义**：镜头内允许「一次」缩放跨越；跨两层必须切镜头。
- **判据**：一镜内出现两个不同量级的对象（如「网络」与「原子核」）即判失败。
- **CQM 落点**：L0→L7 的下潜拆成 6 次变焦，每次只落一层（对应[视觉圣经](CQM_理论动画_视觉圣经.md) §四「连续下潜」）。

### T03 以旁白切镜头，不以页切（旁白指屏上文字，不是配音）
- **操作定义**：先定旁白断句，再把每句绑一个镜头区间；旁白不变则画面不许空转。
- **判据**：时间轴上旁白块与镜头块一一对应，无「等画面播完」的空档。
- **CQM 落点**：v3.0 的每部 ≥10 分钟正片按「机制段 3–5 分钟」切段（见 `CQM_理论动画_正片方案_v3_演算链版.md` §2.4），以旁白句为界；**旁白是屏上文字，全片不配音**。90 秒模板已随该体裁作废。

### T04 矢量优先，文字永远是文字
- **操作定义**：所有图形与文字均由代码绘制；禁止贴位图当主视觉（真实材质除外）。
- **判据**：4K 输出下文字边缘无插值模糊；同一文字在不同帧的字宽完全一致。
- **CQM 落点**：`☯`、$\delta_v$、$\mathrm{SU}(5)$ 等符号全部用路径或排版引擎绘制，不做贴图。

### T05 确定性渲染
- **操作定义**：固定帧率与时间基准；随机量必须带种子；同一份代码在任意机器上输出同一帧序列。
- **判据**：两次渲染的逐帧像素差为 0（除抗锯齿）。
- **CQM 落点**：Track 0 单文件用 `performance.now()` 之外的**虚拟时钟**驱动，支持 `?t=12.5` 定格到指定秒。

### T06 场景即纯函数
- **操作定义**：每个镜头实现为 `frame(t) → 画面状态`，不持有隐式状态、不依赖上一帧累积。
- **判据**：把时间轴拖到任意位置，画面必须与顺序播放到该处一致。
- **CQM 落点**：这是「可逐帧 QA」的前提，也是修改单镜头不影响全片的保证。

### T07 深度层可开关
- **操作定义**：公式、定义、缺口编号放独立图层，默认关；开启后不遮挡主体。
- **判据**：关掉深度层，主叙事仍完整；打开后，每个公式都能对应到一句旁白。
- **CQM 落点**：[视觉圣经](CQM_理论动画_视觉圣经.md) §一第 4 条已定，本文补上开关交互规格（快捷键 `D`）。

### T08 风格库而非单一风格
- **操作定义**：把「质感」抽成可切换的样式表（线宽、纹理、色板、运动曲线），内容不变换风格重渲。
- **判据**：同一镜头在 ≥3 种风格下都能成立。
- **CQM 落点**：主片固定「冷科学」；短片可出「线稿」「蓝图」「纸雕」三套皮肤（借 LEMO 19 风格库思路，但只保留与理论气质相符的三种）。

### T09 连续无限缩放作为叙事骨架
- **操作定义**：用一个连续缩放把多个尺度串成一条镜头，而不是靠切镜罗列。
- **判据**：观众能说出「我们是从哪一层进去的」。
- **CQM 落点**：芝诺案例的「指纹→细胞→原子」正是 CQM 要的语法：**耦合空间 → 前时空 → 因果网络 → 4-单纯形 → 晶胞**，一条缩放贯穿第二、五幕。

### T10 转场即物理
- **操作定义**：转场由画面内对象的真实形态变化完成（网格溶解成节点、晶格展开成单纯形、谱线拉伸成下一幕坐标轴），不用叠化遮盖。
- **判据**：转场前后，画面上至少有一个元素是「同一个东西」的延续。
- **CQM 落点**：[视觉圣经](CQM_理论动画_视觉圣经.md) §五五种转场全部满足此判据。

### T11 静默与留白是节奏的一部分
- **操作定义**：每个 hero 镜头后留 0.4–0.8 s 静默；全片留白占比 ≥15%。
- **判据**：去掉音轨看画面，仍有「呼吸段」。
- **CQM 落点**：状态徽章出现时同时静默，让观众读状态而不被画面抢走。

### T12 反 PPT 清单（硬禁止）
- 禁止：翻页角标、页码、「第 N 页」、卡片投影、满屏项目符号、装饰性英文小字、无意义渐变高光。
- 判据：任意一帧截图，若看起来像幻灯片，即判失败。

## 三、适配矩阵：能借 / 要改 / 禁用

| 手法 | 借用方式 | CQM 改造 | 禁用理由 |
|:---|:---|:---|:---|
| 单文件 HTML 直出 | Track 0 主力：一个 `.html` 播完一集 | 加虚拟时钟、`?t=` 定格、深度层开关 | — |
| 无限缩放 | 第二、五幕的层级下潜 | 每层落地必须停 2 s 并给层名 | 不做无落点的「炫技缩放」 |
| 风格库换肤 | 短片出线稿／蓝图／纸雕三皮肤 | 状态色与徽章形状不随皮肤变 | 风格不得改变状态语义 |
| 12 小时长任务生成 | 用于整片预演（animatic） | 生成后必须逐镜过事实核查矩阵 | 不直接把生成结果当交付 |
| Manim 公式动画 | 深度层公式逐行出现 | 只做透明背景序列，合成进主片 | 不让公式占据主叙事 |
| 3D 引擎（67.js 一类） | 4-单纯形、自旋网络穿行 | 与 Blender 版同参数、同数据 | 不做写实材质（会暗示「已观测」） |
| 电影风格化 | 宣传片／社媒切片 | 理论主体保持冷科学 | 不把理论片做成「史诗预告」 |
| 配乐与音效 | 事件音、静默 | 相位锁定＝短脉冲，角亏＝低频凹声 | 禁预告片鼓点与上升音堆叠 |

## 四、三轨管线（新增 Track 0）

### 4.1 轨道定义

| 轨 | 技术栈 | 单集周期 | 适用 | 画质上限 |
|:---|:---|:---|:---|:---|
| **Track 0（新）** | 单文件 HTML ＋ SVG／Canvas ／ Web Animations，CSS 变量做 tokens | 0.5–2 天／集 | 90 秒短片、社媒切片、交互地图内嵌、提案预演 | 4K 矢量，浏览器直出 |
| Track A | React ＋ TS ＋ Remotion／GSAP，Three.js／R3F | 3–7 天／集 | 需要 3D 与复杂合成的镜头 | 4K，可出 MP4 |
| Track B | Blender 4.x ＋ Cycles；UE5 可选 | 2–5 天／镜头 | hero 镜头（S01、S20–S23、S33） | 电影级 |

**选择规则**：先用 Track 0 把每一集做出来（能播、能审、能改），只有「必须靠体积光与材质才有说服力」的镜头才升级到 B 轨。这样 19 集不必等 3D 管线。

### 4.2 Track 0 工程规格（可验收）

```text
单集产物：cqm_E07_simplex.html          （单文件，无外部依赖，≤ 300 KB）
         ├─ <style>  tokens：颜色／字体／缓动，与 tokens.json 同值
         ├─ <svg> 或 <canvas>  舞台（viewBox 0 0 1600 900，等比缩放）
         ├─ <script>  时间轴：SHOTS = [{t0,t1,render(t)}...]
         └─ 控制层：空格暂停、←→ 逐镜、D 深度层、?t=12.5 定格、?q=0.5 半分辨率
```

| 规格 | 要求 | 理由 |
|:---|:---|:---|
| 时间基准 | 虚拟时钟（帧号／fps），不用 `performance.now()` 累积 | 确定性；定格可复现 |
| 帧率 | 60 fps 预览、24 fps 出片 | 预览流畅，出片与主片一致 |
| 依赖 | 零 CDN、零字体外链（系统字体栈＋内嵌 SVG 字形） | 离线可播、审计可查 |
| 性能 | 单帧绘制 ≤ 8 ms，DOM 节点 ≤ 800 | 4K 缩放不卡 |
| 可访问性 | 支持 `prefers-reduced-motion`：降为分镜静帧序列 | 不牺牲可达性 |
| 审计钩子 | 每镜头 `data-claim="C05"`、`data-status="cyan"` | 与 `claims.yaml` 对账 |

### 4.3 与既有组件库的对应

`NodeGraph`／`PhaseRing`／`Simplex4D`／`LayerStack`／`StatusBadge`／`FormulaCard`／`CameraRig`／`CaptionSystem` 八个 P0 组件，在 Track 0 中以**纯函数 + SVG 组**实现，接口与 [组件库规划](CQM_理论动画_组件库规划.md) 同名同参：
`NodeGraph.draw(svg, {nodes, edges, growth, lockState})`、`CameraRig.viewBox({x,y,w,h})`（对 viewBox 做补间即得推拉摇移）。

## 五、提示词规范（可直接复用）

### 5.1 系统约束（每次生成都带上）

```text
你在做一支【视频】，不是网页、不是幻灯片、不是可滚动长图。
硬约束：
1) 单文件 HTML，双击即播；无外链、无 CDN、无构建步骤。
2) 全片由代码绘制：图形与文字都不许用位图；不许出现翻页角标、页码、卡片阴影、满屏项目符号。
3) 画面必须有镜头语言：每个镜头写明景别、机位运动、焦点、时长；相邻镜头用同一对象的形变交棒。
4) 一个镜头只跨一个抽象层级，最多一次缩放。
5) 确定性：固定 fps 与虚拟时钟，支持 ?t=秒 定格；同一代码两次渲染逐帧一致。
6) 文字少而大：全屏同时出现的中文字符 ≤ 40 个；字幕在安全区内。
7) 提供键盘调试：空格暂停、←→ 逐镜、D 切换深度层。
8) 若涉及状态标识，严格使用给定 tokens（颜色＋形状双编码），不得自创颜色。
```

### 5.2 镜头描述语法（写分镜就用这个句式）

```text
S21 | 03:52–04:05 | 近景推轨 | 机位：#4 单纯形右前 45°，向顶点 v 推进 0.8 单位 | 焦点：角亏楔形由暗转亮
     | 交棒：楔形的开口在下镜变为时钟刻度 | 旁白：质量让角亏出现——不是力，而是几何的凹凸。
```

### 5.3 反例清单（出现即重做）

- 「页面淡入淡出」「滚动到下一屏」「卡片依次弹出」。
- 用 `background-image` 贴一张「宇宙／神经／量子」素材。
- 同一画面出现 >3 个主色，或状态色被当装饰色铺满。
- 公式以图片形式出现，或一行超过 2 个等式。
- 用「推镜头」表达情绪却不改变信息层级（无目的运镜）。

## 六、CQM 专属约束（凌驾于任何视觉炫技）

1. **状态永远双编码**：颜色 ＋ 形状（金环＝公理／青三角＝推导／琥珀断环＝待推／白方框＝外部／紫虚线＝哲学）。风格换肤时形状不变。
2. **每条上屏主张必须可回指**：Track 0 的 `data-claim` 与 `claims.yaml` 对账，缺 `claimIds` 的镜头不允许出片。
3. **琥珀措辞 lint**：琥珀镜头旁白禁止「证明／已证／确定／彻底解决」；只允许「框架内构造／待推／缺口／构造后验数字校验，待独立复现」。
4. **「旁白」一词的口径**：全项目「旁白」一律指**屏上文字**（字幕与标题），**不指配音**；人声（含 TTS、含气息）全片禁用。声音只做两件事——标记结构、映射数值。
4. **不画推力**：引力只以「角亏—固有时流速—光路偏折」表达。
5. **不画平滑同步**：同步必须是一次事件（0.6 s 硬锁定），不允许渐变色过渡。
6. **数值纪律**：主片不出现 $G_N$、$\alpha$ 数值；需要时进深度层并带限定语。
7. **AI 生成物不入主视觉**：模型可以写代码、可以出分镜，但最终画面必须是可复现的程序化图形，不接受生成式位图。
