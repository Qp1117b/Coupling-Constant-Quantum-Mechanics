## 二、v1 的问题与 v2 的呈现层

v1 的验收集中在公式对不对、口径有没有踩红线、排版有没有重叠，没有验「画动不动」。对 v1 成片按秒抽帧做帧差，结果是：全片相邻秒帧平均绝对差 **0.39／255**，中位 0.05，**86% 的秒级帧近乎完全静止**；60–120 s 段更高达 93%。实际观感是会淡入的静态矢量板书，不是动画。

v2 不动内容层，重写呈现层：

| 层 | v2 的实现 |
|:---|:---|
| 全屏流场 | 96 个确定性粒子（带速度尾迹、闪烁）＋ 6 条随时间形变的正弦波纹 ＋ 呼吸径向光晕；任何时刻都在动 |
| 镜头 | 六段各三拍推进（前 38% 推、中 20% 停、后 42% 再推），缩放 0.986→1.128；叠加 0.0075 幅呼吸、0.30° 微旋、±9 px 漂移。字幕与刻度尺在镜头外，保持固定 |
| 转场 | 段边界 ±0.85 s 的光帘横扫＋轻闪；常驻扫描带每 9 s 扫过全屏 |
| 演算脉冲 | 24 个 `OPS` 刻度各触发一次扩散圆环，与 `SCORE` 事件时刻同源，使节奏起伏可指认 |
| 动态排版 | 字幕主行滑入＋淡入、副行延迟 0.10 s、徽章入场、段标呼吸、字幕色条展开 |
| 局部形变 | 段 1 网格漂移、段 3 槽位浮动、段 5 楔形脉动、段 6 四层错相浮动；只改 `transform`，不碰原有 `opacity` 时间窗 |

**实测（同一口径：成片按 1 fps 抽帧、缩到 160×90、逐帧平均绝对差）**：

| 版本 | 0–12 s 均值 | 中位 | 静止帧（差 < 1.0） |
|:---|:---|:---|:---|
| v1 | 0.42 | 0.30 | 91% |
| v2 | **3.73** | **4.13** | **0%** |

短片提升 **9.0 倍**；全片 180 s 复测为 v1 **0.39** → v2 **3.86**（**10.0 倍**），静止帧 **86% → 1%**，六个 30 s 分段均值落在 3.61–4.04，没有静止段。背景元素一律压在内容层之下或字幕层之下，抽帧目视确认不遮挡公式、徽章与琥珀限定语。

声场沿用 v1 已验收的母带：`SCORE` 与 v1 **逐字节一致**，未加人声、旋律或 riser；新增的是与 `OPS` 对齐的视觉脉冲，不是新的音型。`CAPS`／`SEGS`／`OPS`／`SCORE` 四张表均通过逐字节比对，46 条字幕的禁用词 lint 命中 0。
