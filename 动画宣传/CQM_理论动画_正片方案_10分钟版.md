## 一、先定「不空洞」的硬标准

一条镜头能不能进片，用下面四条判据，缺一条即打回：

| 判据 | 含义 | 反例（现有样片的病） |
|:---|:---|:---|
| **① 有对象** | 画面里必须有一个能被指认的数学对象：矩阵、谱、曲线、角、向量、公式 | 一片"物质纹理"在起伏——指不出是什么 |
| **② 有操作** | 该对象必须被**操作**：相乘、求谱、取值、随参数变形、比较两条曲线 | 光点从天上落下——没有运算 |
| **③ 有数值** | 每 15 s 至少一次显式数值或符号变化（数字、谱线位置、角度值、量级） | 自始至终没有一个数字 |
| **④ 有后果** | 讲完必须给出一个可检验／可对比的后果，或明确标"这是待推" | 转完就切下一幕，观众不知道所以要说什么 |

**三拍法**（每章固定节奏）：

```
现象（30%）→ 结构（45%）→ 后果（25%）
   你看到什么      它由什么决定      所以能预测/对比什么
```

**密度指标**：每章（约 66 s）至少 4 个"可指认对象"，其中 ≥1 个是**公式**、≥1 个是**数值**、≥1 个是**结构关系**（矩阵/谱/层级）。全片 9 章合计 ≥36 个对象，不允许重复凑数。

## 三、每章怎么写（模板 + 章 6 示例）

```yaml
chapter: 6
title: 角亏如何变成钟慢
duration: 78
beats:
  - {t: 0,  kind: 现象,  shot: "同一枚钟，放在晶格平坦处与顶点旁，10 s 内走出不同秒数"}
  - {t: 18, kind: 结构,  shot: "角亏楔形张开，δ_v 从 0 爬到 0.10（数字实时显示，旁标「β 待推」）"}
  - {t: 34, kind: 运算,  shot: "旁挂曲线 v_τ = √(1-βδ_v)：先画 β 未定时的「一族曲线」，再固定一个 β 作示例；小角亏处切线斜率 −β/2 可见"}
  - {t: 52, kind: 后果,  shot: "两枚钟的秒针并排：一快一慢，差值随时间线性累积（斜率含 β，标「形状确定／系数待推」）；再切到光线偏折"}
  - {t: 68, kind: 边界,  shot: "G_N 的因子式逐项拆开，右下角徽章转琥珀，附限定语"}
audio: [delta-tone@0.10, curve-tick x12, clock-drift, badge-chime]
claim: ["C08（角亏调制固有时流速）", "构造后验数字校验，待独立复现"]
```

**关键约束**：`运算` 节拍必须让观众看到"代入数值 → 得到结果"的过程，不能只画箭头。这是与"空洞动画"的分水岭。

## 四、声音设计（有声 · 无人声）

### 4.1 三层结构

| 层 | 作用 | 频段 | 触发 | 示例 |
|:---|:---|:---|:---|:---|
| **底床（bed）** | 维持"同一世界"的连续感 | 40–120 Hz 极低正弦 + 极轻粉噪 | 全程，随章切换微调基频 | 章 2 基频 55 Hz；章 5 降到 41 Hz（更"深"） |
| **结构音（structure）** | 把**数值**变成听觉 | 220–1200 Hz | 每次数值变化 | $\delta_v$ 每 +0.01 发一个短音，音高线性映射 |
| **事件音（event）** | 标记**突变** | 全频段 | 锁定、剪枝、谱线点亮、徽章切换 | 相位锁定＝一次 880 Hz 短脉冲 + 金属尾音；剪枝＝一次噪声爆破被瞬间掐断 |

### 4.2 映射规则（必须写死，不许随手配）

| 视觉量 | 声音映射 | 理由 |
|:---|:---|:---|
| $v_\tau$（0.98–1.00） | 连续正弦，频率 440→430 Hz 随其下降 | 钟慢要"听得出"变低 |
| $\delta_v$（0→0.2） | 每 0.01 一个脉冲，间隔随值缩短 | 数值增长＝密度增长 |
| 谱线 $\{9,4,1\}$ | 三条纯音，频率比 9:4:1（180/80/20 Hz 的八度折叠） | 谱的比例关系直接被听见 |
| 分支剪枝 | 每剪掉一层，噪声层减少一道 | "变少"可听 |
| 缺口徽章 | 一个不解决的挂留和弦（suspended） | 悬而未决 = 待推 |

**禁止**：旋律化配乐、鼓点、上升音效堆叠、人声（包括 AI 配音）。声音只做"信息的第二通道"。

### 4.3 技术实现

- **Web Audio 离线渲染**：所有音效由 `OfflineAudioContext` 在页面内合成（正弦、噪声、包络），导出 WAV；与画面同一份状态数据驱动（`SHOTS[].audio`），保证事件对齐。
- **同步基准**：音画共用同一个虚拟时钟；音频以 48 kHz 采样，画面 60 fps，帧→样本换算 `sample = round(t*48000)`。
- **交付**：AAC-LC 48 kHz 立体声 192 kbps（B 站规范）。

## 五、10–11 月参考：借什么、不借什么

| 参考 | 时间 | 借 | 不借 |
|:---|:---|:---|:---|
| **Claude Motion（Anthropic 官方，beta）** | 2026-10-08 | "动画即代码"的确定性：改一个数/一个词，其余帧不动；导出 MP4 的工作流 | 它官方只做 15–45 s 短片、**且明确无声**；10 分钟长片不能照它做，必须自建时间轴与音频层 |
| **HyperFrames（HeyGen 开源）/ Remotion** | 2026-10 | 组件化时间轴、HTML/CSS 即画面、可复现渲染 | 不引入重型 Node 构建链（我们的 Track 0 单文件更利于审计） |
| **67.js + Zeno 悖论 3D** | 2026-11-10 | **连续无限缩放**作为叙事骨架（指纹→细胞→原子） | 不追求写实 3D；CQM 的画面必须可审计（矢量、可复现） |
| **3b1b / Manim 传统** | 长期 | 公式逐行推导、几何直觉、密度 | 不让公式独占叙事 |

## 七、技术规格（682 s 可渲染）

| 项 | 取值 | 说明 |
|:---|:---|:---|
| 结构 | 9 个章节模块，共用一个 `tokens` 与 `timeline` | 单 HTML 过大；建议 `ch01.html`…`ch09.html` + `player.html` 顺序播放 |
| 渲染 | Canvas 2D 为主（比 SVG DOM 快 3–5×），SVG 仅用于公式排版 | 682 s × 60 fps = 40,920 帧，SVG 逐帧截图约 2 h；Canvas + JPEG 中间帧可压到 ~40 min |
| 帧率 | 预览 30 fps / 交付 60 fps | 交付 60 fps 保证相位环与脉冲顺滑 |
| 音频 | OfflineAudioContext → WAV → 与视频合成 | 事件由同一 `timeline` 驱动 |
| 输出 | 1920×1080 60 fps，H.264 High，≤14 Mbps，AAC 192 k | B 站规格 |
| 渲染纪律 | 分章渲染、断点续渲（已存在帧跳过） | 避免一次性 2 h 失败重来 |
| 中间文件 | 渲染完立刻移出工作区 | 上次 1350 帧把 C 盘写备份撑爆，教训在此 |
