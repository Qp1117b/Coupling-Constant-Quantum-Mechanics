## 二、编码参数（B 站规范逐项对齐）

| 项 | 取值 | B 站要求 | 判定 |
|:---|:---|:---|:---|
| 容器 | MP4（`+faststart`） | MP4 / FLV / MKV / MOV / WEBM / TS | ✅ 最稳 |
| 视频编码 | H.264 **High** profile，level 4.2 | H.264 首选 | ✅ |
| 分辨率 | 1920×1080（整数标准尺寸） | 480p–4K，禁非标准尺寸 | ✅ |
| 帧率 | 60 fps（整数） | 24/25/30/50/60，禁 29.97/59.94 | ✅ |
| 码率 | 5.5 Mbps（上限 14 Mbps 封顶） | 1080p60 ≤ 15 Mbps | ✅ 留足余量 |
| 关键帧 | 每 120 帧（2 秒）固定，关场景切换 | 建议 GOP=2 s | ✅ |
| 像素/色彩 | yuv420p · BT.709 · TV range | BT.709 SDR | ✅ |
| 音频 | AAC-LC 48 kHz 立体声 | AAC-LC 44.1/48 kHz，≤320 kbps | ✅ |
| 封面 | 1146×717 PNG | 推荐 1146×717 | ✅ |

**关于 5.5 Mbps**：这支片是深色底 + 矢量线条与字幕，x264 在 ABR 11 Mbps 目标下把量化参数压到极低（近视觉无损），实际只需 5.5 Mbps。码率不是"压低了"，而是这类画面本身就没有更多细节可编码；B 站转码后 1080P 档位不会因此降级。

## 三、内容结构（22.5 s）

| 时间 | 镜头 | 内容 | 状态徽章 |
|:---|:---|:---|:---|
| 0:00–0:06 | S01 拆舞台 | 网格溶解成节点网络，镜头拉远 | 白方框「外部直觉」 |
| 0:06–0:13.5 | S02 耦合空间 | 常数光点落入流形，相位环在曲面上亮起，☯ 浮现 | 金环「框架公理」 |
| 0:13.5–0:15.5 | S03-a 各走各的 | 八个相位环相位各异 | 青三角「框架内推导」 |
| 0:15.5–0:18.5 | S03-b 锁定 | 0.6 s 硬锁定 + 金色扩散环，脉冲沿 4-单纯形边传播 | 青三角「框架内推导」 |
| 0:18.5–0:22.5 | S03-c 角亏 | 顶点金色缺角亮起，时钟指针变慢 | 金环「框架公理」 |

**口径自检**：
- 全片无 $G_N$、$\alpha$ 数值，无"已证明"字样；
- 引力只用「角亏—固有时变慢」表达，无推力箭头；
- 同步是 0.6 s 事件，不是渐变；
- 深度层（`D` 键）只给 $☯$ 与 $v_\tau=\sqrt{1-\beta\delta_v}$ 两个式子，且标"框架内定义／FG 侧固有时流速"。

## 四、投稿建议

- **分区**：科技 → 科学科普（或"物理"）；标签：`理论物理`、`量子力学`、`科普动画`、`编程动画`。
- **简介**：可写「用代码逐帧渲染的理论动画样片，一支片讲三层：拆掉'时空是舞台'的直觉 → 常数是耦合空间的坐标 → 同步是事件、引力是固有时场的几何。所有主张与状态徽章对应原文，未闭合处保留标记。」
- **上传后**：在网页端把清晰度选项确认出现「1080P60」；若只到 720P，多半是上传时开了"智能压缩"，需在高级设置里关闭后重传。
- **竖屏切片**：S03-b（锁定）与 S03-c（角亏）可各切 6 s 竖屏，按 9:16 重新排版字幕（不要直接裁 16:9）。

## 五、改片与重渲

```bash
# 1) 改文案/时序/配色：只改 CQM_动画样片_Track0_三镜头.html
#    - 文案与分段：SHOTS[].cap 与 SHOTS[].sub[{t,cap,badge}]
#    - 镜头时长：SHOTS[].dur（总时长自动重算）
#    - 配色与字体：文件顶部 <style> 与 tokens

# 2) 逐帧渲染（本机 Edge headless + CDP，无外部依赖）
python .workbuddy/tmp/render_frames.py --fps 60 --w 1920 --h 1080 --out .workbuddy/tmp/frames

# 3) 编码（ffmpeg 来自 imageio-ffmpeg）
ffmpeg -framerate 60 -i frames/f%05d.png -i audio.m4a \
  -c:v libx264 -profile:v high -level 4.2 -pix_fmt yuv420p -preset slow \
  -b:v 11M -maxrate 14M -bufsize 22M -g 120 -keyint_min 120 -sc_threshold 0 \
  -color_primaries bt709 -color_trc bt709 -colorspace bt709 \
  -c:a aac -b:a 192k -ar 48000 -ac 2 -shortest -movflags +faststart out.mp4
```

**渲染纪律**：改一处只重渲一次，不做"再生成一遍看运气"；每一版都保留 `SHOTS` 与文案的 diff，便于回溯。
