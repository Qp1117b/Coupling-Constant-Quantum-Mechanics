# 章 6 音效事件表 · 无声解说 / 有声信息

> **原则**：没有配音、没有配乐、没有鼓点。声音只做两件事——**标记结构**（这件事发生了）与**映射数值**（这个数变了多少）。关掉声音画面成立；打开声音，信息多一层。

## 一、三层

| 层 | 频段 | 增益 | 职责 | 触发 |
|:---|:---|:---|:---|:---|
| 底床 bed | 40–120 Hz + 粉噪（低通 400 Hz） | −32 dB | 维持"同一世界"的连续感 | 全程 |
| 结构音 structure | 220–1400 Hz | −24 dB | 把**数值**变成音高 | 数值变化 |
| 事件音 event | 60–3000 Hz | −18 dB | 标记**突变** | 入场、取到、塌陷、落框 |

底床换频是唯一允许的"段落标记"：6A 用 **55 Hz（A1）**，70 s 处降到 **41.2 Hz（E1）**——下潜到量纲层，用耳朵提示"进了更基础的一层"。

## 二、映射规则（写死，不许临场配）

| 视觉量 | 声音规则 | 参数 |
|:---|:---|:---|
| $\delta_v$ 每 +0.01 | 短脉冲，音高随序号上移 | $f=220\times1.02^{n}$ Hz，时长 40 ms，指数衰减，$\tau=12$ ms |
| $v_\tau$ 曲线描线 | 连续正弦，随描线进度降频 | 440 → 430 Hz（对应 $1\to0.9487$ 的可听区间折叠） |
| 数字逐位落定 | 每位一个 tick，高位低、低位高 | $f=880-60k$ Hz（$k$ 为从高位数起），30 ms |
| 乘法链每节 | 五度叠置 | 220 + 330 Hz，80 ms，衰减 $\tau=40$ ms |
| 七格落位 | **按参数数值**定音高，不按音阶 | $f=180+40\log_{10}(\lvert\text{值}\rvert)$ Hz，见下方说明 |
| 逐位比对 | 重合位 tick / 第 6 位起微失谐 | 1200 Hz ／ 1300 Hz（失谐 +3 cent） |
| 缺口徽章 | 挂留和弦，不解决 | A2+C3+E3+sus4，衰减 4 s 至片尾 |
| **演算行写入（v3.0）** | 每个写入行一个 tick，**音高按行的作用分三档**：锚点行低／中间量行中／结果行高 | 锚点 220 Hz／中间量 330 Hz／结果 440 Hz，40 ms，指数衰减 $\tau=12$ ms |
| **一次代入（v3.0）** | 短促带通噪声（“替换”感），与普通 tick 区分 | 1.2–2.6 kHz 带通，120 ms，−24 dB |
| **设定标记出现（v3.0）** | 一声**不着落**的短音（无衰减尾），标出这一步没有推导 | 1.8 kHz 正弦 60 ms，无 decay 尾，−26 dB |

**七格为什么不能听成旋律**：七格间隔取 0.7 s 但**不等长**（第 6 格提前 0.2 s 落，因为它异质），且音高由 $\log_{10}|\text{数值}|$ 决定而非音阶，相邻两格常构成不协和音程（如 200.04 与 1.316 相差两个八度以上）。这是 sonification，不是旋律。

**演算声为什么必要（v3.0）**：「演算行写入」的三档音高让观众**不看画面也能听出这一行是中间量还是结果**——这是「关掉声音画面成立、打开声音信息多一层」的可检验版本。**设定标记**的那声「不着落」的短音是**诚实性的听觉标记**：观众听得见这一步没有推导。

## 四、合成规格

| 项 | 值 |
|:---|:---|
| 采样率 | 48 kHz |
| 渲染 | `OfflineAudioContext(2, 160*48000, 48000)`，页面内一次性渲染 |
| 波形 | 正弦（bed/structure）、白噪经带通（event）、无锯齿波（避免刺耳） |
| 包络 | 全部 ADSR 简化：attack 5–20 ms，decay 指数，无 sustain（除底床） |
| 声像 | bed 居中；structure 按画面 x 坐标映射到 ±0.25；event 居中 |
| 母带 | −16 LUFS，真峰值 ≤ −1 dBTP |
| 编码 | AAC-LC 192 kbps，48 kHz，立体声 |
| 帧对齐 | `sample = round(t × 48000)`，与 60 fps 的帧号严格换算，禁止手动微调 |

## 五、禁项

1. 人声（含 TTS、含气息）。
2. 旋律化旋律线、鼓组、节奏型。
3. "上升音效"（riser）——它暗示期待，而本章的落点是限定语，不是高潮。
4. 音乐化和弦进行（除片尾那一个挂留和弦，且它必须**不解决**）。
5. 与数值无关的随机音效（"听起来热闹"不算设计）。
