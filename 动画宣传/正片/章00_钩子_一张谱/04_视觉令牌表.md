# 章 0（钩子）视觉令牌表

> **继承**：`正片/章06_从角亏到GN/04_视觉令牌表.md` 的色彩、字体、字号、网格、线条、徽章、缓动、红线**全部沿用**，本文只写本章新增项与覆盖项。两者冲突时以本文为准（仅限章 0）。

## 一、覆盖：演算版面（v4 新增）

| 区域 | 范围 | 用途 |
|:---|:---|:---|
| 公式带 | y 110–520（上 38%） | 本步的式子常驻；换步时旧式**不下移**，只压暗至 40% 留在原位 |
| 图形带 | y 540–940（中 52%） | 矩阵、谱轴、比对条 |
| 徽章带 | y 950–1010（底 10%） | 徽章 + 限定语（本章字幕带并入此带，不单独占行） |

**为什么覆盖章 6 的「公式区右栏」**：本章的叙事是**一条式子的连续变形**，公式必须居中且与图形上下对齐；把公式塞进右栏会让「代入」无处落格。章 6 是并置叙事，与此不同，两者不通用。

## 二、新增令牌

| 令牌 | 值 | 用途 |
|:---|:---|:---|
| `--cell` | `#1A2430` | 矩阵空格 |
| `--cell-on` | `#7FB2F0`（8% 填充） | 已点亮格 |
| `--cell-off` | `#2A3441` | 消去后的格（只留边框，不填） |
| `--block-1` | `#5EEAD4` | 谱线组 $\lambda=9$（对应 SU(3) 色） |
| `--block-4` | `#7FB2F0` | 谱线组 $\lambda=4$（对应 SU(2) 弱） |
| `--block-5` | `#E8814A` | 谱线组 $\lambda=1$（对应 U(1) 电磁） |
| `--axis` | `#93A3B3` | 谱轴轴线、刻度 |
| `--trace` | `#5C6B7A` | 迹条件的辅助计数线 |

**颜色纪律（本章）**：青＝$\lambda=9$／SU(3)、蓝＝$\lambda=4$／SU(2)、橙＝$\lambda=1$／U(1)。三色**在谱线与扇区标签两处必须完全一致**——这是本章唯一的跨镜连续性，也是「这不是随便上色」的证据。

**不做的分色**：矩阵元素**不按谱分色**。$1\oplus4\oplus5$ 是表示论分解，在边基下不对应坐标分块；给矩阵上三色即暗示「这三块各自独立」，是造假。矩阵只用 `--cell-on` 单色。

## 七、缓动

| 场景 | 曲线 |
|:---|:---|
| 格点亮 | `ease-out-expo` 60 ms |
| 数字落位 | `ease-in-out` 120 ms，末两帧 y +1 px 回 0 |
| 块消去 | `drop` 0.5 s，错峰 0.08 s |
| 谱线弹出 | `ease-out-expo` 0.35 s |
| 比对推入 | `linear` 0.9 s（匀速才像「逐位核对」） |

**禁令**：不做「数字滚动特效」（那是猜数，不是算数）；数字必须**逐位落定**，落定后不动。

## 八、红线（本章追加）

1. 矩阵、谱轴、比对条三者不得同屏挤压：同屏最多两类。
2. 谱线不得连成曲线（$9,4,1$ 是离散谱，画成曲线即误导）。
3. 扇区颜色不得与块颜色错位。
4. 比对条禁止只显示「差 0.16%」而不显示两排数字。
5. `--foil`（$☯$ 专用色）**本章一次都不许出现**。
