# 章 0（钩子）音效事件表 · 无声解说 / 有声信息

> **原则**：没有配音、没有配乐、没有鼓点。声音只做两件事——**承载运算**（这一步在算什么）与**映射数值**（这个数变了多少）。关掉画面，仅凭声音应能听出「在代入、在分块、在求根」。
> **本章新增第四层 `op`（演算层）**：它不描述气氛，只描述动作类型；同一动作在全片任何位置声音一致。

## 一、四层

| 层 | 频段 | 增益 | 职责 | 触发 |
|:---|:---|:---:|:---|:---|
| 底床 bed | 40–120 Hz 正弦 + 粉噪（低通 400 Hz） | −32 dB | 维持「同一世界」 | 全程 |
| **演算层 op** | 200–2600 Hz | −22 dB | **标记运算类型** | 每个 `op` 起止 |
| 结构层 structure | 220–1400 Hz | −24 dB | 把数值变音高 | 数值变化 |
| 事件层 event | 60–3000 Hz | −18 dB | 标记突变与边界 | 落定、分块、徽章 |

底床在本章**只用一个基频 55 Hz（A1）**，不做换频——90 秒太短，换频会打断「一次连续演算」的印象。片尾（89.4）底床随全静默一同切断。

## 二、音型库（本章用到六种）

| `op` | 音型 | 参数 |
|:---|:---|:---|
| `substitute` | 带通噪声 120 ms + 落定 tick | 1.2→2.6 kHz 扫描；tick 880 Hz 30 ms，−22 dB |
| `set`（陈述／设定） | **不着落**的短音 | 1.8 kHz 正弦 60 ms，无衰减尾，−26 dB |
| `solve` | 三连收敛 tick | 660 Hz，间隔 0.40／0.25／0.12 s，各 40 ms，指数衰减 $\tau=12$ ms |
| `expand` | 宽带上行 | 500→1200 Hz 带通，0.8 s，−26 dB |
| `compare` | 逐位 tick（小数第一位起失谐） | 1200 Hz → 1300 Hz（+3 cent），30 ms |
| `gap` | 挂留和弦，不解决 | A2+C3+E3+sus4，衰减 4 s，−24 dB |

## 三、映射规则（写死，不许临场配）

| 视觉量 | 声音规则 | 参数 |
|:---|:---|:---|
| 矩阵 100 格逐个点亮 | 每格一声落格 tick，音高按**生成序**微升 | $f=180+2n$ Hz（$n=0..99$），18 ms，−30 dB |
| 行和 10 个 `9` 亮起 | 每行一声 tick，10 行依次；全部亮完再一记落定 | 520 Hz，0.12 s 间隔；落定 880 Hz |
| 陈述卡（表示论分解） | `set`：**不着落**的短音 | 1.8 kHz，60 ms，无尾 |
| $\lambda_1=9$ 逐位落定 | 每位一 tick，高位低、低位高 | $f=880-60k$ Hz（$k$ 从高位数起），30 ms |
| 迹条件 30 / 150 | 各一次上行带通 + 一次落定 | `expand` 0.8 s ＋ tick 440 Hz |
| 联立求解 | `solve` 三连，第三次最轻（表示「解出」而非「结束」） | 660 Hz，增益 −24／−23／−22 dB |
| 谱线 10 条 | 三条带各一个基频，重数＝同频重复次数 | 9 → 660 Hz（1 次）；4 → 440 Hz（4 次）；1 → 220 Hz（5 次）；每次 50 ms，间隔 0.18 s |
| 逐位比对 | 重合位 tick / 小数第一位起失谐 | 1200 Hz ／ 1300 Hz（+3 cent） |
| 琥珀徽章 | 挂留和弦，不解决，持续到片尾 | A2+C3+E3+sus4，衰减 4 s |

**为什么谱线要重复同频**：$9$ 出现 1 次、$4$ 出现 4 次、$1$ 出现 5 次——**重数直接被听见**。这比在画面上标「重数 1/4/5」更可靠，因为观众不需要读字。

## 五、合成规格

| 项 | 值 |
|:---|:---|
| 采样率 | 48 kHz |
| 总样本 | 4 320 000（90.0 s） |
| 渲染 | `OfflineAudioContext(2, 4320000, 48000)`，页面内一次性渲染 |
| 波形 | 正弦（bed／structure）；白噪经带通（event／op）；**无锯齿波** |
| 包络 | ADSR 简化：attack 5–20 ms，指数 decay，无 sustain（除底床） |
| 声像 | bed 居中；structure 按画面 x 坐标映射 ±0.25；op 居中；event 居中 |
| 母带 | −16 LUFS；真峰值 ≤−1 dBTP |
| 编码 | AAC-LC 192 kbps，48 kHz，立体声 |
| 帧对齐 | `sample = round(t × 48000)`；与 60 fps（帧号 = $t\times60$）严格换算，禁止手调 |

## 六、盲听验收（G3 门禁）

**做法**：截取 22.0–32.0（行和＋陈述卡）与 56.0–66.0（联立）两段，各 10 s，去掉画面给 5 名未看过的人听，问「刚才更像是在**数同一个值**还是在**解方程**」。

**通过线**：5 人中 ≥3 人答对（两段合计正确率 ≥60%）。

**不通过的处理**：先改音型（`expand` 与 `solve` 的音区必须拉开——现在 500–1200 Hz 上行对 660 Hz 短 tick，若辨析失败，把 `solve` 压到 300–380 Hz 并在每次 tick 前加 20 ms 静默），不动画面。

## 七、禁项

1. 人声（含 TTS、含气息）。
2. 旋律化旋律线、鼓组、节奏型。
3. 「上升音效」（riser）。
4. 与数值或动作无关的随机音效。
5. 用音乐掩盖静默：本章静默总长 1.9 s（含片尾 0.6 s），不得减少。
