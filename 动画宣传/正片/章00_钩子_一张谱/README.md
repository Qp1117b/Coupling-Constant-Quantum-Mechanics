# 章 0 · 钩子「一张谱」（90 s）

方案 v4（`动画宣传/CQM_理论动画_方案v4_演算驱动与声化.md`）的 S0 阶段。全片第一章，任务只有一个：**在 90 秒内证明这套理论能算**——不铺概念，直接对 $10\times10$ 矩阵求谱。

| 文件 | 作用 |
|:---|:---|

## 打开方式

浏览器直接打开 `00_原型_一张谱.html`。

- 空格：播放／暂停（首次播放会先离线合成 90 s 音轨，约 1–2 秒）
- ←／→：±0.1 s；按住 Shift ±1 s
- 底部色块：跳到各镜起点
- `?t=62`：定位到 62 s；`?raw=1`：隐藏控制条、满幅 1920×1080 出图
- `?probe=1`：探测音轨建图（左上角显示 `GRAPH_OK`）

## 与方案的关系

本片不含解说、不含配乐；声音由四层组成：底床（55 Hz）、**演算层**（动作类型音型）、结构层（数值→音高）、事件层（突变与边界）。谱线的重数直接用同频重复次数表达——$9$ 响 1 次、$4$ 响 4 次、$1$ 响 5 次。
