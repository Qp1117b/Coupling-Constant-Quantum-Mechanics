# 元理论反思 · 类型论基础

> 目标：把 CQM 的**命题层**、**缺口层**与**量纲发生学链**放入类型论框架，给出与 Lean 形式化（`08 理论组织和形式化框架/04_Lean对接/Lean源码/`）一致的元描述。
> 本文件只作结构设计，不新增物理主张；缺口编号与状态保持原样。

## 一、命题即类型（Curry–Howard）

CQM 形式化层满足 Curry–Howard 对应：

| 逻辑/数学侧 | 类型论侧 | CQM 载体 |
|:---|:---|:---|
| 命题 | 类型 $P:\mathrm{Prop}$ | 命题表 63 条 |
| 证明 | 项 $p:P$ | Lean 中 `theorem`/`lemma` 的证明项 |
| 假设 / 公理 | 未给项的常项（`axiom`） | H3.1–H3.3、素数冻结、Tate 自对偶 |
| 缺口 | **未闭合目标**（open goal / metavariable） | C、G2–G8、G9–G22、N1–N4 |
| 复合推理 | 函数应用 / `let` 链 | 论证表的有向边与超边 |

> 缺口在类型论中不是"假命题"，而是**尚无项的类型**。将缺口改写为"已证"等价于非法地用 `axiom` 冒充项——违反项目红线"不欺骗"。

## 二、关系类型作为类型构造子

论证表的六类关系对应类型构造子：

| 关系 | 类型论读法 |
|:---|:---|
| 演化 `→` | 一元函数 $c_1\to c_2$ |
| 映射 `→` | 保持结构的函数（同态） |
| 等价 `↔` | 同构 $c_1\cong c_2$（同一对象的两种呈现） |
| 依赖 | 单向蕴含 $c_2\to c_1$（单向推论） |
| 层级含于 | 子类型的嵌入 $\iota:\mathrm{GL}(n)\hookrightarrow\mathrm{Diff}(M)\hookrightarrow\mathrm{Sym}(M)$ |
| **重组实现 `⇒`** | **多参（依赖）函数类型** $(c_1,\dots,c_n)\to c$，即多范畴的多元态射 |

`⇒` 的类型不能写成普通 $\prod$（单参）而不丢失"多因一果"的结构；它对应多范畴/操作范畴（operad）中的 $n$ 元操作。

## 三、量纲发生学链的类型化

量纲发生学（`01 核心理论/CQM_核心_量纲与群论.md` §6）可读作**逐层附加单位的依赖链**：

```
无量纲  ──K_L──▶  L  ──K_M──▶  M  ──K_Q──▶  Q  ──K_Θ──▶  Θ  …  ──K_J──▶  J
```

类型论骨架（示意，非 Lean 源码）：

```text
-- 无量纲耦合坐标
u : Coupling                      -- u = ln r
-- 每压掉一个量纲冒出一个特征常数 K，作为"单位构造子"
K_L : Coupling → Length
K_M : Length³/Time² → Mass        -- K_M = G_N⁻¹
K_Q : Mass^{1/2}·Length^{3/2}/Time → Charge
-- 自守形式 = 使两侧（时间侧 / 空间侧）相容的截面
automorphic : Fibration → Section
```

**要点**：$c$ 不出现在该链中——它是时空同步前沿速度，是两侧自守形式相容的**条件**（P004 / D009 §7.6），不承担量纲转换。这与 `03_超图与理论图/CQM_概念关系超图.md` §四一致。

## 四、自守形式作为截面

自守形式在 CQM 中的地位（`01 核心理论/CQM_核心_共形场论与OPE.md`、`04 前沿研究/CQM_前沿研究_相变弧线与自守形式同步.md`）可读作**纤维丛的截面**：局部共形对称性与全局模对称性同步实现的截面。类型论上，它是
$$\Gamma\bigl(P\bigr)=\bigl\{s:B\to E \mid \pi\circ s=\mathrm{id}_B\bigr\}$$
的元素；在 $\mathbf{C}_{\mathrm{Lean}}$ 中对应一个被构造出来的项，其存在性即"同步成立"的证明（当前为待推项，不得冒充已证）。

## 五、"唯物主义类型论"的元立场

与 `01 核心理论/CQM_核心_唯物主义群论.md`（P006：群是物质自组织的组织约束体现）一致，本框架采取：

- 类型/命题**不是**先验柏拉图实体，而是物质自组织形成的**组织约束**在形式层的投影；
- 故类型论在此是**描述组织约束的工具**，其对象由发生学（前时空→GR→FG）定位，而非独立本体。

此立场是元理论陈述，不新增 CQM 论点，仅登记与现有唯物主义群论的一致性。
