## 已量化的源层缺陷（不遮掩）

| 缺陷 | 实测 | 处置 |
|:---|:---|:---|
| 命题之间**没有** claim 级边 | `depends_on` 原为 96×文档 + 3×缺口，0×命题、0×概念 | 已由 `命题依赖.csv` 补 291 条（含置信与方法） |
| 缺口依赖只在 .md 里 | 数据层原仅 3 条 | 已数据化为 `缺口依赖.csv`，并与闭包 §二 交叉核对 |
| 论证表文本与概念名不对齐 | 前件精确匹配 36%、后件 47%；**10/70 前件数与 ID 数不一致** | 已建 `论证对齐.csv` 与别名表，**如实登记不擅自统一** |
| `G` 前缀重载 | G001–G024 = 缺口，G025–G032 = 其他命题类型 | 已登记 `id_prefix_conflict`，**不擅自重编号**（重编号会牵动 Lean 映射与多处引用） |
| 语料覆盖偏科 | 52 篇中 21 篇零结构化条目 | 如实登记；抽取层的候选池为后续扩表提供入口 |
