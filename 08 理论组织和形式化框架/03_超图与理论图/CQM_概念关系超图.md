# CQM 概念关系超图

> 本文件汇总 CQM 活动文档的概念实体与关系三元组，供**有向超图**构建。
> 关系类型严格区分：`⇒` 仅表**重组实现**（多因一果，有向超边）；`→` 表破缺 / 演化 / 映射 / 极限；另含 `依赖`、`同源`、`等价`、`矛盾`、`层级含于`。
> 提取自活动文档全文，未引入理论外概念。缺口编号保留原样。

## 二、发生学主干（核心超边链）

```
(物质先在, 再生产幂等 μ²=μ) ⇒重组实现 (物质自组织)
(物质自组织) →演化 (质数自组织)
(质数自组织) →演化 (GL(5) 潜能先在)
(GL(5) 潜能先在, 同步算符) ⇒重组实现 (SU(5) 基态)
(SU(5) 基态) ⇒重组实现 (U(1)×SU(2)×SU(3))
(前核子自组织, 粗粒化) ⇒重组实现 (禁闭边界 4-单纯形 A₄)
(4-单纯形边-面结构) →映射 (M=EᵀE 本征值 {9,4,1})

(SU(5) 紧致部分) ⇒重组实现 (U(1)//Z_n 商结构) →映射 (α)
```

## 四、量纲发生学链

```
(质与质的关系) →演化 (量纲 T, L, M, Q, Θ, N, J)
(事件计数 / 固有时) →映射 (时间 T)
(无量纲耦合坐标 r_coupling) →映射 (物理长度 r_phys)（经 K_L）
(L³T⁻²) →映射 (M)（经 K_M, K_M=G_N⁻¹）
(M^{1/2}L^{3/2}T⁻¹) →映射 (Q)（经 K_Q）
(能量) →映射 (Θ)（经 K_Θ）；(无量纲计数) →映射 (N)（经 K_N）
(时间侧自守形式, 空间侧自守形式) ⇒重组实现 (c)
(自守形式) -[等价]-> (量纲间实现关系本身)
```
