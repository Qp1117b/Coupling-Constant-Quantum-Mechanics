    08 理论组织和形式化框架 · CQM 结构化形式系统¶

    将 CQM 自然语言理论文本重构为可计算、可推理、可验证的结构化形式系统。 七个维度（4 核心 + 3 辅助）：核心维度为结构化 → ML 数据准备 → 形式化验证 → 展示可视化；辅助维度为动态机制 → 经验检验 → 元理论反思。 外部理论文本（01–07）不动，本目录只存引用、锚点、结构化数据与形式化产物。 权威源：README.md 符号约定与数值表 > 一体化研究/附录/术语表.md > 一体化研究/附录/缺口台账.md > 各文档概念权威定义处。 顶层设计文档：设计方案.md · 建设报告：10_展示可视化/报告/建设报告.md AI 协作规范：AGENTS.md（七维度运行手册；在本目录内研究前必读）

    一、总原则¶

    • 外部理论文本不动：01–07 理论文档不修改，本目录只存引用与结构化产物。
    • 七个维度：四个核心（结构化 / ML 数据准备 / 形式化验证 / 展示可视化）+ 三个辅助（动态机制 / 经验检验 / 元理论反思）；展示可视化是核心维度，面向人呈现理论的可计算、可推理、可验证、可交互形态。
    • Lean 已有只对接，不重新形式化；ML 只做数据准备，不训练模型。
    • 不引入理论外观点、术语、数值、文献；缺口状态保持原样。

    四、图模型¶

    • 图类型：有向超图（directed hypergraph），已用 XGI 构建可计算对象；等价为多范畴（⇒ 为多元态射）。
    • 节点：82 个概念实体（12 类：本体论、理论框架、数学结构、群论、关系类型、引力层级、纤维丛、几何、量纲、数论、物理、共形场论）。
    • 超边 ⇒：19 条重组实现（多因一果），如 (物质先在, 再生产幂等) ⇒ (物质自组织)。
    • 有向边 →：51 条演化/映射/等价/依赖/层级含于。
    • 可视化：.dot（Graphviz 源，6 cluster）、.svg/.png（networkx 渲染）、超图可视化.html（Cytoscape.js 离线可推演超图：类型分簇布局、邻域聚焦、有向路径、派生级联回放、小地图、导出 PNG）。

    九、维护提示¶

    • 本目录随活动文档增改同步更新；缺口状态以 一体化研究/附录/缺口台账.md 与 Lean 模块为权威。
    • 标注"待独立复现"的 \(G_N\)、\(\alpha\) 类数值，不得改写为"已证明"。
    • 全部产物由 _build/ 内脚本从 01_结构化数据/*.csv 与 08 理论组织和形式化框架/04_Lean对接/Lean源码/ 源码可重复生成；重跑顺序：fix_csv → build_base → build_evidence → build_claims → build_ontology → build_kg → build_lean → build_ml → build_extract → build_dynamics → build_causal → build_bridge → build_site → build_search → build_reader_site → build_meta；收尾必跑 check_provenance.py 与 check_consistency.py。
    • 证据层规则：任何断言都必须能回溯到 00_外部引用/证据映射.csv 的一条记录（含字符区间与引文）；verified 只有人工复核后才能置 True；抽取产物（术语候选、关系候选、语义近邻）只能进候选池，不得直接写入概念表。
    • 交互式可视化在 03_超图与理论图/超图可视化.html 与 10_展示可视化/交互式可视化/超图交互.html 同步；重建后建议在浏览器中验看布局与派生回放（构建期仅有 HTML/JS 语法与 DOM 冒烟检查，不替代人眼验看）。
