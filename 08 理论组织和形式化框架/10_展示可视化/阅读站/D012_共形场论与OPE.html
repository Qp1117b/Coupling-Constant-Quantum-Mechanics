    CQM核心：共形场论与OPE——同步\(⊗\)耦合→群的数学基础¶

    作者：ruster

    概述¶

    CFT描述了临界自组织态扩大的机制，同时也是同步的过程机制。 自组织态是自组织的离散结果，不是自组织本身——自组织是过程，自组织态是该过程产出的离散结果。这不是类比，是数学上的精确等同。CFT（共形场论）不是一门深奥的玄学，它就是描述“一种态模式从触发点向全局无衰减蔓延”这套物理过程的数学语言。CQM里的“同步”——同一种态模式从局部扩展到全局——同步是事件，同步有过程（CFT的幂律传播 \(r^{-2h}\) 描述同步的过程），同步方程描述的是整个同步事件（过程被压缩，体现为定态）。

    共形自举（Conformal Bootstrap）本质是共形自洽。 “自举”的意思是：不靠实验输入任何数字，纯粹靠“逻辑上不能自相矛盾”这一条规则，把所有参数强行算出来。具体来说，自举的是结合律（Associativity）——你可以先配A+B得到C再配C+D，也可以先配B+D得到E再配A+E，两种配对顺序的结果必须完全一样。这个“无论怎么配对结果唯一”的条件叫做自举方程，它把耦合常数从自由变量压缩为唯一的离散解。在CQM中，这就是OPE的相容性条件，也就是Dirac条件的来源。

    “与能量无关”的含义：拉格朗日量里没有任何带量纲的参数（如质量\(m\)），且相互作用强度被锁死为确定的纯数字。没有质量尺子 = 没有特征长度 = 关联长度无穷大 = 标度不变 = 共形固定点（\(\beta(g)=0\)）。

    同步四阶段：FG纤维丛+同步方程+CFT = 同步预备+同步发生+同步过程+同步完成。同步预备（FG纤维丛：各种赝状态——曲率算符 \(\hat{\delta}_v\) 给出可能的同步模式，但还未同步）；同步发生（同步方程 \(\hat{\mathcal{S}}\Psi = n\Psi\)：共振量子化——什么样的态可以发生同步、同步成本多少）；同步过程（CFT：幂律传播 \(r^{-2h}\)——同步从触发点向全局扩大）；同步完成（状态跃迁——从未同步态跃迁到同步态）。共形自举是共形自洽条件（OPE结合律，静态条件）——配对顺序不影响结果，锁死结构常数。

    核心结论：CQM的三角结构（耦合常数↔同步成本↔紧致群）在共形固定点精确实现为CFT的OPE代数。共形自举方程（结合律）锁死耦合常数为离散值。元素FG的周期表第一性推导（Casimir→壳层容量、共形维度 \(h_{\rm shell}=n_{\rm pr}+l\)→Madelung规则、\(A_4\)→\(Z_{\max}=118\)）是CFT框架的三大应用成果。

    1. 从“与能量无关”到共形固定点¶

    1.1 判据¶

    “与能量无关”的判据：拉格朗日量里没有任何带量纲的参数，且相互作用强度被锁死为确定的纯数字。

    \[\mathcal{L} = \underbrace{(\partial\phi)^2}_{\text{动能}} - \underbrace{V(\phi)}_{\text{势能}}\]

    具体来说就是两条：

    1. 势能中禁止质量项 \(\frac{1}{2}m^2\phi^2\)：质量 \(m\) 自带固定能标，有 \(m\) 就有特征长度 \(1/m\)，标度不变性立即被破坏。所以 \(m=0\)。
    2. 耦合常数不跑动 \(\beta(g)=0\)：\(\lambda\phi^n\) 中的 \(\lambda\) 必须是无量纲纯数字，且量子修正严格为零，\(\lambda\) 不随能标流动。
    \[\boxed{\beta(g) = \frac{dg}{d\ln\mu} = 0 \;\;\Longleftrightarrow\;\; \text{没有质量尺子} + \text{耦合锁死为纯数字} \;\;\Longleftrightarrow\;\; \text{共形固定点}}\]

    没有质量尺子 = 没有特征长度 = 关联长度 \(\xi_{\rm corr} \to \infty\) = 标度不变 = 共形固定点。

    1.2 共形固定点的物理效应¶

    条件 物理效应 数学后果 势能中的表现
    \(\beta(g)=0\) 耦合常数不跑动 \(g\) 是固定纯数字 \(\lambda\phi^4\) 的 \(\lambda\) 锁死
    \(m \to 0\) 能隙消失，关联长度 \(\xi_{\rm corr} \to \infty\) 无特征尺寸 \(m^2\phi^2\) 项禁止出现

    1.3 普通微扰失效¶

    关联长度无穷大 \(\to\) 系统失去所有特征尺寸 \(\to\) 普通微扰展开（按 \(1/\xi_{\rm corr}\) 展开）严格发散。

    唯一替代工具：共形场论的OPE——不依赖特征尺寸，直接描述算符乘积的代数结构。

    1.4 \(\phi^4\)理论：维度依赖性的具体例子¶

    \(\phi^4\)理论在不同时空维度下的共形性：

    时空维度 \(d\) \(\phi\) 的标度维度 \(\lambda\phi^4\) 是否允许 \(\beta(\lambda)\) 是否CFT
    \(d=2\) \(\Delta_\phi = 0\) \(\phi^4\) 无量纲 \(\beta=0\)（经典精确） 是CFT
    \(d=3\) \(\Delta_\phi = 1/2\) \(\phi^4\) 有量纲 \(\beta \neq 0\)（但存在Wilson–Fisher固定点） 在固定点是CFT
    \(d=4\) \(\Delta_\phi = 1\) \(\lambda\) 无量纲 \(\beta(\lambda) = 3\lambda^2/(16\pi^2) \neq 0\) 不是CFT（耦合跑动）

    \(d=4\) 不是CFT的原因：虽然 \(\lambda\) 无量纲，但量子修正使 \(\beta(\lambda) \neq 0\)，耦合常数随能标跑动，标度不变性被量子涨落破坏。

    \(d=2\) 是CFT的原因：\(\phi\) 的标度维度为零，\(\phi^4\) 项无量纲，且 \(\beta(\lambda)=0\) 经典精确成立——没有量子修正破坏标度不变性。

    CQM的定位：CQM在共形固定点要求 \(\beta(g_k)=0\) 严格成立，对应 \(g_k = \alpha^{-1}\exp(-(n_k-n_1)/n_1)\) 是与能标无关的固定纯数字。

    2. 三角结构：CQM的CFT实现¶

    2.1 三大要素¶

    2.2 耦合常数：固定纯数字¶

    在共形固定点，\(g_k\) 不是随能标流动的变量。CQM中：

    \[g_k = \alpha^{-1}\exp\left(-\frac{n_k - n_1}{n_1}\right), \quad n_k \equiv C_k = l_k(l_k+1) + \frac{3}{4}\]

    \(g_k\) 由群论（Casimir本征值）唯一确定，是与能标无关的固定纯数字。

    2.3 同步成本：无质量标度维度¶

    与能量无关 \(\to\) 动能项和势能项必须具有完全相同的标度维度。不能存在 \(m^2\phi^2\) 这种带质量参数的项。

    CQM中同步成本 \(n_k = C_k\)（Casimir本征值）是无量纲纯数，天然满足此要求。

    2.4 紧致群：从有限维到无穷维¶

    紧致李群 \(G_k\) 在局域规范变换下发挥作用。但在无标度世界，为配合共形变换的刚性，群的代数结构必须扩展为无穷维：

    \[\boxed{G_k \;\xrightarrow{\text{共形固定点}}\; \hat{G}_k \text{ (Kac–Moody代数)} \;\oplus\; \text{Virasoro代数}}\]
    • Kac–Moody代数 \(\hat{\mathfrak{g}}_k\)：紧致李代数 \(\mathfrak{g}_k\) 的中心扩展，水平 \(k\) 由耦合常数确定
    • Virasoro代数：共形变换的无穷维生成元，中央荷 \(c\) 由Kac–Moody水平通过Sugawara构造确定

    3. OPE：同步本征态 ⊗ 耦合本征态 → 群本征态¶

    3.1 三种本征态¶

    本征态 空间 本征值方程 物理意义
    同步本征态 \(\|\{n_k\}\rangle_{\text{sync}}\) 核子空间 \(\hat{\mathcal{S}}_{\text{nucleon}}\|\{n_k\}\rangle = \left(\sum_k n_k\right)\|\{n_k\}\rangle\) 同步成本（Casimir定义）
    耦合本征态 \(\|u_k\rangle_{\text{coup}}\) 耦合常数空间 \(\hat{u}\|u_k\rangle = \ln g_k\|u_k\rangle\) 耦合常数值
    群本征态 \(\|G_k\rangle_{\text{group}}\) 本征群空间 \(\hat{C}_2(G_k)\|G_k\rangle = C_k\|G_k\rangle\) 对称性类别

    3.2 OPE的核心公式¶

    同步本征态与耦合本征态配对，映射到群本征态：

    \[\boxed{|\{n_k\}\rangle_{\text{sync}} \otimes |u_k\rangle_{\text{coup}} \xrightarrow{\text{OPE}} \sum_{k'} C_{k}^{k'} |G_{k'}\rangle_{\text{group}}}\]

    其中 \(C_{k}^{k'}\) 是OPE结构常数（共形块），由CFT的中央荷和最高权表示严格确定。

    3.3 OPE的CFT标准形式¶

    在共形场论中，两个初级算符的OPE：

    \[\mathcal{O}_i(z) \cdot \mathcal{O}_j(0) \sim \sum_{k} C_{ij}^{k} z^{h_k - h_i - h_j} \mathcal{O}_k(0)\]

    CQM对应： - \(\mathcal{O}_i \leftrightarrow |\{n_k\}\rangle_{\text{sync}}\)（同步算符，标度维度 \(h_i = n_k\)） - \(\mathcal{O}_j \leftrightarrow |u_k\rangle_{\text{coup}}\)（耦合算符，标度维度 \(h_j = \ln g_j / \ln\Lambda\)（\(\Lambda\) 为参考标度）） - \(\mathcal{O}_k \leftrightarrow |G_k\rangle_{\text{group}}\)（群算符，标度维度 \(h_k = C_k\)）

    3.4 OPE系数的确定¶

    OPE结构常数 \(C_{ij}^{k}\) 由以下严格确定：

    1. 三点函数：\(C_{ij}^{k} = \langle \mathcal{O}_k | \mathcal{O}_i \cdot \mathcal{O}_j \rangle\)
    2. 共形自举：交叉对称性 \(\sum_k C_{ij}^{k} C_{kl}^{m} = \sum_k C_{il}^{k} C_{kj}^{m}\)（结合律，对中间通道求和）
    3. Kac–Moody水平：由耦合常数 \(g_k\) 确定水平 \(k\)，进而确定允许的最高权表示

    3.5 共形自举：共形自洽¶

    3.5.1 什么是“自举”（Bootstrap）¶

    “自举”源自“提着鞋带把自己拎起来”这个悖论。在物理学中，它特指一种无参数的、完全自洽的闭合系统：不靠实验输入任何额外数字（如质量、耦合常数），纯粹靠“逻辑上不能自相矛盾”这一条规则，把所有的数字全部强行算出来。

    共形自举（Conformal Bootstrap）是现代物理学中大名鼎鼎的术语。如果听到物理学家说“Bootstrap”，99%指的就是它（为区分于上世纪60年代旧的“S矩阵自举”，现在通常加“共形”二字）。

    3.5.2 自举的是“结合律”¶

    自举的是结合律（Associativity），也就是OPE的相容性条件。

    具体来说：四个算符的四点函数，可以通过两种不同的OPE通道来分解：

    \[\langle \mathcal{O}_1 \mathcal{O}_2 \mathcal{O}_3 \mathcal{O}_4 \rangle = \sum_k C_{12}^{k} C_{k34} \,\mathcal{F}_k^{(s)}(z) = \sum_m C_{14}^{m} C_{m23} \,\mathcal{F}_m^{(t)}(z)\]
    • s通道：先配 \(\mathcal{O}_1 \times \mathcal{O}_2 \to \mathcal{O}_k\)，再配 \(\mathcal{O}_k \times \mathcal{O}_3 \to \mathcal{O}_4\)
    • t通道：先配 \(\mathcal{O}_1 \times \mathcal{O}_4 \to \mathcal{O}_m\)，再配 \(\mathcal{O}_m \times \mathcal{O}_2 \to \mathcal{O}_3\)

    自举方程要求：两种配对顺序得到的最终结果必须完全一样。

    \[\boxed{\sum_k C_{12}^{k} C_{k34} \,\mathcal{F}_k^{(s)}(z) = \sum_m C_{14}^{m} C_{m23} \,\mathcal{F}_m^{(t)}(z) \quad \text{（共形自举方程）}}\]

    8.3 态-算符对应：插入即生成¶

    CFT的第一性原理：

    \[\boxed{|\phi\rangle = \lim_{z \to 0} \phi(z)|0\rangle}\]

    CQM诠释： - 真空 \(|0\rangle\) = 潜能态（质数前网络） - 算符插入 \(\phi(z)\) = 在耦合空间点 \(z\) 建立关系，触发存在者 - 生成的态 \(|\phi\rangle\) = 被关系照亮的有限结构

    关键：算符放在哪，哪就有一个态——不是创造新属性，是把已有的同一种属性模式扩大到该点。

    局域分析足够性：虽然底空间上离散插入点很多（每个Regge顶点 \(v\) 生成不同的局域态 \(|\delta_v\rangle\)），但所有态遵守同一套同步算符 \(\hat{\mathcal{S}}\) 和同步方程 \(\hat{\mathcal{S}}\Psi = n\Psi\)。OPE系数 \(C_{ij}^k\) 由共形对称性固定，不依赖插入点 \(z\)。因此只需取一个体现底空间分布性质的代表性局域分析，同步谱由 \(A_4\) 代数结构统一给出，普适于整个纤维丛（详见 07 精细引力（FG）/FG_纤维丛理论.md §9.9）。
