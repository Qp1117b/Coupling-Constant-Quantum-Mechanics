# 阅读站（离线理论阅读层）

> 由 `_build/build_reader.py` 从理论文本（`README.md` + `01–07` 各主题文档 + `一体化研究/附录`）**只读**派生的单页阅读站。
> 定位：面向人的**阅读层**——目录树 + 全文搜索 + 站内跳转 + 反链 + 公式渲染。
> 与 `../网站/index.html` 的分工：后者呈现 `01_结构化数据/*.csv` 派生的结构化知识，本站在于通读理论原文。

## 打开

直接用浏览器打开 `index.html`（`file://` 即可；语料内嵌，无需本地服务器）。

## 功能

| 功能 | 说明 |
|:---|:---|
| 目录树 | 按主题分组列出全部文档 |
| 全文搜索 | 在全部语料中检索关键词，命中给出行内片段 |
| 反链 | 构建期解析文档间引用（markdown 链接与反引号路径），在文末列出引用本文档的文档 |
| 站内跳转 | markdown 链接与反引号 `.md` 引用均可点击跳转 |
| 公式渲染 | MathJax TeX→SVG，随包离线 |

## 重建

```bash
python _build/build_reader.py
```

## 离线资源

`assets/marked.min.js`（Markdown 渲染，MIT）与 `assets/tex-svg.js`（MathJax TeX→SVG，Apache-2.0）随包存放，站点不依赖 CDN。

## 边界

- 只读取理论文本，不修改任何文档；
- 不引入新内容，不成为第二事实源；
- 产物由 `_build/build_reader.py` 派生，不手工编辑。
