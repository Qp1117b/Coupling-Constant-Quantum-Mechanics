    FG 层级同步算符体系：从元素 FG 到分子 FG 的第一性超导预测框架¶

    ——纤维丛语言下的层级谱传递理论

    作者：ruster

    定位：建立 CQM 超导理论的层级同步算符公理：每种精细引力层级（电子 FG、元素 FG、分子 FG、晶胞 FG）都必须拥有自己的同步算符。同步算符是紧化算符（01 核心理论/CQM_核心_因果网络同步理论.md §4、§9）在各 FG 层级主丛上的实现；层级间的第一性预测链通过谱传递闭合——上层同步算符的本征值谱是下层同步算符的输入，直到晶胞 FG 同步算符的本征值交叉给出 \(T_c\)。

    直接动机：第一性 \(T_c\) 计算链（CQM_超导核心理论.md §11.10）通过本征值交叉 \(T_c=\frac{\theta_D}{2\,\mathrm{arccoth}(x)}\) 建立前向预测框架，从Regge剖分→角亏→声子→涨落→Tc闭式，无数值拟合。论证：分子层级的内禀角亏是分子 FG 同步算符谱的几何显现，第一性链闭合。详见CQM_超导_统一方法论.md。

    依赖文档：CQM_超导核心理论.md §2.5（晶胞路线）、§3（两条链）、§5（主丛）、§11.6/§11.10（同步算符与 \(T_c\) 闭式）；CQM_超导_专题与扩展.md §11.6–§11.9（氢原子能级、元素周期表、中子缺陷、同位素效应）；CQM_超导_统一方法论.md（四层FG剖分方法论与统一计算步骤）；08 理论组织和形式化框架/04_Lean对接/Lean源码/Superconductivity/MolecularGeometry.lean（分子嘉当矩阵形式化）。

    1. 研究进展综述与结构性诊断¶

    1.1 确立的进展¶

    （一）FG 的纤维丛定义（CQM_超导核心理论.md §5）。FG 是 GR 基态的非平庸激发态：底空间 \(M\) 由物质晶胞分布经 Regge 剖分给出（链 A），结构群 \(G_{\text{FG}}\) 由嘉当矩阵链给出（链 B），联络 \(\mathcal{A}_{\text{FG}}\) 由 Regge 晶胞分步生成，产生两种曲率（底空间角亏 \(\delta_v\) 与伴丛曲率 \(F\)），和乐 \(W_v = \exp(i\delta_v \hat{T})\)。超导 = 以和乐平庸化为局域必要条件的全局同步。

    （二）嘉当矩阵链贯通到晶胞（链 B，MolecularGeometry.lean）：

    \[\mathcal{C}_{\text{proton}} = A_4 \xrightarrow{\text{链B}} \mathcal{C}_{\text{element}} \xrightarrow{\text{链B}} \mathcal{C}_{\text{molecule}} \xrightarrow{\text{链B}} \mathcal{C}_{\text{unit\_cell}}\]

    其中 \(\mathcal{C}_{\text{molecule}} = \bigoplus_k \mathcal{C}_{\text{el}}(k) + \sum_{i<j} T_{ij}\)，跨原子因果耦合 \(T_{ij} = t_0 e^{-d_{ij}/\lambda}\Theta(d_{\text{cut}} - d_{ij}) \cdot I_4\)。

    （三）两端层级的同步算符构造：

    • 元素 FG（CQM_超导_专题与扩展.md §11.7）：\(\hat{\mathcal{S}}_{\text{el}} = V_0 + L_{\text{orbital}}\)，本征值 \(N(\gamma_n) + l = n + l\)（Madelung 规则），周期表推导（填充顺序、壳层饱和数 \(2,6,10,14\)、洪特规则三条全部一致）。
    • 晶胞 FG（CQM_超导核心理论.md §11.6、§11.10）：\(\hat{\mathcal{S}}_{\text{super}} = V_0 + V_{\text{角亏激活}}(T)\)，本征值 \(\lambda_n(T) = \gamma_n - V_{\text{角亏激活}}(n,T)\)，本征值交叉 \(\lambda_1(T_c) = \lambda_2(T_c)\) 给出 \(T_c\) 闭式 \(T_c = \theta_D/(2\,\mathrm{arccoth}\,x)\)。
    • 电子 FG（氢原子语境，CQM_超导_专题与扩展.md §11.6）：同步算符谱 \(\{\gamma_n\}\) 经谱序号 \(n = N(\gamma_n)\) 给出 \(E_n = -R/N(\gamma_n)^2\)（精度 \(10^{-12}\)）。

    1.2 结构性诊断：断链的位置¶

    第一性 \(T_c\) 计算链的审计结论（CQM_超导核心理论.md §11.10、CQM_超导_专题与扩展.md §13 缺口表）：公式推导完整，前向预言未闭合。具体断点：

    \[\text{材料结构} \xrightarrow{\text{Regge几何}} \delta_v \xrightarrow{\text{待建立}} \Delta\delta_0^{\text{eff}} \xrightarrow{\theta_D} T_c\]

    从结构几何可计算缺陷涨落部分（位错、空位、压力），但内禀角亏 \(\delta_{\text{intrinsic}}\) 无内部来源——当前只能引入外部 DFT 贝里曲率。前向计算（\(\delta_{\text{intrinsic}} = 0\)）给出 \(T_c = 0\) 对大部分常压超导体，暴露该环节是缺失的关键。

    诊断：断链不是计算技术问题，是层级结构问题。嘉当矩阵链（链 B）从质子一路贯通到晶胞，但同步算符链只在两端有实现（元素 FG、晶胞 FG），中间的分子 FG 层级只有嘉当矩阵而没有同步算符。内禀角亏正是分子层级的信息——分子几何偏离杂化理想几何的球面角亏——没有分子 FG 同步算符，这条信息无法从谱结构中读出，只能外部输入。

    结论：第一性预测链闭合的必要条件是补齐每种 FG 的同步算符。

    2. 层级公理：每种 FG 都有自己的同步算符¶

    2.1 公理陈述¶

    层级同步算符公理（核心）。精细引力 FG 的每个物质组织层级 \(\ell \in \{\text{电子}, \text{元素}, \text{分子}, \text{晶胞}\}\) 都拥有自己的同步算符 \(\hat{\mathcal{S}}_\ell\)——它是紧化算符在该层级主丛截面空间上的实现：

    \[\hat{\mathcal{S}}_\ell : \mathcal{H}_{\text{auto}}(G_\ell) \to \mathcal{H}_{\text{phys}}(\text{层}\ell\text{的物理结构群})\]

    各层级同步算符是同一个紧化算符在不同物质组织层级上的层级化实现（与发生学分层共识一致：基态同步是 SU(5)，重组实现后残留谱结构在物质组织各层级显现；层级谱传递是残留谱结构在物质组织各层级显现的具体机制）。

    2.2 公理的物理依据¶

    为什么必须有层级化实现？ 因为 FG 本身就是层级化的：FG 是 GR 基态的非平庸激发态，而“非平庸因果网络”在不同物质组织层级（原子内、分子内、晶胞间）有不同的构造方式与不同的可观测谱。同步算符是 FG 的谱算符——FG 有几个层级，同步算符就有几个实现：

    FG 层级 非平庸因果网络所在 主丛结构群 层级谱的可观测
    电子 FG 前中子-前质子底空间（\(SU(5)\) 重组实现时形成） 电子底空间规范结构 原子能级 \(E_n = -R/n^2\)
    元素 FG 核子分布（原子） \(U(1) \times SO(2) \times SU(4)\) 壳层结构、Madelung 规则
    分子 FG 键网络（分子几何） 分子点群嵌入的结构群 分子轨道谱、键角、内禀角亏
    晶胞 FG 晶胞空间分布 晶胞嘉当矩阵的结构群 \(T_c\)、超导资格

    为什么共享 \(V_0\)？ 质数势 \(V_0 = \sum_p \frac{\ln p}{\sqrt{p}}\delta(u - \ln p)\) 是 GL(5)固定层级谱结构在耦合空间中的普适显现——电磁相互作用渗透所有物质组织层级（原子、分子、晶胞中电子的行为处处受 GL(5)固定层级谱结构调制），故所有层级的同步算符共享此势。层级特异性编码在结构项 \(V_\ell\) 中。

    2.3 与超导机制的关系¶

    超导相变判据（§11.6）是晶胞 FG 同步算符的本征值交叉。但晶胞 FG 的输入（角亏谱、可实现曲率、结构群）全部来自下层： - 晶胞几何 ← 分子键型与键强 ← 分子 FG 谱 - 晶胞嘉当矩阵 ← 分子嘉当矩阵 ← 元素嘉当矩阵 ← 元素 FG 谱（电子排布）

    没有下层同步算符，晶胞 FG 同步算符的输入只能外部输入（DFT、实验晶格常数）——这正是当前拟合困境的根源。每种 FG 都有自己的同步算符 ⟺ 超导第一性预测链闭合。

    3. 统一纤维丛框架：FG 层级四元组¶

    用纤维丛语言，每个 FG 层级由四元组 \((M_\ell, P_\ell, \mathcal{A}_\ell, \hat{\mathcal{S}}_\ell)\) 完整刻画：

    3.1 层级四元组定义¶

    \[\boxed{(M_\ell,\; P(M_\ell, G_\ell),\; \mathcal{A}_\ell,\; \hat{\mathcal{S}}_\ell)}\]
    要素 定义 层级差异
    底空间 \(M_\ell\) 层级 \(\ell\) 的物质分布几何经 Regge 剖分 电子：前核子底空间；元素：核子壳层几何；分子：键网络球面剖分；晶胞：晶胞空间分布
    主丛 \(P(M_\ell, G_\ell)\) 结构群 \(G_\ell\) 来自链 B 该层级嘉当矩阵的内禀 Weyl 矩阵嵌入 各层级嘉当矩阵谱不同 → 结构群不同
    联络 \(\mathcal{A}_\ell\) 由层级 Regge 晶胞分步生成 层级角亏 \(\delta_v^{(\ell)}\) 与层级伴丛曲率 \(F_\ell\)
    同步算符 \(\hat{\mathcal{S}}_\ell\) 紧化算符在层级截面空间的实现 \(\hat{\mathcal{S}}_\ell = V_0 + V_\ell\)（§4）

    3.2 联络的统一规则¶

    一个联络 \(\mathcal{A}_\ell\) 生成两种曲率（与 §5.1 主丛要素表一致，现在层级化）：

    1. 底空间曲率：层级 Regge 角亏 \(\delta_v^{(\ell)} = 2\pi - \sum_{\Delta \ni v} \alpha_\Delta\)，进入该层级的不确定性关系与谱调制；
    2. 伴丛曲率：\(F_\ell = d\mathcal{A}_\ell + \mathcal{A}_\ell \wedge \mathcal{A}_\ell\)，进入该层级的运动方程与对称性条件。

    层级角亏传递：上层内禀角亏是下层角亏的组成部分：

    \[\delta_v^{(\ell+1)} = \delta_{v,\text{intrinsic}}^{(\ell)} + \Delta\delta_{\text{defect}}^{(\ell+1)}\]

    即晶胞角亏 = 分子内禀角亏 + 晶胞缺陷涨落。这条递推正是 §9 缺口闭合的数学骨架——分子层级的内禀角亏从分子 FG 同步算符谱读出后，晶胞层级的角亏无需外部输入。

    3.3 和乐的层级化¶

    \[W_v^{(\ell)} = \exp(i\delta_v^{(\ell)} \hat{T}_\ell)\]

    其中 \(\hat{T}_\ell\) 是层级结构群 \(G_\ell\) 的生成元。各层级的和乐平庸化条件给出该层级的“稳定构型”： - 电子 FG 层级：和乐平庸化 = 稳定原子轨道（Bohr 能级） - 元素 FG 层级：和乐平庸化 = 闭壳层稳定构型（稀有气体） - 分子 FG 层级：和乐平庸化 = 稳定杂化几何（理想键角） - 晶胞 FG 层级：和乐平庸化 = 超导凝聚（全局相位相干）

    和乐平庸化的偏差即层级角亏：理想构型（和乐平庸）→ 实际构型（和乐非平庸）→ 非零角亏 → 激活下一层级的 FG。

    4. 同步算符的一般形式与两种谱语境¶

    4.1 一般形式¶

    \[\boxed{\hat{\mathcal{S}}_\ell = V_0 + V_\ell}\]
    • \(V_0 = \sum_{p} \frac{\ln p}{\sqrt{p}}\delta(u - \ln p)\)：质数势，所有层级共享（GL(5)固定层级谱的普适显现——电磁相互作用渗透所有物质层级）；
    • \(V_\ell\)：层级结构项，编码层级 \(\ell\) 的主丛对称性与几何，各层级不同。

    4.2 两种谱语境¶

    同步算符本征值在两种语境下进入物理（§11.10 映射规则 3 的层级推广）：

    语境 本征值进入方式 适用层级 原因
    序号语境 \(n = N(\gamma_n)\)（黎曼零点计数函数，离散量子数） 电子 FG、元素 FG、分子 FG 束缚态离散谱（能级由序号标记）
    本征值语境 \(\gamma_n\) 直接（连续本征值） 晶胞 FG 凝聚态准连续谱（同步成本直接竞争）

    层级谱公式：

    \[E_\ell(\text{序号语境}) = F_\ell\big(N(\gamma_n),\, V_\ell\text{参数}\big), \qquad \lambda_n^{(\ell)}(\text{本征值语境}) = \gamma_n - V_\ell\text{修正}\]

    4.3 层级结构项的来源规则¶

    \(V_\ell\) 由该层级主丛的对称性表示论给出——具体地，由链 B 该层级嘉当矩阵的谱在层级对称群下的分解给出投影构造：

    \[V_\ell = \sum_{\Gamma} \lambda_\Gamma^{(\ell)} \cdot \Pi_\Gamma^{(\ell)}\]

    其中 \(\Gamma\) 遍历层级对称群的不可约表示，\(\Pi_\Gamma^{(\ell)}\) 是投影算符，\(\lambda_\Gamma^{(\ell)}\) 是从层级嘉当矩阵谱导出的权重。这一规则在构造的两个层级中均实现（见 §5、§6），分子 FG 层级的构造遵循同一规则——这不是类比，是同一构造原理的层级实例化。

    5. 构造层级：电子 FG 与元素 FG¶

    5.1 电子 FG 同步算符（氢原子语境）¶

    \[\hat{\mathcal{S}}_{\text{elec}} = V_0 \quad (\text{自由库仑场，无额外结构项})\]

    本征值（序号语境）：\(n = N(\gamma_n)\)，导出：

    \[a_n = n^2 a_0, \qquad E_n = -\frac{R}{N(\gamma_n)^2} = -\frac{R}{n^2}\]
    • 精度：能级精度 \(10^{-12}\)；\(|E_n| \cdot a_n = R \cdot a_0\) 不确定关系。
    • 本体论地位：电子 FG 是前中子-前质子底空间的 FG（\(SU(5)\) 重组实现时形成，早于元素 FG），氢原子是其最简实例（§11.6）。
    • 谱结构与可观测对应确立（唯象验证，Riemann-von Mangoldt 渐近精确公式待严格化）。

    5.2 元素 FG 同步算符¶

    \[\hat{\mathcal{S}}_{\text{el}} = V_0 + L_{\text{orbital}}, \qquad L_{\text{orbital}} = \sum_{l=0}^{h-2} l \cdot \Pi_l(u)\]

    其中 \(\Pi_l(u) = \sum_{m=-l}^{l}|Y_l^m(u)|^2\) 是 \(SO(3)\) 第 \(l\) 表示的投影算符（\(Y_l^m\) 从 \(SU(4) \to SO(3)\) 涌现），\(h = 5\)。

    本征值（序号语境）：\(E_{\text{el}}(n, l) = N(\gamma_n) + l = n + l\)——Madelung 规则。

    结构项权重来源：\(\varphi_l(u) = \frac{l}{\lambda_l}\Pi_l(u)\)，\(\lambda_l\)——正是 §4.3 规则的实例：层级谱结构 → 表示权重 → 投影构造。

    • 验证：周期表完整推导（壳层 \(2,6,10,14\)、周期长度 \(2,8,18,32\)、填充顺序、洪特规则三条全部一致）。
    • 状态：构造并验证（周期表推导不依赖 \(\delta\) 精确值；待第三方独立复现）。

    6. 缺失层级：分子 FG 同步算符的构造方案¶

    核心新构造。 以下为构造方案——构造原理与构造层级严格同构，且每一步都有明确的可检验输出。

    6.1 分子 FG 的主丛四元组¶

    要素 构造
    底空间 \(M_{\text{mol}}\) 分子键网络：以每个原子为中心，其成键方向（+孤对电子方向）在单位球面上的剖分
    主丛 \(P(M_{\text{mol}}, G_{\text{mol}})\) \(G_{\text{mol}}\)：分子嘉当矩阵 \(\mathcal{C}_{\text{molecule}} = \bigoplus_k \mathcal{C}_{\text{el}}(k) + \sum_{i<j} T_{ij}\) 的内禀 Weyl 矩阵嵌入给出的结构群，限定于分子点群 \(G_{\text{point}}\)
    联络 \(\mathcal{A}_{\text{mol}}\) 由键方向球面剖分的 Regge 几何分步生成：层级角亏 \(\delta_v^{\text{mol}}\) + 伴丛曲率 \(F_{\text{mol}}\)
    同步算符 \(\hat{\mathcal{S}}_{\text{mol}}\) \(\hat{\mathcal{S}}_{\text{mol}} = V_0 + L_{\text{mol}}\)（下文构造）

    6.2 结构项 \(L_{\text{mol}}\)：点群投影构造¶

    遵循 §4.3 规则（层级嘉当矩阵谱 → 表示权重 → 投影构造）：

    \[\boxed{L_{\text{mol}} = \sum_{\Gamma \in \widehat{G}_{\text{point}}} \lambda_\Gamma^{\text{mol}} \cdot \Pi_\Gamma^{\text{mol}}}\]
    • \(\Gamma\) 遍历分子点群 \(G_{\text{point}}\) 的不可约表示（\(T_d\)、\(D_{3h}\)、\(C_{\infty v}\)、\(C_{2v}\)、…）；
    • \(\Pi_\Gamma^{\text{mol}}(u) = \frac{d_\Gamma}{|G_{\text{point}}|}\sum_{g \in G_{\text{point}}} \chi_\Gamma(g)^* \rho(g)\)：点群投影算符（标准表示论构造，与 \(L_{\text{orbital}}\) 的 \(SO(3)\) 投影同构）；
    • \(\lambda_\Gamma^{\text{mol}}\)：从 \(\mathcal{C}_{\text{molecule}}\) 的谱导出——将 \(\mathcal{C}_{\text{molecule}}\) 本征值谱按点群不可约表示分解，\(\lambda_\Gamma^{\text{mol}}\) 取该表示扇区的谱重心相对偏移：
    \[\lambda_\Gamma^{\text{mol}} = \mu_\Gamma - \mu_{\min}, \qquad \mu_\Gamma = \frac{1}{|\text{扇区}_\Gamma|}\sum_{\lambda \in \text{扇区}_\Gamma} \lambda \quad (\lambda \in \mathrm{Spec}(\mathcal{C}_{\text{molecule}}))\]

    构造的谱传递本质：\(\lambda_\Gamma^{\text{mol}}\) 的输入是 \(\mathcal{C}_{\text{molecule}}\)，而 \(\mathcal{C}_{\text{molecule}}\) 的块 \(\mathcal{C}_{\text{el}}(k)\) 的谱已由元素 FG 同步算符的本征值结构（Madelung 排布决定价壳层、价壳层决定成键轨道对称性）限定。元素谱 → 分子嘉当矩阵 → 分子结构项——层级谱传递在构造内部实现。

    6.3 分子轨道谱（序号语境）¶

    \[E_{\text{mol}}(n, \Gamma) = N(\gamma_n) + \lambda_\Gamma^{\text{mol}}\]

    排序规则（Madelung 规则的分子推广）：主序按 \(N(\gamma_n) + \lambda_\Gamma^{\text{mol}}\) 升序；同值时 \(N(\gamma_n)\) 优先。

    可观测对应： - 分子轨道填充顺序 ↔ HOMO-LUMO 结构； - 成键/反键能级劈裂 ↔ \(\lambda_\Gamma^{\text{mol}}\) 的扇区间隙（点群对称性越大，劈裂越规整）； - 前向可检验：小分子（H₂、H₂O、CH₄、NH₃）的轨道能级排序与光电子能谱对比。

    6.4 杂化几何与分子内禀角亏¶

    关键几何观察：常见杂化的理想几何与 \(A_4\) 结构深层相关——

    • sp³ 杂化（\(T_d\) 对称）：四个键方向指向正四面体顶点，键角 \(\arccos(-1/3) \approx 109.47°\)。正四面体正是 4-单纯形的边界——分子 FG 的 sp³ 理想键几何与质子 \(A_4\) 嘉当矩阵的四面体根空间是同一几何在两个层级（核子层级、分子层级）的显现。
    • 球面剖分角亏：以原子为中心，四个理想 sp³ 键方向把单位球面剖分为 4 个正球面三角形，每个面角 \(120°\)（三条大圆弧在每个顶点三等分圆周），角和 \(= 360° = 2\pi\)：
    \[\delta_{v,\text{ideal}}^{\text{mol}}(\text{sp}^3) = 2\pi - 3 \times \frac{2\pi}{3} = 0\]

    理想杂化几何的和乐平庸化 ⟺ 层级角亏为零——这是 §3.3 和乐层级化的具体实现：分子 FG 层级的“稳定构型”（和乐平庸化）就是理想杂化几何（理想键角），内禀角亏 = 实际键角偏离理想键角的球面角亏。

    \[\boxed{\delta_{v,\text{intrinsic}}^{\text{mol}} = 2\pi - \sum_{\text{球面面片} \ni v} \alpha_{\text{面片}}(\{\theta_{ij}\}_{\text{实际键角}})}\]

    其中 \(\alpha_{\text{面片}}\) 由实际键方向（含孤对电子方向的等效处理）的球面三角剖分计算。

    实例： - CH₄（甲烷，sp³ 理想）：键角全部 \(109.47°\) → \(\delta_{\text{intrinsic}}^{\text{mol}} = 0\)（和乐平庸化构型）。 - H₂O（sp³ 带两对孤对）：键角 \(104.5° \ne 109.47°\) → 非零内禀角亏（孤对压缩效应，可从 \(L_{\text{mol}}\) 的扇区权重差读出方向）。 - NH₃（sp³ 带一对孤对）：键角 \(107.8°\) → 介于二者之间。

    驱动来源：实际几何对理想几何的偏离由 \(\mathcal{C}_{\text{molecule}}\) 的跨原子耦合块 \(T_{ij} = t_0 e^{-d_{ij}/\lambda}\Theta(d_{\text{cut}}-d_{ij}) I_4\) 驱动（不同距离/强度的键 → 非等权耦合 → 键角压缩）。即：分子嘉当矩阵谱（经同步算符结构项）同时决定分子轨道谱与分子内禀角亏——谱与几何在分子 FG 层级统一。

    6.5 分子 FG 同步算符的待严格化问题¶

    本构造方案的开放问题：

    1. \(\lambda_\Gamma^{\text{mol}}\) 的谱重心定义是否唯一（备选：扇区最小值、谱质心加权）——需小分子数值实验判定；
    2. 孤对电子方向在球面剖分中的等效处理（占据方向权重 vs 挤压效应参数化）；
    3. \(V_0\)（序号语境下经 \(N(\gamma_n)\)）与 \(L_{\text{mol}}\) 的相加结构在分子轨道语境的严格推导（类比 \(L_{\text{orbital}}\) 的 \(\lambda_l\) 抵消证明，见 §11.7）；
    4. 过渡金属配合物（d 轨道参与杂化）的点群分解扩展。

    7. 构造层级：晶胞 FG（超导同步算符）¶

    回顾（§11.10，状态：公式已给出（前向验证未闭合））：

    \[\hat{\mathcal{S}}_{\text{super}} = V_0 + V_{\text{角亏激活}}(T), \qquad V_{\text{角亏激活}}(n,T) = \frac{\beta^2 \Delta\delta_v(T)^2 (n^2-1)}{4n^2(1-\beta\delta_v)}\]

    本征值（本征值语境）：\(\lambda_n(T) = \gamma_n - V_{\text{角亏激活}}(n,T)\)；本征值交叉 \(\lambda_1(T_c) = \lambda_2(T_c)\) 给出：

    \[T_c = \frac{\theta_D}{2\,\mathrm{arccoth}\,x}, \qquad x = \frac{3\beta^2\Delta\delta_0^2}{16(1-\beta\delta_v)(\gamma_2 - \gamma_1)}\]

    层级四元组定位：底空间 \(M_{\text{cell}}\) = 晶胞空间分布（链 A）；结构群 = \(\mathcal{C}_{\text{unit\_cell}}\) 的内禀 Weyl 矩阵嵌入（链 B）；联络 = 晶胞 Regge 角亏 \(\delta_v\)（底空间曲率）+ 伴丛曲率（§5.1）；同步算符如上。

    该层级的增量：\(\delta_v\) 的输入经 §3.2 层级角亏递推闭合——

    \[\delta_v(\text{晶胞}) = \underbrace{\delta_{v,\text{intrinsic}}^{\text{mol}}}_{\text{分子 FG 谱导出（§6.4）}} + \underbrace{\Delta\delta_{\text{defect}}}_{\text{缺陷统计力学（§11.10 已有）}}\]

    8. 层级谱传递：完整第一性预测链¶

    8.1 谱传递规则¶

    \[\boxed{\text{上层同步算符谱} \;\Longrightarrow\; \text{下层嘉当矩阵/几何的输入} \;\Longrightarrow\; \text{下层同步算符}}\]

    具体传递边：

    1. 电子 FG → 元素 FG：氢原子谱结构（\(n = N(\gamma_n)\)，\(l\) 分裂）→ 电子轨道量子数 → 元素嘉当矩阵的壳层条件 → \(\hat{\mathcal{S}}_{\text{el}}\) 谱（Madelung 排布）。
    2. 元素 FG → 分子 FG：Madelung 排布 → 价壳层结构 → \(\mathcal{C}_{\text{el}}(k)\) 块的成键对称性 + 跨原子耦合 \(T_{ij}\) → \(\mathcal{C}_{\text{molecule}}\) → \(\hat{\mathcal{S}}_{\text{mol}}\) 谱（分子轨道 + 内禀角亏）。
    3. 分子 FG → 晶胞 FG：分子轨道谱（键型/键强）+ 内禀角亏 → 晶胞几何（链 A 键长键角来源）+ \(\mathcal{C}_{\text{unit\_cell}}\)（链 B）→ \(\hat{\mathcal{S}}_{\text{super}}\) → \(\lambda_n(T)\) → \(T_c\)。

    8.2 完整计算链（12 环节）¶

    \[\boxed{ \begin{aligned} &\text{① 质子 } A_4 + \text{中子 } D(\delta) \xrightarrow{\text{链B}} \mathcal{C}_{\text{el}} \\ &\xrightarrow{\text{②}} \hat{\mathcal{S}}_{\text{el}} = V_0 + L_{\text{orbital}} \text{ 谱} \Rightarrow \text{Madelung 排布 / 价壳层}\\ &\xrightarrow{\text{③}} \mathcal{C}_{\text{molecule}} = \bigoplus_k \mathcal{C}_{\text{el}}(k) + \sum_{i<j} T_{ij} \\ &\xrightarrow{\text{④}} \hat{\mathcal{S}}_{\text{mol}} = V_0 + L_{\text{mol}} \text{ 谱} \Rightarrow \text{分子轨道 + 键几何}\\ &\xrightarrow{\text{⑤}} \delta_{v,\text{intrinsic}}^{\text{mol}} \text{（球面角亏，实际 vs 理想杂化）}\\ &\xrightarrow{\text{⑥ 周期性凝聚}} \mathcal{C}_{\text{unit\_cell}} \text{（链B）} + \text{晶胞 Regge 几何（链A）}\\ &\xrightarrow{\text{⑦}} \delta_v = \delta_{v,\text{intrinsic}}^{\text{mol}} + \Delta\delta_{\text{defect}}\\ &\xrightarrow{\text{⑧ 弹性链}} \theta_D\\ &\xrightarrow{\text{⑨}} \hat{\mathcal{S}}_{\text{super}} = V_0 + V_{\text{角亏激活}}(T)\\ &\xrightarrow{\text{⑩}} \lambda_n(T) = \gamma_n - V_{\text{角亏激活}}(n,T)\\ &\xrightarrow{\text{⑩' 谱间隙推导}} \hat{\mathcal{S}}_2 \text{ 独立离散谱} \to \text{从嘉当矩阵谱间隙第一性推导}\\ &\xrightarrow{\text{⑪ 交叉}} \lambda_1(T_c) = \lambda_2(T_c)\ \text{（本征值交叉）}\\ &F\left(\gamma_2-\gamma_1;\ \text{嘉当矩阵谱间隙};\ \delta_v,\ \theta_D\right)\\ &\xrightarrow{\text{⑫}} T_c = \frac{\theta_D}{2\,\mathrm{arccoth}\,x} \end{aligned}}\]

    谱间隙推导环节⑩'说明：\(\gamma_n\) 从嘉当矩阵谱间隙第一性推导（精度数值无可复核产物）。

    与 §11.10 十环节链的对比：原链的第 4–5 环节（分子嘉当矩阵→原子分布）是纯嘉当矩阵/几何操作，无谱结构参与；新链在第 ④–⑤ 环节插入分子 FG 同步算符——这是唯一改动，且正是断链所在位置。

    8.3 第一性程度审计¶

    环节 输入来源 第一性状态
    ①–② 质子、中子 \(D(\delta)\)、\(\delta(Z,N)\) 谱条件 （周期表）
    ③ 价壳层（②谱输出）+ 键长截断 \(d_{\text{cut}}\)、耦合强度 \(t_0\)、衰减 \(\lambda\) \(t_0, \lambda\) 当前为拟合参数，需从元素谱导出（开放）

    ⑥–⑦ 分子谱输出（⑤）+ 缺陷统计 缺陷部分已有；内禀部分被⑤替代外部 DFT
    ⑧ 弹性常数 标准第一性路径
    ⑨–⑩ \(\hat{\mathcal{S}}_{\text{super}}\)、\(\lambda_n(T)\)（GL(5)固定层级谱） 公式已给出（前向验证未闭合）
    ⑩' 从嘉当矩阵谱间隙第一性推导 \(\gamma_n\) 从嘉当矩阵谱间隙第一性推导

    9. δ_intrinsic 缺口的闭合方案¶

    9.1 原缺口陈述（超导核心理论 §11.10、专题与扩展 §13）¶

    \(\delta_{\text{intrinsic}}\) 的第一性来源是分子 FG 同步算符谱的几何显现（§9.2）。本征值交叉路径 \(T_c=\frac{\theta_D}{2\,\mathrm{arccoth}(x)}\) 构成纯第一性前向预测框架，从Regge剖分→角亏→声子→涨落→Tc闭式，不依赖\(\delta_v\)反推。

    9.2 闭合论证¶

    内禀角亏的第一性来源 = 分子 FG 同步算符谱的几何显现：

    \[\delta_{\text{intrinsic}} = \delta_{v,\text{intrinsic}}^{\text{mol}} = 2\pi - \sum_{\text{球面面片}} \alpha_{\text{面片}}(\{\theta_{ij}\}_{\text{实际键角}})\]

    其中实际键角由 \(\mathcal{C}_{\text{molecule}}\) 的跨原子耦合决定（哪些键受压、哪些伸展），理想键角由点群对称（\(L_{\text{mol}}\) 的表示结构）决定。两者都在 CQM 内部——无需 DFT 贝里曲率。

    对常压超导体的修正预期：原前向计算取 \(\delta_{\text{intrinsic}} = 0\) 仅对完美杂化几何成立（如 CH₄ 理想四面体）。真实超导材料晶胞中： - 金属键/共价键混合 → 杂化偏离理想 → 非零 \(\delta_{v,\text{intrinsic}}^{\text{mol}}\)； - 晶胞中不等价键（如 Nb 的体心立方 8 近邻不等权、YBCO 的 Cu-O 面内/面外键长差）→ 系统性内禀角亏。

    预期量级检验（待数值实现）：若 \(\delta_{v,\text{intrinsic}}^{\text{mol}} \sim 10^{-3}\text{–}10^{-2}\) 能使 Nb 的前向 \(T_c\) 回到 9.2K 量级，缺口闭合成立。这是本方案最直接的数值判据。

    9.2.1 数值判据（待数值实现）¶

    判据内容：内禀角亏由分子 FG 同步算符谱给出，不需要外部贝里曲率输入：

    \[\delta_{v,\text{intrinsic}}^{\text{mol}} = 2\pi - \sum_{\text{球面面片} \ni v} \alpha_{\text{面片}}(\{\theta_{ij}\}_{\text{实际键角}})\]

    其计算路径为：分子嘉当矩阵构造 → 点群判定 → 内禀角亏 → 完整 \(T_c\) 前向预测（单元素材料以晶体配位数作有效原子数 \(n_{\text{eff}}\)）。

    数值状态：无可用数值。该判据的计算链（分子嘉当矩阵 → 点群判定 → 内禀角亏 → \(T_c\) 前向预测）尚未实现于仓库，也不存在该判据的数值产物。

    因此本节的判据只有形式，没有数值：\(\delta_{v,\text{intrinsic}}^{\text{mol}}\) 与材料 \(T_c\) 的对应关系尚未被任何可复核的计算支持。缺口 G18 未闭合；§10 的可检验预言 3 同样处于无数值状态。补入方式为：恢复或重写该计算链脚本，并给出可复核的数值产物（不得以实验值回填任何“预测”字段）。

    9.3 与贝里曲率的关系（方法论定位）¶

    DFT 贝里曲率是电子波函数在动量空间的几何相位——在 CQM 语言中它是伴丛和乐的某种唯象近似。该方案不否定其计算有效性，而是指出：在 CQM 框架内该信息已有第一性来源（分子 FG 同步算符谱），外部计算是不必要的。这与 Hilbert–Pólya 批判（05 方法论与批判/CQM_方法论_HilbertPolya批判.md）的方法论一致：物理过程铸造算符，算符谱决定几何签名——而非从外部几何反推。

    10. 可检验预言¶

    1. 小分子轨道能级排序（§6.3）：H₂、H₂O、CH₄、NH₃ 的分子轨道能级顺序与光电子能谱对比。判据：\(E_{\text{mol}}(n,\Gamma) = N(\gamma_n) + \lambda_\Gamma^{\text{mol}}\) 的排序是否复现实验填充顺序。
    2. 内禀角亏-键角偏离的线性关系（§6.4）：同系列分子（如 NH₃ → PH₃ → AsH₃，孤对压缩递减）的球面角亏应与键角偏离理想值系统相关。
    3. 常压超导体前向 \(T_c\) 判据（§9.2.1）：判据形式为 \(\delta_{v,\text{intrinsic}}^{\text{mol}}\) 由分子 FG 同步算符谱给出，代入后应复现元素超导体的实验 \(T_c\)。当前无数值（计算链脚本不在仓库，见 §9.2.1）。
    4. 氢化物高通量筛选的谱依据：高压氢化物（H₃S、LaH₁₀ 族）中氢的 sp³ 类理想四面体配位（小内禀角亏）+ 重原子大振幅（大缺陷涨落）的组合应给出高 \(T_c\)——与已知“笼状氢化物高 \(T_c\)”现象一致性检验。
    5. 分子对称性-超导关联：点群对称性高的晶胞（近 \(T_d\)、\(O_h\) 局域配位）内禀角亏小 → 超导更依赖缺陷涨落；低对称晶胞（大畸变）内禀角亏大 → 常压下更易满足资格条件。可在 cqm_analysis/superconductors_deduplicated.csv（226 条材料实验数据）中做统计检验。

    11.1 层级状态总表¶

    层级 同步算符 谱输出 状态
    电子 FG \(\hat{\mathcal{S}}_{\text{elec}} = V_0\) \(E_n = -R/N(\gamma_n)^2\) 唯象验证（\(10^{-12}\)）
    元素 FG \(\hat{\mathcal{S}}_{\text{el}} = V_0 + L_{\text{orbital}}\) Madelung 规则、周期表 周期表推导完整（待第三方独立复现）
    分子 FG \(\hat{\mathcal{S}}_{\text{mol}} = V_0 + L_{\text{mol}}\) 分子轨道谱、内禀角亏 内禀角亏判据形式已建立、数值未实现（§9.2.1）；\(L_{\text{mol}}\) 严格构造尚需完善
    晶胞 FG \(\hat{\mathcal{S}}_{\text{super}} = V_0 + V_{\text{角亏激活}}\) \(\lambda_n(T)\)、\(T_c\) 闭式 本征值交叉路径建立纯第一性前向预测框架（\(T_c=\frac{\theta_D}{2\,\mathrm{arccoth}(x)}\)，从Regge剖分到Tc闭式）；公式已给出（前向验证未闭合）、数值未实现
    层级谱传递 上层谱 → 下层输入 第一性链 框架性假设（②→③ 部分构造）

    11.2 开放问题（优先级排序）¶

    1. 最高：\(L_{\text{mol}}\) 的严格构造与数值实现——\(\lambda_\Gamma^{\text{mol}}\) 定义唯一性、孤对处理、小分子轨道谱验证（§6.5 全部四问）。
    2. 中：内禀角亏数值判据（§9.2.1）——\(\delta_{v,\text{intrinsic}}^{\text{mol}} \sim 10^{-2}\) 将前向 \(T_c\) 从 0K 修正回实验量级，是该判据的核心待实现环节；当前无可用数值产物。
    3. 高：③ 环节耦合参数（\(t_0, \lambda, d_{\text{cut}}\)）从元素谱导出——当前为拟合参数，破坏完全第一性。
    4. 高：⑫ 环节双指数敏感度——对 \(\delta_v\) 精度要求极高（精度阈值标定属 G18 行内未闭合项），独立于此，但决定最终前向预言的可行性。
    5. 高：\(f_{\text{corr}}\) 对单元素晶体的参数化——当前 \(f_{\text{corr}} = 1 - 0.3(1 - 1/n_{\text{eff}})\) 对 fcc（配位12）敏感度过高，需从晶胞嘉当矩阵键几何精细化修正。
    6. 中：过渡金属 d 轨道杂化扩展、配合物点群分解。
    7. 中：Lean 形式化——\(L_{\text{mol}}\) 构造与球面角亏计算的 MolecularGeometry.lean 扩展（当前库已有分子嘉当矩阵与距离/耦合引理，扩展点明确）。

    11.3 与发生学分层共识的关系¶

    层级谱传递是发生学分层在超导预测链上的具体化：同步算符（紧化算符）在每个 FG 层级实现，正如各层级零点猜想是物质自组织在相应层级的数学体现——物质自组织逐层级铸造同步算符，同步算符谱逐层级传递，直到晶胞层级的本征值交叉以 \(T_c\) 的形式成为可观测。质数分布的深刻性不在于 GL(5)固定层级，而在于其谱结构（经 \(V_0\) 与 \(N(\gamma_n)\)/\(\gamma_n\) 两种语境）渗透并组织每一个物质层级。

    结论：每种 FG 都有自己的同步算符不是类比修辞，而是第一性预测链闭合的结构必然——嘉当矩阵链（链 B）贯通四层级，同步算符链必须同样贯通；分子 FG 同步算符是当前唯一缺失的层级，其构造（点群投影 + 杂化几何角亏）与元素层级严格同构，且直接给出 \(\delta_{\text{intrinsic}}\) 的内部来源。补齐该层级后，超导 \(T_c\) 预测链在逻辑上全程第一性（外部 DFT 依赖消除），剩余严格性缺口（耦合参数、双指数敏感度）被明确隔离并可独立攻关。
