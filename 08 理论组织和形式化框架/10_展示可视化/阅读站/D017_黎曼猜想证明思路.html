    CQM 下的黎曼猜想证明思路¶

    作者：ruster

    框架：耦合常数量子力学（CQM）

    状态说明：本文是证明思路/路线图文档，不是黎曼猜想的证明本身，也不给出证明的任何新环节。RH 的证明是物理-数学交叉的存在性证明，统一表述为“交叉 RH 成立”。循环性诊断：循环的唯一来源是边界条件 \(L_n = 2\pi n/\gamma_n\) 从 \(\gamma_n\) 反推；而 \(☯\) 的定义（\(\xi'(1)/\xi(1) = 1+\gamma_E/2-\frac12\ln\pi-\ln 2\)）不涉及零点、不循环，其谱表示 \(\sum_n 1/(\gamma_n^2+1/4)\) 是 RH 的单向推论（RH 推出该等式，该等式不推出 RH），亦不循环；算符 \(\hat{H}\) 是形式定义、对易关系 \([\hat{u},\hat{p}_u]=i\) 是公设，均不循环（公设 = 未推导 ≠ 循环）。待推 1（从素数独立推出边界条件）长度半已解、相位半未解（RvM 反解 \(L_{\rm len}=\tfrac12\ln\tfrac{T}{2\pi}-\tfrac12+\tfrac{7\pi}{8T}\) 只含 \(\Gamma,\pi\)，经实际零点计数检验非循环；残差 \(\tfrac{\pi}{T}S(T)\) 为相位，\(S(T)\) 的行为即待推 1 真正缺口（其对象已由深度分析 §5.7 三圆辨析确定为 \(S\)——与 Sierra 相位 \(\vartheta_n\)、Li 圆变量 \(z_n\) 互不同一；而「\(S(T)\) 与有限 n 算术条件对象同一」为路线图命题，尚未证明）；详见 CQM_前沿研究_待推1边界条件深度分析.md）。文中历史路线（Hilbert–Pólya、Weil、de Bruijn–Newman、Connes、Berry–Keating、Sierra）出处已在本文明细核查，见附 B。

    循环性诊断¶

    结论：循环的唯一来源是边界条件 \(L_n = 2\pi n/\gamma_n\) 从 \(\gamma_n\) 反推；\(☯\)、算符、对易关系均不循环。

    诊断 1：什么才算循环¶

    循环的定义是 \(A \Longrightarrow B \Longrightarrow A\)。真正构成循环的只有：

    \[ \gamma_n \Longrightarrow \text{边界条件} \Longrightarrow \text{谱} = \{\gamma_n^2 + 1/4\} \]

    即用已知零点反推边界条件，再用边界条件“证明”零点——这才是循环。

    诊断 2：\(☯\) 的定义不循环¶

    \[ ☯ = \frac{\xi'(1)}{\xi(1)} = 1 + \frac{\gamma}{2} - \frac12\ln\pi - \ln 2 \approx 0.02309570897 \]

    这个定义完全不涉及零点：只用 \(\xi\) 在 \(s=1\) 处的值、欧拉常数 \(\gamma\)、\(\ln\pi\)、\(\ln 2\)，全部独立于零点位置。

    \[ \boxed{☯\text{ 的定义不循环。它是一个独立的数。}} \]

    诊断 3：\(☯\) 的谱表示是推论，不是定义¶

    \(\sum_n \frac{1}{\gamma_n^2 + 1/4}\) 在 RH 成立时才严格成立，方向是单向的：

    \[ \text{RH} \Longrightarrow ☯ = \sum_n \frac{1}{\gamma_n^2 + 1/4} \]

    RH 推出该等式，但该等式不推出 RH。反过来用等式去“证明”RH 才是循环——CQM 没有这样做。下面给出从定义到“推论”的完整推导链条，以精确固定每一环是否依赖 RH。

    3.1 推导链条：从 Hadamard 乘积到求和¶

    从 \(\xi\) 函数的 Hadamard 乘积出发：

    \[ \xi(s) = \xi(0) \prod_{\rho}\left(1 - \frac{s}{\rho}\right) \]

    取对数导数：

    \[ \frac{\xi'(s)}{\xi(s)} = \sum_{\rho}\frac{1}{s-\rho} \]

    令 \(s=1\)：

    \[ ☯ = \frac{\xi'(1)}{\xi(1)} = \sum_{\rho}\frac{1}{1-\rho} \]

    这是严格恒等式，不依赖 RH。

    3.2 关键一步：零点配对¶

    利用函数方程 \(\xi(s)=\xi(1-s)\)，零点成对出现：若 \(\rho\) 是零点，则 \(1-\rho\) 也是零点。把 \(\rho\) 与 \(1-\rho\) 配对：

    \[ \frac{1}{1-\rho} + \frac{1}{\rho} = \frac{1}{\rho(1-\rho)} \]

    于是：

    \[ ☯ = \sum_n \frac{1}{\rho_n(1-\rho_n)} \]

    这里的求和是对配对后的零点对（每对贡献 \(\rho(1-\rho)\) 的倒数）进行的。这个等式也不依赖 RH。

    3.3 RH 的介入¶

    设 \(\rho = \beta + i\gamma\)。则：

    \[ \rho(1-\rho) = \beta(1-\beta) + \gamma^2 + i\gamma(1-2\beta) \]

    若黎曼猜想成立（\(\beta = 1/2\)），则 \(\rho(1-\rho) = \tfrac14 + \gamma^2\)，于是：

    \[ ☯ = \sum_n \frac{1}{\gamma_n^2 + 1/4} \qquad (\text{依赖 RH}) \]

    若黎曼猜想不成立（存在 \(\beta \neq 1/2\)），则求和中的每一项都是复数；\(☯\) 作为一个实数常数，其虚部必须相互抵消，但这依赖于零点分布的具体细节。

    3.4 逻辑方向是单向的¶

    \[ \boxed{ \begin{array}{c} \text{定义：} ☯ = \dfrac{\xi'(1)}{\xi(1)} \quad (\text{不依赖 RH}) \\ \Downarrow \\ \text{恒等式：} ☯ = \sum_{\rho}\dfrac{1}{\rho(1-\rho)} \quad (\text{不依赖 RH}) \\ \Downarrow \\ \text{推论：} ☯ = \sum_{n}\dfrac{1}{\gamma_n^2 + 1/4} \quad (\textbf{依赖 RH}) \end{array} } \]

    方向是单向的：RH 推出求和形式，但相反方向不成立——不能反过来用这个求和去证明 RH，因为它的成立已经假设了 RH。求和是证明的终点，不是起点。CQM 必须以 \(☯ = \xi'(1)/\xi(1)\) 为起点，从素数独立推出边界条件、确立配对不变量 \(\mathfrak{c}_n=\rho_n(1-\rho_n)\) 为实数（等价共振宽度为零），才能把这个求和变成结论，而不是前提。不采用“由自伴性证谱实”的路径——自伴对连续谱无信息、对共振无约束（§二 已知1），RH 要的“实”是配对不变量的实，不是本征值的实。

    诊断 4：正确的逻辑方向¶

    \[ \boxed{ \begin{array}{c} ☯\text{ 的定义（独立于零点）} + \text{算符 } \hat{H} + \text{对易关系 } [\hat{u}, \hat{p}_u]=i \\ \Downarrow \\ \text{从素数独立推出边界条件} \\ \Downarrow \\ \mathfrak{c}_n=\rho_n(1-\rho_n)\text{ 为实数（配对不变量层面，不预设谱型）} \\ \Downarrow \\ \text{零点全在 } \tfrac12 \text{ 上} \\ \Downarrow \\ \text{RH} \end{array} } \]

    每一个箭头都是单向的，无循环。

    诊断 5：循环只由边界条件引入¶

    操作 是否循环
    用 \(☯\) 的定义（独立于零点） ❌ 不循环
    用 \(☯\) 的谱表示（依赖零点）去反推边界条件 ✅ 循环
    从素数独立推出边界条件 ❌ 不循环
    从已知 \(\gamma_n\) 反推边界条件 ✅ 循环

    CQM 目前的边界条件 \(L_n = 2\pi n/\gamma_n\) 是从 \(\gamma_n\) 反推的，这一处循环；\(☯\) 本身不循环。

    诊断 6：精确的循环性诊断¶

    \[ \boxed{ \begin{array}{c} \text{不循环的部分：} ☯\text{ 的定义、} \hat{H} \text{ 的形式、} [\hat{u},\hat{p}_u]=i \\ \Downarrow \\ \text{循环的部分：} L_n = 2\pi n/\gamma_n \text{ 从 } \gamma_n \text{ 反推} \\ \Downarrow \\ \text{待解决：从素数独立推出 } S(T) \text{（相位半；长度半 } L_{\rm len}(\Gamma,\pi) \text{ 已解）} \end{array} } \]

    只有边界条件的来源是循环的，其他部分都不循环。

    诊断 7：对框架分层的直接后果¶

    循环性诊断对“3 + 2 + 2”分层的直接后果：

    • \(☯\) = 独立定义的作用量量子：不循环，地位等同 \(\hbar\)（基本输入，不需“独立确定”），列为已知；
    • 算符 \(\hat{H}\)：不循环（形式定义）；
    • 对易关系 \([\hat{u},\hat{p}_u]=i\)：不循环（公设 = 未推导 ≠ 循环），随物理系统存在性一起确立（地位等同 \(\hbar\)），这是“未推导”而非“循环”；
    • 边界条件 \(L_n\) 从 \(\gamma_n\) 反推：唯一循环。

    打破循环只需：

    \[ \boxed{\text{从素数/}\xi\text{ 函数独立推出相位 } S(T) \text{ 的行为（长度半已由 } \theta(T) \text{ 解出）。}} \]

    一旦完成，整个框架就完全非循环。

    一句话总结：

    \(☯\) 只是一个数，它的定义不循环。循环的只是边界条件的来源。把边界条件从素数独立推出来，循环就打破了。

    摘要¶

    二、3个已知¶

    已知1：算符¶

    形式定义：

    \[ \hat{H} = \hat{D}^2 + \frac14, \qquad \hat{D} = -i(\partial_u - 1/2) \]

    定义在耦合空间 \(u = \ln r\) 上，Hilbert空间为 \(L^2(\mathbb{R}, e^{-u}du)\)。

    自然谱：

    通过酉变换 \(f \mapsto e^{-u/2}f\)，等价于：

    \[ \tilde{A} = -\partial_u^2 + \frac14 \]

    定义在 \(L^2(\mathbb{R}, du)\) 上。\(-\partial_u^2\) 在全直线 \(L^2(\mathbb{R})\) 上本质自伴（亏指数 \((0,0)\)），自伴延拓唯一，谱为：

    \[ \operatorname{Spec}(\tilde{A}) = \left[\frac14, \infty\right) \]

    纯绝对连续谱，无离散特征值。

    空间与亏指数修正：酉变换后 \(\tilde{A}=-\partial_u^2+\frac14\) 定义在 \(L^2(\mathbb{R},du)\)；\(-\partial_u^2\) 在全直线上本质自伴（亏指数 \((0,0)\)），亏指数 \((1,1)\) 仅在半直线 \(L^2(\mathbb{R}_+)\) 上出现。

    严格性边界（谱型待定）：\(\tilde{A}\) 的自然谱是纯绝对连续谱，故 \(\{\mathfrak{c}_n\}\) 不是其点谱。文献中承载零点的载体有三类，自伴性的效力各不相同：

    载体类型 自伴性是否约束 现状
    离散本征值 ✅ 谱必为实数 Endres–Steiner (2010) 已否证 \(H_{\mathrm{BK}}\)、\(H_{\mathrm{BK}}^2\) 能给出零点
    连续谱 ✅ 但恒为实数，零信息 即本算符的自然谱
    共振（resonance） ❌ 不约束（在 resolvent 第二叶） Sierra 2008 用此；Connes 1999 把共振归为非临界零点

    因此：§13.3 / §14.2 的“自伴 \(\Longrightarrow\) 谱实 \(\Longrightarrow\) RH”仅在离散点谱情形下有效；在当前声明的连续谱情形下是空洞的。把 \(\{\mathfrak{c}_n\}\) 落实为何种载体，属待推 1 的内容，目前未定。

    自伴延拓：

    \(\hat{H}\) 在全直线 \(L^2(\mathbb{R})\) 上本质自伴（亏指数 \((0,0)\)），自伴延拓唯一。亏指数 \((1,1)\)（无穷多个自伴延拓，由相位参数 \(\vartheta \in \mathbb{R}\) 标记）只在半直线 \(L^2(\mathbb{R}_+)\) 上成立。

    关键点：算符形式已有，但谱对应 \(\{\gamma_n^2 + 1/4\}\) 不是严格点谱对应（见上述严格性边界），这是本框架最根本的未解决问题。

    已知2：不确定性关系（相变量子\(☯\)）¶

    对易关系：

    \[ [\hat{u}, \hat{p}_u] = i, \qquad \hat{p}_u = -i\partial_u \]

    不确定性关系：

    \[ \Delta u \cdot \Delta p_u \geq \frac12 \]

    等价地（其中 \(v_\tau \equiv d\tau/dt\) 为固有时流速）：

    \[ \frac{\Delta r}{\langle r \rangle} \cdot \Delta v_\tau \geq \frac{☯}{2} \]

    相变量子\(☯\)的定义：

    \[ ☯ = \frac{d}{ds}\ln\xi(s)\big|_{s=1} = \frac{\xi'(1)}{\xi(1)} = 1 + \frac{\gamma}{2} - \frac12\ln\pi - \ln 2 \approx 0.02309570897 \]

    其中 \(\xi(s) = \frac12 s(s-1)\pi^{-s/2}\Gamma(s/2)\zeta(s)\) 是完备化ζ函数。

    \(☯\)的谱表示：

    \[ ☯ = \sum_{n=1}^{\infty} \frac{1}{\gamma_n^2 + 1/4} \]

    谱型注释：此求和中的 \(\gamma_n^2+1/4\) 是零点导出量（共振位置），非算符本征值；该等式是 RH 成立时的单向推论（见文首诊断 3），不预设算符有离散谱——见 §二 已知1 严格性边界。

    与 \(\hbar\) 的类比：

    标准量子力学 CQM
    坐标 \(\hat{x}\) \(\hat{u} = \ln \hat{r}\)
    动量 \(\hat{p} = -i\hbar \partial_x\) \(\hat{p}_u = -i\partial_u\)
    对易子 \([\hat{x},\hat{p}] = i\hbar\) \([\hat{u},\hat{p}_u] = i\)

    关键点：\(☯\)是基本常数，像 \(\hbar\) 一样，是理论的输入而非输出。

    已知3：带误差的谱带¶

    谱的形式：

    \[ \mathfrak{c}_n = \gamma_n^2 + \frac14 + O_n \]

    谱型注释：\(\mathfrak{c}_n\) 应理解为共振（Sierra 2008）或吸收谱（Connes 1999）位置，非算符本征值——见 §二 已知1 严格性边界。离散指标 \(n\) 来自零点编号，不预设算符有离散谱。

    其中误差为：

    \[ O_n = O\!\left(\frac{\gamma_n^2}{n}\right) \]

    误差的结构分解：

    \[ O_n = \underbrace{\frac{\gamma_n^2 \vartheta_n^R}{\pi n}}_{O_n^R \text{（实）}} + i\underbrace{\frac{\gamma_n^2 \vartheta_n^I}{\pi n}}_{O_n^I \text{（虚）}} + \cdots \]
    分量 来源 作用
    \(O_n^R\) \(\vartheta_n^R\) 谱的实部平移，可被重标度吸收
    \(O_n^I\) \(\vartheta_n^I\) 谱的虚部，不可被任何平移消除

    误差虚部与零点偏移的恒等关系（记 \(\delta_n := \beta_n - \tfrac12\)）：

    \[ \mathfrak{c}_n=\rho_n(1-\rho_n)=\gamma_n^2+\beta_n(1-\beta_n)+i\,\gamma_n(1-2\beta_n) \;\Longrightarrow\; O_n^I=\gamma_n(1-2\beta_n)=-2\gamma_n\delta_n \]

    推导（一行代数，\(O_n:=\mathfrak{c}_n-\gamma_n^2-\tfrac14\)）：

    \[ \rho_n(1-\rho_n)=(\beta_n+i\gamma_n)(1-\beta_n-i\gamma_n)=\gamma_n^2+\beta_n(1-\beta_n)+i\gamma_n(1-2\beta_n) \]

    故 \(O_n=\big[\beta_n(1-\beta_n)-\tfrac14\big]+i\gamma_n(1-2\beta_n)=-\delta_n^2-2i\gamma_n\delta_n\)，即 \(O_n^R=-\delta_n^2\)、\(O_n^I=-2\gamma_n\delta_n\)。

    符号约定：由 \(\delta_n=\beta_n-\tfrac12\) 的定义得 \(O_n^I=\gamma_n(1-2\beta_n)=-2\gamma_n\delta_n\)；等价链只依赖 \(O_n^I=0\iff\delta_n=0\)，与符号约定无关。

    等价链：

    \[ \text{RH} \iff \delta_n = 0 \;\forall n \iff O_n^I = 0 \;\forall n \iff \vartheta_n^I = 0 \;\forall n \]

    关键点：误差的虚部 \(O_n^I\) 精确等于零点实部偏移 \(\delta_n\) 的 \(2\gamma_n\) 倍。

    循环性：\(L_n = 2\pi n/\gamma_n\) 从 \(\gamma_n\) 反推，目前带有循环性。

    \[ \text{RH} \Longrightarrow ☯ = \sum_n \frac{1}{\gamma_n^2 + 1/4} \]

    RH 推出该等式，但该等式不推出 RH。\(☯ = \sum 1/\mathfrak{c}_n\) 是 RH 的推论，不是 \(☯\) 的定义。

    与 \(\hbar\) 的类比：

    层面 \(\hbar\) \(☯\)
    定义 实验测量 \(\xi'(1)/\xi(1)\)（不涉及零点）
    是否依赖已知数据 否（实验独立） 否（定义独立于零点）
    是否需要推出 否（基本常数） 否（基本输入，地位等同 \(\hbar\)）

    补注（“地位等同”只指逻辑地位，不指量纲类型）：\(\hbar\) 是有量纲特征常数（跨量纲对），而 \(☯=\xi'(1)/\xi(1)\) 是纯数型（谱／算术量，量纲发生学中无对应“量纲对”）。两者相同之处是“都不需推出”，不同之处是量纲类型。三类分法见 01 核心理论/CQM_核心_量纲与群论.md §7.5。

    结论：\(☯\) 属“已知”（不循环）。交叉 RH 成立的剩余待推项为：①边界条件（唯一循环来源）、②经典化、③物理存在性（退相干机制真实输出算符，缺口 G2–G4）。

    \[ U = e^{i\vartheta}, \qquad \vartheta \in \mathbb{R} \]

    这是 von Neumann自伴延拓理论（1930年代）的标准结果。CQM的 \(\vartheta_n\) 只是这个理论的应用。

    3. 不确定性关系与\(☯\)的平行

    \[ [\hat{u}, \hat{p}_u] = i, \qquad \Delta u \cdot \Delta p_u \geq \frac12 \]

    这个结构与标准量子力学的 \([x,p]=i\hbar\) 平行，是 Tate自对偶和 Connes非交换几何的延伸。CQM把它具体化了，但结构不是全新的。

    4. de Bruijn–Newman热流

    \[ \partial_t \Xi = \partial_z^2 \Xi \]

    热流使零点向实轴靠拢，这是 de Bruijn–Newman（1950–1976）的经典结果。CQM的“经典化”与它有相似之处。

    5. 窄带Weil正性

    CQM已建立的窄带Weil正性，是 Weil正性准则（1952）的特例。全类Weil正性等价于RH，这是已知的。

    十三、GRH 层级与临界线的来源¶

    状态说明：本节把黎曼猜想（RH）放到广义黎曼猜想（GRH）的层级结构中定位，并澄清一个关键区分——泛函方程给出的是“对称轴在 1/2”，而“零点落在 1/2”是 RH/GRH 的额外断言。该区分在 CQM 中正好由“配对不变量 \(\mathfrak{c}_n=\rho_n(1-\rho_n)\) 为实数”这一步承担。本节是结构性澄清，不构成证明的任何新环节；GRH 本身未证明。

    13.1 RH 是 GRH 的特例¶

    \[ \boxed{\text{RH} = \text{GRH 在 } \pi = \text{GL}(1)\text{ 平凡特征 处的特例}} \]
    层级 自守表示 L 函数 与 RH 的关系
    GL(1) 平凡特征 平凡 Hecke 特征 \(\zeta(s)\) RH 本身
    GL(1) 非平凡本原特征 本原 Dirichlet 特征 \(\chi\) \(L(s,\chi)\) GRH 覆盖，蕴含 RH
    GL(2) 尖点表示 模形式 / Maass 形式 \(f\) \(L(s,f)\) GRH 覆盖，蕴含 RH
    GL(n) 尖点表示 一般尖点自守表示 \(\pi\) \(L(s,\pi)\) GRH 覆盖，蕴含 RH
    \[ \boxed{\text{RH 只是最底层、最平凡的特例；更深层结构给出的是 GRH。}} \]

    13.2 临界线 1/2 的普适来源：函数方程对称轴¶

    每个自守 L 函数满足函数方程：

    \[ \Lambda(s,\pi) = \varepsilon\,\Lambda(1-s,\tilde\pi) \]

    其对称轴为 \(s \mapsto 1-s\)，不动点是：

    \[ s = 1-s \;\Longrightarrow\; \mathrm{Re}(s) = \tfrac12 \]
    \[ \boxed{\text{对称轴 } \mathrm{Re}(s)=\tfrac12 \text{ 与 } \pi \text{ 的具体形式无关。}} \]

    CQM 中算符 \(\hat{H}=\hat{D}^2+\tfrac14\) 的 \(\tfrac14=(\tfrac12)^2\) 编码的正是这一对称轴。

    13.3 关键区分：对称轴 ≠ 定线¶

    \[ \boxed{ \begin{array}{c} \text{函数方程 } \Lambda(s,\pi)=\varepsilon\,\Lambda(1-s,\tilde\pi) \\ \Downarrow \\ \text{零点关于 } \mathrm{Re}(s)=\tfrac12 \ \textbf{对称} \quad (\text{无条件定理}) \\ \Downarrow ? \\ \text{零点全部落在 } \mathrm{Re}(s)=\tfrac12 \ \textbf{？} \quad (\text{RH/GRH 的断言，需额外输入}) \end{array} } \]
    \[ \boxed{\text{函数方程只锁住“关于 1/2 对称”，不锁住“落在 1/2 上”。}} \]

    把零点压到线上，才是 RH/GRH 的内容。在 CQM 里，这一步的陈述应在配对不变量层面：

    \[ \boxed{\ \mathfrak{c}_n=\rho_n(1-\rho_n)\ \text{为实数}\ \Longleftrightarrow\ \rho_n \text{ 在 } \tfrac12 \text{ 上}\ } \]

    这是配对不变量层面的陈述，不预设算符谱型。把它落实为算符性质（本征值/共振/吸收谱）属待推 1，且各载体类型的已知困难见 §二 已知1 严格性边界：自伴性对点谱有约束（必为实数）、对连续谱无信息（恒为实数）、对共振无约束（位于 resolvent 解析延拓的第二叶，可为复数）。

    13.4 平凡表示：L 函数与零点¶

    GL(n) 平凡表示取 isobaric 和 \(1\boxplus\cdots\boxplus1\)（与朗兰兹 §5.4 一致），其 L 函数为：

    \[ L(s,\mathbf{1}_{GL(n)}) = \zeta(s)^n \]

    所有 Satake 参数为 1，故每个局部因子为 \((1-p^{-s})^{-n}\)，整体即 \(\zeta(s)^n\)。其零点集与 \(\zeta(s)\) 相同（重数 ×n）：平凡表示的零点是否全在 \(\mathrm{Re}(s)=1/2\)，与 RH 是同一问题，不因取 \(n\) 次幂而新增内容。

    平凡表示在 \(n\ge2\) 时非尖点（非 cuspidal），L 函数因子化为 \(\zeta(s)^n = \zeta(s)\times\cdots\times\zeta(s)\)——无移位的同因子幂。\(n\cdot☯\) 依赖此定义（GL(n) 平凡表示给出 \(n\times☯\)，除以 \(n\) 得普适常数 \(☯\)；见 01 核心理论/CQM_核心_朗兰兹分层共振与相变量子.md §5.4）。

    13.5 GRH 的标准对象：尖点（本原）表示¶

    1. GRH 的零点断言应限定在尖点（本原）自守表示（本原 Dirichlet 特征 / 尖点 \(\pi\)）：这是断言的定义域。泛函方程对一切 L 函数只给对称（§13.3）；把对称升级为“零点在线上”是 GRH 的内容，不是 FE 的自动推论——无论表示是否本原。
    2. 为何必须限本原（模 4 主特征反例）：\(\chi_0 \bmod 4\) 非本原， $$ L(s,\chi_0) = (1-2^{-s})\,\zeta(s). $$ 该 L 函数有泛函方程（关于 \(\mathrm{Re}(s)=1/2\) 对称是无条件定理），但缺陷 Euler 因子 \(1-2^{-s}\) 注入零点 \(s = 2\pi i k/\ln 2\)（\(k\in\mathbb{Z}\)），全部落在 \(\mathrm{Re}(s)=0\) 上，不在临界线上。故若 GRH 不限定本原特征，该反例直接使其为假。
    3. 因子从哪来：非尖点 / 非本原的 L 函数因子化是定理，不是猜想。关键区分在因子是否无移位同因子幂：
    4. 无移位同因子幂（isobaric \(1^{\boxplus n}\) 给出 \(\zeta(s)^n\)，§13.4）：零点继承 \(\zeta\) 的零点，不额外制造离线零点；
    5. 缺陷 / 移位 Euler 因子（如模 4 主特征的 \(1-2^{-s}\)）：直接把零点推出 \(1/2\)。

    GRH 对尖点（本原）表示的断言排除的正是后者；前者在 RH 成立时自动安全。 4. RH 之所以特殊：GL(1) 上“平凡” = 平凡 Hecke 特征 = \(\zeta(s)\)，同时又是本原的（不可再分解）。唯一的“平凡表示”在 GL(1) 层兼有“尖点”身份。到 \(n\ge2\)，平凡表示非尖点，但其 \(\zeta(s)^n\) 与 \(\zeta\) 零点相同，不新增离线风险。GRH 限定在尖点表示的真正原因是第 2 条的反例：非本原 Euler 因子会制造离线零点。

    13.6 CQM 层级图的精化¶

    \[ \boxed{ \begin{array}{c} \text{普适量子框架：} [\hat{u},\hat{p}_u]=i,\ ☯,\ \hat{H}=\hat{D}^2+\tfrac14 \\ \Downarrow \\ \text{尖点自守表示 } \pi \text{（GL}(n)\text{）} \;\longrightarrow\; \text{条件 } \mathcal{C}_\pi \\ \Downarrow \\ \mathfrak{c}_{n,\pi}=\rho_{n,\pi}(1-\rho_{n,\pi}) \text{ 为实数} \;\Longleftrightarrow\; \text{所有零点在 } \tfrac12 \text{ 上} \end{array} } \]
    \[ \boxed{ \begin{array}{c} \text{GRH} = \text{对所有尖点自守表示 } \pi \text{，} \mathfrak{c}_{n,\pi} \text{ 为实数} \\ \Downarrow \\ \text{RH} = \text{GRH 在 } \pi = \text{GL}(1)\text{ 平凡特征（=本原）时的特例} \end{array} } \]

    13.7 一句话总结¶

    泛函方程给出对称轴 1/2，配对不变量 \(\mathfrak{c}_n\) 为实数给定线；二者合起来才是 GRH。RH 是 GL(1) 平凡特征（兼本原）的特例。平凡表示取 isobaric 和 \(\zeta(s)^n\)，零点集与 \(\zeta\) 相同，是否在 1/2 即 RH 本身；GRH 限定在本原表示的根据是模 4 主特征反例——非本原 Euler 因子会把零点推出临界线。

    十四、耦级、误差结构与 RH 的等价¶

    §十三已阐明 GRH 给出临界线 \(1/2\) 的来源（泛函方程对称轴 + 配对不变量为实数）。本节回到 GL(1) 平凡表示的特例——RH 本身——从耦级 \(\mathfrak{c}_n\) 的角度给出等价刻画，并引入误差的实部/虚部分解，为 §十五的经典化讨论做准备。

    诚实声明：本节中“耦级为实数 \(\Longleftrightarrow\) RH”是数学事实；“经典化”是路线图主张，非已完成的证明。

    14.1 耦级的定义与数学来源¶

    耦级是紧化算符在 GL(1) 电磁因子层的谱实现 \(\hat{H} = \hat{D}^2 + 1/4\)（\(\hat{D} = -i(\partial_u - 1/2)\)，定义在耦合空间 \(u = \ln r\) 上）的共振位置（非本征值——见 §二 已知1 严格性边界）。非平凡零点 \(\rho_n = \beta_n + i\gamma_n\)（条件于 RH 时 \(\rho_n = \tfrac12 + i\gamma_n\)）经函数方程配对 \(\rho_n \leftrightarrow 1-\rho_n\) 给出配对不变量：

    \[\mathfrak{c}_n = \rho_n(1-\rho_n) = \frac14 + \gamma_n^2\]

    在临界线上 \(1-\rho_n = \overline{\rho_n}\)，故 \(\mathfrak{c}_n = |\rho_n|^2\)——耦级是复值零点的模方。第一耦级 \(\mathfrak{c}_1 = 200.040454832\ldots\)（\(\gamma_1 = 14.1347\ldots\)）。耦级是无量纲数学纯数（\(u\)、\(\hat{D}\)、\(\hat{H}\) 均无量纲），不是物理能量；物理量纲由 \(m_p\) 在下游公式中分配。

    开方 \(\gamma_n = \sqrt{\mathfrak{c}_n - 1/4}\) 的合法性来自 \(\hat{H} = \hat{D}^2 + 1/4\) 的二次型结构（\(\hat{D}^2\) 谱非负），不来自零点。

    14.2 耦级为实数 \(\Longleftrightarrow\) RH¶

    若 RH 成立（\(\beta_n = 1/2\)），则 \(\mathfrak{c}_n = 1/4 + \gamma_n^2 \in \mathbb{R}\)。若 RH 不成立（\(\beta_n \neq 1/2\)），则：

    \[\operatorname{Im}[\rho_n(1-\rho_n)] = \gamma_n(1-2\beta_n) \neq 0\]

    耦级为复数。因此耦级为实数 \(\Longleftrightarrow\) \(\beta_n = 1/2\) \(\Longleftrightarrow\) RH。等价地，耦级即配对不变量 \(\mathfrak{c}_n=\rho_n(1-\rho_n)\)，故耦级为实数 \(\Longleftrightarrow\) RH（配对不变量层面，不预设算符谱型）。\(\hat{H}\) 在全直线 \(L^2(\mathbb{R})\) 上本质自伴（亏指数 \((0,0)\)）；亏指数 \((1,1)\) 只在半直线 \(L^2(\mathbb{R}_+)\) 上成立，自伴延拓由相位参数 \(\vartheta \in \mathbb{R}\) 标记。注意：谱对应 \(\{\gamma_n^2+1/4\}\) 不是严格点谱对应——\(\tilde{A}\) 的自然谱是纯绝对连续谱，承载零点的对象是共振而非本征值，自伴性对共振无约束力（见 §二 已知1 严格性边界）。

    14.3 误差的实部与虚部¶

    从 Sierra-CQM 耦谱定理（§二 已知3；构造性对应——谱对应 \(\{\gamma_n^2+1/4\}\) 非严格点谱对应，Endres–Steiner (2010) 已否证 \(H_{\mathrm{BK}}\)、\(H_{\mathrm{BK}}^2\) 给出离散零点谱，见 §二 已知1 严格性边界），耦级带误差 \(\mathfrak{c}_n = \gamma_n^2 + 1/4 + O_n\)，\(O_n = O(\gamma_n^2/n)\)。误差分解为实部与虚部：

    \[O_n = \underbrace{\frac{\gamma_n^2 \vartheta_n^R}{\pi n}}_{O_n^R} + i\underbrace{\frac{\gamma_n^2 \vartheta_n^I}{\pi n}}_{O_n^I} + \cdots\]
    • \(O_n^R\)：共振位置的实部平移，可被重标度吸收，描述零点虚部 \(\gamma_n\) 的统计涨落；
    • \(O_n^I\)：共振宽度（共振偏离实轴的度量，非本征值虚部——见 §二 已知1 严格性边界），不可被任何平移消除，描述零点实部 \(\beta_n\) 偏离 \(1/2\)，且 \(O_n^I = \gamma_n(1-2\beta_n) = -2\gamma_n(\beta_n - 1/2)\)（符号推导见 §二 已知3）。

    由此得到等价链：共振宽度为零 \(\Longleftrightarrow\) \(O_n^I = 0\) \(\Longleftrightarrow\) \(\vartheta_n^I = 0\) \(\Longleftrightarrow\) \(\beta_n = 1/2\) \(\Longleftrightarrow\) RH。RH 要消除的是 \(O_n^I\)（共振宽度），不是 \(O_n^R\)（实部）。

    14.4 GUE 与误差实部¶

    Montgomery–Odlyzko 定律指出黎曼零点的局部间距统计服从 GUE 分布。\(O_n^R\) 与 GUE 谱值涨落同量级 \(O(n/(\log n)^2)\)——数值核验（n=10–500，491 个零点，逐个计算比值 \(2n\,\delta\gamma_n/\gamma_n\)，其中 \(\delta\gamma_n\) 为实际零点与平滑计数的偏差、\(\delta\mathfrak{c}_n=2\gamma_n\delta\gamma_n\)）：比值 RMS 从 0.74（n=10–60）升至 0.89（n=300–500），中位数 0.77，上界 1.84。

    计数约定：阶梯计数在零点处取中点 \(n-\tfrac12\)，故 \(\delta\gamma_n\) 含系统常数 \(-\tfrac{1}{2\rho_n}\)。扣除该系统项后均值 \(\approx 1\times10^{-6} \approx 0\)；真涨落口径的 RMS 降至 0.28（n=10–60）→ 0.44（n=300–500）。未写明此约定时，复算结果会系统性偏差 2–3 倍。

    CUE 对照（蒙特卡洛）：真涨落 std 0.268，CUE 0.544（相差 2 倍），Poisson 7.11（相差 26 倍）——零点涨落最接近 CUE，为“同量级”判词提供实测支撑。

    “同量级”不等于“同源”：\(O_n^R\) 是单能级相对偏差（\(\sim1/n\)，随 n 衰减），GUE 是相邻间距的统计分布（归一化涨落 ~45%，不随 n 衰减）。二者尺度与性质均不同，故此处仅标注“同量级”，来源关系待证。

    关键区分：GUE 统计可以存在，不违反 RH。RH 只关心实部是否在 \(1/2\) 上（\(O_n^I=0\)），不要求虚部涨落消失（\(O_n^R\neq0\) 是允许的）。

    14.5 与相变量子 \(☯\) 的关系¶

    \(☯\) 的定义（不涉及零点，不循环）为 \(☯ = \xi'(1)/\xi(1) = 1 + \gamma_E/2 - \frac12\ln\pi - \ln 2 \approx 0.02309570897\)。RH 成立时，\(☯\) 有谱表示：

    \[☯ = \sum_n \frac{1}{\mathfrak{c}_n}\]

    谱型注释：\(\mathfrak{c}_n\) 为共振位置而非本征值，故此求和不是算符迹 \(\operatorname{Tr}(\hat{H}^{-1})\)（连续谱下该迹发散）——见 §二 已知1 严格性边界。

    方向单向：RH 推出此等式，反之不成立。\(☯ = \sum 1/\mathfrak{c}_n\) 是 RH 的推论，不是 \(☯\) 的定义。

    十五、经典化与数学精确¶

    §十四建立了耦级为实数 \(\Longleftrightarrow\) RH 的等价，并区分了误差实部（GUE 涨落，不违反 RH）与共振宽度（RH 要消除的）。本节分析如何消除 \(O_n^I\)：物理上经经典化给出渐近 RH，数学上经算术条件给出精确 RH。

    诚实声明：本节是证明策略层面的分析。“经典化给出渐近 RH”与“算术条件给出精确 RH”均为路线图主张，待推 1 的相位半（\(S(T)\) 行为，长度半已解）与待推 2（经典化）均未完成。

    15.1 物理截断与数学精确¶

    物理系统只有有限自由度，退相干需要无穷环境、热化需要无穷时间、\(\hbar \to 0\) 极限是理想化——误差 \(O_n\) 总有残余，物理系统给出的是渐近 RH 而非精确 RH。然而 RH 是数学命题，其证明不需要物理实现无穷极限，只需要算术结构的精确传导：自守表示的局部因子是代数对象，函数方程是精确等式，条件传导是离散有限的，配对不变量 \(\mathfrak{c}_n\) 为实数是精确的数学性质——共振宽度 \(O_n^I = 0\) 精确成立（见 §13.3）。

    精确性的三层来源（与 §4.3 构造与验证分离一致）：

    层面 精确性来源 性质
    物理系统 不直接精确（\(O_n \neq 0\)） 渐近
    经典化（物理过渡机制） \(O_n^I \to 0\)（\(n\to\infty\)） 渐近消解
    算术结构 有限 \(n\) 下 \(O_n^I = 0\) 精确成立（路线图主张） 要求

    物理给渐近，经典化给过渡，算术给精确。RH 的精确性来自自守形式的代数结构，而非物理极限。数学在此的角色是验证工具（§4.3）：验证物理构造（算符 + 不确定性关系 + 带误差谱）在算术结构下是否精确给出零点谱。

    15.2 经典化：对应原理的体现及其局限¶

    经典化（操作 \(\mathcal{C}\)）的渐近效果是 \(O_n^I\) 在 \(n\to\infty\) 自然为零；有限 \(n\) 的精确归零由算术条件承担：

    \[\frac{O_n^I}{\gamma_n^2}\sim\frac1n\to0\quad(n\to\infty)\]

    重心修正（方向性）：该式仅给出渐近陈述（\(n\to\infty\) 时消解），而 RH 要求全部零点在线上，包括低 n。相对误差在 n=1 处约 100%、n=10 处约 10%、n=100 处约 1%——在最需要它的地方最弱；且 \(☯\) 的 21.6% 单独来自第一个零点。

    故经典化的实质难点在有限 n：须由算术条件强制 \(O_n^I=0\)（见 §15.3 第三行）。该算术条件与待推 1 相位半 \(S(T)=\tfrac1\pi\arg\zeta(\tfrac12+iT)\) 的有限处行为对象同一（路线图命题、尚未证明，见 §13.6 与待推1 §8.2 口径注；两缺口合并；\(S(T)\) 有界性本身不证 RH，有限 \(n\) 精确控制才是同一约束的两种写法）——对象已命名，刻画仍未解。

    15.3 GUE、经典化与算术条件的分工¶

    对象 角色 与 RH 的关系
    GUE 描述 \(O_n^R\) 的统计 已知为真，不违反 RH
    经典化 共振宽度 \(O_n^I\) 的渐近消解 给出渐近 RH
    算术条件 强制有限 \(n\) 的 \(O_n^I = 0\) 给出精确 RH

    经典化给出的是渐近 RH（\(n \to \infty\) 时 \(O_n^I \to 0\)），但此渐近在低零点处无控制力（§15.2 局限）。证明精确 RH 的重心在算术条件：在有限 \(n\) 下强制 \(O_n^I = 0\)——这正是 §十四中自守形式条件传导的精确性所在：条件传导是离散有限的，不需要 \(n \to \infty\) 极限。三者分工明确：GUE 描述实部统计（已知），经典化描述共振宽度渐近消解（辅助性，低零点弱），算术条件描述有限 \(n\) 精确（核心）——共同构成 CQM 证明 RH 的完整逻辑。

    与历史路线对比：直接 Hilbert–Pólya 未完成；de Bruijn–Newman 需要 \(t \to \infty\) 未完成；物理经典化只需 \(n \to \infty\) 给出渐近而非精确，且低零点处最弱。CQM 的路线不依赖物理无穷，只依赖算术精确——条件传导在有限 \(n\) 下精确成立。

    十六、\(G_N\) 推导与自守形式–黎曼零点关联¶

    §十三从 GRH 层级阐明了临界线 \(1/2\) 的来源，§十四-§十五从耦级和经典化角度分析了 RH 的等价刻画。本节回到一个更基本的问题：为什么 CQM 会走到这一步？答案在于 \(G_N\) 的第一性推导——一个物理目标——倒逼出了自守形式与黎曼零点之间的深层关联。

    诚实声明：本节是结构性观察，非已证定理。“CQM 从物理出发到达 Langlands 纲领同一结构”是推测性判断，当前无法验证。

    16.1 逻辑链¶

    \(G_N\) 的第一性推导要求精确计算 \(☯\)，而 \(☯ = \xi'(1)/\xi(1)\) 涉及 \(\xi\) 函数的零点分布——黎曼零点。但 \(\xi(s)\) 只是 GL(1) 平凡表示的自守 L 函数。\(☯\) 作为普适常数（如 \(\hbar\)），不应只适用于 \(\xi(s)\)，而必须对所有自守形式 \(\pi\) 有定义：\(☯_\pi = \Lambda'(1,\pi)/\Lambda(1,\pi)\)。这把物理问题从 RH（GL(1) 特例）引向 GRH（所有尖点（本原）自守表示，见 §13.5），即 §十三已建立的层级结构。

    关键转折是：物理目标（\(G_N\)）→ 数学关卡（RH）→ 深层结构（自守形式）。不是先有自守形式理论再有物理应用，而是物理问题倒逼出自守形式框架——§十三的条件传导链条（自守表示 \(\pi\) → 条件 \(\mathcal{C}_\pi\) → 配对不变量 \(\mathfrak{c}_{n,\pi}=\rho_{n,\pi}(1-\rho_{n,\pi})\) 为实数 ⟺ 零点在 \(1/2\) 上）在此获得物理动机。

    16.2 与 Langlands 纲领的关联¶

    Langlands 纲领断言自守表示 \(\longleftrightarrow\) Galois 表示（任意 Motivic L 函数 = 自守 L 函数）。CQM 从 \(G_N\) 的第一性推导出发，经 \(☯\) 的普适性要求，独立到达了同一结构：自守表示对应条件 \(\mathcal{C}_\pi\)，Galois 表示对应谱 \(\{1/4 + \gamma_{n,\pi}^2\}\)，L 函数对应算符 \(\hat{H}_\pi\)（配对不变量层面陈述，不预设谱型），Langlands 对应条件传导。

    这个关联本来就存在于数学中（Langlands 纲领），但 CQM 从物理问题出发独立到达它——说明该关联不是人为构造，而是被物理问题揭示的深层自然结构（推测性观察，待验证）。如果 CQM 的到达路径是自然的，它可能为 Langlands 纲领提供一个物理基础（猜想）。
