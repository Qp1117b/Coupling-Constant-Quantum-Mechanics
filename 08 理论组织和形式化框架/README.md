## 一、总原则

- **外部理论文本不动**：`01`–`07` 理论文档不修改，本目录只存引用与结构化产物。
- **七个维度**：四个核心（结构化 / ML 数据准备 / 形式化验证 / 展示可视化）+ 三个辅助（动态机制 / 经验检验 / 元理论反思）；展示可视化是核心维度，面向人呈现理论的可计算、可推理、可验证、可交互形态。
- **Lean 已有只对接**，不重新形式化；**ML 只做数据准备**，不训练模型。
- **不引入理论外观点、术语、数值、文献**；缺口状态保持原样。

## 四、图模型

- 图类型：**有向超图（directed hypergraph）**，已用 XGI 构建可计算对象；等价为**多范畴**（`⇒` 为多元态射）。
- 节点：82 个概念实体（12 类：本体论、理论框架、数学结构、群论、关系类型、引力层级、纤维丛、几何、量纲、数论、物理、共形场论）。
- 超边 `⇒`：19 条**重组实现**（多因一果），如 `(物质先在, 再生产幂等) ⇒ (物质自组织)`。
- 有向边 `→`：51 条演化/映射/等价/依赖/层级含于。
- 可视化：`.dot`（Graphviz 源，6 cluster）、`.svg`/`.png`（networkx 渲染）、`超图可视化.html`（离线交互）。
