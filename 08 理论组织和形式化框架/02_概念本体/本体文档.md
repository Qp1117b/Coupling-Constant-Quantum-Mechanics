> 本文件说明 `本体.owl` 的类结构、对象属性、个体集合与查询方式。
> 本体由 `_build/build_ontology.py` 从 `01_结构化数据/{概念表,命题表,论证表}.csv` 生成，可重复构建。
> 权威源：`README.md` 符号约定 > `一体化研究/附录/术语表.md` > `一体化研究/附录/缺口台账.md` > 各文档概念权威定义处。
> 本体只登记概念、命题与论证的结构，不改动任何理论文档；缺口状态保持原样。

## 三、对象属性（二元关系）

| 属性 | 关系类型 | 语义 | 例 |
|:---|:---|:---|:---|
| `cqm:evolvesTo` | 演化 | 一般演化 / 极限 `→` | 前时空 → GR |
| `cqm:mapsTo` | 映射 | 结构保序映射 `→` | A₄ → M=EᵀE 本征值 |
| `cqm:equivalentTo` | 等价 | 同一数学对象两种诠释 | 联络 A_ℓ ↔ Virasoro {L_n} |
| `cqm:dependsOn` | 依赖 | 单向推论依赖 | ☯ 谱表示 → RH |
| `cqm:subsumedIn` | 层级含于 | 群层级含于 | GL(n) ⊂ Diff(M) ⊂ Sym(M) |
| `cqm:hasPremise` | （超边） | 前件集合 | 保留位 |
| `cqm:hasConclusion` | （超边） | 后件 | 保留位 |

> **`cqm:Hyperedge` 承载 `⇒` 重组实现**：多因一果的 n 元关系以个体重新化（reification），前件与后件分别写入注释属性 `cqm:premisesText` / `cqm:conclusionText`。二元属性（上表前五项）**不得**用于表示 `⇒`，以维持"`⇒` 仅表重组实现"的权威约定。

## 六、加载与查询

### 6.1 owlready2

```python
from owlready2 import get_ontology
onto = get_ontology("02_概念本体/本体.owl").load()
q = onto.search(iri="*C048")[0]
print(q.label, q.definition)          # ['相变量子'] ['☯=ξ'(1)/ξ(1)≈0.02309570897']
print(onto.NumberTheoryConcept.instances())   # 数论类全部个体
```

### 6.2 SPARQL（Protégé / rdflib / Apache Jena）

```sparql
PREFIX cqm: <http://cqm.local/ontology#>
SELECT ?label ?status WHERE {
  ?g a cqm:GapItem ; rdfs:label ?label ; cqm:status ?status .
} ORDER BY ?status
```

### 6.3 Protégé

`本体.owl` 为 RDF/XML，可直接在 Protégé 打开（OWL 2 QL 子集）；HermiT / ELK 可做一致性检验，`cqm:dependsOn`、`cqm:equivalentTo` 可作域/值域约束推断。

## 七、一致性约定（引用本体时须遵守）

1. **关系类型严格区分**：`⇒`（`cqm:Hyperedge`）仅表重组实现；演化 / 映射 / 等价 / 依赖 / 层级含于分别对应独立对象属性。
2. **缺口状态原样**：`status` 取自命题表，不得将 `待证明` / `未闭合` 改写为 `已证明`。
3. **跨文档歧义**：同一记号在 README 与各文档不同（见 `01_结构化数据/缺口依赖闭包.md` §七），本体的 `sourceDoc` + `sourceLoc` 用于消歧，不强行归一。
4. **登记保持项**：$\Delta\delta_v$ 与 $\Delta\delta_0$、$K_{\text{eff}}$ 与量纲转换常数族、$\kappa$ 多语义等术语表 §七"不得擅自统一"项，在本体中作为不同个体并存。
