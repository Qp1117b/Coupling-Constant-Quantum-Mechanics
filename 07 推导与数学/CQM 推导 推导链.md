# CQM 推导链

> **定位**：CQM 唯一逻辑骨架——合并推导链、研究展开链、状态总览。
>
> **两路径说明**：CQM 方程可从两条路径导出，但仅**因果集路径**自洽。**经典路径**（`08-经典路径：从作用量到谱的严格推导.md`）以作用量原理为工具，数学推导严格，在各推导层提供了精确计算入口，但**根本上走不通**——根本原因是**传输方程违背光速因果限制，与四维时空对抗**：传输方程 $\partial_\tau\phi + c e^u\partial_u\phi = 0$ 的 $u$ 方向是耦合常数/能标维度，其 RG 流动力学不遵守 4D Lorentz 因果结构。**因果集路径**（`07-论文/01` §3–§6）以因果集为底层本体论，Sprinkling 涌现 $\mathbb{H}^2$ 几何，是唯一自洽的本体论路径。本文以因果集路径为权威推导蓝本；经典路径的数学工具作为计算入口保留。
>
> **权威核心论文**：[`07-论文/01-耦合常数量子力学（CQM）：因果集、谱几何与物理常数的第一性原理.md`](../07-论文/01-耦合常数量子力学（CQM）：因果集、谱几何与物理常数的第一性原理.md) — 本文档以该文为最高权威的完整推导蓝本。
> **G_N 谱公式论文**：[`07-论文/02-CQM牛顿引力常数G_N的谱公式.md`](../07-论文/02-CQM牛顿引力常数G_N的谱公式.md)
>
> 全景评估与开放问题见 [`04-规范、群与标准模型：CQM视角与全景评估.md`](04-规范、群与标准模型：CQM视角与全景评估.md)。完整方程层级系统见 [`07-完整方程组.md`](07-完整方程组.md)，为当前最高权威的方程总表。严格数学推导见 [`08-经典路径：从作用量到谱的严格推导.md`](08-经典路径：从作用量到谱的严格推导.md)。

## 1. 推导总图

### 1.1 权威推导路径（因果集为底层）

```
物质先在（唯一公理）
  → 再生产动力学 μ∘μ=μ（有限存在者自我维持）
  → 因果集 C=(X,≺)（再生产事件的离散因果骨架）← 底层结构
  → Sprinkling → 测度 e^{-u}du → Adele框架
  → ℍ² 壳层几何（ds² = du² + e^{-2u}dθ²）
  → Ĥ_∞ = D̂² + 1/4（谱哈密顿量） → 谱 E_n = 1/4 + γ_n²
  → C = ξ'(1)/ξ(1) → [τ̂, û] = iC
  → Ĝ = -iCe^u∂_u（RG生成元）→ 传输方程（经典退化）
  → RG等价（du/dτ = Ce^u）→ SU(5)几何定理
  → 物理常数涌现（G_N, α⁻¹, sin²θ_W, …）
       │
       ├── 规范侧（语法层，数学必然）：群候选 → 破缺 → F² + Dμ
       └── 非规范侧（语义层，必须涌现）：质量谱 → 混合 → CP
```

**核心公理**：物质先在（唯一公理）。仅一个实验输入：$m_p$。
