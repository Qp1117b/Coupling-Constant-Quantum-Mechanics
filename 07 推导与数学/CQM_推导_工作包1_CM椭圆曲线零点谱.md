# CQM 工作包1：CM 椭圆曲线 L-函数零点谱精确计算

> 状态：**完成，经 PARI/GP 双通道复核**
> 目标：为非常规 d/p 波超导的 GL(2) 零点差 $\gamma_2^{(f)}-\gamma_1^{(f)}$ 提供权威算术精确值，替代早期文档中的启发式数值。

---

## 1. 目标与动机

CQM 发生学分层中，非常规（d/p 波）超导由 GL(1)+GL(2) **双谱**现象描述。由于指定的两条椭圆曲线均为 **rank=0** 的 CM 椭圆曲线，函数方程严格给出谱量子 $C_f = 0$，故 GL(2) 不通过谱量子进入转变温度 $T_c$，而是通过**零点差** $\gamma_2^{(f)}-\gamma_1^{(f)}$ 进入本征值交叉（与 GL(1) 的 $\gamma_2-\gamma_1$ 完全平行）。

早期文档将此零点差记为启发式值 **d 波 ≈ 0.367、p 波 ≈ 0.346**（约为 GL(1) 零点差 6.887315 的 5%）。本工作包的目标是：对这两条曲线做**精确解析数论计算**，给出逐条曲线的 $\gamma_1^{(f)},\gamma_2^{(f)},\gamma_2^{(f)}-\gamma_1^{(f)}$。

- 曲线选择（来自 CQM 理论，非本工作包改动）：
 - **d 波** ⟷ $E_1: y^2 = x^3 - x$，CM 由高斯整数 $\mathbb{Z}[i]$ 实现，导子 $N = 32$。
 - **p 波** ⟷ $E_2: y^2 = x^3 - 1$，CM 由三次单位根环 $\mathbb{Z}[\omega]$ 实现，导子 $N = 27$。

## 2. 计算方法

- 工具：**PARI/GP 2.17.3**（在 WSL/Debian 上经 `apt install pari-gp` 获得），使用内建 `lfunzeros`（Riemann–Siegel 型解析数论算法）。
- 精度：`default(realprecision, 40)`，输出保留 ≥ 20 位。
- **双通道复核**：
 1. `lfunzeros(E, 25)`（直接以椭圆曲线数据构造 L 函数）；
 2. `lfunzeros(lfuncreate(E), 25)`（显式以 L 函数数据构造）；
 两路的 $\gamma_1^{(f)},\gamma_2^{(f)}$ 逐位一致，确认实现稳定、数值可信。
- 可复现脚本：`CQM_推导_工作包1_CM椭圆曲线零点谱.gp`（同目录）。

## 4. 精确值与理论角色

精确零点差 d 波 `2.196681962`、p 波 `2.128515269` 作为后续标定的不动输入。GL(2)/GL(1) 比值为 d 波 $\approx 0.319$、p 波 $\approx 0.309$（$31\%$–$32\%$），自旋配对与电磁配对同量级，是协同主导项。

## 5. 对理论的影响

1. **映射系数标定**：文档以 $\gamma_{\text{eff}} = \gamma_n + 0.39\, j(j+1)$ 把 GL(2) 引入本征值交叉，系数 `0.39` 及 LOOCV 精度（中位约 35.7%）在精确零点差输入上标定。
2. **重新标定结果**（`gl2_contribution_analysis.py`，164 材料 LOOCV）：方案 A（$j(j+1)$）λ=+0.1692、GL2 中位 33.3%；方案 B（$\Delta\gamma_f$）λ=−0.3109、GL2 中位 33.1%；方案 C（标准化 $\Delta\gamma_f/\Delta\gamma_1$）λ=−2.1415、GL2 中位 33.1%；三者 R²≈0.639 基本持平。GL(2) 零点差与 $j(j+1)$ 在线性回归框架中携带相同信息量；零点差数值本身不提供额外预测力，其物理角色由底空间几何（而非数值大小）决定。
3. **双层谱结构**：四层 GL(1)×GL(2) 平凡/非平凡组合框架（常规 s 波 = GL(1) 非平凡 + GL(2) 平凡；非常规 d/p 波 = GL(1) 非平凡 + GL(2) 非平凡）。
