## 三、公式 (42) 验证

从 HTML 全文（arxiv.org/html/2406.01828v3）抓取公式 (40)–(42)：

$$\xi(s) \equiv s(s-1)\,\chi(s)/2, \quad \Re(s) > \tfrac{1}{2} \tag{40}$$

$$\frac{\xi'}{\xi}(s) = \frac{1}{s} + \frac{1}{s-1} - \frac{1}{2}\log\pi + \frac{1}{2}\frac{\Gamma'}{\Gamma}(s/2+1) - \sum_\rho\left(\frac{1}{s-\rho}+\frac{1}{\rho}\right) \tag{41}$$

$$B = -\gamma_E/2 - 1 + \log(2\sqrt{\pi}) = -0.0230957\ldots \tag{42}$$

其中 $\gamma_E$ 为 Euler-Mascheroni 常数。

### 与 CQM 相变量子 ☯ 的关系

CQM 中相变量子闭式：

$$☯ = 1 + \frac{\gamma}{2} - \frac{1}{2}\ln(4\pi) = 0.02309570897\ldots$$

验证 $B = -☯$：

$$B = -1 - \frac{\gamma_E}{2} + \log(2\sqrt{\pi})$$

利用 $\log(2\sqrt{\pi}) = \ln 2 + \frac{1}{2}\ln\pi = \frac{1}{2}(2\ln 2 + \ln\pi) = \frac{1}{2}\ln(4\pi)$：

$$B = -1 - \frac{\gamma}{2} + \frac{1}{2}\ln(4\pi) = -\left(1 + \frac{\gamma}{2} - \frac{1}{2}\ln(4\pi)\right) = -☯ \quad \checkmark$$

**结论**：✅ LeClair 论文公式 (42) 中常数 $B = -0.0230957\ldots$ 恰等于 $-☯$。☯ 在外部独立文献中涌现，非 CQM 独有构造。
