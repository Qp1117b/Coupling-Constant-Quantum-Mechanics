# CQM 探索：非弹性隧穿的零点共振指纹——无量纲比值预言、少数峰主导与 Z3/G21 边界——R60

> **定位**：探索稿（非权威源），v0.1，2026-11-17，第三十八轮。承接 R59（记忆核低能谱、$\gamma^{-2}$ 重尾、少数零点主导）、R30（只用频率比 $\gamma_n/\gamma_1$、不看绝对位置的诚实范式）。本轮把低能记忆核谱推进为一个**可证伪的无量纲实验预言**：若配对场记忆核谱在非弹性隧穿（$d^2I/dV^2$）显形，则共振峰位置比/强度比应为零点谱的纯数序列。
>
> **克制拟合声明**：零参数、无最小二乘——只预言无量纲比值（$\gamma_n/\gamma_1$、$w_n/w_1$），绝对能量标度外生（Z3）。**严格标注**：这是配对通道的【构造】候选，G21（赝能隙→STM 谱函数映射）仍未闭合，不声称"STM 峰=赝能隙"。脚本 `.calc/stm_fingerprint.py`（gitignore）。

## 第零部分：一句话结论

从 R59 记忆核低能谱给出一条**无量纲、可证伪**的预言：若配对场记忆核在非弹性隧穿显形，则共振峰位置比 $E_n/E_1=\gamma_n/\gamma_1=1,1.487,1.770,2.153,\ldots$，强度比 $I_n/I_1=w_n/w_1\propto\gamma_n^{-2}=1,0.45,0.32,0.21,\ldots$，且**少数峰主导**（第一峰 21.6%、前三峰 38.5% 的总权重）。这与通用 STM 非弹性谱"一个强 bosonic 模 + 弱伴峰"的形态一致，但给出**具体的纯数比值序列**可证伪。BCS 极限退化为单峰（无伴峰）。**严格边界**：只预言比值（Z3 绝对标度外生），且标为配对通道【构造】候选——G21 未闭合，不声称 STM 峰=赝能隙。新增判据 R60a/b/c。

## 第三节：理想模型与图像

### §3.1 配对场记忆核→非弹性隧穿（构造候选）

$$
\frac{d^2I}{dV^2}(V)\ \supset\ \sum_n w_n\,\delta(eV-E_n),\quad
\frac{E_n}{E_1}=\frac{\gamma_n}{\gamma_1},\quad \frac{I_n}{I_1}=\frac{w_n}{w_1}\approx\Big(\frac{\gamma_1}{\gamma_n}\Big)^2.
\tag{R60.1}
$$

只有**比值**是 CQM 预言；$E_1$（第一峰绝对能量）是外生标度（Z3），由材料声子/博索尼模能标定。

### §3.2 图像：少数峰指纹

```
  d2I/dV2
    │  █  <- 第一峰 (100%, E_1)
    │  █
    │  █  ░      <- 第二峰 (45%, 1.487 E_1)
    │  █  ░ ▒    <- 第三峰 (32%, 1.770 E_1)
    └─┬──┬─┬──→ eV
      E1 1.487E1 1.770E1 ...
  位置比/强度比 = 零点谱纯数; 绝对 E1 外生
```

## 第四节：预言计算（零参数，无量纲）

### §4.1 峰位置比与强度比

| $n$ | $\gamma_n$ | $E_n/E_1=\gamma_n/\gamma_1$ | $I_n/I_1=w_n/w_1$ |
|:---|:---|:---|:---|
| 1 | 14.1347 | 1.000 | 1.000 |
| 2 | 21.0220 | 1.487 | 0.447 |
| 3 | 25.0109 | 1.770 | 0.319 |
| 4 | 30.4249 | 2.153 | 0.216 |
| 5 | 32.9351 | 2.330 | 0.184 |

序列 $1,1.487,1.770,2.153,\ldots$ 与 $1,0.45,0.32,0.22,\ldots$ 是**纯数**，由零点谱给出，无拟合参数。

### §4.2 少数峰主导

第一峰占总权重 21.6%、前三峰 38.5%（R59）——预言"一个强峰 + 若干弱伴峰"，与通用 STM bosonic 模谱形态一致（Z2），但给出**具体比值序列**可证伪。

### §4.3 BCS 退化

单模极限（只留第一零点）→ 单一共振峰、无伴峰（$I_{n\ge2}\to0$）——标准单极点 BCS/Eliashberg 响应，退化守住。

## 第五节：新判据 R60（三条，可证伪）

- **R60a（峰位置比）**：若配对场记忆核在非弹性隧穿显形，共振峰位置比须为 $\gamma_n/\gamma_1=1,1.487,1.770,2.153,\ldots$。若高分辨 $d^2I/dV^2$ 测到一组峰，其位置比系统性偏离此序列（超出实验误差），则本构造候选被证伪。
- **R60b（强度比）**：峰强度比须 $\propto\gamma_n^{-2}=1,0.45,0.32,0.22,\ldots$；若强度不随峰序单调递减或标度不符，则记忆核权重图像失效。
- **R60c（少数峰 + BCS 退化）**：应见"一强峰 + 弱伴峰"（前三峰占主体）；BCS 端（配对限制支）伴峰消失、退化为单峰。若非常规端无伴峰或常规端仍有伴峰序列，则两阶段退化失败。

> **可证伪性诚实说明**：这些比值是固定纯数序列，实验可检验——非同义反复。但**前提**（配对场记忆核在 $d^2I/dV^2$ 显形）是【构造】，未经证实；若 STM 峰来自其他机制（声子/磁模/PDW），本判据不适用。与 R41（约瑟夫森）、R42（NMR）、R55（THG）测不同对象。

## 第七部分：边界与开放问题

1. **G21 未闭合**：本轮**不声称** STM 峰=赝能隙；只说"若配对场记忆核在隧穿显形"的条件预言。赝能隙→谱函数映射仍是缺口。
2. **Z3 绝对标度**：只预言峰**比值**，不预言第一峰绝对能量（外生，需材料 bosonic 模能标定）。
3. **前提未证**：配对场记忆核是否在 $d^2I/dV^2$ 显形本身是构造；实验若显示峰来自声子/磁模，本判据不适用。
4. **与已知 STM 的关系**：Z2 的多峰是 bosonic 模耦合，未必是零点谱——本轮给的是**另一种比值pattern**供区分，不硬套。
