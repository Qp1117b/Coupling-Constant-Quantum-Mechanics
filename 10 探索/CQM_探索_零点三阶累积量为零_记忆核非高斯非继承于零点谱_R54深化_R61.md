## 第零部分：一句话结论

对 6000 零点展开谱做窗口计数统计：方差 **var=0.12–0.35**（Poisson 应为 5–80，即 GUE 刚性饱和）、偏度 **$\approx0$**（L≥40 精确为 0）、**三阶累积量 per length $\approx0$**（$\pm5\times10^{-4}$）。这是**行列式点过程**（GUE）的预期：n 点关联由 $\det[K(x_i,x_j)]$ 给出，connected 高阶累积量为零。**判决**：零点谱计数统计近高斯（偏度≈0）、三阶累积量≈0，而 R54 相位耦合记忆核 $\kappa_3=0.25\ne0$——两者**不同源**。故记忆核的非高斯性（$K_{123}\ne0$）**不是从零点谱继承的**，只能来自相位耦合（R54 机制唯一性获排除性支撑）。新增判据 R61a/b/c。

## 第三节：理想模型与图像（两层非高斯辨析）

### §3.1 零点层 vs 记忆核层的三阶统计

$$
\text{零点层（行列式）}:\ \langle\langle C_{12}C_{23}C_{31}\rangle\rangle_{\rm zeros}=0;\qquad
\text{记忆核层（相位耦合）}:\ \kappa_3^{\rm mem}=0.25\ne0.
\tag{R61.1}
$$

- 零点计数统计：方差饱和（刚性）、偏度≈0、三阶累积量≈0 → 近高斯（行列式/自由费米子）。
- 相位耦合记忆核：R54 双谱检测 $\kappa_3=0.25$、独立相位为 0 → 非高斯来自相位耦合。

### §3.2 图像：非高斯性的来源分工

```
  零点谱 {gamma_n}  ──行列式过程──> 计数近高斯 (skew≈0, kappa3≈0)
        │  (谱刚性, var 饱和)
        │  不携带非高斯性
        ↓ 频率集 (M1 谱位置)
  记忆核 K(t)=sum A_n e^{i gamma_n t}
        │
        └─ 非高斯性来源 = 相位耦合 (R54: kappa3=0.25)
           NOT 继承自零点谱 (本轮排除)
```

## 第五节：新判据 R61（三条）

- **R61a（零点谱近高斯）**：零点计数统计的偏度须≈0、三阶累积量 per length≈0、方差饱和（GUE 刚性）；若某"零点集"显显著非零偏度/三阶累积量，则非 GUE 行列式过程。
- **R61b（非继承性）**：记忆核的非高斯性（$\kappa_3^{\rm mem}\ne0$）不能由零点谱统计（$\kappa_3^{\rm zeros}\approx0$）解释，必来自相位耦合；若实验测到记忆核 $\kappa_3\ne0$ 但零点通道无相位耦合证据，则 R54 的"相位耦合唯一来源"被挑战。
- **R61c（两通道分离）**：零点层给频率集/刚性（形状），相位耦合层给非高斯/相变（$K_{123}$）；若某观测量把两者混为一谈（如用零点 $\kappa_3$ 解释 $K_{123}$），则违反本判决。

> 与 R54（相位耦合产 $\kappa_3$）、R48（两点 GUE）、R51（振幅 Gumbel）测不同对象：R61 测**零点层三阶累积量（排除性判决）**。

## 第七部分：边界与开放问题

1. **数学非 CQM 独有**：行列式过程三点关联/累积量是标准理论（Conrey 2008/X2），CQM 增量只在接入记忆核非高斯来源辨析。
2. **三点关联本身非零**：行列式过程 connected 三阶累积量为零，但三点关联 $\det[K]$ 本身非零（X1）——本轮测的是计数统计的 connected 累积量（≈0），与三点关联非零不矛盾。
3. **低零点非普适**：小 L 偏度有波动（L=20: −0.221），高 L 趋 0——低零点半经典区非普适（R48 同结论）。
4. **"不同源"是判决**：R54 的相位耦合非高斯与零点谱非高斯被严格区分——这是本轮的正面成果（防止错误嫁接）。
