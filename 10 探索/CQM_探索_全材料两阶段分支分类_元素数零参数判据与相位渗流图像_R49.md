## 第零部分：一句话结论

把 CQM 两阶段理论的两支映射到数据库的机制标签——**配对限制支（$T_c=T^*$，单阶段 BCS，无赝能隙）= 常规超导；相位限制支（$T_c=T_\theta<T^*$，相位渗流，赝能隙）= 非常规（铜氧化物/铁基/有机）**——发现一条零参数无量纲判据：组成元素数 $n_{\rm elem}\ge3$（多元素→更多 Regge 失配来源→相位阻挫网络→需渗流）以 **90.5%** 准确率分类 169 个材料（非常规 recall 0.94、常规 TN 90/102），阈值 $k=3,4$ 同分居稳、留一类交叉验证对未见常规类近全对。这不是拟合 $T_c$，而是 CQM"相位渗流需要复杂网络"图像在**全数据库**上的直接印证。判据给出三条可证伪预言 R49a/b/c，并逐项守住 BCS/迈斯纳退化。

## 第三节：理想模型与图像

### §3.1 理想模型：连通性→相位渗流→两阶段分支

CQM 两阶段的物理链（核心 §0.2、DM.9–DM.13）：

$$
\underbrace{\text{结构复杂度}}_{\text{元素数/失配源}}\ \longrightarrow\ \underbrace{\text{相位阻挫}\ K_{123}}_{\text{三体环路核}}\ \longrightarrow\ \underbrace{\text{渗流阈值}\ p_c}_{\text{相位网络连通}}\ \longrightarrow\ T_c=\min(T^*,T_\theta).
\tag{R49.1}
$$

- 少元素、三维简单晶格（A15/元素/合金）：相位阻挫弱、$T_\theta\gg T^*$ → $T_c=T^*$ → **配对限制支（BCS 型）**。
- 多元素、强关联层状（铜氧化物/铁基/有机）：失配源多、相位阻挫强、$T_\theta<T^*$ → $T_c=T_\theta<T^*$ → **相位限制支（赝能隙型）**。

**零参数代理**：元素数 $n_{\rm elem}$ 是"失配源数目/网络复杂度"的最简无量纲代理（不参与拟合，只作分类阈值）。

### §3.2 图像：两阶段分支相图（无量纲）

```
  相位阻挫 K_123 / n_elem  →
  低(简单,3D)                          高(复杂,层状)
  ┌─────────────────────────────────────────────────┐
  │ 配对限制支               crossover        相位限制支 │
  │ Tc=T*, 无赝能隙        T*=Tθ            Tc=Tθ<T*    │
  │ BCS 型                (最佳掺杂)        赝能隙型      │
  │ ΔC/γTc=1.43           ΔC→0             ΔC=0        │
  │ 常规: 元素/A15/合金/   铜氧化物/铁基/有机             │
  │       氢化物/石墨插层                                │
  └─────────────────────────────────────────────────┘
        n_elem <=2                          n_elem >=3
```

## 第四节：数据判决（226 材料，零参数）

### §4.0 数据与方法

数据库 `superconductors_deduplicated.csv` 226 条，类别 12 族；机制字段常规 125 / 非常规 61 / 非常规 d 波 22 / 待定若干。按类别分两组（避免用机制文本自我循环）：
- **相位限制支**（非常规）：铜氧化物 22、铁基 26、有机 19 = 67 条。
- **配对限制支**（常规）：元素常压 27、元素高压 15、A15 14、合金 8、氢化物 22、富勒烯 9、石墨插层 7 = 102 条。
- 其余 57 条（"其他金属间/其他特殊"）机制混杂，保留为独立验证集。

特征：从化学式提取**不同元素数** $n_{\rm elem}$（去压力/conditions 字段，正则抓元素符号去重）。

### §4.1 主结果（零参数阈值）

| 组 | n | $n_{\rm elem}$ 中位数 | 均值 | $P(n_{\rm elem}\ge3)$ |
|:---|:---|:---|:---|:---|
| 相位限制支（非常规） | 67 | 5.0 | 4.55 | 0.94 |
| 配对限制支（常规） | 102 | 2.0 | 1.74 | 0.12 |
| 其他（混合） | 57 | 3.0 | 2.61 | 0.51 |

零参数规则 $n_{\rm elem}\ge3\Rightarrow$ 相位限制支：TP=63、FP=12、TN=90、FN=4，**accuracy=0.905**，precision(非常规)=0.840、recall(非常规)=0.940。中位数差 5.0 vs 2.0 是**天然分界**（非拟合）。

### §4.2 稳健性（核过拟合）

- **阈值平台**：$k=3$ 与 $k=4$ 同为 0.905；$k=4$ precision 升到 0.99（FP=1）但 recall 降到 0.77。$k=2$（0.633）、$k=5$（0.805）都差——$k=3,4$ 是稳定平台，不是尖峰调参。
- **留一类交叉验证**（在剩余类定阈值、测留出类）：A15 / 元素常压 / 元素高压 / 合金 / 石墨插层测试全 **1.00**；有机 0.95、铜氧化物 0.91。**未见过的常规族完全正确**，排除 L2 的家族偏向陷阱。
- **已知失败族（诚实登记）**：富勒烯 0.44、铁基 0.54、氢化物 0.68——多元素但机制特殊（富勒烯分子晶体、铁基 s±、氢化物高压强耦合），是判据边界，不硬套。
- **混淆检查**：高压比例非常规 18% vs 常规 40%——分类**不是**"高压代理"；$n_{\rm elem}$ 与 $T_c$ 的相关性此前已登记弱且类间驱动，本判据不依赖 $T_c$。

### §4.3 解释力（覆盖所有数据现象）

| 数据现象 | 两阶段分类解释 | 状态 |
|:---|:---|:---|
| 常规 $T_c\lesssim23$ K（A15/元素/合金） | 配对限制支，单阶段 BCS，$\lambda$ 中等 | ✅ 自洽 |
| 铜氧化物 $T_c$ 高达 130 K + 赝能隙 | 相位限制支，强相位阻挫，赝能隙=$T^*>T_c$ | ✅ 自洽 |
| 铁基高 $T_c$ + s± | 相位限制支（多元素），配对对称性细节另论 | ⚠ 分类对、配对分支边界 |
| 氢化物高压 200+ K | 配对限制支（强电声，高压给大 $\omega_D$），元素数少 | ✅ 自洽（高压仅能标，非分类） |
| 有机/富勒烯低 $T_c$ | 有机=相位限制（强关联）；富勒烯=多元素但分子晶体，判据边界 | ⚠ 部分 |
| $T_c$ 绝对值跨族散乱 | Z2：外生能标，本理论只给无量纲分支+比值 | ✅ 诚实边界 |

## 第五节：可证伪判据 R49（三条，与 R32/R40–R48 测不同对象）

- **R49a（分支分类）**：对任一新材料，按 $n_{\rm elem}\ge3$ 预测其分支——非常规（相位限制、有赝能隙、$\Delta C(T_c)=0$）vs 常规（配对限制、BCS 跳变 $\approx1.43$）。若某 $n_{\rm elem}\ge3$ 材料在 $T_c$ 处显尖锐 BCS 比热跳变且无赝能隙，或 $n_{\rm elem}\le2$ 材料显赝能隙，则该判据被证伪。
- **R49b（阈值平台）**：门槛应在 $k=3$–$4$ 附近（非 $k=2$ 或 $\ge5$）；若更大样本上最优阈值系统性漂移出 [3,4]，则"元素数=失配源代理"的图像需重建。
- **R49c（与能标解耦）**：在同一分支内 $T_c$ 的绝对差异（如氢化物 200 K vs 元素 10 K）应由外生能标（$\theta_D$/压力）决定，与 $n_{\rm elem}$ 无关；若 $n_{\rm elem}$ 能预测分支内绝对 $T_c$，则违反 Z2，需改理论。

> R49 测**分支归属（无量纲）**，与 R32（谱普适类）、R40–R42（比热/光学/约瑟夫森/NMR 的 $x$ 投影）、R48（记忆核 SFF）测不同对象，互相独立。

## 第七部分：边界与开放问题

1. **分类非预测**：$n_{\rm elem}$ 是粗代理，不是 CQM 原生几何量（原生量是 $\Delta\varepsilon$ 涨落谱）；数据库缺逐材料 $\Delta\varepsilon$，故用元素数代理。这是形状层的可证伪指纹，不是第一性 $T_c$ 公式。
2. **失败族诚实登记**：富勒烯/铁基/氢化物是判据边界（§4.2），不硬套、不删数据凑数。
3. **机制标签自洽性**：分组用"类别"而非"机制"文本，避免自我循环；但类别本身是人为归类，留有主观性。
4. **$T_c$ 不是目标**：守 Z2，本轮明确拒绝"拟合所有 $T_c$"的误读。
5. **M1/RH 未触碰**：本轮不涉及零点通道同一性或 RH 证明。
6. **文档处理**：本轮未发现需删除的"不对劲"文档；既有纠错稿按项目惯例以纠错指针处理，物理删除须你确认，本轮不删任何文档。
7. **未做**：lean、网站、完整理论文档、任何参数拟合。
