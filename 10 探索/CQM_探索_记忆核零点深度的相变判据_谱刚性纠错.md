## 第零部分：问题与路线

前四轮已确立命题 Z：$\zeta$ 通道标度无关，零点 $\gamma_n$ 是无量纲纯数，$t_n=\gamma_n/(2\omega_0)$ 的绝对时刻由外部 $\omega_0$（$\propto T_c$ 或 $\theta_D$）决定，零点只提供比值 $\gamma_n/\gamma_1$（GUE 形状指纹）。据此 R1 被收紧为 R1′：只看无量纲比值，不看绝对时刻。

但 R1′ 仍是**静态**指纹——它说"极小出现在何处"，没说"极小随温度如何变化"，因而没有把零点与**相变本身**连起来。《通道》§10 虽写了 $2\sigma_0=1/2\leftrightarrow T=T_c$（竖直线穿越临界线），却停在定性层面，没有问：**穿越临界线时，记忆核在零点时刻发生什么可观测的变化？**

|                                                                                                              |   |                                                                                                  |
| ------------------------------------------------------------------------------------------------------------ | - | ------------------------------------------------------------------------------------------------ |
| 本轮的回答是严格数学：$K(t)$ 沿竖直线 $\Re s=2\sigma_0$ 取值，当且仅当 $2\sigma_0=1/2$ 时，$t=\gamma_n/(2\omega_0)$ 是 $K$ 的**真零点**（$ | K | =0$）；$2\sigma_0>1/2$时零点离开实轴，时域只剩**部分相消**，深度随$\sigma_0$ 单调。于是"→临界线"等价于"极小深度→100%"。这就把零点指纹升级成相变判据。 |

## 第一部分：严格核心——相消深度 $d(\sigma_0)$

记忆核（《通道》M.7/M.8，幂律权重条件下）：

$K(t)=\sum_{n\ge1}n^{-2\sigma_0}e^{i2\omega_0t\ln n}=\zeta\!\left(2\sigma_0-i\,2\omega_0t\right).\tag{1}$

|                                                                |   |                                                                                        |
| -------------------------------------------------------------- | - | -------------------------------------------------------------------------------------- |
| 令 $\tau=2\omega_0t$，竖直线 $\Re s=2\sigma_0\equiv q$。考察 $q$ 固定时 $ | K | $在$\tau=\gamma_1$（第一个零点虚部）与其邻域背景（取 $\tau_m=\tfrac12(\gamma_1+\gamma_2)$）之比，定义**相消深度**： |



|                 |                    |    |                  |             |
| --------------- | ------------------ | -- | ---------------- | ----------- |
| $$d(q)=1-\frac{ | \zeta(q+i\gamma_1) | }{ | \zeta(q+i\tau_m) | }.\tag{2}$$ |

【严格：$\zeta$ 标准数学，$q>1$ 收敛，$q\le1$ 由解析延拓】数值（$q=2\sigma_0$，$\gamma_1=14.134725$、$\gamma_2=21.022040$）：

| $q=2\sigma_0$ | $                   | \zeta(q+i\gamma_1) | $          | 背景 $ | \zeta(q+i\tau_m) | $ | 相消深度 $d$ |
| :------------ | :------------------ | :----------------- | :--------- | ---- | ---------------- | - | -------- |
| **0.50（临界线）** | $6.7\times10^{-16}$ | 2.3160             | **100.0%** |      |                  |   |          |
| 0.51          | $7.9\times10^{-3}$  | 2.3041             | 99.7%      |      |                  |   |          |
| 0.55          | $3.9\times10^{-2}$  | 2.2578             | 98.3%      |      |                  |   |          |
| 0.60          | $7.6\times10^{-2}$  | 2.2023             | 96.5%      |      |                  |   |          |
| 0.70          | $1.5\times10^{-1}$  | 2.0990             | 93.0%      |      |                  |   |          |
| 1.00          | $3.3\times10^{-1}$  | 1.8413             | 82.3%      |      |                  |   |          |
| 1.50          | $5.4\times10^{-1}$  | 1.5436             | 64.7%      |      |                  |   |          |

**严格读法**：

|   |   |   |
| - | - | - |

1. $q=1/2$ 时 $|\zeta(1/2+i\gamma_1)|=0$（数值 $6.7\times10^{-16}$ 为浮点零），$d=100\%$ ——真零点。
2. $d(q)$ 在 $q>1/2$ 上**单调递减**（$1\to0.5$ 方向单调加深），从 $64.7\%$ 连续升到 $100\%$。
3. 深度只依赖 $q$ 与零点位置——**与 $\omega_0$、与材料无关**：这是无量纲量，天然跨材料可比。

## 第二部分：条件映射与可证伪判据 R1″

《通道》§9/§10 给出（**条件严格**：基态主导 + 矩阵元缓变）：权重指数即物理逆温度，$\sigma_0(T)=\beta_u(T)$，且

$2\sigma_0=\frac12\quad\Longleftrightarrow\quad T=T_c.\tag{3}$

把 (3) 接入第一部分，得**判据 R1″**：

$\mathbf{R1''}:\quad T\to T_c^{-}\ \Longrightarrow\ \sigma_0\to\frac14\ \Longrightarrow\ d\to100\%\ \text{（记忆核自相关第 }n\text{ 个极小深度趋于完全相消）}.\tag{4}$

可观测量：记忆核自相关（通量噪声自相关 / 微波阻抗谱的时间结构，沿用《通道》R1 的探针）在 $\tau_n=\gamma_n/(2\omega_0)$ 处的极小**深度**随温度降低单调加深，并在 $T_c$ 处达到 100%（零点）。判据的证伪方式：

- 若极小深度**不随温度变化**，或 $T_c$ 处不到 100% → 竖直线-临界线对应失败，$K=\zeta$ 的相变读法被否定。
- 若深度变化但**非单调** → (3) 的 $\sigma_0(T)$ 映射需重建。
- 若深度普适但极小**时刻比值** $t_n/t_1\ne\gamma_n/\gamma_1$ → 回到质数模式通道（《通道》R1′ 的分支）。

> **分层诚实**（三层依赖强度不同，不可混同）：
>
> - 【严格】给定竖直线 $\Re s=q$，深度函数 $d(q)$ 单调且 $d(1/2)=100\%$（第一部分）；
> - 【条件严格】$2\sigma_0=1/2\leftrightarrow T=T_c$（《通道》§10，依赖基态主导 + 矩阵元缓变）；
> - 【候选：合并】$T\to T_c\Rightarrow d\to100\%$（R1″，继承上一层的条件性）。
>
> **重要边界**：$\sigma_0(T)$ 的矩阵元缓变假设正是《通道》§30.1 撤销 M.33 后"来源待重建"的那一项。故 R1″ 的**温度自变量**站在一条已被部分撤销的假设上——这是它相对第一部分严格数学的主要弱点，登记为开放项，不在本文隐瞒。

**相对 R1′ 的实质推进**：R1′ 只断言"极小在 $\gamma_n/\gamma_1$ 处"（静态、与温度无关）；R1″ 断言"极小深度随 $T\to T_c\to100\%$"（动态、绑定相变点）。二者是同一记忆核的两个独立可证伪面：一个测位置，一个测深度。R1″ 更强，因为它把零点直接连到相变临界点，而非只连到谱形状。

## 第三部分：跨材料塌缩——无量纲深度曲线

R1″ 之所以能跨材料检验，因为深度 $d$ 是**无量纲**的：它只依赖 $q=2\sigma_0$ 与纯数 $\gamma_n$，不含 $\omega_0$。故预言：

$\text{对材料 A 与 B：}\quad d_A\!\left(\frac{T}{T_{c,A}}\right)=d_B\!\left(\frac{T}{T_{c,B}}\right)\quad\text{当 }\sigma_0(T/T_c)\text{ 取同一函数形式}.\tag{5}$

即：把不同材料的记忆核极小深度对归一化温度 $T/T_c$ 作图，应**塌缩到同一条曲线**；曲线在 $T/T_c=1$ 处取 100%。这是"形状通道"能给出的最强普适性声明——不是能标普适（$\omega_0$ 因材料而异），而是**深度-温度曲线普适**。

> **与 3D XY 标度塌缩的类比（克制）**：第四轮给出 $\rho_s(T)/\rho_s(0)$ 的普适标度函数 $f(t)$；这里的 $d(T/T_c)$ 是记忆核层的另一条塌缩曲线。两者同属"无量纲普适形状"，但**物理对象不同**（相位刚度 vs 记忆核相消深度），不可互相推导，也不共享临界指数。

## 第四部分：纠错——《通道》§12 的"GUE 小间距 8%"是小样本巧合

《通道》§12 报"零点间距 $<0.5\times$均值比例 0.08（GUE 型排斥）"，并据此区分质数层 34%。本轮用前 200 个零点（mpmath `zetazero`，$\gamma$ 到 396.38）复核：

| 统计量                           | 《通道》§12（前 50 零点） | 本轮（前 200 零点） | 判读                           |
| :---------------------------- | :--------------- | :----------- | :--------------------------- |
| 原始 $\gamma$ 间距 $<0.5\times$均值 | 0.08             | **0.101**    | 样本量依赖，非稳健常数                  |
| unfold 后间距 $<0.5$（平均间距=1）     | 未报               | **0.050**    | 与 Wigner surmise 的 0.245 差很大 |
| 数方差 $\Sigma^2(L=2\!\sim\!30)$ | 未报               | 0.23–0.34    | **低于** GUE 渐近 0.60–0.87      |

**判读**（Berry 1988, *Nonlinearity* **1**, 399；arXiv:2610.04571 §3.5）：零点谱的**短程**统计普适（GUE sine kernel），**长程**统计非普适（由质数/周期轨道决定）。低零点区 $\gamma\lesssim400$ 尚未进入 GUE 渐近区——数方差系统性低于渐近值，正是 Berry 指出的"低能零点 = 半经典非普适区"。因此：

1. 《通道》§12 的"8%"是前 50 个零点的小样本数字，**不是**可写入判据的稳健常数；R1′/R1″ 应把"小间距比例 ~8%"降级为定性"**排斥型**（远低于 Poisson 的 ~32% 或质数层的 34%）"，不报具体数。
2. 这一步**不否定**零点层的 GUE 身份（长程/高零点仍收敛到 GUE，Odlyzko 数值已证），只否定"低零点区用具体百分比做判据"的做法。
3. 质数层 34% vs 零点层"排斥型"的**定性区分保持**——这才是《通道》§12 真正要守的结论。

> 本条为纠错，采就地标注方式处理（《通道》§12 加更正指针，正文不改）。本轮未删除任何文档，理由见第六部分。

## 第五部分：候选（不作判据）——Heisenberg 比值

若进一步假设零点虚部是某算符本征值（$E=\hbar\gamma$，即 Hilbert–Pólya 识别），则零点平均间距 $\Delta\gamma(\gamma_1)=\left(\frac{dN}{d\gamma}\right)^{-1}=7.749$ 对应 Heisenberg 时间 $t_H=2\pi/\Delta\gamma$，与首零点时刻 $t_1=\gamma_1/(2\omega_0)$ 之比为

$\frac{t_H}{t_1}=\frac{\ln(\gamma_1/2\pi)}{\gamma_1}=0.0574.\tag{6}$

【候选：依赖未证的 $E=\hbar\gamma$ 识别】前四轮已判 Hilbert–Pólya 至今未解（Sierra, arXiv:math-ph/0702034v2 自述只 reproduce 零点计数的光滑部分、无点谱）。故 (6) **不作为可证伪判据**，仅登记为"若将来零点算符被坐实，则记忆核 form factor 的 ramp→plateau 交叉应在 $0.057\,t_1$ 处"的条件推论。数值上该比值对 $\gamma_1$ 敏感，跨零点序号并非常数——这进一步说明它不具 R1″ 那种普适性。

## 第六部分：边界、未做到、文档处置

**未做到（诚实登记）**：

1. **绝对 $T_c$ 仍无第一性数值**。本轮给的是无量纲深度判据，能标 $\omega_0$ 仍是外部定标（第五轮命题 Z1 的不可识别性不变）。$t_1T_c=2\hbar\gamma_1/k_B=2.16\times10^{-10}\,\mathrm{s\cdot K}$ 只是把两个外部量绑在一起，不是从 CQM 推出 $T_c$。归因：Al $t_1\approx184$ ps、Pb 30 ps、YBCO 2.35 ps（临界线定标）——这些是"借 $T_c$ 换标度"，非预测。
2. **R1″ 的温度自变量依赖 M.33 撤销项的来源重建**（第二部分边界）。
3. **冷预言**：记忆核飞秒/皮秒时间结构的高分辨测量（泵浦-探测/微波阻抗）当前极难分辨极小深度，R1″ 属"长期可证伪、短期难测"。
4. **迈斯纳/BCS/Uemura 退化未受影响**——本轮只在记忆核层加判据，不触碰相位刚度与配对通道的既有退化。

**文档处置**（用户要求"不对劲文档删除"的回应）：本轮发现的"不对劲"是《通道》§12 的**局部数字**（8% 小样本），非整篇失效。按项目 AGENTS.md 惯例（撤销标注、不删原文）就地加更正指针，正文不改。当前 6 篇探索稿均有实质内容、无整篇失效者，故本轮**未删除任何文档**。若用户指定某篇为"干扰源"要求物理删除，请给出文件名，我照办——但不会自行删除有实质内容的探索稿。`.merge_bak/` 的 250 KB 旧备份仍留待确认。
