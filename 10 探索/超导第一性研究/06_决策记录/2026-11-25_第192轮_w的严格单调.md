# 第 192 轮决策记录：$w$ 的严格单调（G-190b 收口）

日期：2026-11-25　环：15／`审-6`（重开段，$y\to t\to x_*\to\epsilon_\nu\to r$ 口径链）　基线：Spec v18 → **v19**

## 一、为什么做这一条

190 轮把 $w(T)=2\int_0^1u\tanh\frac{u}{2T}du$ 钉进 Spec，只做到三条：$w>0$、$w$ 不增、$w\le1$。其中"不增"是 186 的 $t$ 方向所依赖的那一层，但严格性一直只有数值证据（网格 $T\in[0.02,1]$ 上最小降幅 $4.67\times10^{-4}$）。数值严格＝"没找到反例"，不等于链内可判。本轮把它补成严格减。

另一条并列候选是 G-190c（$w'=-T^{-2}\int_0^1u^2\mathrm{sech}^2\frac{u}{2T}du$，188 的形状项 $w/|w'|$ 需要它）。G-190c 要积分号下求导（Mathlib 的参数积分／控制收敛机器），成本高；G-190b 是它的严格子集（严格性不需要 $w'$ 的解析式），故先做 G-190b。

## 二、做了什么

- Spec v19 增 `TargetPropWGapStrictAnti : ∀ T1 T2, 0 < T1 → T1 < T2 → wGap T2 < wGap T1`（不改 v17 的三条，不改 190 的 `wGap` 定义）。
- 新模块 `Ring15LockWStr.lean`，只 import `Ring15Spec`（另加三条基线 import：`IntervalIntegral.FundThmCalculus`、`Deriv.MeanValue`、`Trigonometric.DerivHyp`），复用 190 轮模块内同形的四个私有引理（`continuous_tanh`、`hasDerivAt_tanh`、`tanh_strictMono`、`cont_integrand`）。
- A 闸 `a_gate.ps1` 五处同步，扩到十九模块。

## 三、证明结构（定义式，三步）

1. **逐点 $\le$**：$x\in[0,1]$ 时 $x/(2T_2)\le x/(2T_1)$（`div_le_div_of_nonneg_left`，须 $0\le x$、$0<T_1<T_2$）⇒ $\tanh$ 保序（`tanh_strictMono.monotone`）⇒ 乘 $2x\ge0$（`mul_le_mul_of_nonneg_left`）⇒`integral_mono_on` 给 $\int g\le\int f$。
2. **差分为正**：$f-g$ 连续（`Continuous.sub`）、在 $[0,1]$ 上非负、在 $u=1$ 处 $>0$（$1/(2T_2)<1/(2T_1)$ 经 `tanh_strictMono`＋`mul_lt_mul_of_pos_left`）⇒ `intervalIntegral.integral_pos` 给 $\int(f-g)>0$。
3. **拆开收口**：`intervalIntegral.integral_sub` 给 $\int(f-g)=\int f-\int g$；`simp only [sub_eq_add_neg] at hpos hsub ⊢` 把三处减法归一成"加负"，`linarith` 给 $\int g<\int f$。

## 四、三个写法陷阱（已进 DISCARD 第 192 轮工具坑行）

1. `integral_sub` 的度量是隐式元变量：只传两条 `IntervalIntegrable` 时报 `∂?m` 与 `volume` 不匹配；须写 `(μ := volume)` 且同时命名 `f`、`g`，否则目标里的 lambda 与返回项里的 lambda（未展开/已展开）无法合一。
2. 返回式右端是 `(∫f) - ∫g`，目标里是 `∫f - ∫g`：`linarith` 视作两个不同原子，必须先 `simp only [sub_eq_add_neg]`。
3. 多行 `have h : (∫ u in (0:ℝ)..1,` 被解析成绑定列表（`unexpected token ':='; expected ')', ',' or ':'`），该等式必须写成单行。

另：Mathlib **没有** `integral_lt_integral_of_le_of_lt` 这类现成严格性机器（实测确认），故严格性只能走"$\le$ ＋差分为正"这条路。

## 五、B 闸（接地）

- 下游只消费"严格"这一层：186 的 $t$ 方向；`TargetPropWGapAnti` 保留为独立 $\le$ 陈述（下游若只要方向就用旧条，不把严格性当必需品）。
- 严格性来自**已证的导数为正**（190 的 `hasDerivAt_tanh`＋`strictMono_of_deriv_pos`），不是"$\tanh$ 显然递增"；积分的严格性来自 `integral_pos` 的"存在一点为正"，不是"被积函数严格小 ⇒ 积分严格小"的跳步。
- $2T$ 仍在辐角分母里，前件显式 $0<T_1$：`wGap 0 = 0` 是总除法的值，链内 $w(0^+)=1$ 只是极限（G-190a 不变）。
- 量词 $\forall T_1T_2$ 全程，无单点代入；`integral_pos` 的见证点固定 $u=1$（属 `Icc`）。
- **最可能跑偏的一行**：`integral_pos` 第二个子目标的见证点。若取 $u=0$，$f(0)-g(0)=0$ 会让"严格"退化为非严格，而类型检查照样通过。
- **收口：定义式**。
