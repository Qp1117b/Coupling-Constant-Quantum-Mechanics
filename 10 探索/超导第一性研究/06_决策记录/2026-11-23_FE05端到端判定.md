# 决策：FE05 首次端到端独立参数 $T_c$ 判定——单带 3–8% 通过、多带失效（候选·未落地）

**日期**：2026-11-23
**性质**：【候选·未落地·不碰权威源】；首次用独立参数（非反解）检验 CQM 完整候选式。
**范围**：候选区＋数据目录；不改主链、06、08 台账、编号与状态栏、账面。

## 一、决定

1. **抓取独立材料参数**：arXiv API 检索命中三篇第一性 Eliashberg 论文，给出**非从 $T_c$ 反解**的 $(\lambda,\mu^\ast,\omega_{\log})$：Mo₂NF₂（arXiv:2603.06284）、MgB₂（arXiv:cond-mat/0111182）、BP₃（arXiv:2604.10026）。数据落地 `07_数据与现象/数据/独立参数集_第一性Eliashberg.csv`。
2. **端到端预测检验**：代入 CQM 完整候选式（FE03）算 $T_c$，与文献值对照（非回代）：Mo₂NF₂-CDW 0.92 vs 1.0K（偏差 8%）、strain 4.12 vs 4.0K（3%）——**单带系统首次通过**；MgB₂ 12.9 vs 39K（0.33×）——**多带失效**，但文献明证 MgB₂ 需双带（$\lambda(k,k')$ 从 0.1 到 2.5）。
3. **与第69轮互证**：Pb 双带实验解释 gap ratio 偏差；本轮 MgB₂ 双带解释 $T_c$ 低估——两个独立观测量都指向"CQM 单带式对单带有效、对多带需推广"的同一结论。
4. **诚实边界**：依赖 FE01 外生公设＋外部 Allen-Dynes 式，非纯链内；$\mu^\ast=0.10$（Mo₂NF₂）、$\omega_{\log}=670$K（MgB₂）为假设，已标注/敏感性扫描；多带无公式（`临-5`/`临-6` 未闭合）。
5. 保留所有编号与状态栏；账面不变（62 行/35 唯一/35 推进/0 余）。

## 二、否决的读法

1. 认为 CQM 第一性推出绝对 $T_c$：否——依赖 FE01 公设＋Allen-Dynes 外部式。
2. 认为 MgB₂ 失败是 CQM 错：否——单带近似不适用，文献明证需双带。
3. 认为多带系统已处理：否——`临-5`/`临-6` 未闭合，无多带 $T_c$ 公式。
4. 认为 $\mu^\ast=0.10$ 是精确值：否——假设，已敏感性扫描。
5. 认为改了权威式：否。

## 三、保留的可证伪分支

1. 若 Mo₂NF₂ 的实测 $\mu^\ast$ 公布，可检验 0.10 假设是否给出正确 $T_c$。
2. 若多带 $T_c$ 公式（CQM 12.A 定量推广、`临-5`/`临-6`）建立，可处理 MgB₂/Pb/BP₃。
3. 若更多单带材料的独立参数可得，可扩大 3–8% 吻合的统计。
