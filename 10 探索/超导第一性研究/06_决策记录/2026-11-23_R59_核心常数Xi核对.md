# R59 决策记录：核心常数 $☯$ 两种定义的数值一致性核对

**范围**：`10 探索/超导第一性研究`；不改 README 权威数值表、不改主链／06、不动账面。
**日期**：2026-11-23
**方向**：从头算到尾严格数值核对（核心常数）

## 一、做什么

README 权威定义 $☯=\frac{d}{ds}\ln\xi(s)|_{s=1}\approx0.02309570897$、谱表示 $\sum1/(\gamma_n^2+1/4)$ 条件于 RH——这是 CQM 最核心数值常数，从未做过两种定义的独立一致性核对。本轮用 mpmath 40 位高精度核对。文献工具超时（如实现 Riemann ξ 标准函数，属标准数学），如实记录。

## 二、结果（5/5 PASS）

- $\xi'(0)/\xi(0)=\ln(2\sqrt\pi)-1-\gamma_E/2=-0.02309570897$（**负**）；
- $\xi'(1)/\xi(1)=-\xi'(0)/\xi(0)=+0.02309570897$（函数方程 $\xi(s)=\xi(1-s)$）；
- 谱和闭式 $1+\gamma_E/2-\ln(2\sqrt\pi)=+0.02309570897$；
- **两种定义一致到 11 位**（差 $3.88\times10^{-12}$），与 README 权威值一致；
- 谱和部分和（前 40 零点）从下方逼近闭式（尾部 22%）。

## 三、方法论细节（易混淆符号，必须记录）

初稿曾担心 README 符号有误（$\xi'(0)/\xi(0)$ 是负的）——核对后发现是**混淆了 $s=0$ 与 $s=1$**：函数方程给 $\xi'(1)/\xi(1)=-\xi'(0)/\xi(0)$，谱和为正、与 $s=1$ 定义同号。README 权威值正确。这是"发现不对劲就厘清"的落实（未改权威值，核对确认其正确）。

## 四、对 R50 的意义

R50 的 $\langle|K|^2\rangle=☯$ 用的正是这个权威值——本核对确认了 R50 的数值基础正确。

谱表示条件于 RH（外部假设）；纯数学核对，不改任何物理缺口、不给 $T_c$、不改 README 权威数值表（核对确认其正确）。
