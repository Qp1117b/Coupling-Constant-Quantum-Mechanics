## 一、本环要解决的问题

198 把 $w''$ 写进了链内，但写法是

$$w''=-\frac{2}{T}w'-\frac{1}{T^4}\int_0^1u^3\,\mathrm{sech}^2\frac{u}{2T}\tanh\frac{u}{2T}\,du ,$$

两项反号、量级相当，符号无法由单项判定；$S'=\dfrac{w\,w''-(w')^2}{(w')^2}$ 的符号就卡在这里。198 留下的缺口是"$w''>0$ 与 $S'$ 分段符号"，本环要解决：**$w''$ 有没有一条不经过 $u^3$ 积分的写法，使符号判据退化成单条标量不等式**。

## 二、输入与第一性依据

- **链内输入**：`TargetPropWGapIbp`（$w=\tanh\frac{1}{2T}+\frac T2w'$，v24）；`TargetPropWGapDeriv`／`TargetPropWGapDerivNeg`（v23）；`TargetPropWGapDeriv2`（$w''$ 为 $w'$ 的导函数，v25）；`TargetPropShapeDeriv`（v25）。
- **第一性依据（链内）**：197 的恒等式不是恒等变形技巧，而是"窗口平均＝端点＋半温×导数"的闭合关系。既然 $w$ 有两套写法而二者对 $T$ 处处相等，对 $T$ 求导必然给出 $w'$ 的两套写法；再求导一次即得 $w''$ 的两套写法。$\tanh\frac{1}{2T}$ 的导数只由 $\tanh'=\mathrm{sech}^2$ 与内层 $\left(\frac{1}{2T}\right)'=-\frac{1}{2T^2}$ 复合给出，不引新量、不引前因子、不借命名带过。
- **外部锚（只作边界，不给方程形式）**：
  - `arXiv:2409.16930`：刚度定义为 $J_{\mu\nu}=\partial^2f/\partial Q_\mu\partial Q_\nu$，Fig.1 中 $J_{22}(Q_2)$ 随 $Q_2$ 过零变号 ⇒ 二阶系数**不保证恒正**；
  - `arXiv:2410.22704`：NbN 多孔膜的 $J_s(T)$ 与涡旋核能，$J_s$ 在 $T$ 上单调掉到零；
  - Banerjee 2025（twisted trilayer，`ciqm.harvard.edu` 上的 PDF）：$d\rho_s/dT\approx0.2$–$0.3$，近线性 ⇒ 曲率小且会变号。
  这些只说明"二阶量有意义、符号不必恒正"，**不提供 $w''$ 的表达式**；恰好构成本轮"无条件凸性不成立"的外部旁证边界。

## 三、建成的方程

对 $w=\tanh\frac{1}{2T}+\frac T2w'$ 两边求导：

$$w'=-\frac{1}{2T^2}\mathrm{sech}^2\frac{1}{2T}+\frac12w'+\frac T2w'' .$$

移项得 $\frac T2w''=\frac12w'+\frac{1}{2T^2}\mathrm{sech}^2\frac{1}{2T}$，乘 $\frac2T$：

$$w''(T)=\frac{w'(T)}{T}+\frac{1}{T^3}\mathrm{sech}^2\frac{1}{2T}.$$

用 $w'=-|w'|$，正性化为单条标量不等式：

$$w''>0\iff \frac{|w'|}{T}<\frac{\mathrm{sech}^2\frac{1}{2T}}{T^3}\iff T^2|w'(T)|<\mathrm{sech}^2\frac{1}{2T}\iff \int_0^1u^2\mathrm{sech}^2\frac{u}{2T}du<\mathrm{sech}^2\frac{1}{2T}.$$

形状项符号由代数直接给出（分母 $(w')^2>0$）：

$$S'<0\iff w\,w''<(w')^2 .$$

Spec v26 落点（`05_Lean验证/Ring15Spec.lean` 尾部）：

- `wGapDeriv2Alt T := wGapDeriv T / T + sechSq (1/(2*T)) / T^3`
- `TargetPropWGapDeriv2Alt := ∀ T > 0, wGapDeriv2 T = wGapDeriv2Alt T`
- `TargetPropWGapDeriv2Pos := ∀ T > 0, T^2*|wGapDeriv T| < sechSq (1/(2*T)) → 0 < wGapDeriv2 T`
- `TargetPropShapeDerivSign := ∀ T > 0, shapeDeriv T < 0 ↔ wGap T * wGapDeriv2 T < (wGapDeriv T)^2`

## 四、证明结构

1. `hasDerivAt_tanh_inv`：$T\mapsto\tanh\frac{1}{2T}$ 在 $T>0$ 处导数为 $-\frac{1}{2T^2}\mathrm{sech}^2\frac{1}{2T}$（`hasDerivAt_inv` 给内层，`const_mul` 缩放，再与 `hasDerivAt_tanh'` 复合）。
2. `hF`：$F(T)=\tanh\frac{1}{2T}+\frac T2w'(T)$ 的导数 $=\frac12w'+\frac T2w''-\frac{1}{2T^2}\mathrm{sech}^2\frac{1}{2T}$（`add`＋`mul`，$w''$ 由 v25）。
3. `hEq`：在 $T$ 的邻域（`Set.Ioo 0 (2*T)`）上 $F=w$（197 的恒等式逐点），经 `HasDerivAt.congr_of_eventuallyEq`（用 `.symm`）与 v25 的 `HasDerivAt wGapDeriv` 做 `HasDerivAt.unique`，得 $w'=F'$。
4. 代数：由 $w'=\frac12w'+\frac T2w''-\frac{1}{2T^2}\mathrm{sech}^2$ 解出 $w''=\frac{w'}{T}+\frac{\mathrm{sech}^2}{T^3}$（`field_simp` 后一次 `ring` 即闭合，不再多写）。
5. 正性：`lt_div_iff₀` 把 $|w'|<\frac{\mathrm{sech}^2}{T^2}$ 化为 $T^2|w'|<\mathrm{sech}^2$；再用 `congrArg (fun x => T^2*x) hwabs`（$|w'|=-w'$）得 $T^2w'+\mathrm{sech}^2>0$，除以 $T^3>0$ 即 $w''>0$。
6. 符号：`div_lt_iff₀ ((w')^2>0)` 把 $S'<0$ 化为 $w\,w''-(w')^2<0$，与 $w\,w''<(w')^2$ 线性等价。

**首轮失败五类（全属写法，已逐条改）**：①`Spec.TargetPropWGapIbp` 是 `def … : Prop`，不能当函数套用，须 import `Ring15LockIbp` 取 `LockIbp.targetPropWGapIbp`；②`HasDerivAt.congr_of_eventuallyEq` 要 `wGap =ᶠ F`，手头是 `F =ᶠ wGap`，须 `.symm`；③`field_simp` 已闭合目标时后接 `ring` 报 `No goals`；④`congrArg` 后是 beta-项，`rw` 找不到模式，须先 `simp only [] at hmul`；⑤在 $|w'|$ 内部 `rw [hwabs]` 会得 $|-|w'||$，须用 `congrArg`；`pow_pos (abs_pos …) 2` 与 $w'^2$ 差一层 `sq_abs`，用 `by simpa [sq_abs] using …`。
