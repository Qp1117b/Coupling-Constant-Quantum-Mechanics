# 预注册判定 R19：同位素效应 $\alpha=1/2$ 上界——链内声速质量依赖的机制身份检验

> 跑数前写死判据。这是机制身份的核心检验：同位素指数 $\alpha=-d\ln T_c/d\ln M$ 的 BCS 值 1/2 直接来自声子机制。链内第88轮导出 $\Theta_D=(\hbar c_s/k_B)(6\pi^2n)^{1/3}$、声速 $c_s\propto M^{-1/2}$（谐振子几何），故纯 BCS $\alpha=1/2$ 是链内 A 类纯数。实验全部 ≤1/2（上界），偏离来自外生 $\mu^*$。

## 一、待检 CQM 预言
| 预言 | 链内出处 | 数值 |
|:---|:---|:---|
| P1 纯 BCS 同位素指数 $\alpha=1/2$ | 第88轮 $\Theta_D\propto c_s\propto M^{-1/2}$＋C5 $T_c=1.13\Theta_D e^{-1/\lambda}$ | 0.5 |
| P2 $\alpha=1/2$ 是**上界**（实验无 >1/2） | McMillan 修正 $\mu^{*2}\ge0$ | ≤0.5 |
| P3 弱耦合非过渡金属 α≈0.5 | P1＋小 $\mu^*$ | Hg/Tl/Cd/Sn/Pb 0.46–0.50 |
| P4 过渡金属/低 Tc 趋 0 | 外生 $\mu^*$ 修正（第60轮归口） | Zr/Ru=0 |
| P5 链内 $T_c$ 形状 ∝ $\Theta_D$ | C5 前因子 | $T_c\propto M^{-1/2}$ |

## 二、推导
链内第88轮：$\Theta_D=(\hbar c_s/k_B)(6\pi^2 n)^{1/3}$。谐振子声速 $c_s=\sqrt{k/\rho}\propto M^{-1/2}$（力常数 $k$ 与质量无关，几何/键刚度给定）。C5 的 $T_c=\frac{2e^\gamma}{\pi}\Theta_D e^{-1/\lambda}$，$\lambda=N(0)V$ 是静态量（M-独立，Illinois 讲义明确）。故
$$\alpha\equiv-\frac{\partial\ln T_c}{\partial\ln M}=-\frac{\partial\ln\Theta_D}{\partial\ln M}=\frac12\quad(\text{纯 BCS}).$$
McMillan 库仑修正：$\alpha=\frac12\Big[1-\frac{1.04(1+\lambda)(1+0.62\lambda)\mu^{*2}}{[\lambda-\mu^*(1+0.62\lambda)]^2}\Big]\le\frac12$（修正项≥0）。强耦合 $\lambda$ 大或 $\mu^*\to0$ 时 $\alpha\to1/2$；弱耦合/大 $\mu^*$ 时 $\alpha\to0$。**关键**：α 永不超过 1/2——这是可证伪上界，实验（Webb 2015 Table 3）全部满足。

## 三、预注册判据
1. **P1**：链内 $\alpha=1/2$ 推导（$c_s\propto M^{-1/2}$ 的几何来源）代数核对。
2. **P2**：实验元素 α（Webb 2015 Table 3）全部 ≤0.5（含误差），无 >0.5 者——若有即否证。
3. **P3**：弱耦合非过渡金属（Hg 0.5、Tl 0.5、Cd 0.5、Sn 0.46、Pb 0.48）α∈[0.44,0.5]，接近上界。
4. **P4**：过渡金属/低 Tc（Zr 0、Ru 0、Os 0.21）α 显著低于 0.5——外生 $\mu^*$ 修正，预注册允许，不否定 P1。
5. **P5**：McMillan 修正对任意 $\lambda>0,\mu^*\ge0$ 给 $\alpha\le0.5$（数值扫描）。
6. **禁止**：不用实验调 $\mu^*$ 反拟合、不引入非声子机制解释反常元素（U 的 -2、PdH 的 -0.25 只登记为链外，不进链）；实验只作上界检验。

## 四、方法与诚实边界
- **A 类**：$\alpha=1/2$ 上界由链内声速质量依赖＋C5 结构推出（机制身份）；**B 类标注**：McMillan 修正式是外部工具；$\mu^*$ 外生（第60轮已归口）。
- 链内 $\Theta_D$ 口的 $n$、$c_s$ 材料归一外生，但质量依赖指数 -1/2 是纯几何。
- 反常同位素效应（U α=-2、PdH α=-0.25）是链外现象，只登记不解释（不虚构非声子机制）。
- 绝对 $T_c$ 外生；不碰 `临-8`／`临-22`／RH；不改状态。
