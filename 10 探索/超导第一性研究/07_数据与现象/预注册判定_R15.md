# 预注册判定 R15：超流密度与 London 穿透深度全程曲线——链内 gap 曲线唯一决定，接 Uemura 标度

> 跑数前写死判据。热力学链已闭合（R14），但还有一个独立可观测量未验：**超流密度 $\rho_s(t)/\rho_s(0)$ 与 London 穿透深度 $\lambda(t)/\lambda(0)$**。关键：Johnston Eq.(42a) 把它们**唯一地**联系到 gap 的温度导数——$\frac{\Lambda}{\Lambda_0}=1-\frac{t}{2\tilde\Delta^2}\frac{d\tilde\Delta^2}{dt}$，$\rho_s/\rho_s(0)=\Lambda_0/\Lambda$——故**完全由链内 gap 曲线决定，无材料参数**。这把第 98 轮的 Uemura T=0 刚度推广到全程。

## 二、推导
链内 gap 曲线 $\tilde\Delta(t)$（R11）→
- Eq.(42a)：$\frac{\Lambda(t)}{\Lambda(0)}=1-\frac{t}{2\tilde\Delta^2}\frac{d\tilde\Delta^2}{dt}$（gap 导数路径）；
- Eq.(40)：$I(t)=\frac12\int_0^\infty \operatorname{sech}^2 z\,dy$，$z=\frac12\sqrt{y^2+(\alpha\tilde\Delta/t)^2}$（积分路径）；
- Eq.(39)(44a)：$\rho_s/\rho_s(0)=1-I(t)$，$\lambda/\lambda(0)=1/\sqrt{1-I(t)}$。
**近 $T_c$**：Eq.(17) $\frac{t}{\tilde\Delta^2}\frac{d\tilde\Delta^2}{dt}|_1=-\frac{1}{1-t}$ ⇒ Eq.(43) $\frac{1}{1-I}=1+\frac{1}{2(1-t)}$ ⇒ $\rho_s=\frac{1-I}{1}=\frac{1}{1+\frac{1}{2(1-t)}}\to2(1-t)$，斜率 $=-2$（与 $\kappa$ 同出 $d\tilde\Delta^2/dt|_1=-\frac{8e^{2\gamma}}{7\zeta_3}$）。
**低温**：Eq.(41) $I=\sqrt{2\pi\alpha/t}e^{-\alpha/t}$，Eq.(45b) $\Delta\lambda/\lambda(0)=\sqrt{\pi\alpha/2t}e^{-\alpha/t}$，$\alpha=\pi/e^\gamma$（C5）。

## 三、预注册判据
1. **P1**：链内 $I(t)$ vs Johnston Table VI（BCS $\alpha=1.764$，全温区 $t=0.06$–$0.99$）相对误差：中温（$0.2\leq t\leq0.9$）<0.5%、低温（$t<0.2$）<2%（数值敏感）。
2. **P2**：$1/(1-I)$ vs $\Lambda/\Lambda_0$ 两路径相对误差 <0.1%。
3. **P3**：近 $T_c$（$t\geq0.99$）$\rho_s/(1-t)\to2$（相对误差 <1%）。
4. **P4**：低温 $\Delta\lambda/\lambda(0)$ 拟合指数 $-\alpha_{BCS}=-\pi/e^\gamma$（扣 $t^{-1/2}$ 幂律后）。
5. **P5**：$\lambda/\lambda(0)=1/\sqrt{1-I}$ 对 Table VI $\Delta\lambda$ 列盲测 <0.5%。
6. **禁止**：不用 Table VI 调参、不拟合 gap/$\alpha$；Table VI 只作盲测标准。

## 四、方法与诚实边界
- 数值：链内 gap 复用 R11；Eq.(40) sech² 积分、Eq.(42a) gap 导数（中心差分 h=1e-4）；Table VI 从 arXiv:1304.2275 附录提取。
- **B 类工具标注**：Eq.(40)/(42a)/(44a) 是标准 BCS/α-model 电动力学关系（外部工具）；链内贡献是 gap 曲线＋$\alpha_{BCS}$＋Uemura 前件。超流密度形状的链内决定性是 A 类结构，电动力学工具本身 B 类。
- 强耦合/各向异性/杂质（洁净 London 极限假设）偏离（第 100 轮已登记）；Al 是 Pippard 极限（非 London），本轮 London 曲线对 Al 只定性；绝对 $T_c$ 外生；不碰 `临-8`／`临-22`／RH；不改状态。
