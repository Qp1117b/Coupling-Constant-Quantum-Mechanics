# 预注册判定 R35：两把阶梯的辨析——$\gamma_n$ 与 $2\ln n$ 不是同一把梯子

> 判据先于计算写死。本轮不改缺口状态栏、不新增环号。
> **待检**：链内 L1280 写“全对冻结只把频率阶梯钉成 $2\ln n$（$\gamma_n$ 侧）”，而 L616 又写“$\gamma_n$ 随 $n$ 递增，与 (12.3) 递减方向相反，两梯不可互译”。这两句是否自洽？外部数论标准如何判？
> **性质**：A 类文本／对象审计＋B 类数论标准对照。

## 一、链内前件

- L616：`γ_n` 随 `n` 递增，与 (12.3) 的递减方向相反，**两梯不可互译**。
- L1280：全对冻结只把频率阶梯钉成 `$2\ln n$（γ_n 侧）`，而 `β_n` 是 ζ 的性质（`临-22`）。
- L544：(13.A2) 的 `$2\ln n$` 与 26.B2 的 `{log p}` 是**两套刻度，不能互相替换**。
- L1429：`临-26` 的“$\delta v_{\tau,i}/\bar v_\tau$ 与 $\{2\ln n\}$ 阶梯的对齐未证”。

## 二、结论先行（脚本与 Lean 只作核验）

1. **外部数论（B 类）**：Riemann–von Mangoldt 给 $N(T)=\frac{T}{2\pi}\log\frac{T}{2\pi}-\frac{T}{2\pi}+O(\log T)$，故第 $n$ 个零点虚部
   $$\gamma_n\sim\frac{2\pi n}{\ln n},\qquad \gamma_{n+1}-\gamma_n\sim\frac{2\pi}{\ln n}. \tag{R35.1}$$
   而 $2\ln n$ 阶梯的间距为 $2\ln(1+1/n)\sim 2/n$；$\{\log p\}$ 的间距 $\sim1/p$。**三者互不相同**。
2. **A 类判定**：$\gamma_n$ 与 $2\ln n$ 不是同一把梯子；L1280 的“（γ_n 侧）”属**刻度混用**（与 L616 的“两梯不可互译”直接张力）。本轮只登记该口径问题，**不改 06／主链原文**，也不闭合 `临-26`／`临-22`。
3. **后果**：`临-26` 的“$\delta v/\bar v$ 与 $2\ln n$ 对齐”不能用 `γ_n` 的零点数值来替代验证；`临-22` 的“阻尼率统一”也不能靠把 `β_n` 读成 `2ln n` 来消解。

## 三、预注册判据

| 编号 | 判据 | 阈值 |
|:---|:---|:---|
| P1 | 四处原文审计（L616／L1280／L544／L1429） | 逐条命中 |
| P2 | 外部数论：γ_n∼2πn/ln n、间距∼2π/ln n | Riemann–von Mangoldt（MathWorld；arXiv:1307.5723；Wikipedia） |
| P3 | 数值：γ_n/(2ln n) 随 n 发散；Δγ_n 与 2ln(1+1/n) 量级不同 | n=1..1000 比值从 <1 增至 >100；间距比跨 ≥2 个量级 |
| P4 | 三把刻度互不相同（γ_n／2ln n／log p） | 渐近间距 2π/ln n、2/n、1/p 两两不同 |
| P5 | Lean：2ln 阶梯间距公式与不可仿射同一 | 退出码 0、无禁用项 |

**判定规则**：P1–P5 全过 ⇒ L1280 的“（γ_n 侧）”判为刻度混用、登记为口径问题；两个缺口状态不动。

## 四、文献依据（外部 B 类）

- Riemann–von Mangoldt：$N(T)=\frac{T}{2\pi}\log\frac{T}{2\pi}-\frac{T}{2\pi}+\frac78+S(T)+O(T^{-1})$（MathWorld；arXiv:1307.5723 §1；Wikipedia）；平均零点间距在高度 $T$ 为 $2\pi/\log T$。
- arXiv:1011.3997（Korolev, *Izvestiya Math.* **76** (2012) 275, DOI `10.4213/im5558`）：相邻零点平均距 $t_{n+1}-t_n\sim2\pi/\ln n$。
- 素数间距：$\ln p_{n+1}-\ln p_n\sim1/p_n$（标准 PNT）。
- 链内：L616／L1280／L544／L1429；`临-22`／`临-26`。
