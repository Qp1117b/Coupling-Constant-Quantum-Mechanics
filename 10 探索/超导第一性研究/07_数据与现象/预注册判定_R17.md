# 预注册判定 R17：准粒子态密度与 Giaever 隧穿谱——链内 gap 的谱学直接验证

> 跑数前写死判据。前 16 轮都是热力学/电动力学整体量；本轮触及**能量分辨谱学**——历史上首次直接"看见"能隙的 Giaever 隧穿（1960）。BCS 态密度 $N_s(E)/N_n=|E|/\sqrt{E^2-\Delta^2}$ 是链内 gap $\Delta_0=\pi e^{-\gamma}k_BT_c$ 的直接后果，带两个严格可检验特征：gap edge 平方根发散系数 $\sqrt{\Delta_0/2}$，以及态守恒 sum rule。

## 一、待检 CQM 预言
| 预言 | 链内出处 | 数值 |
|:---|:---|:---|
| P1 态密度 $N_s(E)/N_n=E/\sqrt{E^2-\Delta_0^2}$（$E>\Delta_0$） | 链内 gap＋Bogoliubov 粒子守恒 $N_s dE=N_n d\xi$ | 谱形 |
| P2 gap edge 平方根发散系数 $\sqrt{\Delta_0/2}$ | chain gap $\Delta_0/k_BT_c=\pi/e^\gamma$ | $\sqrt{\pi/2e^\gamma}$ |
| P3 态守恒 sum rule $\int_0^\infty(N_s/N_n-1)dE=0$ | 被隙驱逐态=相干峰吸收态 | 精确 0 |
| P4 有限和 $\int_0^X(N_s/N_n-1)dE=\sqrt{X^2-\Delta_0^2}-X$ | 解析恒等式 | 数值核对 |
| P5 Giaever 隧穿 $dI/dV\propto N_s(eV)$（$T\to0$） | 低偏压电导直接测 DOS | gap edge at $eV=\Delta_0$ |

## 二、推导
Bogoliubov 准粒子 $E=\sqrt{\xi^2+\Delta_0^2}$，粒子守恒 $N_s(E)dE=N_n d\xi$ ⇒
$$\frac{N_s(E)}{N_n}=\frac{E}{\sqrt{E^2-\Delta_0^2}}\Theta(E-\Delta_0)$$
代入链内 $\Delta_0=\pi e^{-\gamma}k_BT_c$（C5 gap ratio 一半）。两个严格后果：
- **edge 发散**：$E\to\Delta_0^+$ 时 $N_s/N_n\simeq\sqrt{\Delta_0/[2(E-\Delta_0)]}$，系数 $\sqrt{\Delta_0/2}$ 由链内 gap 定；
- **sum rule**：$\int_0^X(N_s/N_n-1)dE=\sqrt{X^2-\Delta_0^2}-X\to0$（$X\to\infty$），即隙中缺失的态全部搬到相干峰。

有限温 N-I-S 隧穿：$I(V)\propto\int N_s(E)[f(E)-f(E+eV)]dE$，$T\to0$ 时 $-\partial f/\partial(eV)\to\delta$ ⇒ $dI/dV\propto N_s(eV)$。

## 三、预注册判据
1. **P1**：链内 DOS 谱形（gap=0、edge 发散、高能 $\to1$）定性正确。
2. **P2**：edge 发散系数数值 vs $\sqrt{\Delta_0/2}=\sqrt{\pi/2e^\gamma}$（相对误差 <0.1%）。
3. **P3**：sum rule $\int_0^X(N_s/N_n-1)dE$ vs $\sqrt{X^2-\Delta_0^2}-X$（绝对误差 <$10^{-8}$）；$X\to\infty$ 极限 $\to0$。
4. **P4**：有限和数值-解析恒等式核对。
5. **P5**：$dI/dV\propto N_s(eV)$ 的 gap edge 位置 $=eV=\Delta_0$（chain gap ratio）；有限温展宽定性。
6. **禁止**：不用实验 gap 调 $\Delta_0$、不拟合展宽；实验只作定性对照。

## 四、方法与诚实边界
- 数值：链内 $\Delta_0=\pi/e^\gamma$（$k_BT_c=1$）；DOS 积分在 gap edge 用 `points` 处理平方根奇点。
- **B 类工具标注**：$N_s(E)/N_n=E/\sqrt{E^2-\Delta^2}$ 与 Giaever 隧穿公式是标准 BCS 谱学关系（外部工具）；链内贡献是 gap $\Delta_0$＋守恒律结构。谱学谱形的链内决定性是 A 类结构，工具本身 B 类。
- **强耦合（Pb/Hg）的声子 wiggles** 偏离纯 BCS DOS（Giaever 1973 Nobel 演讲明确），本轮只验弱耦合单带极限；实验展宽/样品不完美使实验 edge 不如理论尖锐（Giaever-Hart-Megerle 1962）。
- 绝对 $T_c$ 外生；不碰 `临-8`／`临-22`／RH；不改状态。
