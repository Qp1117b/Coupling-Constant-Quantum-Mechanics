# 预注册判定 R45：七纯数的生成元结构——指数矩阵与封闭性

> 判据先于计算写死。本轮不改缺口状态栏、不新增环号。
> **待检**：R112 五纯数、R39 第六纯数、R44 第七纯数均登记。它们是否由同一组生成元（$\pi,e^\gamma,\zeta_3$）生成？有无未登记的第八生成元？
> **性质**：A 类代数结构核对＋B 类纯数定义对照。

## 一、链内前件

- $R_1=2\pi/e^\gamma$、$R_2=12/(7\zeta_3)$、$R_3=2\sqrt\pi$、$R_4=3/(4e^{2\gamma})$、$\kappa=2\sqrt2 e^\gamma/\sqrt{7\zeta_3}$（R112）。
- $R_6=\pi^2/(2e^\gamma)=R_1R_3^2/16$（R39）；$S_J=4\pi e^\gamma/(7\zeta_3)$（R44）。
- 恒等式 $R_4\cdot2\kappa^2=R_2$、$R_3^2=4\pi$（Lean `FiveRatioNetwork`、`SixRatioClosure`）。

## 二、结论先行（脚本与 Lean 只作核验）

把七纯数写成 $C\cdot\pi^a(e^\gamma)^b\zeta_3^c$（$C$ 为有理常数），指数矩阵：

| 纯数 | $\pi$ | $e^\gamma$ | $\zeta_3$ |
|:---|:---:|:---:|:---:|
| $R_1$ | 1 | −1 | 0 |
| $R_2$ | 0 | 0 | −1 |
| $R_3$ | 1/2 | 0 | 0 |
| $R_4$ | 0 | −2 | 0 |
| $\kappa$ | 0 | 1 | −1/2 |
| $R_6$ | 2 | −1 | 0 |
| $S_J$ | 1 | 1 | −1 |

**封闭性**：七个向量均在 $\mathbb Q^3$ 中；由 $R_1,R_2,R_3$ 生成的格‑秩为 3，其余四个向量都可由它们线性组合给出：

$$R_4\propto R_1^{-2}R_3^4,\quad \kappa\propto R_1^{-1}R_2^{1/2}R_3,\quad R_6=R_1R_3^2/16,\quad S_J=4R_1^{-1}R_2^{-1}R_3^6/(16\cdots)\ \text{（见脚本）}.$$

故**无第八生成元**；生成元集合为 $\{\pi,e^\gamma,\zeta_3\}$（比 R112 的“两生成元”多一个 $\pi$，因 $R_1,R_3$ 已含 $\pi$；本轮只登记指数事实，不重判“2 生成元”口径）。
