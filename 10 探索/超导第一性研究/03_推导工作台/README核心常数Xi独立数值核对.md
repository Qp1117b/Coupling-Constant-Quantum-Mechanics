## 一、两种定义

1. **导数定义**（README 权威）：$☯=\frac{d}{ds}\ln\xi(s)\big|_{s=1}=\frac{\xi'(1)}{\xi(1)}$，其中 $\xi(s)=\frac12 s(s-1)\pi^{-s/2}\Gamma(s/2)\zeta(s)$（Riemann ξ 函数）。
2. **谱表示**（条件于 RH）：$☯=\sum_n\frac{1}{\gamma_n^2+\frac14}$，$\rho_n=\frac12+i\gamma_n$。

## 二、闭式推导（Hadamard 乘积 + 函数方程）

标准结果（Hadamard 乘积在 $s=0$）：
$$\frac{\xi'(0)}{\xi(0)}=\ln(2\sqrt\pi)-1-\frac{\gamma_E}{2}\approx-0.02309570897. \tag{59.1}$$
函数方程 $\xi(s)=\xi(1-s)$ 给 $\xi'(1)=-\xi'(0)$、$\xi(1)=\xi(0)$，故
$$\boxed{\ \frac{\xi'(1)}{\xi(1)}=-\frac{\xi'(0)}{\xi(0)}=1+\frac{\gamma_E}{2}-\ln(2\sqrt\pi)=0.02309570897.\ }\tag{59.2}$$
谱表示由 $\rho_n=\frac12+i\gamma_n$、共轭配对 $\frac1\rho+\frac1{\bar\rho}=\frac{1}{\gamma_n^2+1/4}$ 直接给同一值——两种定义一致。

## 三、数值核对（可复跑，mpmath 高精度）

## 四、方法论细节（易混淆点，必须记录）

**符号**：$\xi'(0)/\xi(0)$ 是**负**的（$-0.0231$），$\xi'(1)/\xi(1)$ 是**正**的（$+0.0231$）。谱和为正、与 $s=1$ 定义同号。若误用 $s=0$ 导数会被符号坑——本轮明确记录。这是"发现不对劲就厘清"的具体落实（初稿曾担心 README 符号有误，核对后发现函数方程消除了矛盾）。
