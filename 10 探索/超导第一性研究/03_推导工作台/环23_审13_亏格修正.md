# 环 23／`审-13`：最小环生成的亏格修正——缺 $2g+b$ 个绕数标签

**状态**：工作台推导卡；未写入主链正文、06、08 台账。
**触发**：`审-13`——(5.3b) 的"最小环张成环路空间"只在单连通平面成立；带孔、三维、有限样品三种情形须补环绕生成元。本轮给**精确亏格修正**：面边界子空间在环空间中的余维 $=2g+b$（初稿 $2g+b-1$ 已核对更正）。

**一句话**：对闭可定向亏格 $g$ 曲面，环空间维数 $\dim Z_1=E-V+1$，面边界（最小环）子空间维数 $=F-1$；Euler $V-E+F=2-2g$ 给

$$\boxed{\ (E-V+1)-(F-1)=2g.\ } \tag{13.1}$$

带 $b$ 个边界时 $\chi=2-2g-b$，余维为 $2g+b$。故**最小环只在 $g=0,b=0$（闭球面）时张成全部环路**；否则缺 $2g+b$ 个不可缩圈（handle 或外边界圈）。CQM 用最小环数 $n$ 做节点质数化的计数标签，在带孔、有限样品或三维材料中**不完整**，须补绕数标签。而这些缺失标签正是和乐/单值性所在（第二十二轮核模、`临-8` 和乐），与相位扇区同源。

## 二、亏格修正的推导

设三角化闭可定向曲面 $(V,E,F)$，环空间 $Z_1=\ker\partial$（边集上的 1-链，无边界）。

1. **环空间维数**：连通图 $\dim Z_1=E-V+1$（秩—零化度，与外部标准一致）。
2. **面边界子空间**：最小环由面边界生成；$F$ 个面中只有 $F-1$ 个独立（ totality 边界和为 0），故面生成子空间维数 $F-1$。
3. **Euler**：$V-E+F=2-2g$ ⇒ $F=2-2g-V+E$，故

$$F-1=E-V+1-2g.\tag{13.2}$$

于是 (13.1)：面生成子空间比整个环空间少 $2g$ 维。商 $Z_1/\text{(面边界)} \cong H_1$ 的维数 $2g$，正是 $2g$ 个 handle 绕数。

**带边界**：$\chi=2-2g-b$ ⇒ $F-1=E-V+1-2g-b$，余维 $=2g+b$。平面圆盘 $g=0,b=1$ 给余维 $1$——缺失的是**外边界圈**（它本身是环，但不是任何面的边界）；闭球面 $g=0,b=0$ 给余维 $0$。有限样品的截断边界 $b\ge1$ 必然产生边界绕数标签缺失。

> **口径说明**：本轮纠正初稿的一处算术错误——初稿写"余维 $2g+b-1$、$g=0,b=1$ 时精确"。核对 Euler 关系后正确结果是 **$2g+b$**，精确域只有 **$g=0,b=0$（闭球面）**；带一个边界的平面片余维为 1（外边界圈）。这不推翻主链 (5.3b) 在其适用域（单连通闭曲面）的正确性，只明确该域比初稿设想的更窄。

## 三、对 CQM 的作用

1. **计数标签不完整**：节点质数化的序数 $n$ 来自最小环计数（(13.4) 与 23.3）。在 $g>0$ 或 $b\ge1$ 时，必须有额外 $2g+b$ 个绕数标签，否则阶梯 $2\ln n$ 只覆盖面边界部分——这就是 `审-13` 要求"补环绕生成元"的定量值。
2. **缺失标签与和乐同源**：不可缩圈的和乐是规范不变的 monodromy（`临-8`），且亏角映射的核模承载连接（W-3′）。故"补的绕数"不是纯数学附录，而是**相位扇区的自由度**；振幅扇区的 $n$ 计数与相位扇区的绕数必须分开。
3. **三维**：3D 中 $H_1$ 可能有挠，面边界子空间与环空间的关系更复杂；本轮只给 2D 闭/带边界曲面的精确式，3D 化为**挂账**（外部拓扑问题，CQM 未涉及）。
4. **有限样品读数**：§0.2 层 C 用截断样品；截断产生 $b\ge1$，因此**总是**缺至少一个外边界绕数标签——这是有限尺寸标度之外的一个**拓扑**修正，不改 $\Delta p\sim L^{-3/4}$ 等已有标度。
