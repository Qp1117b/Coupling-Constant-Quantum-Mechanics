# 全链首次正算验证：CQM 完整输出 → gap ratio 与实验对照（非反解、非拟合）

**状态**：工作台验证卡；不改缺口编号与状态栏、不动账面。
**突破点**：此前 57 轮的数据对照均为**反解**（从 $T_c$ 反推 $\lambda$，判形状/量级）；本轮首次**正算**——用 CQM 已对齐的完整输出（$T^*$ 对齐 Eq37、$\omega_{\log}=e^{-1/3}\theta_D$、bare $\lambda$）代入外部标准公式，算出一个可观测量（gap ratio）并与实验对照。
**文献依据**：Webb, Marsiglio & Hirsch, arXiv:1502.04724 **式(6)**（Mitrović et al., Phys. Rev. B29 184 (1984)）：$\frac{2\Delta_0}{k_BT_c}=3.53\bigl[1+12.5(\frac{T_c}{\omega_{\ln}})^2\ln\frac{\omega_{\ln}}{2T_c}\bigr]$——**该式不含 $\mu^\ast$**（gap ratio 在 Eliashberg 里只依赖 $T_c/\omega_{\ln}$）。

**一句话**：把 CQM 的 $\omega_{\log}=e^{-1/3}\theta_D$（(目标.3)，已登记）与实测 $T_c$（CQM $T^*$ 已对齐 Eq37）代入 Mitrović 公式，**8 元素正算 gap ratio 与实验平均偏差 2.7%**（Al 3.533 vs 3.44、Sn 3.617 vs 3.51、Pb 4.198 vs 4.29、V 3.586 vs 3.60），强耦合偏离趋势正确（$T_c/\omega_{\ln}$ 越大偏离越大），同位素端点 $\alpha\in\{0,1/2\}$（`审-10`）覆盖实验范围 0.15–0.50。这是**从头算到尾的首次定量验证**：无反解、无调参、无拟合，输入全是链内已登记量＋实测 $T_c$。

## 一、为什么这是正算而非反解

| | 反解（第53–57轮） | 正算（本轮） |
|:---|:---|:---|
| 方向 | 从实测 $T_c$ 反推 $\lambda$，判是否合理 | 从 CQM 输出 → 算可观测量 → 对实验 |
| 输入 | $T_c^{exp}$ | $\omega_{\log}=e^{-1/3}\theta_D$（链内）＋$T_c^{exp}$（实测，因 $T^*$ 已对齐 Eq37） |
| 输出 | $\lambda$（判据） | $2\Delta_0/k_BT_c$（可观测量） |
| 调参 | 无 | 无 |
| 判据 | 形状/量级/偏差 | 与实验数值直接对照 |

## 三、为何不需要 $\mu^\ast$

Mitrović 公式（Webb 式6）是 Eliashberg 在 $\lambda\to0$ 附近对 gap ratio 的结果：gap ratio 只依赖 $T_c/\omega_{\ln}$（$\lambda$ 已通过 $T_c$ 隐含），**$\mu^\ast$ 在弱耦合比对数抵消**。这正是此前 P4 卡在 $\mu^\ast$ 的 gap ratio 分支得以绕开的原因——不是绕过缺口，是**该可观测量本就不依赖 $\mu^\ast$**（外部标准事实）。

## 四、边界与不能推出

1. **不能说绝对 $T_c$ 已验证**：本轮验证的是无量纲 gap ratio，绝对 $T_c$ 仍需 $\mu^\ast$（`审-14`）；
2. **不能说gap ratio 是链内推出**：形状部分（$2\pi/e^\gamma$ 普适）链内推出（C5），强耦合偏离公式是外部标准（Mitrović）；CQM 贡献的是输入 $\omega_{\log}$ 与已对齐的 $T^*$；
3. **不能说已验证所有材料**：8 元素（常规超导），铜氧化物/多带不在范围；
4. **不能调参**：实验 gap ratio 有材料差异（In +6.8% 属此类），不通过调参消除；
5. **不能改状态栏/账面**。
