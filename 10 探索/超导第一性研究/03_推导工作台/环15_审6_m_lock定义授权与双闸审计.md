## 二、为什么必须修订（v1 → v2）

v1（第 161 轮闭环的 `Ring15Spec.lean`）把结论写进了值函数：

```
def lockMult … := if ⟨(a,b),h⟩ ∈ edges then 1 else 0
def TargetProp := ∀ … , InducedBond s edges a b → lockMult edges a b = 1
```

`TargetProp` 对任意键图恒真：`≤1`（"每对至多一条键"）与"恰为一条"两半同时退化为定义展开，"多键不可能"与"锁定事件存在"不可分辨，"星级读法被排除"也无从承载。按术语锚点属**定义式冒充命题**，B 闸判跑偏（已登记 `DISCARD.md` 第 162 轮行）。

v2 立法：把两半分开承担——
- **$m_{\rm lock}\le1$** 由**键图编码**承担（`Edge := Sym2 ℕ`，`BondGraph := Finset Edge`：无序对＋去重 ⇒ 简单图，即 SB.3 的"每对相邻占据点只加一条键"）；
- **$m_{\rm lock}\ge1$** 由**前提**承担（`InducedBond` 已给出该对存在键）；
- `lockMult` 改为 `edges.filter (· = {a,b})` 的基数，不再是 0/1 值函数。

由此得到的是**充要刻画**：$m_{\rm lock}=1\iff$ 该对存在键；而不是"结论恒真"。

## 四、B 闸（接地）逐问

| 问 | 答 |
|:---|:---|
| 下游消费了哪部分？ | 只消费 iff 的"存在键 ⇒ $m=1$"一支（`mLock_eq_one` 的输入恰为 `hb.1 : Adj`）；不消费 `≤1` 之外的任何内容 |
| 靠定义展开还是命名带过？ | 证明由 `unfold lockMult` ＋ `Finset` 基数引理给出；"每对至多一条"落在 `Sym2`／`Finset` 编码上（**建模选择**，有 SB.3 授权），不是命名带过；判**定义式**（在其声明的计数口径内） |
| 只借符号没借语义？ | **风险在此**：外部文献的整数 $n$ 是涡旋绕数，本环 $m_{\rm lock}$ 是键的条数，**同名不同义**。v2 已在 Spec 注释写明"不是节点度数，也不是涡旋绕数量子数"；下游若把 $m_{\rm lock}$ 当绕数使用，即语义漂移，判 FAIL |
| 尺度·参数·索引显式？ | 无实数参数；`a ≠ b` 是显式侧条件（自环不承载锁定，$m_{\rm lock}(a,a)=0$）；未藏进 tactic |
| 量词被单点／特例偷换？ | `TargetProp` 对任意键图与任意点对全称；证明未取特例 |
| 防抵消？ | 无归一化／求和／取实部；基数不可被"抵消"，错则必现 |
| 体积层 | 载体是**有限** `Finset`，只在结构／读数层成立；$p_c$ 的无限体积严格性不在本环，未混用 |

**B 闸结论**：v2 **判定义式，通过（限"键级计数"口径）**；但**未覆盖**的物理输入必须外置记账：

> 一条键无涡旋 ⇒ 该对相干，且失锁概率 $=y(T)$（R-158 的 $p_{\rm lock}=1-y$）——这是**假设**，不在本 Spec，也不在本轮证明之内。

## 五、外部对照（B 类，仅对照）

- 2D XY 的每个格点一个相位、涡旋绕数为整数（$w[\mathcal C]\in\mathbb Z$）：arXiv:cond-mat/9707007 式(13)；MIT 8.334 讲稿式(227)；arXiv:1706.09454 式(4)。

- 用途：只说明"键级单连接"与"整数绕数"是**两个不同量**，防止同名混用；CQM 不由此推出其晶格模型，也不引入绕数语义。

## 六、不能推出什么

1. 不能推出 $p_{\rm lock}=1-y$（每键一次涡旋事件的独立性与指数形式），属 R-158 假设，未形式化；
2. 不能推出 $p_{\rm sync}>p_c$ 充分（`M8` 仍必要）；
3. 不能推出任何无限体积陈述（$p_c$、BKT 下界的严格性只在无限体积成立，本轮载体有限）；
4. 不闭合 `审-6`：编号仍 37、闭合数仍 0、状态栏未动；
5. 不把 `mLock_eq_one` 升格为"超导相已证"——它只是计数口径的组合结论。
