## 二、两条定理（Spec v4）

```lean
def TargetPropFugMono : Prop :=
  ∀ (Ec1 Ec2 T : ℝ), 0 < T → Ec1 ≤ Ec2 → yFug Ec2 T ≤ yFug Ec1 T
def TargetPropSyncMono : Prop :=
  ∀ (ppair y1 y2 : ℝ) (m : ℕ), 0 ≤ ppair → 0 ≤ y1 → y1 ≤ y2 → y2 ≤ 1 →
    pSync ppair y2 m ≤ pSync ppair y1 m
```

证明只用 `neg_le_neg`、`div_le_div_of_nonneg_right`、`Real.exp_le_exp`、`pow_le_pow_left₀`、`mul_le_mul_of_nonneg_left`；无 `nlinarith` 跳步。

## 三、故意不写的第三条（这是本轮最重要的一条判断）

按直觉该有"$E_c\uparrow\Rightarrow p_{\rm sync}\uparrow$"的组合定理。**我没写**：它要求 $y\le1$，而 $y\le 1$ 的值域来自前因子 $2\pi$ 的归一（外部边界，DISCARD 161），链内不可得。把它写成定理，就等于把外部条件塞进假设再宣布证毕——正是 B 闸要抓的那一类。所以拆成两条、各带显式侧条件，并在脚本里留下这句注释。

## 四、可检验的定量推论

若局域刚度有相对涨落 $\sigma_\Upsilon/\Upsilon$（实验把手：局域穿透深度图 $\lambda_L(x)$ 的分布），则linear：

$$\frac{\sigma_{T_{\rm sync}}}{T_{\rm sync}}\approx\left|\frac{\partial\ln T_{\rm sync}}{\partial\ln\Upsilon}\right|\cdot\frac{\sigma_\Upsilon}{\Upsilon}=0.1725\,\frac{\sigma_\Upsilon}{\Upsilon},$$

系数 0.1725 取自第 168 轮的 $\lambda$ 扫描（$\lambda$ 即 $E_c\propto\Upsilon$ 的缩放）的解析有限差分值——不是拟合。

读法：$\sigma_\Upsilon/\Upsilon=10\%$ ⇒ $T_{\rm sync}$ 展宽 $1.7\%$；$\sigma_\Upsilon/\Upsilon=30\%$ ⇒ $5.2\%$。注意这里**不是**弱效应：同样 10% 的几何涨落会让 $y$ 变 $e^{\pm1.07}\approx2.9$ 倍，只是 $T_{\rm sync}$ 已被饱和压平（第 168 轮已判）。**所以"耦合涨落"确实存在，但它的可见后果集中在 $y$ 与展宽，而不在 $T_{\rm sync}$ 的均值。**

## 七、不能推出什么

1. 不能推出 `审-6` 闭合——条件来源、$2\pi$、和乐层三项仍开；
2. 不能推出 $T_{\rm sync}$ 的绝对展宽值——只有线性化系数，$\sigma_\Upsilon$ 须实测；
3. 不能推出"局域刚度涨落在链内已被描述"——链内 $\Upsilon$ 仍是均匀标量，涨落谱未立；
4. 不能把展宽系数当第一性预言——它是既有模型对参数的导数。
