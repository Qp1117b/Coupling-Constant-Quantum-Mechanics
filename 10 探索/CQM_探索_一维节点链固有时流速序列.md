# CQM 探索：一维节点链固有时流速序列（局域比值递推）

> **定位**：探索稿（非权威源）。按用户要求建立一维节点链的固有时流速序列模型：参考节点流速记为 $v_o$（origin/reference node，变量符号），流速沿链**局域递推**——下一个节点流速只由前一个节点流速与两者之间那条边的亏角决定，不是前面节点的"加和"，也不是全局累积。全程 CQM 内生，权威口径逐处标注。
>
> **权威口径**：LQG 铰链亏角—固有时流速关系 $v_\tau=\sqrt{1-\varepsilon/2\pi}$（FG_核心理论 §3.1，$\varepsilon$ 为铰链亏角本体、曲率载体，未另乘耦合常数）；超导核心 §0.2/§0.3 节点间固有时流速差异由两两亏角经 FG 接口定出。

## 1. 模型（用户图像）

一维节点链上，参考节点（第 1 个）流速记为 $v_o$（变量符号，表示 origin/reference node，不是数值 1）。节点 $k$ 与 $k+1$ **之间那条边的亏角** $\varepsilon_{k,k+1}$（曲率载体）经 FG/LQG 接口给相邻节点流速**比值**，于是**局域递推**：

$$\boxed{v_{k+1}=v_k\cdot\sqrt{1-\frac{\varepsilon_{k,k+1}}{2\pi}},\qquad \varepsilon_{k,k+1}=2\pi-\sum_{T\supset e_{k,k+1}}\theta_{e_{k,k+1}}^{T}.}\tag{1}$$

**这是乘积关系**：逐步展开式 (1) 得一维链的流速序列

$$v_1=v_o,\qquad v_{k}=v_o\prod_{j=1}^{k-1}\sqrt{1-\frac{\varepsilon_{j,j+1}}{2\pi}}=v_o\cdot\prod_{j=1}^{k-1} r_j.\tag{2}$$

每一步 $v_{k+1}$ 只由前一个节点流速 $v_k$ 与当前边亏角 $\varepsilon_{k,k+1}$ 决定，是**乘积关系**，**不是加和（求和）**——这是您强调的关键区分。乘积是逐边比值 $r_j$ 的连乘，每一因子由对应那条节点间边的亏角经 LQG 接口给出。

**亏角都是节点之间的（铰链亏角）**，没有"节点自身亏角"这个说法；不做节点关联亏角聚合（那会引入配位数污染、非纯两两量）。

## 2. 一维开链的拓扑性质

- **无环 ⇒ 无反馈 ⇒ 无全局固有时流速同步**：一维开链没有闭合回路，节点间没有反馈耦合，因此**不存在**"全局固有时流速"这种整体同步量，不能把集体量 $\hat u_G=\tfrac1N\sum\hat u_i$ 之类的全局/加和结构套到一维开链上。全局同步是闭环/渗流网络才有的性质（超导核心两阶段框架的 $T_\theta$ 相位渗流），一维开链不具备。
- **无阻挫**：一维链路径唯一，没有环路多路径不一致——和乐平庸 $\mathcal H\approx1$ 自动满足。
- **单调减慢**：Delaunay 剖分铰链亏角 $\varepsilon\ge0$，故相邻比值 $\sqrt{1-\varepsilon/2\pi}\le1$，式 (2) 的逐边乘积使流速沿链逐步减慢（引力时间膨胀的逐边乘积效应），这是 $\varepsilon\ge0$ 的必然，非错误。

## 4. 边界（不得升级）

| 环节 | 状态 | 说明 |
|:---|:---|:---|
| FG/LQG 接口 $v_\tau=\sqrt{1-\varepsilon/2\pi}$ | 【假设】（FG_核心理论 §3.1）| 引力时间膨胀的 Regge 版本 |
| 曲率载体 = 节点间边亏角 $\varepsilon_{k,k+1}$ | 【几何事实】| 亏角都是节点间（铰链）的，无"节点自身亏角" |
| 参考节点流速 $v_o$ | 【变量符号】| origin/reference node，非数值 1 |
| 局域递推 (1) | 【模型实现选择】| 下一步只由前一步 + 当前边亏角定 |
| $u=\ln g$ 与 $p_u=v_\tau/☯$ | 【正则共轭对】| 不从 $v_\tau$ 臆造 $\alpha$ |
| 全局同步/集体量 | 【不适用于一维开链】| 一维无环无反馈，无全局固有时流速同步 |
