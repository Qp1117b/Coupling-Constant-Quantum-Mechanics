## 二、量纲空间与量纲分析基础

### 2.1 Buckingham π 定理

量纲分析的核心定理是 Buckingham π 定理（Buckingham, 1914）：

> 若一个物理上有意义的方程涉及 $n$ 个物理量，且这些量由 $k$ 个独立量纲构成，则该方程可改写为 $p = n-k$ 个无量纲组合（π 群）之间的关系。

形式化表述：设物理量 $q_1,\dots,q_n$ 满足某物理定律 $\Phi(q_1,\dots,q_n)=0$，其量纲矩阵的秩为 $r$，则存在 $p=n-r$ 个独立的无量纲量 $\pi_1,\dots,\pi_p$，使得定律等价于：

$$\Psi(\pi_1, \pi_2, \dots, \pi_p) = 0$$

**物理意义**：物理定律不依赖于单位制的选择——只有无量纲组合才是“真实的”物理关系，有量纲量只是这些关系在特定单位制下的表达。

**群论形式（与 §7.6 锚点论证衔接）**：单位制的任意选择，就是**量纲空间的重标度群**
$$G_{\text{scale}}\cong(\mathbb{R}_{>0})^{k}$$
作用在 $k$ 个独立量纲上——换单位即施加群作用：$q_i\mapsto\lambda_1^{a_{i1}}\cdots\lambda_k^{a_{ik}}q_i$。$\pi$ 定理说的正是：**该群作用下的不变量恰是无量纲组合**；量纲矩阵的秩 $r$ 给出轨道维数，$p=n-r$ 即独立不变量的个数。

⇒ **单个量纲并非“没有非平凡关系化”**：它自带 $\mathbb{R}_{>0}$ 重标度，只是该作用**不跨量纲**；跨量纲的锚须另求（§7.6 二）。【标准数学】

## 三、电磁部分：高斯单位制

采用高斯单位制（CGS-esu 与 CGS-emu 的对称合成）。为什么选高斯制而不是 SI、Heaviside–Lorentz 或其他？

**高斯制的核心优点**：
1. **电荷量纲完全导出**：$[q] = M^{1/2}L^{3/2}T^{-1}$，不需要引入第四独立量纲（电流/电荷）
2. **电场与磁场同量纲**：$[E] = [B] = M^{1/2}L^{-1/2}T^{-1}$，相对论协变性更直观——$E$ 和 $B$ 是同一张量的分量，量纲理应相同。
3. **$c$ 显式出现在基本方程中**：实现关系不藏在 $\varepsilon_0$、$\mu_0$ 里，而是直接以光速形式出现，符合“特征常数显式呈现”的原则。
4. **理论物理界的传统选择**：量子力学、量子场论、粒子物理教材普遍采用高斯制或其近亲 Heaviside–Lorentz 制，因为公式更简洁、物理关系更透明。

**为什么不选 Heaviside–Lorentz（有理化高斯制）**：Heaviside–Lorentz 去掉了 $4\pi$ 因子，麦克斯韦方程更对称，但代价是库仑定律和毕奥-萨伐尔定律多出 $4\pi$。在 CQM 框架中，**$4\pi$ 因子有物理意义**（球对称、立体角），不应被有理化“吸收”掉。高斯制保留了 $4\pi$ 在力定律中的原始位置，更有利于追踪几何来源。

电荷是导出量：

$$\boxed{
[q] = M^{1/2} L^{3/2} T^{-1}
}$$

电荷单位：

$$\boxed{\text{esu} = \text{statC}}$$

其他电磁量也全部由 $M,L,T$ 组合：

| 物理量 | 高斯制量纲 |
|---|---|
| 电荷 | $M^{1/2}L^{3/2}T^{-1}$ |
| 电流 | $M^{1/2}L^{3/2}T^{-2}$ |
| 电场 | $M^{1/2}L^{-1/2}T^{-1}$ |
| 磁场 | $M^{1/2}L^{-1/2}T^{-1}$ |
| 电压 | $M^{1/2}L^{1/2}T^{-1}$ |
| 电阻 | $L^{-1}T$ |

### 3.1 esu → esu(SI) → C：$K_Q$ 的推导

**核心原则**：特征常数的功能是提供一个新量纲。电荷量纲 $Q$ 不是预先存在的，而是由**真正的特征常数**从力学量纲中生成。**方向决定角色**：乘在旧单位上、使旧量纲变成新量纲的因子，才是特征常数。

**esu 的量纲**：高斯制库仑定律 $F=q_1q_2/r^2$ 给出 $[\text{esu}]=M^{1/2}L^{3/2}T^{-1}$。CGS 中 $1\ \text{esu}=1\ \mathrm{g}^{1/2}\mathrm{cm}^{3/2}\mathrm{s}^{-1}$。

**esu → esu(SI)**：由 $1\ \mathrm{g}=10^{-3}\ \mathrm{kg}$，$1\ \mathrm{cm}=10^{-2}\ \mathrm{m}$，得 $1\ \text{esu}=10^{-9/2}\ \text{esu(SI)}$，其中 $\text{esu(SI)}:=\mathrm{kg}^{1/2}\mathrm{m}^{3/2}\mathrm{s}^{-1}$。$10^{-9/2}$ 是纯数。

**C 与 esu 的关联**：$1\ \mathrm{C}=10c\ \text{esu}$，故 $1\ \text{esu}=\frac{1}{10c}\ \mathrm{C}$。$10c$ 是关联因子，不是特征常数。

**$K_Q$ 的定义**：CQM 要求 SI，联立得 $1\ \mathrm{C}=\frac{10c}{10^{9/2}}\ \text{esu(SI)}$。定义：

$$\boxed{K_Q=\frac{10c}{10^{9/2}}\approx 9.480\times 10^{4}}$$

$$\boxed{1\ \mathrm{C}=K_Q\ \text{esu(SI)}}$$

量纲：$Q=[K_Q]\cdot M^{1/2}L^{3/2}T^{-1}$，故

$$\boxed{[K_Q]=QM^{-1/2}L^{-3/2}T}$$

$K_Q$ 是电荷层的量纲特征常数（统一公式模式 §6.3：旧×$K$=新），满足 $M^{1/2}L^{3/2}T^{-1}\cdot K_Q=Q$。$10c$ 只是 C → esu 的关联因子，不是特征常数。

## 五、温度、物质的量、发光强度

### 5.1 温度

温度作为独立量纲 $\Theta$，由温度层特征常数 $K_\Theta$ 从能量转换（统一公式模式 §6.3：旧×$K$=新）：

$$\boxed{ML^2T^{-2}\cdot K_\Theta=\Theta}$$

与已有物理常数的关系：$K_\Theta = k_B^{-1}$，其中玻尔兹曼常数

$$k_B = 1.380649\times 10^{-23}\ \text{J/K}$$

量纲（$\Theta$ 为温度量纲符号）：

$$\boxed{
[K_\Theta] = \Theta M^{-1} L^{-2} T^2
}$$

实现关系验证：$ML^2T^{-2}\cdot[K_\Theta]=ML^2T^{-2}\cdot\Theta M^{-1}L^{-2}T^2=\Theta$，实现关系成立。等价地，$E=k_B T$ 中 $k_B=K_\Theta^{-1}$，$[k_B]\cdot\Theta=\Theta^{-1}ML^2T^{-2}\cdot\Theta=ML^2T^{-2}=[E]$。

理论目标：

$$\boxed{
\text{由更深层理论推出 }K_\Theta\text{ 的数值}
}$$

### 5.2 物质的量

物质的量作为独立量纲 $N$，由物质的量层特征常数 $K_N$ 锁定计数基准（统一公式模式 §6.3：旧×$K$=新）：

$$\boxed{1\cdot K_N=N}$$

与已有物理常数的关系：$K_N = N_A^{-1}$，其中阿伏伽德罗常数

$$N_A = 6.02214076\times 10^{23}\ \text{mol}^{-1}$$

量纲（$N$ 为摩尔量纲符号）：

$$\boxed{
[K_N] = N
}$$

实现关系验证：$1\cdot[K_N]=N$，实现关系成立。等价地，$[N_A]\cdot N = N^{-1}\cdot N = 1$（无量纲），即 $N_A\times 1\ \text{mol}=6.02214076\times 10^{23}$ 为纯数。

### 5.3 发光强度

发光强度作为独立量纲 $J$，由发光强度层特征常数 $K_J$ 从功率转换（统一公式模式 §6.3：旧×$K$=新）：

$$\boxed{ML^2T^{-3}\cdot K_J=J}$$

与已有物理常数的关系：$K_J = K_{cd}^{-1}$，其中光度学常数

$$K_{cd} = \frac{1}{683}\ \text{W/cd} \quad(\text{555 nm 明视觉})$$

量纲（$J$ 为坎德拉量纲符号）：

$$\boxed{
[K_J] = J M^{-1} L^{-2} T^3
}$$

实现关系验证：$ML^2T^{-3}\cdot[K_J]=ML^2T^{-3}\cdot JM^{-1}L^{-2}T^3=J$，实现关系成立。等价地，$[K_{cd}]\cdot J = J^{-1}ML^2T^{-3}\cdot J = ML^2T^{-3} = [\text{W}]$，与 $1\ \text{cd}=\frac{1}{683}\ \text{W}$ 一致。

$$\boxed{

| 时空量→质量   | 质量 $M$      | $K_M$      | 时空量→质量的实现关系       |
| 力学量纲→电荷  | 电荷 $Q$      | $K_Q$      | 力学量纲→电荷的实现关系      |
| 能量→温度    | 温度 $\Theta$ | $K_\Theta$ | 能量→温度的实现关系        |
| 无量纲→物质的量 | 摩尔 $N$      | $K_N$      | 无量纲计数→物质的量的实现关系   |
| 功率→发光强度  | 坎德拉 $J$     | $K_J$      | 功率→发光强度的实现关系      |

因此：

$$\boxed{
\text{量纲数} + \text{特征常数数} \approx \text{守恒}
}$$

并且：

$$\boxed{
\text{特征常数比被压掉的量纲更基础。}
}$$


### 6.2 大差异与同量纲内差异：量纲发生学的双重结构

量纲发生学中存在两种根本不同的差异类型，它们由自守形式的不同差异层级锁定：

#### 6.2.1 大差异：不同量纲之间

$$\boxed{
\text{大差异：不同量纲之间，由自守形式的大差异锁定，产生量纲特征常数}\text{（＝属性 }P\text{ 被实现为该量纲时的特征常数）。}
}$$

这是量纲发生学的核心机制：不同量纲之间存在**大差异**，这种差异需要特征常数来“桥接”。例如：
- 温度 $\Theta$ 与能量 $ML^2T^{-2}$ 之间：由 $K_\Theta$ 桥接（大差异）

大差异产生量纲特征常数，这些常数正是量纲发生学的“生成节点”（§6.0）。

#### 6.2.2 同量纲内差异：同一量纲内部细分

$$\boxed{
\text{同量纲内差异：同一量纲内部，由自守形式的小差异锁定，不产生新的跨量纲特征常数——}\\\text{同量纲内差异表现为实现之间的无量纲标度，与不可简单组合的结构性差异。}
}$$

**定义**：量纲内差异是同一量纲内部不可简单组合、不可简单归约的结构性差异。它不是“同一量纲内的不同数值”，而是同一量纲内部有各自独立谱来源、各自锁定方式的不同层面。

**判定标准——不能简单组合**：
- 不是加法：$m \neq m_{\text{惯性}} + m_{\text{引力}} + m_{\text{静}}$
- 不是函数关系：$q \neq f(q_{\text{裸}}, q_{\text{有效}})$
- 而是：各差异类型分属不同表示类别、不同边界条件、不同自守形式参数

各量纲内部差异对照表：

| 量纲              | 内部差异类型    | 为什么不能简单组合                                                      |
| --------------- | --------- | -------------------------------------------------------------- |
| **时间** $T$      | 坐标时       | 外部参数，依赖参考系，不描述系统内禀演化                                           |
|                 | 固有时       | 运动学量，与粒子世界线绑定，是“经历”而非“寿命”                                      |
|                 | 寿命        | 动力学量，由衰变矩阵的谱决定，与坐标时、固有时属于不同范畴                                  |
| **长度** $L$      | 固有长度      | 时空几何量，与坐标系无关                                                   |
|                 | 坐标长度      | 依赖参考系，是规范变量                                                    |
|                 | 康普顿波长     | 质量的内禀量子尺度，对应粒子离散谱                                              |
|                 | 德布罗意波长    | 依赖动量，对静止粒子无定义                                                  |
| **质量** $M$      | 惯性质量      | 由牛顿第二定律定义，概念来源是惯性定律                                            |
|                 | 引力质量      | 由万有引力定律定义，概念来源是引力定律                                            |
|                 | 粒子静质量     | 由四维动量不变量定义，属于量子场论范畴                                            |
|                 | 有效质量      | 来自 $T_{ij}$ 的局部应力结构，对应连续谱的局部激发                                 |
| **电荷** $Q$      | 裸电荷       | 依赖截断；截断趋于无穷时裸电荷趋于零                                             |
|                 | 有效电荷      | 与裸电荷通过重整化群方程联系，但不可简单相加                                         |
| **温度** $\Theta$ | 全局温度      | 在引力场中可能根本不存在                                                   |
|                 | 局部温度      | 只在系统尺度足够大时存在；量子多体系统中不一定存在                                      |
|                 | Tolman 温度 | 与局部温度、全局温度分属不同物理层面                                             |
| **物质的量** $N$    | 离散计数      | 计数本身是离散的，不参与连续谱的曲率变形机制                                         |
|                 | 宏观摩尔量     | $N_A$ 是计数基准而非**同量纲内**物理特征常数（其跨量纲转换角色见 §5.2、§6.1）；二者之间不存在连续变形关系 |
| **发光强度** $J$    | 辐射强度      | 纯物理量，不依赖观察者                                                    |
|                 | 发光强度      | 视见函数依赖人类视觉系统的生理响应，不是物理常数                                       |

**注意**：上表为粗略分类，不严格，甚至可能有误。表中分类仅作示意，关键在于各差异类型背后的具体物理关系——不同表示类别、不同边界条件、不同自守形式参数，而非表中的分类本身。

**关键区分**：坐标时 $T$ 是量纲发生学中的基本时间量纲，长度由 $K_L$ 从无量纲耦合坐标直接生成（大差异），不经过时间。$c$ 是时空同步前沿速度，不承担量纲转换，但定义局部时空结构。固有时 $\tau$ 是观测者自身经历的时间，涉及引力红移和时空弯曲，属于同量纲内差异，由曲率/自守形式的小差异锁定，不产生新的量纲特征常数。本句即**两个锚点**的读法：长度不经时间——各有其无量纲来源，时间来自事件计数，长度来自耦合空间经 $K_L$（§6.3.1）；发生学上时间先于空间，而空间不借时间量纲承担自守链。二者随后**同步**为时空，其表现为保持时空间隔的群 $O(1,3)$ 与光速 $c$（§7.6 二）。严格链式（长度依靠时间，$\ell=\mathsf{F}(\tau)$）则要求 $K_L$ 的输入换成由寿命导出的数，与 $K_L$ 在耦合空间中的存在方式不相容（§7.7.3）。

#### 6.2.3 自守形式差异层级

自守形式的差异层级决定了量纲转换的性质：

| 差异类型 | 作用范围 | 表现 | 是否产生量纲特征常数 |
|---|---|---|---|
| **大差异** | 不同量纲之间 | 量纲分化与锁定 | 是（$K_L$、$K_M$、$K_Q$、$K_\Theta$、$K_N$、$K_J$） |
| **同量纲内差异** | 同一量纲内部 | 各量纲内部细分（详见 §6.2.2） | 否（由曲率/度规锁定） |

自守形式承担**关系本身的锁定**：不同量纲之间是**大差异**，由自守形式之间的分化锁定（§6.2.6）；同一量纲内部细分是**同量纲内差异**，由同一量纲自守形式的变形分化锁定（§6.2.6）。

#### 6.2.4 核心结论

$$\boxed{
\text{“不能简单组合”是判定量纲内差异的核心标准。}
}$$

各量纲内部差异之所以不可简单组合，根源在于它们**不是同一个谱点的不同数值，而是不同表示类别、不同边界条件、不同自守形式参数在物理层的投影**——即同一量纲自守形式的变形分化。

每一个量纲都是一个有内部结构的谱，而非一个标量点。

#### 6.2.5 转换与关联：核心区分

量纲发生学中的所有关系可分为两类：**转换**（量纲之间的关系，即大差异，由特征常数锁定）与**关联**（量纲内的关系，即同量纲内差异）。

| | 转换 | 关联 |
|---|---|---|
| **作用范围** | 量纲之间 | 量纲内（同一量纲内部） |
| **锁定方式** | 特征常数 | 曲率 / 自守形式谱条件 |
| **是否普遍** | 不确定 | 依赖具体谱点、曲率、观测者 |
| **典型例子** | $L^3T^{-2}\cdot K_M=M$，$ML^2T^{-2}\cdot K_\Theta=\Theta$，$M^{1/2}L^{3/2}T^{-1}\cdot K_Q=Q$ | 坐标时↔固有时，惯性质量↔引力质量，裸电荷↔有效电荷 |

$$\boxed{
\text{转换是关联的特例；关联是更普遍的结构。}
}$$

**特征常数的性质——跨量纲特征常数**：每个量纲转换有一个**跨量纲特征常数**（如长度层的 $K_L$、质量层的 $K_M$、电荷层的 $K_Q$）。“特征”体现在考虑的是直接的量纲-量纲转换，而非具体场景。具体情况下的量纲特征常数可能与之不同，但可能和跨量纲特征常数有关：

1. **跨量纲特征常数是量纲实现关系上的标准常数**（大差异的锁定），不是“通用”那种含糊的“到处可用”；
2. **具体情况下可能不同**——量纲内差异下的特征常数可能不是跨量纲特征常数（如质量层的跨量纲特征常数是 $K_M$，但在具体的质量情况下，可能不是 $K_M$ 而是别的）；
3. **但可能和跨量纲特征常数有关**——具体情况下的量纲特征常数与跨量纲特征常数之间可能存在关联，这种关联是量纲内差异的体现；
4. **是否有普适性不确定**——跨量纲特征常数是否具有普适性（即是否在更广泛的意义上适用），目前不确定。

**质量层的特殊情况**：质量层**同时有转换和关联**——$K_M$（质量层特征常数，$[K_M]=ML^{-3}T^2$，$K_M=G_N^{-1}$）是真正的量纲特征常数（$L^3T^{-2}\cdot K_M=M$）。

**角色区分（避免循环）**：本节的量纲发生学只确定**哪一个常数承担转换角色**（质量层为 $K_M$），不涉及该常数的**数值从何而来**；$K_M$（$=G_N^{-1}$）的数值是否可由谱不变量算出，是 `03 引力与退相干/CQM_引力_GN可能公式.md` 的议题。二者层次不同，不构成“$K_M$ 既是输入又是输出”的角色冲突：量纲层用 $K_M$ 作为时空–质量的锁定关系，数值层才追问 $K_M$ 本身的来源。


#### 6.2.6 自守形式—量纲—分化

**核心对应**：一个自守形式 ↔ 一个量纲。自守形式的分化分两个层次：

- **自守形式之间的分化**（跨量纲）：不同量纲对应不同自守形式，其分化对应量纲之间的转换（生成新量纲，锁定为特征常数），即大差异；
- **同一自守形式内部的变形分化**（量纲内）：同一量纲自守形式在不同谱参数下的变形分化，对应量纲内差异，不产生新量纲、不产生新的量纲特征常数。

$$\boxed{
\text{自守形式是量纲的数学载体；}\\
\text{其分化（自守形式之间）生成新量纲（特征常数）；}\\
\text{其变形分化（同一自守形式内部）对应量纲内差异。}
}$$

此对应属 CQM 框架内的结构性类比，尚待第一性推导与严格化。


### 6.3 各特征常数的角色

每个量纲特征常数统一遵循 **旧量纲 × 特征常数 = 新量纲**（“旧”“新”指量纲发生学先后）：

$$\boxed{[\text{旧}]\cdot K = [\text{新}]}$$

- **$K_L$**：禁闭映射常数，$[K_L]=L$，$r_{\text{coupling}}\cdot K_L=r_{\text{phys}}$（无量纲 × $K_L$ = 长度）。$r_{\text{coupling}}$ 与固有时 $\tau$ 共轭（$[\hat{u},\hat{p}_u]=i$，$u=\ln r_{\text{coupling}}$，$p_u=v_\tau/☯$，固有时流速 $v_\tau=d\tau/dt$ 见 `CQM_核心_因果网络同步理论.md` §6.3.6）。长度层特征常数，不要求普适。$K_L$ 值有待确定（第一性链给 $K_L=0.656$ fm，标定链 $0.67860$ fm，几何值 $0.6805$ fm，值链间差 3.3%，$g_s^{IR}$ 张力 3.73%，见 §6.3.1 及 `04 前沿研究/CQM_前沿研究_待推1边界条件深度分析.md` §6.5）。
- **$c$**：时空同步前沿速度（信息传播前沿速率），$[c]=L/T$，不承担量纲转换。$L=c\,T$ 是物理速度关系（速度=距离/时间），非量纲实现关系。$c$ 同时定义局部时空结构。
- **$K_M$**：质量层特征常数，$[K_M]=ML^{-3}T^2$，$L^3T^{-2}\cdot K_M=M$（时空量 × $K_M$ = 质量）。由万有引力定律锁定。
- **$c^2$**：质能特征常数，$[c^2]=L^2T^{-2}$，由 $E=mc^2$ 锁定。但 $[c^2]$ 不含 $M$，不消除质量量纲，故 $c^2$ 不是量纲特征常数。
- **$K_Q$**：电荷层特征常数，$[K_Q]=QM^{-1/2}L^{-3/2}T$，$M^{1/2}L^{3/2}T^{-1}\cdot K_Q=Q$（力学量纲 × $K_Q$ = 电荷）。
- **$K_\Theta$**：温度层特征常数，$[K_\Theta]=\Theta M^{-1}L^{-2}T^2$，$ML^2T^{-2}\cdot K_\Theta=\Theta$（能量 × $K_\Theta$ = 温度）。
- **$K_N$**：物质的量层特征常数，$[K_N]=N$，$1\cdot K_N=N$（无量纲计数 × $K_N$ = 物质的量）。
- **$K_J$**：发光强度层特征常数，$[K_J]=JM^{-1}L^{-2}T^3$，$ML^2T^{-3}\cdot K_J=J$（功率 × $K_J$ = 发光强度）。

**与已有物理常数的对比**：

| 特征常数 | 已有物理常数 | 关系 | 已有常数数值 |
|---|---|---|---|
| $K_L$ | — | 禁闭映射常数 | $0.656$/$0.67860$/$0.6805$ fm |
| $K_M$ | $G_N$ | $K_M = G_N^{-1}$ | $G_N \approx 6.674\times10^{-11}\ \mathrm{m^3\,kg^{-1}\,s^{-2}}$ |
| $K_Q$ | — | 电荷层特征常数 | $K_Q \approx 9.480\times10^{4}$ |
| $K_\Theta$ | $k_B$ | $K_\Theta = k_B^{-1}$ | $k_B \approx 1.381\times10^{-23}\ \mathrm{J\,K^{-1}}$ |
| $K_N$ | $N_A$ | $K_N = N_A^{-1}$ | $N_A \approx 6.022\times10^{23}\ \mathrm{mol^{-1}}$ |
| $K_J$ | $K_{cd}$ | $K_J = K_{cd}^{-1}$ | $K_{cd} = 1/683\ \mathrm{W/cd}$ |

#### 6.3.1 $K_L$ 的谱结构与数值状态

**前置量**：

| 量 | 公式 | 数值 | 含义 |
|---|---|---|---|
| $r_{\text{conf}}$ | $\sqrt{I\lambda_c}$ | $1.481$ | 无量纲耦合空间禁闭壳 |
| $r_{\text{GUT}}$ | $\sqrt{4\pi\,☯\,\lambda_c}$ | $0.6180$ | GUT 标度（无量纲） |
| $g_s^{IR}$ | $\sqrt{I\cdot\lambda_c}$ | $1.481$ | 红外强耦合冻结值（归档定理 10.4，见 `04 前沿研究/CQM_前沿研究_待推1边界条件深度分析.md` §6.5，相变点 $\lambda_c=(g_s^{IR})^2/I$） |
| $\Lambda_{\text{QCD}}$ | $m_p c^2/(☯\cdot\mathfrak{c}_1)$ | $203$ MeV | QCD 能标先验公式（归档定理 10.2） |
| $\lambda_{\text{QCD}}$ | $\hbar c/\Lambda_{\text{QCD}}$ | $0.9716$ fm（第一性）/$1.005$ fm（标定） | QCD 特征长度 |

其中 $\mathfrak{c}_1=\gamma_1^2+\tfrac14\approx 200.04$ 是第一耦级（黎曼谱第一本征值）。

**谱参数公式**（归档 D1 回捞）：

$$K_L = \frac{\lambda_{\text{QCD}}}{r_{\text{conf}}} = \frac{\hbar c \cdot ☯ \cdot \mathfrak{c}_1}{m_p c^2 \cdot g_s^{IR}}$$

$K_L$ 把无量纲禁闭壳转换为 QCD 特征长度：$r_{\text{conf}}\cdot K_L=\lambda_{\text{QCD}}$（无量纲 $\times\,K_L$ = 长度）。

**几何确定方式**（归档 §6.1）：

$$K_L = \frac{\sqrt{\lambda_p \cdot r_p}}{r_{\text{GUT}}} = \frac{\sqrt{0.2103 \times 0.8409}}{0.6180} \approx 0.6805 \text{ fm}$$

其中 $\lambda_p=\hbar/(m_p c)=\hbar c/(m_p c^2)=0.2103$ fm 为质子康普顿波长，$r_p=0.8409$ fm 为质子电荷半径。$K_L$ 是质子内外尺度几何平均与 GUT 标度之比。

**量纲地位（禁闭映射常数）**：

$K_L$ 是**禁闭映射常数**：量纲为长度（fm）的特征常数，把无量纲耦合壳 $r_{\text{coupling}}$ 映为物理长度 $r_{\text{phys}}=r_{\text{coupling}}\cdot K_L$。它与 $K_M=G_N^{-1}$、$K_Q$ 同属层间特征常数，是「旧量纲 × 特征常数 = 新量纲」模式（§6.3）在长度层的实例。

> **不是交织算子**：$K_L$ 是换算比值，不是两套 Hilbert 空间之间的算符。交织算子的严格定义要求先指定群 $G$ 与两侧表示；本框架中不存在这样的群作用，故 $K_L$ 不具备交织算子的数学身份；又算子范数在两侧同归一化时是纯数，与 $K_L$ 的长度量纲（fm）冲突；且 $\{\gamma_n\}$ 不是任何一维自伴算符的严格点谱（Weyl 律否证），以 $\gamma_n$ 为谱的 $\mathcal H_{\text{Riemann}}$ 不存在。详见 `04 前沿研究/CQM_前沿研究_待推1边界条件深度分析.md` §6.5.1。【框架内构造（比值定义）】

**自对偶结构（D4–D7）**：

经 $K_L$ 映射后，质子康普顿波长 $\lambda_p$、GUT 标度 $r_{\text{GUT}}$、质子电荷半径 $r_p$ 在耦合空间中形成 $\tfrac{1}{2}:1:2$ 几何级数：

| 发现 | 关系 | 偏差 |
|---|---|---|
| D4 | $\lambda_p/K_L = 0.3100 \approx r_{\text{GUT}}/2 = 0.3090$ | $0.32\%$ |
| D5 | $r_p/K_L = 1.2394 \approx 2\,r_{\text{GUT}} = 1.2360$ | $0.27\%$ |
| D6 | $\sqrt{\lambda_p \cdot r_p\,/\,K_L^2} = 0.6199 \approx r_{\text{GUT}} = 0.6180$ | $0.30\%$ |
| D7 | $\lambda_p/K_L : r_{\text{GUT}} : r_p/K_L = \tfrac{1}{2} : 1 : 2$ | $<0.33\%$ |

GUT 壳层是质子内部尺度（$\lambda_p$）与外部尺度（$r_p$）的几何平均——自对偶中心。上述偏差依赖 $K_L=0.67860$（标定链谱参数公式）；几何公式给 $K_L=0.6805$（差 ~0.3%），改用第一性 $K_L=0.656$ 则偏差全部升至 ~$3.74\%$。

**两条值链与不一致**：

| 链 | 起点 | $K_L$ 值 | 状态 |
|---|---|---|---|

### 6.4 量纲作为属性实现：独立属性、特征常数与差异分类

本节把量纲发生学的三条线索系统化：**属性→量纲的实现**、**独立属性的判定**、**差异的分类学**；并给出与群论的对接（群侧完整讨论见 `01 核心理论/CQM_核心_唯物主义群论.md` 第 5、6 章）。

#### 6.4.1 量纲＝属性的量度类别；常数＝该次实现的特征常数

量纲不是“转换”来的，而是**属性被实现的结果**：

$$\text{属性 }P\ \xrightarrow[\ \text{特征常数}\ K_{P\to\mathcal{R}}\ ]{\ \text{被实现为}\ }\ \text{量纲（或实现）}\ \mathcal{R}$$

其中“**属性**”≈ 物理上的**自由度**（degree of freedom）——指系统在描述中**可独立取值、并承受变换作用的那些方面**（空间广延、相位、质量……）。

#### 6.4.2 三个层次：量纲／具体值（表面）／属性量的值（内蕴）

| 层次 | 内容 | 性质 |
|:---|:---|:---|
| ① | 属性被实现为**量纲** | 量纲＝该属性的**量度类别**；$K$＝该次实现的特征常数 |
| ② | 各形式（实现）各带**具体值**（数值 $\times$ 量纲） | **表面层**——**表面值不一定一样**；“原形式 → 新形式”由自守因子联系 $f(\gamma x)=j(\gamma,x)f(x)$（$j\not\equiv1$ 时二者不等） |
| ③ | **属性量的值** | **内蕴层**——该量的值在实现过程中具有**内在不变性**，区别于表面不变性 |

#### 6.4.3 七大 SI 基本量纲均为独立属性

| 档 | 成员 | 判定依据 |
|:---|:---|:---|
| **独立属性**（七大 SI 基本量纲） | 时间 $[T]$、长度 $[L]$、质量 $[M]$（**惯性实现**）、电流／电荷 $[Q]$、温度 $\Theta$、物质的量 $N$、发光强度 $J$ | 各有独立的本体论来源；质量须限定为**惯性实现**（见 §6.2.2 的四种实现） |

- **“与别的基本量纲有联系”应解释为**：**该属性在别的属性约束下被实现**（如高斯制下 $[Q]=[M]^{1/2}[L]^{3/2}[T]^{-1}$、$\Theta$ 由能量经 $K_{\Theta}$ 引出）——不是“可还原”；
- 独立性**挂在“属性”上**，不挂在“量纲符号”上；**本体论独立 $\ne$ 单位制独立**（量纲可压缩，代价是生成特征常数）；
- **温度**是统计量，且**没有对应的基本对称群**——是与群对应时的唯一例外。

#### 6.4.4 特征常数的两支

- **跨量纲支**（＝本节的**大差异**）：$[K]=[Q']/[Q]$，量纲上跨量纲；如 $c:[L]/[T]$、$\hbar:ML^{2}T^{-1}$、$K_M=G_N^{-1}:[M][L]^{-3}[T]^{2}$、$K_Q$、$K_\Theta$；
- **同量纲内支**（＝**同量纲内差异**）：同一量纲内部的标度，量纲上为 $1$。须再分三类：
  1. **约定性单位换算**（$1\ \mathrm{m}=100\ \mathrm{cm}$、SI 词头）——**非物理常数**；
  2. **物理性标度**（$\ell_P/\mathrm{m}$、$\lambda_C=\hbar/(mc)$、$a_0=4\pi\varepsilon_0\hbar^{2}/(m_ee^{2})$）——**这才是特征常数**；
  3. **结构性差异**（惯性／引力／有效质量，裸／有效电荷）——各有独立谱来源，**不可用单一常数桥接**（§6.2.2）。

- **注意（勿混两套分类）**：本小节的“两支”是按**量纲性质**分（跨量纲支／同量纲内支）；§7.5 则按“**是不是某个量纲对之比的体现**”把基本常数分**三类**（有量纲特征常数／比值型无量纲常数／纯数型）。其中本小节的“**同量纲内支**”与 §7.5 的“**比值型无量纲常数**”是同一件事的两个角度（同量纲内的实现标度 ⇒ 量纲相消 ⇒ 无量纲）。

#### 6.4.5 量纲间差异＝属性类型；量纲内差异＝实现群

| 层级 | 差异所在 | 差异的内容 |
|:---|:---|:---|
| **量纲间差异** | 不同量纲之间 | **属性类型的差异**（不同自由度 ⇒ 不同量纲） |
| **量纲内差异** | 同一量纲之内 | **实现群的差异**，分两级：**大内差异**＝**连续属性关系群的选取**；**小内差异**＝**离散子群的选取**——两级都是**结构性**差异；**数值差异**（固定 $(G_Q,\Gamma)$ 后的参数与谱数据）不是内差异、单列 |

- **大内差异改结构**：改的是“哪个群保这个量”（同一属性量在不同实现空间给出不同属性关系群；例：“保距离”在欧氏平面 → $O(2)$、三维欧氏 → $O(3)$、双曲平面 → $PSL(2,\mathbb{R})$、闵氏时空 → $O(1,3)$、弯曲流形 → $\mathrm{Isom}(M,g)$）；其**群链读法**（粗粒化／细粒化＝沿子群链上下）见 §6.5.9.2。
- **小内差异也是结构性的**：在选定连续属性关系群内取哪种离散子群（晶格 $\mathbb{Z}^{3}$、空间群、离散洛伦兹群 $O(1,3;\mathbb{Z})$、$U(n;\mathbb{Z}[i])$、点群）带结构性——商空间紧性决定连续谱有无（无尖点 ⇒ 无 Eisenstein 连续谱）、算术（同余）／非算术决定 Hecke 算子代数、尖点数与秩亦然（群论文档 §5.6、§8.2）；
- **数值差异（不是内差异）**：固定 $(G_Q,\Gamma)$ 之后的参数与谱数据（格常数、傅里叶系数、Hecke 特征值 $\lambda_p$）只调数值——它们**不是群**，不属于“实现群的差异”，单列一层（§7.5 的比值型无量纲常数即这一层的定量体现）；
- **勿混**：单位与标度（米→英尺）不是任何内差异——同一群的不同标度约定、群不变。

> **用语提示**：本节的“**大差异**”指**量纲间**；“**大内差异**”指**量纲内**的一级细分——两者不在同一层次，勿混。
> 另：这里的“属性关系群”指 §5.3 分类中的**属性量纲关系群**（针对属性的量纲实现；完整分类见 `CQM_核心_唯物主义群论.md` §5.3）——属性关系群**不止**“属性量纲关系群”这一类，本节只用了其中的这一支。

#### 6.5.2 基本层级：$G\le H\le GL(n,\mathbb{F})$

#### 6.5.3 核心定义

**定义 1（属性量）**【标准数学】

$$\mathrm{Dim}:=[G].$$
即：**基础量纲 ＝ 作用群的同构类。**

**定义 4（量纲等价）**【CQM 构造假设】
两个属性量同量纲 $\iff$ 它们的作用群同构：
$$f_1\sim f_2\iff[G_1]=[G_2].$$

**定义 5（基础量纲计数）**【CQM 构造假设（研究纲领）】
固定 $H\le GL(n,\mathbb{F})$ **与作用 $\rho$**，
$$D_{H,\rho}(n):=\Bigl|\Bigl\{[G]\ \Bigm|\ G\le H,\ \exists f\in\mathbb{F}[M_n]^{G,\rho},\ f\not\equiv\text{常数}\Bigr\}\Bigr|.$$
即：$H$ 的子群同构类中，**能作为非平凡不变标量函数作用群出现**的类的数目。

> **作用标签**：$\mathbb{F}[M_n]^{G}$ **依赖 $\rho$**（同一 $G$，左乘与共轭下的不变量环不同），故 $D$ 必须带 $\rho$。
>
> **【标准数学】“$\exists f\not\equiv$ 常数”这一条正是可观察性条件**：若 $\mathbb{F}[M_n]^{G}=$ 常数（例如 $G=GL(n)$ 作**左乘**，其不变量环平凡），则 $G$ **不计入**。$G$ 能否由不变量环恢复，即**可观察子群（observable subgroup）**问题（Grosshans 一系），**非自动成立**。
>
> **【标准数学】与稳定子版的关系**：要求 $f\not\equiv$ 常数，**排除了常数函数给出满群类 $[G_0]$ 的计入**（稳定子版中 $f\equiv c$ 使 $\mathrm{Stab}(f)=G_0$，$[G_0]$ 被平凡计入）。这是两版计数自 $n=1$ 起不同的直接原因（见 §6.5.12）。

#### 6.5.4 核心命题

**命题 1（作用群即量纲）**【CQM 构造假设／定义性重述】
作用群 $G$ 的同构类 $[G]$ 就是一个基础量纲。
**诚实标注**：本命题是定义 3 的重述，**非实质定理**（符合项目“避免平凡证明”的要求，故明标）。

**命题 2（量纲的相对性）**【CQM 构造假设】
$$\mathrm{Dim}=[G].$$
**$[G]$ 只依赖 $G$**（的同构类）；$(H,\rho)$ **只决定“哪些 $G$ 计入”**——即**量纲的集合**相对 $(H,\rho)$，**单个量纲不相对**。换 $G$ ⇒ 量纲改变；换 $H$ 或换作用类型 $\rho$ ⇒ **可计入的 $G$ 改变**（见命题 6）。

**命题 3（量纲数 $\le$ 子群种类数）**【标准数学】
$$D_{H,\rho}(n)\ \le\ \bigl|\{[G]\mid G\le H\}\bigr|.$$
**证明**：$D_{H,\rho}(n)$ 是集合 $\{[G]:G\le H\}$ 的**子集**的基数，故不超过全集基数。$\blacksquare$

> **注意（$n^2$ 不是种类数上界）**：$n^2=\dim M_n$ 是**坐标个数**，与“子群种类数”无关。$n\ge2$ 时 $\mathbb{Z}/m$（在某个二维平面内作 $2\pi/m$ 旋转、其余方向固定）对一切 $m\ge1$ 都是 $GL(n,\mathbb{R})$ 的 **Zariski 闭**子群，且两两不同构，故 $|\{[G]:G\le H\}|\ge\aleph_0$。**只有 $n=1$ 有限**。$n^2$ 至多可作为“**单坐标**属性量 $A_{ij}$ 的候选个数”（$A_{ij}\in\mathbb{F}[M_n]^G$ 须 $G\le G_{ij}$），**不是**基础量纲数的上界。

**命题 4（函数不同 $\ne$ 量纲不同）**【CQM 构造假设／定义性重述】
同一 $G$ 下的不同 $G$-不变函数 $f_1,f_2$ 属于同一量纲——它们是同一量纲的不同分量。
**诚实标注**：本命题在**作用群版**定义下是定义 3、4 的**直接重述**（同一 $G$ ⇒ 同一 $[G]$）。**注意**：在**稳定子版**下此命题**不成立**——同一 $G$ 下可有不同稳定子群。这正是两版定义的实质分野。

**命题 5（子群约束）**【标准数学】
$G$ 必须是 $H$ 的子群，$H$ 必须是 $GL(n,\mathbb{F})$ 的子群。**不是任意抽象群。**
$$G\le H\le GL(n,\mathbb{F}).$$

> **【标准数学】这条硬约束的后果**：①**不能嵌入** $GL(n,\mathbb{F})$ 的抽象群**排除**；②**超出** $GL(n,\mathbb{F})$ 的更大群**排除**；③与 $GL(n,\mathbb{F})$ **无包含关系**的群**排除**。基础量纲的计数范围因此严格限定在 $GL(n,\mathbb{F})$ 的**子群范畴**内。

**命题 6（量纲的等号）**【CQM 构造假设／定义性重述】
$$G\cong H\iff[G]=[H]\iff\text{同一个基础量纲}.$$
**诚实标注**：本命题是定义 3 的**重述**（$[\cdot]$ 即同构类），**非实质定理**。

> **同构口径必须取“李群同构”，不可取“抽象群同构”**：抽象群同构**过粗**，会出反例——
> $$(\mathbb{R},+)\ \cong\ (\mathbb{R}^2,+)\qquad(\text{同为 }\mathbb{Q}\text{-向量空间，维数 }2^{\aleph_0}),$$
> 按“抽象同构即同量纲”将得 $[\mathbb{R}]=[\mathbb{R}^2]$，把**一维与二维加法群判为同一基础量纲**，不应。取**李群同构**（或**代数群同构**）则 $\dim$ 是不变量 ⇒ $(\mathbb{R},+)\ncong(\mathbb{R}^2,+)$；而 $SO(2)\cong U(1)$（同为 $1$ 维紧连通）**仍成立**，故“$SO(2)$ 与 $U(1)$ 同一量纲”这一结论**保住**。**紧群**情形二者无差别（**紧李群的抽象同构必为李群同构**，标准结果）；差别只在**非紧**群。

> **“不同单位” $\ne$ “不同表示”（类比错位）**：常见类比“米/英尺＝同量纲不同**单位** $\leftrightarrow$ $SO(2)/U(1)$＝同量纲不同**表示**”**不成立**——米、英尺是**单位（标度）**，**不是群**；把长度建模为 $(\mathbb{R},+)$ 时，米与英尺是**同一个群**的两种单位约定，**谈不上“同构”**。正确的对应：
>
> | 标准物理 | 唯物群论 |
> |:---|:---|
> | 同一量纲的不同**单位**（米/英尺） | 同一群的**不同标度／单位约定**（群**不变**） |
> | 同一量纲的不同**矩阵实现**（$SO(2)\subset GL(2,\mathbb{R})$ vs $U(1)\subset GL(1,\mathbb{C})$） | 同构但**不同**的具体群（**不同忠实表示**） |
>
> 即：$SO(2)/U(1)$ 配的是“**不同矩阵实现**”，**不是**“不同单位”。

> **【标准数学】跨母群同一量纲是允许的**：$SO(2)\le GL(2,\mathbb{R})$ 与 $U(1)\le GL(1,\mathbb{C})$ 的**母群不同**（$n=2$ vs $1$、基域 $\mathbb{R}$ vs $\mathbb{C}$）。在**李同构类**口径下二者是同一基础量纲——这与命题 5 的**子群约束不冲突**：子群约束管的是“**哪些 $G$ 合法**”，**不是**“同一量纲的 $G$ 必须同一母群”。

##### 6.5.5.4 计数层级：基础候选与组合候选（量纲归属不分层）

| 层级 | 对象 | 数量（候选口径） |
|:---|:---|:---|

#### 6.5.9 量纲的粗细结构：分解、粗粒化与两级量纲

##### 6.5.9.1 三种分解

| 分解类型 | 数学 | 量纲读法 |
|:---|:---|:---|
| **群链分解** | $G\supset G_1\supset G_2$ | 粗细层级（见 §6.5.9.2） |
| **直积分解** | $G=G_1\times G_2$ | $[G_1\times G_2]$ 由因子种类对 $([G_1],[G_2])$ 决定【标准数学】；半直积／扩张则不然（由作用而定） |
| **不可约表示分解** | $V=\bigoplus V_i$ | 属性空间如何承载 $G$——属性种类的表示论分类【标准数学】；对应到量纲读法【CQM 构造假设】 |

##### 6.5.9.2 粗粒化＝子群关系

$$\boxed{\ \text{粗粒化}=\text{沿子群链向上（群变大，量纲变粗）；细粒化}=\text{沿链向下（群变小，量纲变细）。}\ }$$

| 方向 | 群变化 | 量纲变化 |
|:---|:---|:---|
| **粗粒化** | 群变大 | 不变量更少、种类更粗 |
| **细粒化** | 群变小 | 不变量更多、种类更细 |

- **物理量纲**＝最粗端点（最大群）；**唯物论基础量纲**＝链上中间节点（子群）；**全约束**＝最细端点（$\{I\}$，一切函数皆不变）；
- **“量纲格＝子群格”是类比，不是定理**【CQM 构造假设（类比层面）】：沿**固定群链**粗细是良定义的全序；但子群格商去同构后**不保格运算**——同构类的 join 依赖具体嵌入（$G_1\cong G_1'$、$G_2\cong G_2'$ 而 $\langle G_1,G_2\rangle\not\cong\langle G_1',G_2'\rangle$ 可能），故只在链内逐点比较，不设全局格结构。

##### 6.5.9.3 物理量纲 vs 唯物论基础量纲（两级量纲）

| 层级 | 对象 | 粒度 |
|:---|:---|:---|
| **物理量纲** | 属性的量度类别（如“长度”） | 粗（SI 的 7 个基本量纲） |

### 7.1 自守形式作为数值来源

### 7.3 量纲发生学第一步：无量纲→时间——自守链的锚点，不是自守形式

$$\boxed{\ \text{"无量纲} \longrightarrow \text{时间"是量纲发生学的第一步、自守链的锚点；但它本身不是自守形式。}\ }$$

**为什么不是自守形式**：自守形式需要协变律的全套数据——离散子群 $\Gamma$、自守因子 $j(\gamma,z)$、原形式与新形式（群论文档 §8.2）。“无量纲→时间”的实现（事件计数经固有时获得 $T$）发生在这些数据**之前**：此步没有 $\gamma$ 可作用、没有 $j$ 可携带，是量纲发生学的**第一步**（固有时机制，§6.0 时间动力学），不是自守形式。

**它是什么**：它是自守链的**锚点**——打破量纲循环的无量纲-量纲直接关系（§7.6 二）；计数标定与再生产循环使时间获得**自守化起点**，自守形式在锚定之后的链上环节出现（如寿命—长度稳定关系的自守实现，§7.6 三之②、§7.7.2）。“最原始的自守形式”是链上哪一个，属待定问题。

也就是说：

- 数学侧：计数标定与再生产周期——数学结构，无量纲，纯数；
- 物理侧：时间量纲 $T$，固有时，可测量；
- 桥：**固有时机制本身**（不是自守形式）；
- 该桥是最原始的量纲生成器，也是自守链的起点（锚定之后自守形式才登上链条）。

**注**：无量纲→时间的特征常数未知，可能没有。但无量纲与固有时关系紧密：固有时本质上与事件计数紧密关联——事件计数是无量纲的纯数，固有时是事件计数在物理侧的体现。因此，无量纲→时间的转换并非任意，而是通过固有时/事件计数自然实现：事件计数的纯数（无量纲）经固有时获得时间量纲 $T$。时间 $T$ 是量纲发生学的第一个量纲，这正是 CQM 一直指出的时间动力学（因果时、固有时）。

### 7.4 自守形式输出的量纲性质

自守形式输出的量纲性质取决于输入的量纲性质与具体分析语境，不能一概而论。

**输入决定输出**：当自守形式的输入参数为纯数（无量纲）时，输出为纯数；当输入参数带有物理量纲（如曲率 $R$ 量纲 $L^{-2}$、能量 $E$ 量纲 $ML^2T^{-2}$）时，输出自然带有相应量纲。自守形式作为映射，其输出量纲由输入量纲与映射结构共同决定。

**情形一：无量纲输入 → 纯数输出，直接作为无量纲常数。** 如精细结构常数 $\alpha \approx 1/137$，自守形式以无量纲参数为输入，给出的纯数本身就是物理常数。

**情形二：无量纲输入 → 纯数输出，作为有量纲特征常数的数值部分。** 如 $10c = 2.99792458\times 10^9$、$K_Q = 10c/10^{9/2} \approx 9.480\times 10^{4}$。自守形式给出的纯数本身无量纲，但扮演有量纲特征常数的数值角色，需配合单位制翻译得到带量纲的物理量。

**情形三：有量纲输入 → 有量纲输出。** 当自守形式的输入参数带有物理量纲时，输出直接带有量纲，无需单位制翻译。自守形式作为“量纲-量纲的实现关系本身”（§7.2），输入端量纲与输出端量纲可以不同，自守形式本身就是带量纲的转换映射。

**情形四：作为量纲结构参数。** 如表示维数 $70 = \dim \mathrm{Sym}^4(\mathrm{SU}(5))$，纯数但承载量纲发生学的结构信息，不直接对应某个物理常数。

**总结**：自守形式输出的数值是否无量纲，取决于输入是否带量纲以及具体分析语境。输入无量纲时输出为纯数（可作为无量纲常数或有量纲特征常数的数值部分）；输入有量纲时输出直接有量纲。不应笼统断言“自守形式只能给出纯数”而掩盖这些区别。

### 7.5 三条腿的分工与常数的分类

把“量纲—群论—自守形式”三者的分工摆清楚，是本章最容易误读的一点：三条腿**给的东西不是同一类**。

| 腿 | 给什么 | 性质 | 出处 |
|:---|:---|:---|:---|
| **量纲发生学** | 量纲类别；“每压掉一个量纲就冒出一个特征常数 $K$” | **定性**（哪些常数有量纲、$K$ 是什么） | §6.1、§6.4.1 |
| **唯物主义群论** | 哪个群保哪个属性量（属性关系群 $G_Q$） | **结构**（不给数值） | `CQM_核心_唯物主义群论.md` §5.3、§6.1 |
| **自守形式** | 特征常数的**数值**；且本身即“量纲-量纲的实现关系” | **定量** | §7.1、§7.2 |

⇒ 三条腿合起来才“打通”：**量纲那条腿与群论那条腿都不出数字**，数字只出自守形式那条腿。

**“无法解释的基本常数”不能只按“有无量纲”分**——那样会把两类性质完全不同的东西混在一起。正确判据是：**这个常数是不是某个“量纲对”之比的体现**。据此分三类：

| 类 | 成员 | 与量纲的关系 | 对应 |
|:---|:---|:---|:---|
| **有量纲特征常数** | $c$、$\hbar$、$G_N$、$K_L$、$K_Q$、$K_\Theta$、$k_B$…… | **跨量纲对**（大差异）的实现特征常数——**直接相关** | §6.2.1、§6.4.4 跨量纲支 |
| **比值型无量纲常数** | $m_e/m_p$、$\lambda_C/a_0$、$\alpha$（$[\text{能量}\cdot\text{长度}]$ 相消）…… | **同量纲对**——即 §6.2.2“同量纲内差异表现为实现之间的**无量纲标度**”的定量体现——**紧密相关**：其“无量纲”来自**量纲相消**，不是“不涉及量纲” | §6.2.2、§6.4.5 |
| **纯数型无量纲常数** | $☯=\xi'(1)/\xi(1)$、$\gamma_n$、$70=\dim\mathrm{Sym}^{4}(\mathrm{SU}(5))$…… | 谱／表示论／算术量，量纲发生学中**没有对应的“量纲对”** | §7.4 情形四 |

**核心表述**：**“无量纲” $\ne$ “与量纲无关”**。判据不是“有没有量纲”，而是“**它是不是某个量纲对之比的体现**”：

- **跨量纲对** → 有量纲特征常数（$K$ 系列）；
- **同量纲对** → 比值型无量纲常数（**量纲内差异的定量体现**）；
- **不对应任何量纲对** → 纯数型（谱／算术量）。

⇒ 三条腿的接法也随之明确：**量纲腿**给出“量纲对”（跨量纲的 $K$，以及同量纲内的实现差异），**自守形式腿**给出该比值／数值，**群论腿**给出结构。因此“基本常数都与量纲有关”这句话，**对前两类成立**（它们都是某个量纲对的体现），**只对第三类不成立**。这与 §8.1 记录的立场一致：无量纲常数才是跨文明客观的基本量；但有量纲常数并非“只是人为构造”——它们代表的是**量纲之间的实现关系**，关系是客观的，只是量纲形式依赖单位制（§8.2 末行“自守形式＝最底层”）。

> **状态标注**：本节建立在 §7 章首的**“自守形式猜想”**之上——“自守形式作为数值来源”本身是**猜想**（§8.2 表中亦标“最底层（猜想）”），不是已证事实。另有两处未定：$K_L$ 的数值**尚未定死**（§6.3.1：第一性链 $0.656$ fm 与标定链 $0.67860$ fm 相差 $3.3\%$，几何公式另给 $0.6805$ fm）；$\alpha$ 的数值属**构造后验校验**（$\approx0.16\%$ 近似），非已被公认的独立第一性推导。

### 7.6 自守-量纲链：三层实现、锚点与计算路径

> 链条由**三层实现**生成，其起点是**锚点**，其展开顺序即**计算路径**；链条的**依托结构**见 §7.7.3，其**检验**见 §7.7.4。

**一、三层实现：原形式的属性被群实现为量纲形式的属性**

属性矩阵（$GL(n)$ 的矩阵表示下，每个元素代表一个属性自由度）承受**属性量纲关系群**的作用；对该矩阵的**标量不变函数** $f$ 给出**内蕴不变量**，该内蕴不变量即**属性的量**：

| 属性量 | 属性量纲关系群 | 保持的结构 |
|:---|:---|:---|
| 距离 | $O(n)$ | 实内积 |
| 概率 | $U(n)$ | 复内积（模方） |
| 相空间面积 | $Sp(2n)$ | **辛形式** $\Omega$，$M^{\mathsf T}\Omega M=\Omega$ |

$Sp(2n)$ 由保辛形式**定义**，“保二维相空间面积”是 $n=1$ 时的推论；$n\ge2$ 时保体积的 $SL(2n)$ 严格大于 $Sp(2n)$，故“保面积”不足以定义 $Sp$（群论文档 §3.1／§5.2／§6.1）。

> **$f$ 的给定性**：$f$ 是**给定**的 $G$-不变函数，不由群自动保证。任意作用都有平凡的常数不变量；**非平凡**不变量是否存在、是否足以分离轨道，取决于**不变量环** $\mathbb{F}[M_n]^{G}$——即**可观察子群**条件（§6.4.7）。【标准数学】

在离散子群上取协变律 $F(gz)=j(g,z)F(z)$（群论文档 §8.2；$z$ 取自属性矩阵侧的作用空间），自守因子 $j$ 兼作**量纲因子**：$F(gz)$ 即原属性形式被作用后成为的量纲形式，$j$ 承载表面层的换算（§6.4.2 层②；$j$ 的第四身份见群论文档 §8.2 三种身份注）。

于是实现自上而下分三层：

| 层 | 群 | 说明 |
|:---|:---|:---|
| **一般量纲** | **极大关系群** $G_{\max}(f)$ | 对指定的属性自由度组合构造；极大性消除任意性（§6.4.7 定义顺序口径） |
| **量纲内细分** | 连续子群；跨实现时另有各自的 $G_{\max}$ | 一般长度量纲之下：空间长度→$E(3)$、波长→$O(3)$、粒子尺度→$SO(3)$……（群论文档 §5.3） |
| **具体量纲实现** | 离散子群 | 再取离散子群，对应物体实例层（小内差异，群论文档 §5.6） |

**二、锚点论证：链条凭什么能开始算**

单个量纲**没有跨量纲的非平凡关系化**——它自己关系化自己，只给出自身的**重标度群** $\mathbb{R}_{>0}$；$k$ 个独立量纲给 $(\mathbb{R}_{>0})^{k}$，这正是 §2.1 Buckingham $\pi$ 定理的**群论形式**（换单位即群作用，其不变量恰是无量纲组合）。故量纲与量纲之间若无直接关系，关系链就是**循环结构**——互相定义、无外部锚点，即 §8.1 批判的“单位锚定”困局。

打破循环需要一个既是**无量纲-量纲的直接关系**、又能**自守化**的实现。这样的实现有**两个**：时间与空间各自从无量纲锚定、各自自守化，而**发生学上有先后**——

| 锚点 | 无量纲-量纲的直接关系 | 自守化途径 | 发生学次序 |
|:---|:---|:---|:---|
| **时间** $T$ | 事件计数是无量纲纯数，经固有时获得 $T$（§7.3、§6.0） | **再生产循环**：计数标定给出周期结构 | **先** |
| **长度** $L$ | 耦合空间坐标是无量纲的，经 $K_L$ 获得 $L$（$r_{\rm coupling}\cdot K_L=r_{\rm phys}$，§6.3.1） | **几何**：双曲实现（§7.7.5） | **后** |
| **物质的量** $N$ | 有（计数） | **不能**：计数基准自身不能自守化，且它是**人为定义的**（$N_A$ 为 SI 精确定义值，属计数基准层而非链条导出，§6.1／§6.2.2）；$N$ 虽有自己的特征常数 $K_N$，却位于**链条之外**（§7.7.3） | **链条外** |

**先后与依托是两回事**：

- **发生学上时间先于空间**——第一个量纲是时间（§6.0 时间层、§7.3），长度层在其后；
- **但空间不需要时间量纲来承担自守链**——长度的自守化走自己的几何途径，量纲来源是耦合空间的 $K_L$，不经由时间。故“时间先于空间”是**发生学次序**，不是**依托关系**：$L$ 并不依靠 $T$ 生成（§7.7.3）。

**时空一体是同步的产物，不是出发点**：$T$ 与 $L$ 各自锚定并各自自守化之后，二者**同步**为一个结构——其数学表现是保持时空间隔 $ds^{2}=c^{2}dt^{2}-d\vec{x}^{\,2}$ 的**洛伦兹群** $O(1,3)$（群论文档 §5.1），它**混合**时间与空间，不是 $O(1)\times O(3)$ 的直积；其物理产物即**光速** $c$（见 §7.6 三）。⇒ 时空一体在发生学上**后于**两个锚点，不能反过来当作出发点【CQM 构造假设】。

**同步之后的自守化载体**：$T$ 与 $L$ 同步为时空后，自守化落在保时空间隔的那一层——$SL(2,\mathbb C)$（$SO^{+}(1,3)$ 的双覆盖）作用于双曲三空间 $\mathfrak H^{3}$，其算术子群（Bianchi 群 $SL(2,\mathcal O_K)$）给出 Bianchi 模形式；它同时容纳两侧的周期方向与几何方向（§7.7.5）【标准数学】＋【CQM 构造假设】。

⇒ 关系经自守化而**稳定、自然、结构化**，自守链由此建立。

**三、计算路径：总前提与顺序**

总前提——数学（特别是数论）结构与物理结构存在对应：无量纲也需要来源，即**把量纲转成数学结构来锚定**（§8.1“理论锚定而非单位锚定”的正面表述）【CQM 构造假设（总前提）】。

| 步 | 做什么 | 承接者 |
|:---|:---|:---|
| ① | **时间**：数学结构上的再生产周期 ↔ 符合该结构的粒子 ⇒ 时间单位制 | 固有时机制（§7.3） |
| ② | **长度**：由耦合空间经 $K_L$ 锚定（§6.3.1）；与时间的稳定关系 $\ell=\mathsf{F}(\tau)$ 是同步之后的联系（§7.7.2） | $K_L$（§6.3.1） |
| ③ | **质量**：同理 | $K_M=G_N^{-1}$（§6.4.6） |
| ④ | **电荷**：用高斯制，把电荷量纲链接到 $L,M,T$ 上（$[Q]=[M]^{1/2}[L]^{3/2}[T]^{-1}$，§3、§6.4.3） | $K_Q$（§3.1） |

**角色勿混**：$c$ 带跨量纲量纲（$[c]=L/T$，§6.4.6、§7.5 第一类），但**不是长度层的量纲特征常数**——$L=c\,T$ 是**速度关系**而非**量纲生成关系**（§6.3）；故自守侧若输出一个“带长度量纲的数”，应读作 $K_L$ 而非 $c$。同理，电荷层的 $K_Q$（§3.1）与温度层的 $k_B$（$K_\Theta=k_B^{-1}$，§5.1）**不是同一个常数**，列举时勿错位。

**光速是两个自守形式相容结合的产物**：时间侧给出一个自守形式（周期／再生产），空间侧给出另一个（几何／耦合空间）；$c$ 不是任一侧单独的输出，而是二者的**同步（相容）条件**。⇒ 推导 $c$ 需要**两个自守形式的相容结合**，而不是某一个自守形式的输出（§7.7.5）。这也正是 §6.3 判读的由来：$c$ 不“承担”量纲转换——两侧的量纲实现各自完成在前，$c$ 是它们同步之后的常数【CQM 构造假设】。

其中光速的**自洽计算值** $c=299\,792\,458.258\ \mathrm{m/s}$，并由它**导出某种长度**——“自洽”而非“第一性”：计算在链条内自洽，不宣称独立预测【数值待验证：该值目前无第一性推导】。口径随之澄清：SI 的 $c$ 是**定义值**（精确 $299\,792\,458\ \mathrm{m/s}$，米由 $c$ 定义），自洽计算给出的 $+0.258\ \mathrm{m/s}$ 偏差，含义是“由该数学结构导出的长度与 SI 米的**再现精度差**”（导出的是**长度**，不是 $c$ 的测量值）。

**四、量纲分析的新读法**

经典量纲分析（白金汉 $\pi$）在此框架中可读作**量纲因子 $j$ 与属性量纲关系群之间的作用**——$\pi$ 定理的无量纲化即 $j$ 的量纲相消【CQM 构造假设（一句话纲领）】；与 §6.5.1“量纲分析 vs 量纲发生学”定位表衔接。注意二者的分工：$\pi$ 定理处理的是**同量纲内**的重标度（§2.1），本链条处理的是**跨量纲**的锚（锚点论证）——互补，不是同一件事。

**五、检验**

链条自洽不等于链条**存在**。检验分**约定无关检验／强检验／弱检验**三级及其成立条件，见 §7.7.4。

> **标注**：【标准数学】（高斯制电荷量纲、$O/U/Sp$ 保持的结构、协变律形式、$\pi$ 定理的群论形式）＋【CQM 构造假设】（自守因子＝量纲因子、锚点论证、计算路径、量纲分析读法）＋【数值待验证】（$c=299\,792\,458.258$：无推导出处；“自洽计算”口径下其输出为**导出长度**的再现精度差，见计算路径段）。

### 7.7 锚定的具体化与检验

> 锚定的具体化：起点取**哪个粒子**（§7.7.1），它给出的**寿命—长度关系**（§7.7.2）如何把链条组织成**逐层依托**的结构（§7.7.3）；链条的**检验**分三级（§7.7.4），其自守化有**周期、几何与时空**三条途径（§7.7.5）。

#### 7.7.1 起点的选择：锚定粒子

锚定粒子须同时满足三条：**有限本体**（有明确定义的寿命、质量、量子数，不依赖额外的束缚结构）＋**自带计数—时间结构**（衰变是离散事件，其计数为无量纲纯数，经固有时获得 $T$，§7.3）＋**自身尺度可测**（有“粒子相关长度”可作长度分析对象）。

自由中子满足前两条（$\tau_n$、$m_n$ 明确），且电中性使它成为“有限本体”的干净样本；但也正因电中性，**第三条含糊**（§7.7.2），且电荷链**必须另找带电粒子**。

> **中子寿命的实验张力**——束流法 $\tau_n^{\rm beam}=888.0\pm2.0$ s、瓶法 $\tau_n^{\rm bottle}=879.4\pm0.6$ s，差 $8.6\pm2.1$ s（$\approx4\sigma$，约 $1\%$；不同实验组合给出的数值略有出入，此处取代表性测量）。截至 2026 年两法**未收敛**，即所谓“中子寿命谜题”，并引出暗衰变等新物理猜测（亦有一份 2026 年预印本主张经系统误差修正后收敛到 $877.92\pm0.30$ s，属**非定论**）。参见 Wietfeldt, *Symmetry* **16**(8):956 (2024)；Wei et al., arXiv:2001.10041。
> ⇒ 若以 $\tau_n$ 锚定时间单位制，这 $1\%$ 的张力**沿链传给每一个下游量**（§7.7.3 推论 1），且**不能**被链条自身的自洽性吸收——自洽只说明内部无矛盾，不说明锚点准确。
> ⇒ 中子在**概念上**适合作为起点（有限本体、衰变即离散事件计数），在**数值上**则受上述张力所限。**另一种锚定粒子**是 $\mu$ 子：$\tau_\mu=2.1969811(22)\ \mu$s（相对不确定度 $\sim10^{-6}$），且 $\mu^{\pm}$ **带电** ⇒ 电荷链可与时间链同源锚定；代价是它不是物质的稳定组分。【数值事实】＋【CQM 构造假设】

#### 7.7.2 寿命—长度假设

时间与长度**各有其无量纲来源**；二者同步之后的稳定关系，写成**可证伪的形式**即：

> **假设（寿命—长度锚定）【CQM 构造假设】**：对锚定粒子，存在由数学结构（自守形式）确定的稳定关系
> $$\ell=\mathsf{F}(\tau)$$
> 把寿命 $\tau$（量纲 $T$）映到该粒子的特征长度 $\ell$（量纲 $L$）；$\mathsf{F}$ 的**结构**由数学侧给出，其**量纲**由 $K_L$ 承接。

- **两个锚点**：时间由事件计数经固有时锚定（§7.3），长度由耦合空间经 $K_L$ 锚定（§6.3.1）；$\mathsf{F}$ 是二者**同步之后**的稳定关系，不是长度的量纲来源；
- **$\ell$ 的选取**：对中子，候选有康普顿波长 $\lambda_{C,n}=\hbar/(m_nc)\approx0.210$ fm、QCD 特征长度 $\lambda_{\rm QCD}=\hbar c/\Lambda_{\rm QCD}\approx0.97$ fm（§6.3.1）、电荷半径——但中子均方电荷半径为**负**（$\langle r_n^{2}\rangle\approx-0.116\ \mathrm{fm}^{2}$），“电中性粒子的特征长度”这一说法本身含糊。**$\ell$ 一经指定，该关系即可检验**；
- **$\mathsf{F}$ 的量纲定位**：$\mathsf{F}$ 把 $T$ 映到 $L$，故 $[\mathsf{F}]=[L]/[T]$，是**速度型**量纲（与 $[c]$ 同型，§6.3）⇒ $\ell=\mathsf{F}(\tau)$ 是**同步之后 $L$ 与 $T$ 之间的关系**，不是量纲生成关系；长度的量纲来源仍是耦合空间的 $K_L$。
- **与既有路径的汇合点**：§6.3.1 已有一条长度实例——$K_L$ 把无量纲禁闭壳映为物理长度（$r_{\rm coupling}\cdot K_L=r_{\rm phys}$）。若把其中的“无量纲输入”换成“寿命经 $\mathsf{F}$ 给出的数”，两条路径应当**汇合**；汇合点即 $\mathsf{F}$。注意 $K_L$ 本身**尚未定死**（第一性链 $0.656$ fm vs 标定链 $0.67860$ fm，差 $3.3\%$）。

#### 7.7.3 量纲-自守链的层级依托结构

链条不是四个平铺的量纲，而是**逐层依托**：每个下游量纲的“量纲-自守链”是**借上游量纲**搭起来的。高斯制的作用正在于此——它把电荷量纲链接到 $L,M,T$ 上（$[Q]=[M]^{1/2}[L]^{3/2}[T]^{-1}$），**使得电荷能依靠别的量纲来建立量纲-自守链**，正如质量依靠时间—长度、温度依靠能量。

| 量纲 | 依靠什么 | 承接者 | 链上位置 |
|:---|:---|:---|:---|
| $T$ | **无量纲计数**（事件计数经固有时，§7.3） | 无量纲→$T$ 的特征常数未知（可能没有） | **锚点**：发生学第 1 |
| $L$ | **不依靠 $T$**：各有其无量纲来源，长度经耦合空间的 $K_L$ 实现（§6.3.1）；$\ell=\mathsf{F}(\tau)$ 是同步之后的关系（§7.7.2） | $K_L$（§6.3.1） | **锚点**：发生学第 2 |
| $M$ | 依靠 $T,L$ | $L^{3}T^{-2}\cdot K_M=M$，$K_M=G_N^{-1}$（§6.3） | 下游第 1 层 |
| $Q$ | 依靠 $L,M,T$（**高斯制**，§3） | $K_Q$（§3.1） | 下游第 2 层：**链是借来的，自身不是锚点** |
| $\Theta$ | 依靠能量 $ML^{2}T^{-2}$ | $K_\Theta=k_B^{-1}$（§5.1） | 更下游 |
| $J$ | 依靠功率 $ML^{2}T^{-3}$ | $K_J$（§5.3） | 更下游 |
| $N$ | 依靠计数，但**人为定义、不能自守化**（§7.6 二） | $K_N=N_A^{-1}$（§5.2） | **链条外** |

**自守化途径：谁自己能自守化，谁必须借链**。依托关系决定了后者（哪些量纲没有独立途径，只能继承）；而自守化本身有**三条途径**（周期、几何、时空，§7.7.5），与依托链不是同一条分野——

| 量纲 | 自守化途径 | 独立性 |
|:---|:---|:---|
| $T$ | **再生产循环**：计数标定给出周期结构（§7.6 二） | **独立**（锚点，发生学第 1；提升机制见 §7.7.5） |
| $L$ | **几何自守化**：双曲实现 $\mathbb H^{2}$ 的保距离群 $PSL(2,\mathbb R)$（群论文档 §8.2） | **独立**（锚点，发生学第 2，§7.6 二） |
| $M$、$Q$、$\Theta$、$J$ | **继承**：依靠上游量纲的链——**否则无法自守化** | 不独立 |
| $N$ | **无**：人为定义，计数基准不能自守化 | 链条外 |

电荷正是“否则无法自守化”的那一类：它自身没有独立的自守化途径，必须靠高斯制把量纲链接到 $L,M,T$ 上（见上表第 4 层）。【CQM 构造假设】

**三条推论**：

1. **依托＝依赖：误差沿链继承**。每一环都把上游的数值不确定度**带下去**——若时间侧用中子寿命标定（$1\%$，§7.7.1），则凡由时间给出的量——$M$、$Q$，以及经 $\ell=\mathsf{F}(\tau)$ 算出的长度值——**全部**继承，且**无法**在下游被修正（下游的自洽检查不到锚点）⇒ **锚点精度是整个链条的精度上界**；
2. **依托 $\ne$ 还原**。“电荷依靠 $L,M,T$”的意思是“该属性在别的属性约束下被实现”（§6.4.3），**不是**“电荷可还原为力学量”——本体论独立 $\ne$ 单位制独立。依托关系属**大差异**，由特征常数承接（§6.2.2）；
3. **依托链越长，“绝对数值”的检验力越弱——但 $\alpha$ 不受此限**。$Q$ 在下游第 2 层、依托链最长、误差累积最多，看似最不适合当检验点；而 §7.7.4 恰恰把电荷（$\alpha$）列为**最强**检验点。两者不矛盾：$\alpha=e^{2}/\hbar c$ **无量纲**（§7.5 比值型），依托链上的量纲在 $\alpha$ 中**相消**——它检验的是**比值**而非链条的绝对刻度。⇒ **依托长度削弱“绝对数值”的检验力，不削弱“无量纲比值”的检验力**；这解释了为何检验点选在链条最长的那一支上。

**长度的位置**：长度的量纲来源是耦合空间——$K_L$ 把无量纲耦合坐标映为物理长度（$r_{\rm coupling}\cdot K_L=r_{\rm phys}$，§6.3.1）；它**不依靠时间量纲**生成，自守化走自己的几何途径。发生学上时间先于空间（§6.0），但**先后不是依托**：二者各自从无量纲实现，随后**同步**为时空（§7.6 二）。$\ell=\mathsf{F}(\tau)$ 是同步之后 $L$ 与 $T$ 之间的关系（$\mathsf{F}$ 带 $[L]/[T]$ 量纲，§7.7.2）。⇒ $K_L$ 的输入保持为无量纲耦合坐标（§6.3.1 的 $r_{\rm conf}=\sqrt{I\lambda_c}$），$c$ 读作“速度关系”（§6.3、§7.6 三）。若反过来取严格链式（长度依靠时间），$K_L$ 的输入须换成由寿命导出的数，§6.3.1 的 $K_L$ 值链（$0.656$／$0.67860$／$0.6805$ fm）须**重算**，且 $T$ 的 $1\%$ 张力**直接**进入长度——这与 $K_L$ 在耦合空间中的存在方式不相容。

> **标注**：【标准数学】（依托关系的量纲合成、误差继承、$\alpha$ 的量纲相消）＋【CQM 构造假设】（层级依托结构、依托≠还原、寿命—长度假设）＋【数值事实】（中子寿命张力、$\tau_\mu$）。

#### 7.7.4 检验的分层

链条**自洽**不等于链条**存在**。检验分三级，各自的成立条件不同：

| 级 | 内容 | 检验力 | 成立条件 |
|:---|:---|:---|:---|
| **约定无关检验** | 由数学结构算出**无量纲**数（如 $\alpha=e^{2}/\hbar c$），与单位制约定无关 | **最强**：连“锚点准不准”都不依赖（§7.7.3 推论 3） | 需第一性算出；目前 $\alpha$ 属**构造后验校验**（$\approx0.16\%$ 近似，§7.5 状态标注） |
| **强检验** | **同一套机制**迁移到别的基本粒子上仍成立 | **强**：跨对象复用才是真正的预测 | **前提：迁移时不新增自由参数**（见下） |
| **弱检验** | 同一套自守数学结构**同时**导出链条上若干特征常数（$K_L$、$K_M$、$K_Q$、$K_\Theta$…） | **弱**：只说明该结构有足够输出与之相容 | 须先清点 $N$ vs $p$（见下） |

- **强检验的前提：不新增自由参数**。若机制对每个新粒子都引入新的可调参数（新粒子＝新拟合），那么“对中子适用、对质子也适用”就**没有任何检验力**——它只说明机制有足够自由度去匹配任意数据。**操作判定**：迁移时先**固定**已在锚定粒子上定死的参数，再看下游量的预测值与实测之差；
- **弱检验要成为检验，须清点 $N$ 与 $p$**：把“导出 $N$ 个常数”写成“$N$ 个输出 vs $p$ 个自由参数”的计数比较——只有 $N\gg p$ 才有意义；$N\le p$ 时所谓“导出”只是**重参数化**。当前链条的 $N$ 与 $p$ **均未清点**；
- **电荷为何是检验点**：高斯制下 $[Q]$ 由 $L,M,T$ 复合**导出**，故电荷不是独立锚点（与 §7.4 情形二 $K_Q=10c/10^{9/2}$ 由 $c$ 构造一致）；而 $\alpha$ 是**无量纲**纯数（§7.5 比值型：$[\text{能量}\cdot\text{长度}]$ 相消），与单位制约定无关——若 $\alpha$ 能由自守形式第一性算出，即构成对整条链条的**约定无关检验**；
- **高斯制的双重角色（勿只记其一）**：①把断掉的电荷量纲链**拉通**，使电荷能与别的量纲建立联系（§7.7.3）；②但**连通 $\ne$ 锚定**——电荷侧仍须完整走一遍粒子锚定步骤（选带电的锚定粒子 → 取其电荷属性 → 由数学结构定出 $K_Q$，§3.1）。

⇒ **检验力排序**：**约定无关检验（$\alpha$ 一类）$\;>\;$跨粒子强检验$\;>\;$常数复现弱检验$\;>\;$链条自洽（**不是检验**）**。

#### 7.7.5 自守化的途径：周期、几何与时空

自守化有三条途径，须分开看待：

| 途径 | 载体 | 状态 |
|:---|:---|:---|
| **几何**（长度侧） | 双曲实现 $\mathbb H^{2}$ 的保距离群 $PSL(2,\mathbb R)$ 作用于上半平面 $\mathfrak H$；模形式的自守因子 $j=(cz+d)^{k}$（群论文档 §8.2） | 有**成熟的数学载体**，无下述缺口；具体取哪个长度实现、哪个 $\Gamma$，尚待给出 |
| **周期**（时间侧） | **再生产循环**：计数标定给出周期 $\mathbb{Z}$（$t\mapsto t+nT$） | **有缺口**，见下 |
| **时空**（同步后） | $SL(2,\mathbb C)\to SO^{+}(1,3)$（双覆盖）作用于双曲三空间 $\mathfrak H^{3}$；算术子群为 Bianchi 群 $SL(2,\mathcal O_K)$ | **同时容纳**上述两条：幺幂平移给出周期方向，$\mathfrak H^{3}$ 给出几何方向；二者的**相容条件**给出 $c$（§7.6 三） |

**时间侧的缺口**：$\mathbb{Z}$ 作用在 $\mathbb{R}$（或圆周）上给出的不变对象是**周期函数**（傅里叶级数），**不是**经典意义的自守形式；后者要求 $\Gamma$ 作用在**非平凡对称空间**上。从 $\mathbb{Z}$ 到这样的 $\Gamma$ 需**提升一层**：把平移 $z\mapsto z+1$ 实现为 $SL(2,\mathbb{Z})$ 的幺幂元 $\begin{pmatrix}1&1\\0&1\end{pmatrix}$，再补上 $S:z\mapsto-1/z$ 一类元素才生成整个 $SL(2,\mathbb{Z})$——“**补上 $S$ 的物质根据**”尚待给出。

⇒ **时空途径对上述缺口的收窄**：$SL(2,\mathbb C)$ 的算术子群（Bianchi 群）本身**含**幺幂平移子群，且生成元多于单独的 $\mathbb{Z}$，故“从周期 $\mathbb{Z}$ 提升到 $\Gamma$”这一步在时空途径中有现成的落点——即把 $\mathbb{Z}$ 嵌入 $SL(2,\mathcal O_K)$ 的幺幂子群，而不必另行补上 $S$ 一类的元素。⇒ 两个锚点同步为时空（§7.6 二）不只是物理上的要求，也是**自守化在数学上得以落地**的条件。若只取幺幂子群，得到的不是模形式而是周期函数／傅里叶展开，§7.7.4 的检验力须**相应下调**。而**长度侧的几何途径不受此限**——这正是“长度也能自守化”（§7.6 二）与时间侧缺口可以并存的原因【标准数学】＋【CQM 构造假设】。


> **标注**：【标准数学】（$\pi$ 定理的群论形式、可观察子群、$Sp$ 由辛形式定义、$\mathbb{Z}$ 作用的周期函数 vs 模形式）＋【数值事实】（中子寿命张力、$\tau_\mu$、$c$ 自洽计算值）＋【CQM 构造假设】（起点主张、寿命—长度假设、层级依托结构、检验分层与 $N$ vs $p$ 判据）。

## 八、自然单位制的批判

$$\boxed{
\text{自然单位制是还原论暴政，掩盖了不可还原的关系。}
}$$

自然单位制令：

$$\hbar = 1,\qquad c = 1$$

表面上看，这是“统一”。但实际上，它用**定义**强行抹平了不同物理范畴之间的差异。

它做的事是：

$$\boxed{
\text{把“关系”从公式里赶出去，藏进单位定义。}
}$$

- 光速 $c$ 不是消失了，而是被吸收进“米”和“秒”的定义里；
- 普朗克常数 $\hbar$ 不是消失了，而是被吸收进“焦耳”和“赫兹”的定义里。

所以：

$$\boxed{
\text{自然单位制} = \text{把不可还原的关系，伪装成“1”。}
}$$

它是**单位锚定**，不是**理论锚定**。

### 8.1 学界争论：有量纲常数 vs 无量纲常数

关于“哪些常数才是真正基本的”，物理学界有长期争论。以 Duff、Okun 等人为代表的一派认为：**只有无量纲常数才是真正基本的**，有量纲常数（如 $c, \hbar, G_N$）只是单位制的人为构造，其数值随单位选择而变，不具有客观物理意义。

**CQM 的立场与此有同有异**：
- **同意**：无量纲常数（如 $\alpha, m_e/m_p$）是所有文明都能达成一致的客观量；
- **不同意**：有量纲常数“只是人为构造”——在 CQM 看来，有量纲常数代表的是**量纲之间的实现关系**，这些关系是客观的，只是其量纲表现形式依赖于单位制选择。

换言之，$c$ 的数值是人为的（依赖米和秒的定义），但“长度和时间各自从无量纲直接实现、存在跨量纲特征常数”这件事是客观的。自然单位制令 $c=1$，消灭的是数值，不是实现关系本身——实现关系还在，只是被藏进了“时空是一个四维流形”的几何语言里。
