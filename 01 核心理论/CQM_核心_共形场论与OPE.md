# CQM核心：共形场论与OPE——同步⊗耦合→群的数学基础

## 概述

**CFT描述了临界自组织态扩大的机制，同时也是同步的过程机制。** 自组织态是自组织的离散结果，不是自组织本身——自组织是过程，自组织态是该过程产出的离散结果。这不是类比，是数学上的精确等同。CFT（共形场论）不是一门深奥的玄学，它就是描述"一种态模式从触发点向全局无衰减蔓延"这套物理过程的数学语言。CQM里的"同步"——同一种态模式从局部扩展到全局——**同步是事件，同步有过程**（CFT的幂律传播 $r^{-2h}$ 描述同步的过程），同步方程描述的是整个同步事件（过程被压缩，体现为定态）。

**共形自举（Conformal Bootstrap）本质是共形自洽。** "自举"的意思是：不靠实验输入任何数字，纯粹靠"逻辑上不能自相矛盾"这一条规则，把所有参数强行算出来。具体来说，自举自举的是**结合律（Associativity）**——你可以先配A+B得到C再配C+D，也可以先配B+D得到E再配A+E，**两种配对顺序的结果必须完全一样**。这个"无论怎么配对结果唯一"的约束叫做**自举方程**，它把耦合常数从自由变量压缩为**唯一的离散解**。在CQM中，这就是OPE的相容性条件，也就是Dirac约束的来源。

**"与能量无关"的含义**：拉格朗日量里没有任何带量纲的参数（如质量$m$），且相互作用强度被锁死为确定的纯数字。没有质量尺子 = 没有特征长度 = 关联长度无穷大 = 标度不变 = 共形固定点（$\beta(g)=0$）。

**同步四阶段**：FG纤维丛+同步方程+CFT = 同步预备+同步发生+同步过程+同步完成。**同步预备**（FG纤维丛：各种赝状态——曲率算符 $\hat{\delta}_v$ 给出可能的同步模式，但还未同步）；**同步发生**（同步方程 $\hat{\mathcal{S}}\Psi = n\Psi$：共振量子化——什么样的态可以发生同步、同步成本多少）；**同步过程**（CFT：幂律传播 $r^{-2h}$——同步从触发点向全局扩大）；**同步完成**（状态跃迁——从未同步态跃迁到同步态）。共形自举是**共形自洽条件**（OPE结合律，静态约束）——配对顺序不影响结果，锁死结构常数。

**核心结论**：CQM的三角结构（耦合常数↔同步成本↔紧致群）在共形固定点精确实现为CFT的OPE代数。共形自举方程（结合律）锁死耦合常数为离散值。元素FG的周期表第一性推导（Casimir→壳层容量、共形维度 $h=n+l$→Madelung规则、$A_4$→$Z_{\max}=118$）见 `09 精细引力（FG）/FG_元素FG_第一性.md` §17.9-§17.12。

## 1. 从"与能量无关"到共形固定点

### 1.1 判据

**"与能量无关"的判据**：拉格朗日量里没有任何带量纲的参数，且相互作用强度被锁死为确定的纯数字。

$$\mathcal{L} = \underbrace{(\partial\phi)^2}_{\text{动能}} - \underbrace{V(\phi)}_{\text{势能}}$$

具体来说就是两条：

1. **势能中禁止质量项** $\frac{1}{2}m^2\phi^2$：质量 $m$ 自带固定能标，有 $m$ 就有特征长度 $1/m$，标度不变性立即被破坏。所以 $m=0$。
2. **耦合常数不跑动** $\beta(g)=0$：$\lambda\phi^n$ 中的 $\lambda$ 必须是无量纲纯数字，且量子修正严格为零，$\lambda$ 不随能标流动。

$$\boxed{\beta(g) = \frac{dg}{d\ln\mu} = 0 \;\;\Longleftrightarrow\;\; \text{没有质量尺子} + \text{耦合锁死为纯数字} \;\;\Longleftrightarrow\;\; \text{共形固定点}}$$

没有质量尺子 = 没有特征长度 = 关联长度 $\xi \to \infty$ = 标度不变 = 共形固定点。

### 1.2 共形固定点的物理效应

|:---|:---|:---|:---|

关联长度无穷大 $\Rightarrow$ 系统失去所有特征尺寸 $\Rightarrow$ 普通微扰展开（按 $1/\xi$ 展开）**严格发散**。

**唯一替代工具**：共形场论的OPE——不依赖特征尺寸，直接描述算子乘积的代数结构。

### 1.4 $\phi^4$理论：维度依赖性的具体例子

$\phi^4$理论在不同时空维度下的共形性：

| 时空维度 $d$ | $\phi$ 的标度维度 | $\lambda\phi^4$ 是否允许 | $\beta(\lambda)$ | 是否CFT |
|:---:|:---:|:---:|:---:|:---|

## 3. OPE：同步本征态 ⊗ 耦合本征态 → 群本征态

### 3.2 OPE的核心公式

**同步本征态与耦合本征态配对，映射到群本征态**：

$$\boxed{|\{n_k\}\rangle_{\text{sync}} \otimes |u_k\rangle_{\text{coup}} \xrightarrow{\text{OPE}} \sum_{k'} C_{k}^{k'} |G_{k'}\rangle_{\text{group}}}$$

其中 $C_{k}^{k'}$ 是**OPE结构常数**（共形块），由CFT的中央荷和最高权表示严格确定。

$$\mathcal{O}_i(z) \cdot \mathcal{O}_j(0) \sim \sum_{k} C_{ij}^{k} z^{h_k - h_i - h_j} \mathcal{O}_k(0)$$

CQM对应：
- $\mathcal{O}_i \leftrightarrow |\{n_k\}\rangle_{\text{sync}}$（同步算子，标度维度 $h_i = n_k$）
- $\mathcal{O}_j \leftrightarrow |u_k\rangle_{\text{coup}}$（耦合算子，标度维度 $h_j = \ln g_k / \ln\Lambda$）
- $\mathcal{O}_k \leftrightarrow |G_k\rangle_{\text{group}}$（群算子，标度维度 $h_k = C_k$）

### 3.4 OPE系数的确定

OPE结构常数 $C_{ij}^{k}$ 由以下严格确定：

1. **三点点函数**：$C_{ij}^{k} = \langle \mathcal{O}_k | \mathcal{O}_i \cdot \mathcal{O}_j \rangle$
2. **共形自举**：交叉对称性 $C_{ij}^{k} C_{kl}^{m} = C_{il}^{m} C_{mj}^{k}$（结合律）

## 3.5 共形自举：共形自洽

### 3.5.1 什么是"自举"（Bootstrap）

"自举"源自"提着鞋带把自己拎起来"这个悖论。在物理学中，它特指一种**无参数的、完全自洽的闭合系统**：不靠实验输入任何额外数字（如质量、耦合常数），纯粹靠"逻辑上不能自相矛盾"这一条规则，把所有的数字全部强行算出来。

**共形自举（Conformal Bootstrap）**是现代物理学中大名鼎鼎的术语。如果听到物理学家说"Bootstrap"，99%指的就是它（为区分于上世纪60年代旧的"S矩阵自举"，现在通常加"共形"二字）。

### 3.5.2 自举自举的是"结合律"

自举自举的是**结合律（Associativity）**，也就是OPE的相容性条件。

**具体来说**：四个算子的四点点函数，可以通过两种不同的OPE通道来分解：

$$\langle \mathcal{O}_1 \mathcal{O}_2 \mathcal{O}_3 \mathcal{O}_4 \rangle = \sum_k C_{12}^{k} C_{k34} \,\mathcal{F}_k^{(s)}(z) = \sum_m C_{14}^{m} C_{m23} \,\mathcal{F}_m^{(t)}(z)$$

- **s通道**：先配 $\mathcal{O}_1 \times \mathcal{O}_2 \to \mathcal{O}_k$，再配 $\mathcal{O}_k \times \mathcal{O}_3 \to \mathcal{O}_4$
- **t通道**：先配 $\mathcal{O}_1 \times \mathcal{O}_4 \to \mathcal{O}_m$，再配 $\mathcal{O}_m \times \mathcal{O}_2 \to \mathcal{O}_3$

**自举方程要求：两种配对顺序得到的最终结果必须完全一样。**

$$\boxed{\sum_k C_{12}^{k} C_{k34} \,\mathcal{F}_k^{(s)}(z) = \sum_m C_{14}^{m} C_{m23} \,\mathcal{F}_m^{(t)}(z) \quad \text{（共形自举方程）}}$$

这个方程极其严苛——它把耦合常数 $g_k$ 从"自由变量"强行压缩为**唯一的离散解**。

### 3.5.3 为什么叫"共形"

"配对顺序不影响结果"的约束，只在**共形对称性（尺度+角度不变）**下才成立。如果系统有质量尺子（能隙 $m > 0$），配对的顺序就会受到距离的影响，自举方程就不成立了。所以：

$$\text{共形自举} = \text{共形自洽}$$

### 3.5.4 共形自举 = 共形自洽

共形自举本质上是**共形自洽条件**：OPE的结合律（配对顺序不影响结果）是共形场论内部的自洽性要求，不依赖外部输入。具体来说：

- **自洽性**：四点函数通过两种OPE通道分解（s通道和t通道），结果必须一致——这是代数内部的自洽要求，不是外加约束
- **共形性**：此自洽要求只在共形对称性（尺度+角度不变）下成立；有质量尺子时配对顺序受距离影响，自洽方程失效
- **后果**：自洽方程把耦合常数从自由变量压缩为唯一的离散解

共形自举本身**不是**自组织——它是共形场论的**自洽性条件**，纯粹是数学内部的逻辑要求。但这个自洽条件**背后体现了自组织**：CFT描述了临界自组织态扩大的机制，自举作为CFT的自洽条件，反映的是自组织过程必须满足的内在相容性——配对顺序不影响结果，正是自组织过程无外部指令驱动、自我闭合的代数印记。

### 3.5.5 $A_4$结合律验证：锁定s,p,d,f，禁戒g

$A_4$结合律恰好锁定4种自组织模式（s,p,d,f）并禁戒g（$l=4$）——代数原因（$4\times4$矩阵只有4个本征值）、自举原因（第5通道自举方程无解）、物理原因（g需$A_5$即新核物质相）。详见 `09 精细引力（FG）/FG_元素FG_第一性.md` §17.9。

## 5. Kac-Moody代数与Virasoro代数

### 5.1 从紧致李群到Kac-Moody代数

紧致李代数 $\mathfrak{g}_k$ 的仿射扩展（Kac-Moody代数）：

$$[\hat{J}^a_m, \hat{J}^b_n] = if^{abc}\hat{J}^c_{m+n} + k\,m\,\delta^{ab}\delta_{m+n,0}$$

- $m, n \in \mathbb{Z}$：模（loop）指标
- $k$：水平（由耦合常数 $g_k$ 确定）
- 中央项 $k\,m\,\delta^{ab}\delta_{m+n,0}$：无穷维扩展的核心

### 5.2 Sugawara构造：Virasoro代数

Virasoro生成元通过Sugawara构造从Kac-Moody代数导出：

$$\hat{L}_n = \frac{1}{2(k + h^\vee)} \sum_m :\hat{J}^a_{n-m} \hat{J}^a_m:$$

其中 $h^\vee$ 是对偶Coxeter数。Virasoro代数：

$$[\hat{L}_m, \hat{L}_n] = (m-n)\hat{L}_{m+n} + \frac{c}{12}m(m^2-1)\delta_{m+n,0}$$

中央荷：

$$c = \frac{k\,\dim\mathfrak{g}}{k + h^\vee}$$

### 5.3 CQM中的具体值

对 $A_4$（$\mathfrak{su}(5)$）：
- $\dim\mathfrak{g} = 24$
- $h^\vee = 5$（对偶Coxeter数）
- 水平 $k$ 由耦合常数 $g_k$ 确定

#### 5.4.3 谱量子 $C$ 作为GL(1)层的正则化自由度

谱量子 $C$ 可以表示为：

#### 5.4.4 $C$ 与 $c_{\text{GL}(1)}$ 的关系：Sugawara严格推导

**定理（GL(1)层中央荷严格不变性）**：GL(1)层的Kac-Moody中央荷 $c_{\text{GL}(1)} = 1$ 严格成立，不依赖谱量子 $C$。即 $c_{\text{GL}(1)}^{\text{eff}} = 1 - 12C\eta + O(C^2)$ 中 $\eta = 0$。

**证明**（3步）：

**步骤1：U(1) Sugawara中央荷不依赖水平**

U(1) Kac-Moody代数 $\hat{u}(1)_k$ 的Sugawara中央荷：

$$c = \frac{k \cdot \dim(\mathfrak{u}(1))}{k + h^\vee_{\mathfrak{u}(1)}} = \frac{k \cdot 1}{k + 0} = 1$$

对**任意**水平 $k > 0$，$c = 1$。这是U(1)的特殊性质——$\dim(\mathfrak{u}(1)) = 1$ 且 $h^\vee_{\mathfrak{u}(1)} = 0$ 使得 $k$ 严格约去。

**步骤2：谱量子 $C$ 通过水平修正进入，但被U(1)中央荷的 $k$-无关性吸收**

谱量子 $C$ 通过紧化算符（Hilbert-Pólya算符 $\hat{H}_{\text{HP}} = \hat{\mathcal{S}}^2 + 1/4$，本征值 $\gamma_n^2 + 1/4$）修正GL(1)层的Kac-Moody水平：

$$k_1^{\text{eff}} = k_1(1 + \delta(C) + O(C^2))$$

其中 $\delta(C)$ 是 $C$ 的某个函数。但由步骤1：

$$c_{\text{GL}(1)}^{\text{eff}} = \frac{k_1^{\text{eff}} \cdot 1}{k_1^{\text{eff}} + 0} = 1$$

水平修正被U(1)中央荷的 $k$-无关性**严格吸收**，不论 $\delta(C)$ 的具体形式。

**步骤3：GRH保证共形对称性保持**

## 8. 临界自组织态的扩大：CFT的本质

**CFT描述了临界自组织态扩大的机制，同时也是同步的过程机制。** 这不是类比，是数学上的精确等同。CFT的每一个核心概念——态-算符对应、幂律传播、OPE——都是临界自组织态扩大过程的一个侧面。共形自举则是这套数学结构必须满足的**共形自洽条件**。同步是事件，同步有过程——CFT描述的是同步的过程，同步方程描述的是整个同步事件（过程被压缩，体现为定态）。

### 8.1 再生产与扩大：马克思谱系的再生产

CQM中的"再生产"是**马克思谱系的再生产**——再次生产维持结构的条件（自维持/自激），不是生物学上的复制繁衍。再生产是有限本体维持自身存在的操作（$\mu: S \to S$，$\mu^2 = \mu$，幂等性——维持而非生成，详见 `CQM_核心_集成理论.md` §1.3）。

**再生产与扩大的关系**：再生产是**维持机制**（结构为何能持续存在），扩大是**同步过程**（结构如何从局部扩展到全局）。两者不矛盾——再生产提供维持的条件，CFT描述的扩大是同步的过程机制。

| | 再生产（马克思谱系） | 临界自组织态的扩大 |
|:---|:---|:---|
| **含义** | 再次生产维持结构的条件（自维持） | 同一种态模式从触发点向全局扩展 |
| **本体论角色** | 维持机制：结构为何持续存在 | 同步过程：结构如何从局部到全局 |
| **CFT对应** | 幂等约束 $\mu^2=\mu$（存在论约束） | 两点函数传播 $\langle\phi(r)\phi(0)\rangle = r^{-2h}$ |
| **物理图像** | 质子通过再生产维持自身存在 | 晶体生长、火焰蔓延（态模式扩大） |

**同步的本质**：同步是事件——同一种态模式从触发点向全局无衰减扩展，直到覆盖整个系统。同步有过程——这个过程就是CFT描述的物理过程（幂律传播 $r^{-2h}$）。同步方程描述的是整个同步事件（过程被压缩，体现为定态）——定态不是扩大完成后的末端状态，而是整个同步过程被压缩后的表现形式。再生产维持同步态的存在——同步完成后，再生产确保同步态持续维持。

### 8.2 同步有过程，同步方程描述同步事件

同步四阶段：**预备**（FG纤维丛：曲率算符 $\hat{\delta}_v$ 给出各种赝状态）→ **发生**（同步方程 $\hat{\mathcal{S}}|\psi\rangle = \mathcal{E}|\psi\rangle$：共振量子化，什么样的态可以发生同步、同步成本 $\mathcal{E}$ 是多少）→ **过程**（CFT：幂律传播 $r^{-2h}$，同步从触发点向全局扩大）→ **完成**（状态跃迁：从未同步态跃迁到同步态）。同步的过程需要CFT补充：

$$\text{触发点} \xrightarrow{\text{态-算符对应}} \text{态模式点燃} \xrightarrow{\text{幂律传播}} \text{全局覆盖} \xrightarrow{\text{定态约束}} \text{同步锁定}$$

### 8.3 态-算符对应：插入即生成
