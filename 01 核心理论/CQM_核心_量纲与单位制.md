## 二、量纲基与量纲分析基础

### 2.1 Buckingham π 定理

量纲分析的核心定理是 Buckingham π 定理（Buckingham, 1914）：

> 若一个物理上有意义的方程涉及 $n$ 个物理量，且这些量由 $k$ 个独立量纲构成，则该方程可改写为 $p = n-k$ 个无量纲组合（π 群）之间的关系。

形式化表述：设物理量 $q_1,\dots,q_n$ 满足某物理定律 $\Phi(q_1,\dots,q_n)=0$，其量纲矩阵的秩为 $r$，则存在 $p=n-r$ 个独立的无量纲量 $\pi_1,\dots,\pi_p$，使得定律等价于：

$$\Psi(\pi_1, \pi_2, \dots, \pi_p) = 0$$

**物理意义**：物理定律不依赖于单位制的选择——只有无量纲组合才是“真实的”物理关系，有量纲量只是这些关系在特定单位制下的表达。

## 三、电磁部分：高斯单位制

采用高斯单位制（CGS-esu 与 CGS-emu 的对称合成）。为什么选高斯制而不是 SI、Heaviside–Lorentz 或其他？

**高斯制的核心优点**：
1. **电荷量纲完全导出**：$[q] = M^{1/2}L^{3/2}T^{-1}$，不需要引入第四独立量纲（电流/电荷）
2. **电场与磁场同量纲**：$[E] = [B] = M^{1/2}L^{-1/2}T^{-1}$，相对论协变性更直观——$E$ 和 $B$ 是同一张量的分量，量纲理应相同。
3. **$c$ 显式出现在基本方程中**：实现关系不藏在 $\varepsilon_0$、$\mu_0$ 里，而是直接以光速形式出现，符合“特征常数显式呈现”的原则。
4. **理论物理界的传统选择**：量子力学、量子场论、粒子物理教材普遍采用高斯制或其近亲 Heaviside–Lorentz 制，因为公式更简洁、物理关系更透明。

**为什么不选 Heaviside–Lorentz（有理化高斯制）**：Heaviside–Lorentz 去掉了 $4\pi$ 因子，麦克斯韦方程更对称，但代价是库仑定律和毕奥-萨伐尔定律多出 $4\pi$。在 CQM 框架中，**$4\pi$ 因子有物理意义**（球对称、立体角），不应被有理化“吸收”掉。高斯制保留了 $4\pi$ 在力定律中的原始位置，更有利于追踪几何来源。

电荷是导出量：

$$\boxed{
[q] = M^{1/2} L^{3/2} T^{-1}
}$$

电荷单位：

$$\boxed{\text{esu} = \text{statC}}$$

其他电磁量也全部由 $M,L,T$ 组合：

| 物理量 | 高斯制量纲 |
|---|---|
| 电荷 | $M^{1/2}L^{3/2}T^{-1}$ |
| 电流 | $M^{1/2}L^{3/2}T^{-2}$ |
| 电场 | $M^{1/2}L^{-1/2}T^{-1}$ |
| 磁场 | $M^{1/2}L^{-1/2}T^{-1}$ |
| 电压 | $M^{1/2}L^{1/2}T^{-1}$ |
| 电阻 | $L^{-1}T$ |
| 电容 | $L$ |

### 3.1 esu → esu(SI) → C：$K_Q$ 的推导

**核心原则**：特征常数的功能是提供一个新量纲。电荷量纲 $Q$ 不是预先存在的，而是由**真正的特征常数**从力学量纲中生成。**方向决定角色**：乘在旧单位上、使旧量纲变成新量纲的因子，才是特征常数。

**esu 的量纲**：高斯制库仑定律 $F=q_1q_2/r^2$ 给出 $[\text{esu}]=M^{1/2}L^{3/2}T^{-1}$。CGS 中 $1\ \text{esu}=1\ \mathrm{g}^{1/2}\mathrm{cm}^{3/2}\mathrm{s}^{-1}$。

**esu → esu(SI)**：由 $1\ \mathrm{g}=10^{-3}\ \mathrm{kg}$，$1\ \mathrm{cm}=10^{-2}\ \mathrm{m}$，得 $1\ \text{esu}=10^{-9/2}\ \text{esu(SI)}$，其中 $\text{esu(SI)}:=\mathrm{kg}^{1/2}\mathrm{m}^{3/2}\mathrm{s}^{-1}$。$10^{-9/2}$ 是纯数。

**C 与 esu 的关联**：$1\ \mathrm{C}=10c\ \text{esu}$，故 $1\ \text{esu}=\frac{1}{10c}\ \mathrm{C}$。$10c$ 是关联因子，不是特征常数。

**$K_Q$ 的定义**：CQM 要求 SI，联立得 $1\ \mathrm{C}=\frac{10c}{10^{9/2}}\ \text{esu(SI)}$。定义：

$$\boxed{K_Q=\frac{10c}{10^{9/2}}\approx 9.480\times 10^{4}}$$

$$\boxed{1\ \mathrm{C}=K_Q\ \text{esu(SI)}}$$

量纲：$Q=[K_Q]\cdot M^{1/2}L^{3/2}T^{-1}$，故

$$\boxed{[K_Q]=QM^{-1/2}L^{-3/2}T}$$

$K_Q$ 是电荷层的量纲特征常数（统一公式模式 §6.3：旧×$K$=新），满足 $M^{1/2}L^{3/2}T^{-1}\cdot K_Q=Q$。$10c$ 只是 C → esu 的关联因子，不是特征常数。

## 五、温度、物质的量、发光强度

### 5.1 温度

温度作为独立量纲 $\Theta$，由温度层特征常数 $K_\Theta$ 从能量转换（统一公式模式 §6.3：旧×$K$=新）：

$$\boxed{ML^2T^{-2}\cdot K_\Theta=\Theta}$$

与已有物理常数的关系：$K_\Theta = k_B^{-1}$，其中玻尔兹曼常数

$$k_B = 1.380649\times 10^{-23}\ \text{J/K}$$

量纲（$\Theta$ 为温度量纲符号）：

$$\boxed{
[K_\Theta] = \Theta M^{-1} L^{-2} T^2
}$$

实现关系验证：$ML^2T^{-2}\cdot[K_\Theta]=ML^2T^{-2}\cdot\Theta M^{-1}L^{-2}T^2=\Theta$，实现关系成立。等价地，$E=k_B T$ 中 $k_B=K_\Theta^{-1}$，$[k_B]\cdot\Theta=\Theta^{-1}ML^2T^{-2}\cdot\Theta=ML^2T^{-2}=[E]$。

理论目标：

$$\boxed{
\text{由更深层理论推出 }K_\Theta\text{ 的数值}
}$$

### 5.2 物质的量

物质的量作为独立量纲 $N$，由物质的量层特征常数 $K_N$ 锁定计数基准（统一公式模式 §6.3：旧×$K$=新）：

$$\boxed{1\cdot K_N=N}$$

与已有物理常数的关系：$K_N = N_A^{-1}$，其中阿伏伽德罗常数

$$N_A = 6.02214076\times 10^{23}\ \text{mol}^{-1}$$

量纲（$N$ 为摩尔量纲符号）：

$$\boxed{
[K_N] = N
}$$

实现关系验证：$1\cdot[K_N]=N$，实现关系成立。等价地，$[N_A]\cdot N = N^{-1}\cdot N = 1$（无量纲），即 $N_A\times 1\ \text{mol}=6.02214076\times 10^{23}$ 为纯数。

### 5.3 发光强度

发光强度作为独立量纲 $J$，由发光强度层特征常数 $K_J$ 从功率转换（统一公式模式 §6.3：旧×$K$=新）：

$$\boxed{ML^2T^{-3}\cdot K_J=J}$$

与已有物理常数的关系：$K_J = K_{cd}^{-1}$，其中光度学常数

$$K_{cd} = \frac{1}{683}\ \text{W/cd} \quad(\text{555 nm 明视觉})$$

量纲（$J$ 为坎德拉量纲符号）：

$$\boxed{
[K_J] = J M^{-1} L^{-2} T^3
}$$

实现关系验证：$ML^2T^{-3}\cdot[K_J]=ML^2T^{-3}\cdot JM^{-1}L^{-2}T^3=J$，实现关系成立。等价地，$[K_{cd}]\cdot J = J^{-1}ML^2T^{-3}\cdot J = ML^2T^{-3} = [\text{W}]$，与 $1\ \text{cd}=\frac{1}{683}\ \text{W}$ 一致。

## 六、特征常数与量纲压缩（量纲发生学层级）

> **术语**：本文用"**（属性实现的）量纲特征常数**"，记号 $K_X$ 不变（$K_L,K_M,K_Q,K_\Theta,K_N,K_J$）。
> 它不是"量纲之间的转换器"，而是"**属性 $P$ 被实现为某个量纲（某种实现）时的特征常数**"——
> $\text{属性 }P\xrightarrow{\ \text{特征常数}\ K_{P\to\mathcal R}\ }\text{量纲（或实现）}\ \mathcal R$。
> 数值与量纲不因术语而变（$c$ 是 $[L]/[T]$；$K_M=G_N^{-1}$ 即 $[K_M]=ML^{-3}T^{2}$）。
> 同名关系在 §7.2、§8.1 称"**实现关系**"；"转换因子"一律并入"特征常数"。
> 跨量纲支与同量纲内支同构：见 §6.2.1（大差异）、§6.2.2（同量纲内差异）与 §6.4（四）。


核心观察：

$$\boxed{
\text{每压掉一个量纲，就会冒出一个特征常数。}
}$$

这不是简单的“替换”，而是量纲发生学中的**层级生成**：从原初层出发，通过特征常数的锁定，逐层生成我们在物理世界中观察到的量纲结构。

### 6.2 大差异与同量纲内差异：量纲发生学的双重结构

量纲发生学中存在两种根本不同的差异类型，它们由自守形式的不同差异层级锁定：

#### 6.2.1 大差异：不同量纲之间

$$\boxed{
\text{大差异：不同量纲之间，由自守形式的大差异锁定，产生量纲特征常数}\text{（＝属性 }P\text{ 被实现为该量纲时的特征常数）。}
}$$

这是量纲发生学的核心机制：不同量纲之间存在**大差异**，这种差异需要特征常数来“桥接”。例如：
- 温度 $\Theta$ 与能量 $ML^2T^{-2}$ 之间：由 $K_\Theta$ 桥接（大差异）

大差异产生量纲特征常数，这些常数正是量纲发生学的“生成节点”（§6.0）。

#### 6.2.2 同量纲内差异：同一量纲内部细分

$$\boxed{
\text{同量纲内差异：同一量纲内部，由自守形式的小差异锁定，不产生新的跨量纲特征常数——}\\\text{同量纲内差异表现为实现之间的无量纲标度，与不可简单组合的结构性差异。}
}$$

**定义**：量纲内差异是同一量纲内部不可简单组合、不可简单归约的结构性差异。它不是“同一量纲内的不同数值”，而是同一量纲内部有各自独立谱来源、各自锁定方式的不同层面。

**判定标准——不能简单组合**：
- 不是加法：$m \neq m_{\text{惯性}} + m_{\text{引力}} + m_{\text{静}}$
- 不是函数关系：$q \neq f(q_{\text{裸}}, q_{\text{有效}})$
- 而是：各差异类型分属不同表示类别、不同边界条件、不同自守形式参数

|                 | 宏观摩尔量     | $N_A$ 是计数基准而非**同量纲内**物理特征常数（其跨量纲转换角色见 §5.2、§6.1）；二者之间不存在连续变形关系 |
| **发光强度** $J$    | 辐射强度      | 纯物理量，不依赖观察者                                                    |
|                 | 发光强度      | 视见函数依赖人类视觉系统的生理响应，不是物理常数                                       |

**注意**：上表为粗略分类，不严格，甚至可能有误。表中分类仅作示意，关键在于各差异类型背后的具体物理关系——不同表示类别、不同边界条件、不同自守形式参数，而非表中的分类本身。

**关键区分**：坐标时 $T$ 是量纲发生学中的基本时间量纲，长度由 $K_L$ 从无量纲耦合坐标直接生成（大差异），不经过时间。$c$ 是时空同步前沿速度，不承担量纲转换，但定义局部时空结构。固有时 $\tau$ 是观测者自身经历的时间，涉及引力红移和时空弯曲，属于同量纲内差异，由曲率/自守形式的小差异锁定，不产生新的量纲特征常数。

#### 6.2.3 自守形式差异层级

自守形式的差异层级决定了量纲转换的性质：

| 差异类型 | 作用范围 | 表现 | 是否产生量纲特征常数 |
|---|---|---|---|
| **大差异** | 不同量纲之间 | 量纲分化与锁定 | 是（$K_L$、$K_M$、$K_Q$、$K_\Theta$、$K_N$、$K_J$） |
| **同量纲内差异** | 同一量纲内部 | 各量纲内部细分（详见 §6.2.2） | 否（由曲率/度规锁定） |

自守形式承担**关系本身的锁定**：不同量纲之间是**大差异**，由自守形式之间的分化锁定（§6.2.7）；同一量纲内部细分是**同量纲内差异**，由同一量纲自守形式的变形分化锁定（§6.2.7）。

#### 6.2.5 核心结论

$$\boxed{
\text{"不能简单组合"是判定量纲内差异的核心标准。}
}$$

各量纲内部差异之所以不可简单组合，根源在于它们**不是同一个谱点的不同数值，而是不同表示类别、不同边界条件、不同自守形式参数在物理层的投影**——即同一量纲自守形式的变形分化。

每一个量纲都是一个有内部结构的谱，而非一个标量点。

#### 6.2.6 转换与关联：核心区分

量纲发生学中的所有关系可分为两类：**转换**（量纲之间的关系，即大差异，由特征常数锁定）与**关联**（量纲内的关系，即同量纲内差异）。

| | 转换 | 关联 |
|---|---|---|
| **作用范围** | 量纲之间 | 量纲内（同一量纲内部） |
| **锁定方式** | 特征常数 | 曲率 / 自守形式谱条件 |
| **是否普遍** | 不确定 | 依赖具体谱点、曲率、观测者 |
| **典型例子** | $L^3T^{-2}\cdot K_M=M$，$ML^2T^{-2}\cdot K_\Theta=\Theta$，$M^{1/2}L^{3/2}T^{-1}\cdot K_Q=Q$ | 坐标时↔固有时，惯性质量↔引力质量，裸电荷↔有效电荷 |

$$\boxed{
\text{转换是关联的特例；关联是更普遍的结构。}
}$$

**特征常数的性质——量纲转换特征常数**：每个量纲转换有一个**量纲转换特征常数**（如长度层的 $K_L$、质量层的 $K_M$、电荷层的 $K_Q$）。“特征”体现在考虑的是直接的量纲-量纲转换，而非具体场景。具体情况下的量纲特征常数可能与之不同，但可能和量纲转换特征常数有关：

1. **量纲转换特征常数是量纲实现关系上的标准常数**（大差异的锁定），不是“通用”那种含糊的“到处可用”；
2. **具体情况下可能不同**——量纲内差异下的特征常数可能不是量纲转换特征常数（如质量层的量纲转换特征常数是 $K_M$，但在具体的质量情况下，可能不是 $K_M$ 而是别的）；
3. **但可能和量纲转换特征常数有关**——具体情况下的量纲特征常数与量纲转换特征常数之间可能存在关联，这种关联是量纲内差异的体现；
4. **是否有普适性不确定**——量纲转换特征常数是否具有普适性（即是否在更广泛的意义上适用），目前不确定。

**质量层的特殊情况**：质量层**同时有转换和关联**——$K_M$（质量层特征常数，$[K_M]=ML^{-3}T^2$，$K_M=G_N^{-1}$）是真正的量纲特征常数（$L^3T^{-2}\cdot K_M=M$）。

**角色区分（避免循环）**：本节的量纲发生学只确定**哪一个常数承担转换角色**（质量层为 $K_M$），不涉及该常数的**数值从何而来**；$K_M$（$=G_N^{-1}$）的数值是否可由谱不变量算出，是 `03 引力与退相干/CQM_引力_GN可能公式.md` 的议题。二者层次不同，不构成“$K_M$ 既是输入又是输出”的角色冲突：量纲层用 $K_M$ 作为时空–质量的锁定关系，数值层才追问 $K_M$ 本身的来源。


#### 6.2.7 自守形式—量纲—分化

**核心对应**：一个自守形式 ↔ 一个量纲。自守形式的分化分两个层次：

- **自守形式之间的分化**（跨量纲）：不同量纲对应不同自守形式，其分化对应量纲之间的转换（生成新量纲，锁定为特征常数），即大差异；
- **同一自守形式内部的变形分化**（量纲内）：同一量纲自守形式在不同谱参数下的变形分化，对应量纲内差异，不产生新量纲、不产生新的量纲特征常数。

$$\boxed{
\text{自守形式是量纲的数学载体；}\\
\text{其分化（自守形式之间）生成新量纲（特征常数）；}\\
\text{其变形分化（同一自守形式内部）对应量纲内差异。}
}$$

此对应属 CQM 框架内的结构性类比，尚待第一性推导与严格化。


### 6.3 各特征常数的角色

每个量纲特征常数统一遵循 **旧量纲 × 特征常数 = 新量纲**（“旧”“新”指量纲发生学先后）：

$$\boxed{[\text{旧}]\cdot K = [\text{新}]}$$

- **$K_L$**：禁闭映射常数，$[K_L]=L$，$r_{\text{coupling}}\cdot K_L=r_{\text{phys}}$（无量纲 × $K_L$ = 长度）。$r_{\text{coupling}}$ 与固有时 $\tau$ 共轭（$[\hat{u},\hat{p}_u]=i$，$u=\ln r_{\text{coupling}}$，$p_u=v_\tau/☯$，固有时流速 $v_\tau=d\tau/dt$ 见 `CQM_核心_因果网络同步理论.md` §6.3.6）。长度层特征常数，不要求普适。$K_L$ 值有待确定（第一性链给 $K_L=0.656$ fm，标定链 $0.67860$ fm，几何值 $0.6805$ fm，值链间差 3.3%，$g_s^{IR}$ 张力 3.73%，见 §6.3.1 及 `04 前沿研究/CQM_前沿研究_待推1边界条件深度分析.md` §6.5）。
- **$c$**：时空同步前沿速度（信息传播前沿速率），$[c]=L/T$，不承担量纲转换。$L=c\,T$ 是物理速度关系（速度=距离/时间），非量纲实现关系。$c$ 同时定义局部时空结构。
- **$K_M$**：质量层特征常数，$[K_M]=ML^{-3}T^2$，$L^3T^{-2}\cdot K_M=M$（时空量 × $K_M$ = 质量）。由万有引力定律锁定。
- **$c^2$**：质能特征常数，$[c^2]=L^2T^{-2}$，由 $E=mc^2$ 锁定。但 $[c^2]$ 不含 $M$，不消除质量量纲，故 $c^2$ 不是量纲特征常数。
- **$K_Q$**：电荷层特征常数，$[K_Q]=QM^{-1/2}L^{-3/2}T$，$M^{1/2}L^{3/2}T^{-1}\cdot K_Q=Q$（力学量纲 × $K_Q$ = 电荷）。
- **$K_\Theta$**：温度层特征常数，$[K_\Theta]=\Theta M^{-1}L^{-2}T^2$，$ML^2T^{-2}\cdot K_\Theta=\Theta$（能量 × $K_\Theta$ = 温度）。
- **$K_N$**：物质的量层特征常数，$[K_N]=N$，$1\cdot K_N=N$（无量纲计数 × $K_N$ = 物质的量）。
- **$K_J$**：发光强度层特征常数，$[K_J]=JM^{-1}L^{-2}T^3$，$ML^2T^{-3}\cdot K_J=J$（功率 × $K_J$ = 发光强度）。

**与已有物理常数的对比**：

| 特征常数 | 已有物理常数 | 关系 | 已有常数数值 |
|---|---|---|---|
| $K_L$ | — | 禁闭映射常数 | $0.656$/$0.67860$/$0.6805$ fm |
| $K_M$ | $G_N$ | $K_M = G_N^{-1}$ | $G_N \approx 6.674\times10^{-11}\ \mathrm{m^3\,kg^{-1}\,s^{-2}}$ |
| $K_Q$ | — | 电荷层特征常数 | $K_Q \approx 9.480\times10^{4}$ |
| $K_\Theta$ | $k_B$ | $K_\Theta = k_B^{-1}$ | $k_B \approx 1.381\times10^{-23}\ \mathrm{J\,K^{-1}}$ |
| $K_N$ | $N_A$ | $K_N = N_A^{-1}$ | $N_A \approx 6.022\times10^{23}\ \mathrm{mol^{-1}}$ |
| $K_J$ | $K_{cd}$ | $K_J = K_{cd}^{-1}$ | $K_{cd} = 1/683\ \mathrm{W/cd}$ |

#### 6.3.1 $K_L$ 的谱结构与数值状态

**前置量**：

| 量 | 公式 | 数值 | 含义 |
|---|---|---|---|
| $r_{\text{conf}}$ | $\sqrt{I\lambda_c}$ | $1.481$ | 无量纲耦合空间禁闭壳 |
| $r_{\text{GUT}}$ | $\sqrt{4\pi\,☯\,\lambda_c}$ | $0.6180$ | GUT 标度（无量纲） |
| $g_s^{IR}$ | $\sqrt{I\cdot\lambda_c}$ | $1.481$ | 红外强耦合冻结值（归档定理 10.4，见 `04 前沿研究/CQM_前沿研究_待推1边界条件深度分析.md` §6.5，相变点 $\lambda_c=(g_s^{IR})^2/I$） |
| $\Lambda_{\text{QCD}}$ | $m_p c^2/(☯\cdot\mathfrak{c}_1)$ | $203$ MeV | QCD 能标先验公式（归档定理 10.2） |
| $\lambda_{\text{QCD}}$ | $\hbar c/\Lambda_{\text{QCD}}$ | $0.9716$ fm（第一性）/$1.005$ fm（标定） | QCD 特征长度 |

其中 $\mathfrak{c}_1=\gamma_1^2+\tfrac14\approx 200.04$ 是第一耦级（黎曼谱第一本征值）。

**谱参数公式**（归档 D1 回捞）：

$$K_L = \frac{\lambda_{\text{QCD}}}{r_{\text{conf}}} = \frac{\hbar c \cdot ☯ \cdot \mathfrak{c}_1}{m_p c^2 \cdot g_s^{IR}}$$

$K_L$ 把无量纲禁闭壳转换为 QCD 特征长度：$r_{\text{conf}}\cdot K_L=\lambda_{\text{QCD}}$（无量纲 $\times\,K_L$ = 长度）。

**几何确定方式**（归档 §6.1）：

$$K_L = \frac{\sqrt{\lambda_p \cdot r_p}}{r_{\text{GUT}}} = \frac{\sqrt{0.2103 \times 0.8409}}{0.6180} \approx 0.6805 \text{ fm}$$

其中 $\lambda_p=\hbar/(m_p c)=\hbar c/(m_p c^2)=0.2103$ fm 为质子康普顿波长，$r_p=0.8409$ fm 为质子电荷半径。$K_L$ 是质子内外尺度几何平均与 GUT 标度之比。

**量纲地位（禁闭映射常数）**：

$K_L$ 是**禁闭映射常数**：量纲为长度（fm）的特征常数，把无量纲耦合壳 $r_{\text{coupling}}$ 映为物理长度 $r_{\text{phys}}=r_{\text{coupling}}\cdot K_L$。它与 $K_M=G_N^{-1}$、$K_Q$ 同属层间特征常数，是「旧量纲 × 特征常数 = 新量纲」模式（§6.3）在长度层的实例。

> **不是交织算子**：$K_L$ 是换算比值，不是两套 Hilbert 空间之间的算符。交织算子的严格定义要求先指定群 $G$ 与两侧表示；本框架中不存在这样的群作用，故 $K_L$ 不具备交织算子的数学身份；又算子范数在两侧同归一化时是纯数，与 $K_L$ 的长度量纲（fm）冲突；且 $\{\gamma_n\}$ 不是任何一维自伴算符的严格点谱（Weyl 律否证），以 $\gamma_n$ 为谱的 $\mathcal H_{\text{Riemann}}$ 不存在。详见 `04 前沿研究/CQM_前沿研究_待推1边界条件深度分析.md` §6.5.1。【框架内构造（比值定义）】

**自对偶结构（D4–D7）**：

经 $K_L$ 映射后，质子康普顿波长 $\lambda_p$、GUT 标度 $r_{\text{GUT}}$、质子电荷半径 $r_p$ 在耦合空间中形成 $\tfrac{1}{2}:1:2$ 几何级数：

| D4 | $\lambda_p/K_L = 0.3100 \approx r_{\text{GUT}}/2 = 0.3090$ | $0.32\%$ |
| D5 | $r_p/K_L = 1.2394 \approx 2\,r_{\text{GUT}} = 1.2360$ | $0.27\%$ |

GUT 壳层是质子内部尺度（$\lambda_p$）与外部尺度（$r_p$）的几何平均——自对偶中心。上述偏差依赖 $K_L=0.67860$（标定链谱参数公式）；几何公式给 $K_L=0.6805$（差 ~0.3%），改用第一性 $K_L=0.656$ 则偏差全部升至 ~$3.74\%$。

### 6.4 量纲作为属性实现：独立属性、特征常数与差异分类

本节把量纲发生学的三条线索系统化：**属性→量纲的实现**、**独立属性的判定**、**差异的分类学**；并给出与群论的对接（群侧完整讨论见 `01 核心理论/CQM_核心_群约束性与对称群谱系.md` 第 5、6 章）。

**（一）量纲＝属性的量度类别；常数＝该次实现的特征常数**

量纲不是"转换"来的，而是**属性被实现的结果**：

$$\text{属性 }P\ \xrightarrow[\ \text{特征常数}\ K_{P\to\mathcal{R}}\ ]{\ \text{被实现为}\ }\ \text{量纲（或实现）}\ \mathcal{R}$$

其中"**属性**"≈ 物理上的**自由度**（degree of freedom）——指系统在描述中**可独立取值、并承受变换作用的那些方面**（空间广延、相位、质量……）。

**（二）三个层次：量纲／具体值（表面）／属性量的值（内蕴）**

| 层次 | 内容 | 性质 |
|:---|:---|:---|
| ① | 属性被实现为**量纲** | 量纲＝该属性的**量度类别**；$K$＝该次实现的特征常数 |
| ② | 各形式（实现）各带**具体值**（数值 $\times$ 量纲） | **表面层**——**表面值不一定一样**；"原形式 → 新形式"由自守因子联系 $f(\gamma x)=j(\gamma,x)f(x)$（$j\not\equiv1$ 时二者不等） |
| ③ | **属性量的值** | **内蕴层**——该量的值在实现过程中具有**内在不变性**，区别于表面不变性 |

**（三）七大 SI 基本量纲均为独立属性**

| 档 | 成员 | 判定依据 |
|:---|:---|:---|
| **独立属性**（七大 SI 基本量纲） | 时间 $[T]$、长度 $[L]$、质量 $[M]$（**惯性实现**）、电流／电荷 $[Q]$、温度 $\Theta$、物质的量 $N$、发光强度 $J$ | 各有独立的本体论来源；质量须限定为**惯性实现**（见 §6.2.2 的四种实现） |

- **"与别的基本量纲有联系"应解释为**：**该属性在别的属性约束下被实现**（如高斯制下 $[Q]=[M]^{1/2}[L]^{3/2}[T]^{-1}$、$\Theta$ 由能量经 $K_{\Theta}$ 引出）——不是"可还原"；
- 独立性**挂在"属性"上**，不挂在"量纲符号"上；**本体论独立 $\ne$ 单位制独立**（量纲可压缩，代价是生成特征常数）；
- **温度**是统计量，且**没有对应的基本对称群**——是与群对应时的唯一例外。

**（四）特征常数的两支**

- **跨量纲支**（＝本节的**大差异**）：$[K]=[Q']/[Q]$，量纲上跨量纲；如 $c:[L]/[T]$、$\hbar:ML^{2}T^{-1}$、$K_M=G_N^{-1}:[M][L]^{-3}[T]^{2}$、$K_Q$、$K_\Theta$；
- **同量纲内支**（＝**同量纲内差异**）：同一量纲内部的标度，量纲上为 $1$。须再分三类：
  1. **约定性单位换算**（$1\ \mathrm{m}=100\ \mathrm{cm}$、SI 词头）——**非物理常数**；
  2. **物理性标度**（$\ell_P/\mathrm{m}$、$\lambda_C=\hbar/(mc)$、$a_0=4\pi\varepsilon_0\hbar^{2}/(m_ee^{2})$）——**这才是特征常数**；
  3. **结构性差异**（惯性／引力／有效质量，裸／有效电荷）——各有独立谱来源，**不可用单一常数桥接**（§6.2.2）。

**（五）量纲间差异＝属性类型；量纲内差异＝实现群**

| 层级 | 差异所在 | 差异的内容 |
|:---|:---|:---|
| **量纲间差异** | 不同量纲之间 | **属性类型的差异**（不同自由度 ⇒ 不同量纲） |
| **量纲内差异** | 同一量纲之内 | **实现群的差异**，分两级：**大内差异**＝**关系群的选取**；**小内差异**＝**离散群的选取** |

- **大内差异改结构**：改的是"哪个群保这个量"（同一属性量在不同实现空间给出不同关系群；例："保距离"在欧氏平面 → $O(2)$、三维欧氏 → $O(3)$、双曲平面 → $PSL(2,\mathbb{R})$、闵氏时空 → $O(1,3)$、弯曲流形 → $\mathrm{Isom}(M,g)$）；

### 7.1 自守形式作为数值来源

$$\boxed{

\end{aligned}}$$

### 7.2 自守形式作为量纲实现本身

更进一步：

$$\boxed{
\text{自守形式不只是数值来源；}\\
\text{它可能就是量纲与量纲之间的实现关系本身。}
}$$

即：

$$\boxed{
\text{自守形式} \equiv \text{量纲-量纲的实现关系}
}$$

### 7.3 最原始的自守形式

最终命题：

$$\boxed{
\text{最原始的自守形式，就是"无量纲} \longrightarrow \text{时间"的实现。}
}$$

也就是说：

- 数学侧：自守形式，无量纲，纯数；
- 物理侧：时间量纲 $T$，单位，可测量；
- 桥：自守形式本身；
- 自守形式是“纯数”与“时间”之间的实现机制，是最原始的量纲生成器。

**注**：无量纲→时间的特征常数未知，可能没有。但无量纲与固有时关系紧密：固有时本质上与事件计数紧密关联——事件计数是无量纲的纯数，固有时是事件计数在物理侧的体现。因此，无量纲→时间的转换并非任意，而是通过固有时/事件计数自然实现：事件计数的纯数（无量纲）经固有时获得时间量纲 $T$。时间 $T$ 是量纲发生学的第一个量纲，这正是 CQM 一直指出的时间动力学（因果时、固有时）。

### 7.4 自守形式输出的量纲性质

自守形式输出的量纲性质取决于输入的量纲性质与具体分析语境，不能一概而论。

**输入决定输出**：当自守形式的输入参数为纯数（无量纲）时，输出为纯数；当输入参数带有物理量纲（如曲率 $R$ 量纲 $L^{-2}$、能量 $E$ 量纲 $ML^2T^{-2}$）时，输出自然带有相应量纲。自守形式作为映射，其输出量纲由输入量纲与映射结构共同决定。

**情形一：无量纲输入 → 纯数输出，直接作为无量纲常数。** 如精细结构常数 $\alpha \approx 1/137$，自守形式以无量纲参数为输入，给出的纯数本身就是物理常数。

**情形二：无量纲输入 → 纯数输出，作为有量纲特征常数的数值部分。** 如 $10c = 2.99792458\times 10^9$、$K_Q = 10c/10^{9/2} \approx 9.480\times 10^{4}$。自守形式给出的纯数本身无量纲，但扮演有量纲特征常数的数值角色，需配合单位制翻译得到带量纲的物理量。

**情形三：有量纲输入 → 有量纲输出。** 当自守形式的输入参数带有物理量纲时，输出直接带有量纲，无需单位制翻译。自守形式作为“量纲-量纲的实现关系本身”（§7.2），输入端量纲与输出端量纲可以不同，自守形式本身就是带量纲的转换映射。

**情形四：作为量纲结构参数。** 如表示维数 $70 = \dim \mathrm{Sym}^4(\mathrm{SU}(5))$，纯数但承载量纲发生学的结构信息，不直接对应某个物理常数。

**总结**：自守形式输出的数值是否无量纲，取决于输入是否带量纲以及具体分析语境。输入无量纲时输出为纯数（可作为无量纲常数或有量纲特征常数的数值部分）；输入有量纲时输出直接有量纲。不应笼统断言“自守形式只能给出纯数”而掩盖这些区别。

## 八、自然单位制的批判

$$\boxed{
\text{自然单位制是还原论暴政，掩盖了不可还原的关系。}
}$$

自然单位制令：

$$\hbar = 1,\qquad c = 1$$

表面上看，这是“统一”。但实际上，它用**定义**强行抹平了不同物理范畴之间的差异。

它做的事是：

$$\boxed{
\text{把"关系"从公式里赶出去，藏进单位定义。}
}$$

- 光速 $c$ 不是消失了，而是被吸收进“米”和“秒”的定义里；
- 普朗克常数 $\hbar$ 不是消失了，而是被吸收进“焦耳”和“赫兹”的定义里。

所以：

$$\boxed{
\text{自然单位制} = \text{把不可还原的关系，伪装成"1"。}
}$$

它是**单位锚定**，不是**理论锚定**。

### 8.1 学界争论：有量纲常数 vs 无量纲常数

关于“哪些常数才是真正基本的”，物理学界有长期争论。以 Duff、Okun 等人为代表的一派认为：**只有无量纲常数才是真正基本的**，有量纲常数（如 $c, \hbar, G_N$）只是单位制的人为构造，其数值随单位选择而变，不具有客观物理意义。

**CQM 的立场与此有同有异**：
- **同意**：无量纲常数（如 $\alpha, m_e/m_p$）是所有文明都能达成一致的客观量；
- **不同意**：有量纲常数“只是人为构造”——在 CQM 看来，有量纲常数代表的是**量纲之间的实现关系**，这些关系是客观的，只是其量纲表现形式依赖于单位制选择。

换言之，$c$ 的数值是人为的（依赖米和秒的定义），但“长度和时间各自从无量纲直接实现、存在量纲转换特征常数”这件事是客观的。自然单位制令 $c=1$，消灭的是数值，不是实现关系本身——实现关系还在，只是被藏进了“时空是一个四维流形”的几何语言里。

### 8.2 四种单位制层次对比

| 单位制 | 独立量纲数 | 常数处理 | 基础性 |
|---|---|---|---|
| 自然单位制 | 少 | 令为 1 | 最不基础（纯工具） |
| 高斯单位制 | 3 | $c$ 显式出现 | 较基础 |
