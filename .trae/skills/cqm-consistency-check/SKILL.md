# 组织层一致性

## 何时加载

- 对理论内容（概念 / 命题 / 论证）有增改；
- 改动 `08 理论组织和形式化框架/` 任一产物。

## 必做

1. 按 `08 理论组织和形式化框架/AGENTS.md` 的**七维度闭环**同步。
   - 核心维度：结构化（`00`–`03`）、ML 数据准备（`05`）、形式化验证（`04`）、展示可视化（`10`）。
   - 辅助维度：动态机制（`06`）、经验检验（`07`）、元理论反思（`08`）。
   - 支撑层：概念本体（`02`）、桥接与翻译（`09`）、元数据（`11`）。
   - 原则：源 CSV 是"因"，其余是"果"；新事实先落源 CSV，再重跑脚本派生，不得手工改派生文件。
2. 运行一致性检查，未通过即视为未完成：

```bash
python "08 理论组织和形式化框架/_build/check_consistency.py"
```

该检查跨产物核对计数、引用完整性与 `⇒` / `→` 约定。

## 复现性

按 `一体化研究/科研AI全栈方案.md` §8.3 清单逐项核对。
