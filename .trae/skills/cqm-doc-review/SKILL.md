# CQM 文档修改规则

## 何时加载

- 修改 `01–07` 活动文档、`归档/` 文档、`README.md`、`一体化研究/附录/` 任一文件时。

## 规则

1. **权威源**：`README.md` 符号约定与数值表 > 各概念权威定义处 > 文件首现定义 > 全库词频多数写法。
2. **禁用词**：`已删除`、`已澄清`、`已修正`、`已解决`、`旧版`、`已废弃`、`现已统一`、`早期形式`、`本版` 等过程性表述。
3. **必须保留**：`缺口`、`未解决`、`待推`、`构造后验数字校验`、`待第三方复现` 及全部缺口编号（C/G2–G8、G9–G22、N1–N4）。
4. **最小改动**：以词、短语、单句、单元格、公式为单位替换；不得重写整段、不得"顺手润色"。
5. **禁止新增**：不得引入原理论未涉及的观点、术语、数值、文献、编号。
6. **数值不改**：除非与权威定义处矛盾（此时改为权威值并注明依据）。
7. **$G_N$ 限定语**：凡出现 $G_N$ 数值或偏差之处，必须带"构造后验数字校验，待独立复现"。

## 提交前审校清单

- [ ] 禁用词扫描（负向引用除外）
- [ ] 术语变体一致
- [ ] `$` 成对
- [ ] 相对链接有效
- [ ] `⇒` / `→` 未误用
- [ ] 缺口标注完整、状态未被升级
