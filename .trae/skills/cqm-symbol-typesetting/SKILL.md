# 排版与符号规范

## 何时加载

- 写入或修改含公式、表格、符号的 Markdown / 文档时。

## 规则

- 标点：中文语境全角；数学环境 ASCII。
- 空格：中英文、中文与数字、中文与数学环境之间加半角空格。
- 公式：行间 `$$...$$` 独占一行；行内 `$...$`；`$` 成对。
- 表格：紧凑格式 `|:---|:---|`；单元格内 `|` 转义为 `\|`。
- 符号：`⇒` 仅表重组实现；一般演化/极限/映射用 `→`。
- 太极符号 ☯ 作为数学量须用 LaTeX `$...$` 包裹。
