## 一句话定位

CQM 是建立在**因果集**、**关系量子力学**与**圈量子引力**三大理论之上的耦合常数量子力学。它不量子化时空，而量子化**耦合常数本身**——时空与标准模型都是耦合常数量子力学在禁闭边界退相干后的涌现。**以 $m_p$（质子质量）作为唯一量纲锚点**，其余无量纲参数由一组组合-谱不变量给出。状态说明：系统内部的数值自洽与"偏差 ppm"属于**构造后验数字校验**，该框架以纯数学"推导"物理常数目前仍属构造性/待第三方复现的主张，未被主流学界当作公认的独立第一性推导（α、$G_N$ 在标准物理中仍是实验参数或基本输入，见各文档的状态标注与 `05 方法论与批判/`）。
